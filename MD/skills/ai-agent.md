System Message와 Tool 설명에는 사용 조건 · 필수 정보 · 없는 정보 처리 · 완료 기준을 담되, **초보자가 읽고 이해할 수 있는 길이(5~8줄 안팎)**로 쓴다. 정상 입력 외에 누락 · 대상 없음 · 중복을 확인하되 장애를 일부러 만들지 않는다. 정답은 시험 시점의 시트와 대조한다(등록 실습 뒤에는 처음 명단을 고정 정답으로 쓰지 않음). **지침만으로 중복 차단 · 입력 검증이 보장되지 않으므로, 이런 동작을 성공 기준으로 삼지 않고 "AI가 지침을 어기면 시트에서 직접 지운다" 같은 대처를 함께 쓴다.** Memory 실습도 조회 Tool을 포함하고, 같은 세션의 맥락 유지와 새 세션 분리를 함께 확인한다.
