## 2. 실습 SET 구성 (2026-11-19 DAY 02에서 확정 · 다른 날에도 같은 리듬)

- **실습 SET은 STEP으로 나눈다.** 기본 리듬은 **STEP 01 고르기 · 만들기 → STEP 02 나란히 놓고 확인 → STEP 03 고치기 · 맞추기 · 비교하기**. 모양은 3일차와 같다: STEP 01은 `h3.text-lg.mt-10.mb-4.font-bold`, STEP 02부터는 공통 4절의 점선 소제목. 제목 옆 `span.text-sm.font-medium.text-slate-500`에 "— 같은 채팅에서 이어서" / "— 새 채팅에서"처럼 어느 채팅인지 적는다.
- 그림으로 보여 주는 안(한 장 → 세 갈래 SVG)과 비교했을 때 사용자가 STEP 쪽을 골랐다. SET마다 생김새가 같아야 덜 헷갈린다.
- 같은 작성 틀로 여러 번 보내는 실습은 **"어느 칸만 바꿔서 몇 번 보내는지"**를 STEP 안내에 적고, 바꿀 조합은 체크 목록 상자로 보여 준다. 상자 제목은 "지금부터 차례로 만들어 보기", "이 세 가지로 바꿔 보기"처럼 문장으로.
- 확인하기는 **고치기보다 먼저** 둔다(확인 → 문제가 있으면 → 고치는 요청).
- 여러 장을 한 세트로 쓰는 실습은 "AI는 한 장씩 따로 만든다 → 통일할 것을 따로 말해 준다"로 마무리한다.

## 3. 이미지 프롬프트 작성 틀

- **기본 사진**: SET 01에서 새 채팅으로 만든 첫 사진. 이후 같은 채팅에서 이어서 바꾼다. 페이지 설명에는 "기본 사진", "SET 02에서 만든"을 써도 되지만, **작성 틀 안에는 쓰지 않는다**(AI는 모름). 작성 틀에서는 "맨 처음 만든 사진 속 텀블러는", "앞에서 만든 [고른 사진의 구도] 사진의"처럼 AI가 채팅에서 볼 수 있는 말로 가리킨다. 우리가 붙인 번호(①~⑥)도 AI는 모르니 구도로 가리키게 안내한다.
- 칸 이름은 DAY 01의 6칸(**무엇을 · 어디서 · 어떻게 · 빛·색 · 느낌 · 용도**)을 다시 쓴다.
- **접힌 예시는 다른 대상으로 쓴다.** 학생이 텀블러를 만들면 예시는 핸드크림, 아이콘 주제는 고르는 목록에 없는 주제(반려견 산책). 요약 줄에 "다른 제품(핸드크림)으로 쓴 예"라고 밝히고, 첫 예시 아래에 "그대로 복사하지 말고 내 제품으로 바꿔 쓰세요"를 둔다.
- [ ] 칸에는 정답 같은 "예: ○○"를 넣지 않고 칸 이름 + 짧은 안내만 둔다. 제품 색 · 재질은 학생이 정한다(모두 같은 민트색으로 고정하지 않음).
- **비율을 꼭 넣는다.** 이어서 요청하면 앞 사진 비율이 그대로 남기 쉬워서 용도 짝짓기가 성립하지 않는다. 만들 목록에는 줄 끝에 쉼표 뒤로 바로 적는다(`① 45도 비스듬히, 정사각형 1:1`, 오른쪽 상자 배지 X). 작성 틀에는 "비율은 [비율]로 새로 만들어줘." 비율이 안 바뀌면 "이 장면을 가로 16:9 비율로 새로 만들어줘"처럼 다시 말하게 안내한다. 기준: 쇼핑몰 목록 정사각형 · 상세 페이지 · 인스타 세로 · 배너 가로.
- 브랜드 '하루잔'(가상의 텀블러 브랜드)의 실제 의뢰 용도(쇼핑몰 · 인스타그램 · 계절 이벤트)에 맞춰 비교 질문을 만든다. "누구에게 팔 것 같나", "[누구에게]에게 어울리는" 같은 없는 결정은 넣지 않는다.

## 4. DAY 02 (2026-11-19 정리)

- 섹션 14개, PART A 같은 제품 여러 구도 · B 콘셉트 바꾸기 · C 역설계와 마무리.
- 3장 표는 5장 실습의 구도와 같은 이름으로("45도 비스듬히 → '이렇게 생긴 제품이에요'"). 어디에 쓸지는 표에 쓰지 않고 5장 STEP 03에서 직접 고른다.
- SET 02: 6장(구도 + 비율) → 확인 후 이상한 한 장만 고치기 → 쇼핑몰 대표 · 상세 페이지 · 인스타 피드 · 광고 배너 4칸 `[ ]번` 고르기(입력칸 아님, 칸마다 판단 질문 두 줄).
- SET 03 빛: 한 장 고르기 → 조명 · 색감 조합 세 번 → 느낌 비교 질문. SET 04 분위기: 서로 많이 다른 세 가지 고르기 → 세 번 → 같은 텀블러인지 · 묻히지 않았는지. SET 05 계절: 4장 → 다른 점 찾기 → 작성 틀 ⑤-2로 한 세트 맞추기. SET 06 화풍: 세 가지 + 더 해 보기 → 비교 질문. SET 07 아이콘(새 채팅): 만들기 → 한 세트 확인 → 고치기 · 늘리기 · 색 바꾸기.
- 수업 전 강사 확인: Gemini에서 이어서 요청할 때 비율(가로 16:9)이 실제로 바뀌는지.

## 5. DAY 03 (2026-11-24 개편)

- 활성 페이지는 `html/ai-content/day03v2/`. 기존 day03은 보존한다.
- 도입에서 이미지 투 비디오와 이미지 학습의 이유를 설명한다. 캐릭터·제품·배경의 모습을 이미지에서 정한 뒤 움직임을 더한다. 모든 영상에 이미지가 필수라고 단정하지 않는다.
- DAY 02는 이미지 조절, DAY 03은 참고 사진 활용·합성·광고 문구와 게시글 완성으로 구분한다. 배경·부분 수정은 광고 목적에 맞게 적용하고 기초를 다시 가르치지 않는다.
- 주제는 빵집·고깃집·카페 등 12개 업종 카드로 고른다. 큰 화면 4열 × 3행, 작은 화면 2열·1열. 목록 밖의 주제도 가능하다. 이후 실습은 고른 주제를 유지한다.
- 주된 결과물은 세로 4:5 광고 이미지 1장과 게시글 본문. 글자 없는 광고 사진과 수정 가능한 슬라이드 원본도 저장한다. 카드뉴스 5장과 포스터는 같은 광고를 확장하는 활동으로 둔다.
- 실제 사진과 생성 이미지 준비 경로를 모두 제공한다. 서비스 업종도 도구·공간을 대상으로 진행할 수 있게 안내한다.

- 수업 분량 점검(2026-11-24): 기본 실습 약 82~103분, 카드뉴스 30~45분, 다른 용도 제작 10~20분으로 예상한다. 기존 구성으로 2시간을 진행할 수 있어 과제·예제 파일은 추가하지 않았다. 시간의 근거와 운영 예시는 강사용 v2 커리큘럼 txt에 기록한다.
- 분량을 보강할 필요가 생기면 같은 작업의 반복보다 다른 활용 실습과 예제 자료를 추가한다. 충분한 경우에는 구성을 유지하고 말투·진행 안내를 점검한다.
