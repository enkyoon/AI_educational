- DAY 01: 직접 하면 간단한 일 / AI를 쓰면 좋은 일 / 사람이 판단할 일을 나눠 본다. DAY 08의 작업 구분과 같은 기준이다. 직장이 없으면 가상 업무나 생활 상황을 사용한다.
- DAY 03: 제품 카드의 확인된 사실·미정 정보를 나눠 소개서를 만든다. Google 문서 첫 화면·앱 즐겨찾기·Gemini 패널 캡처를 설명 옆에 둔다. 공유는 협업 기능을 익히는 활동이며 마지막 날 제출 요구와 별개다.
- DAY 04: 자체 요약표(상반기 1~6월·금액 단위 만 원)로 보고 슬라이드를 끝낸다. 시트 선행 수업을 요구하지 않는다. 차트용 작은 표 붙여넣기는 이 페이지에서 설명한다. 기본 디자인·가독성 정리는 공통 과정, 표지 이미지 확장은 선택이다.
- DAY 05 데이터: 2026년 1~3월·3지점·8품목·정상 3,000건 + 완전 중복 8줄과 정리 연습용 오류. `day05v2/sales-practice.xlsx` 준비 파일이 기본, 직접 생성은 선택이다. 원본 보존 → 진단·기준 선택 → 집계 → 조건 찾기·자동 분류 → 원가 연결 → 피벗·검산. 주문번호가 같다고 품목별 정상 기록을 삭제하지 않는다. 빈칸은 추측으로 채우지 않는다.
- DAY 05의 집계표·피벗은 같은 기간과 제외 조건을 적용한다. AI가 답에 적은 숫자와 시트의 실제 수식을 구분하고, 수식 입력줄의 =·원본 값 변경 후 되돌리기로 재계산을 확인한다. Google 시트 FILTER의 대상 없음 처리는 바깥 IFNA 등으로 한다.
- DAY 06 시작 파일: `day06v2/sales-clean.xlsx` (정리본·제품목록·정리기록). 원본 3,008줄 − 완전 중복 8줄 − 미확인 10줄 = 2,990줄, 집계 금액 216,346,600원. 수업용 제품목록 단가로 재계산한 시작 자료이며 실제 거래에서는 단가 차이의 이유를 확인한다.
- DAY 06: 회사·거래처 자료의 양방향 대조 → 같은 정리본을 나눈 지점 CSV 세 개 통합 → 차트·대시보드 → 한 번에 맡긴 결과와 단계별 검증값 비교. 지점 파일을 전체 정리본에 다시 덧붙이지 않는다. 대조 단위·중복 의미를 먼저 확인하고 한쪽에 없는 값을 0원으로 채우지 않는다. AI가 반드시 틀려야 하는 실습이 아니다.
- DAY 07: Deep Research를 40분으로 고정하지 않는다. 짧은 조사 안내와 결과 검증 뒤 Notebook에 약 80분, 강사 운영에 따라 최대 90분을 배정한다. 조사 완료를 기다려야 Notebook을 시작할 수 있는 구조를 만들지 않는다. 사용자가 추가 수업 자료를 주면 해당 내용을 우선 반영한다.
