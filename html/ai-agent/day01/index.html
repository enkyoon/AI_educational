3.AI가 다 해주는데 왜 배워야 할까?

1교시 · AI Agent와 Workflow의 기본 원리

ChatGPT에게 물어보면 프로그램 사용법도, 코드도, 오류 해결 방법도 알려줍니다. 그렇다면 이런 생각이 들 수 있습니다.

"GPT가 다 알려주는데 굳이 자동화를 배울 필요가 있을까?"

하지만 AI에게 질문하는 것과 실제로 움직이는 자동화를 만드는 것은 서로 다른 능력입니다. 예를 들어 이런 자동화를 만들고 싶다고 해 봅시다.

만들고 싶은 자동화

홈페이지에 고객 문의가 들어오면 → 문의 내용을 AI가 읽고 → 문의 종류를 판단한 뒤 → Google Sheets에 저장하고 → 담당자에게 이메일을 보내고 싶다.

GPT가 해줄 수 있는 일

저장하는 방법, 이메일 보내는 방법처럼 기능 하나하나를 만드는 방법을 설명해 줍니다.

사람이 먼저 정해야 하는 일
  • 어떤 정보가 들어오는가?
  • 어떤 작업을 해야 하는가?
  • 어디에서 AI의 판단이 필요한가?
  • 어떤 서비스와 연결해야 하는가?
  • 최종 결과는 무엇이어야 하는가?

이 수업에서 배우는 것은 특정 프로그램이 아니다

이번 과정에서는 Google Opal과 n8n을 사용하지만, 목표는 버튼 위치를 외우는 것이 아닙니다. AI 자동화 도구는 계속 바뀝니다. 몇 년 뒤에는 지금 쓰는 도구가 다른 서비스로 바뀔 수도 있습니다. 대신 아래 순서로 생각하는 힘을 기르면 도구가 바뀌어도 그대로 적용할 수 있습니다.

1문제를 발견하기
2원하는 결과 정하기
3작업을 작은 단계로 나누기
4단계마다 필요한 도구 고르기
5단계를 연결하기
6결과를 테스트하기
7문제가 생기면 고치기

핵심 — AI는 강력한 도구지만, 무엇을 만들지 정하고 전체 흐름을 설계하는 일은 여전히 사람의 몫입니다.

4.생성형 AI · 자동화 · Workflow

비슷해 보이는 네 가지 말을 먼저 구분합니다. 뒤로 갈수록 앞의 개념을 품고 조금씩 커집니다.

① 생성형 AI

ChatGPT나 Gemini처럼 사용자의 요청을 받아 새로운 내용을 만들어주는 AI입니다. 기본 구조는 "질문 → AI → 답변"입니다.

넣는 것AI가 하는 일결과
긴 문서핵심 내용 분석문서 요약
상품 정보문장 생성상품 소개문
이메일 내용내용 분석답변 초안
아이디어내용 확장기획안

② 자동화(Automation)

반복하는 일을 정해진 규칙에 따라 알아서 실행하게 만드는 것입니다. 매일 같은 보고서를 이메일로 보내야 한다면 이렇게 자동화할 수 있습니다.

오전 9시 Google Sheets 데이터 가져오기 보고서 작성 담당자에게 이메일

③ Workflow (작업 흐름)

Workflow

하나의 목표를 이루기 위해 여러 작업을 순서대로 연결한 작업 흐름입니다. 각 단계가 이어져 하나의 업무를 완성합니다.

신청서 접수 신청자 정보 확인 Google Sheets 저장 확인 이메일 발송

④ AI Workflow

Workflow 안에 AI가 들어가면 데이터를 옮기기만 하는 것이 아니라 내용을 읽고 분석하거나 새로 만들 수 있습니다. AI는 흐름 속 한 단계의 역할을 맡습니다.

고객 문의 접수 AI가 내용 분석 문의 유형 분류 Google Sheets 저장 답변 이메일 작성 이메일 발송

표시는 AI가 맡는 단계입니다.

5.AI Agent란?

AI Agent (AI 에이전트)

문장을 만드는 데서 그치지 않고, 주어진 목표를 이루기 위해 필요한 행동을 스스로 판단하고 도구를 사용하는 AI 구조입니다.

예를 들어 이렇게 요청했다고 해 봅시다.

"이번 주 미처리 고객 문의를 확인하고 필요한 사람에게 답변을 보내줘."

이 요청을 처리하려면 Agent는 여러 행동을 이어서 해야 합니다.

1요청 이해하기
2고객 문의 데이터 확인
3미처리 문의 찾기
4문의 내용 분석
5필요한 답변 작성
6이메일 발송
7처리 결과 기록

생성형 AI와 가장 큰 차이는 답변만 만드는 것이 아니라 필요한 행동까지 이어서 한다는 점입니다.

일반 자동화와 AI Agent 비교

구분일반 자동화AI Agent
실행 방식미리 정한 순서대로상황에 따라 판단
판단사람이 조건을 정함AI가 일부를 판단
실행 경로거의 고정요청에 따라 달라짐
AI의 역할없어도 됨핵심 역할
도구(Tool) 사용정해진 서비스를 실행필요한 도구를 골라서 실행
예시신청서가 오면 저장 후 이메일 발송요청을 분석해 필요한 일을 판단하고 처리
모든 자동화를 AI Agent로 만들 필요는 없습니다. 단순 반복 작업은 일반 Workflow가, 상황을 보고 행동을 골라야 하는 일은 AI Agent가 더 잘 맞습니다.

6.Node와 Trigger

Node (노드)

Workflow 안에서 한 가지 역할만 맡는 작업 칸입니다. 앞으로 사용할 자동화 도구에서 가장 중요한 개념입니다.

아래 Workflow에는 역할이 다른 Node가 네 개 있습니다. Node 하나가 모든 일을 하는 것이 아니라, 각자 맡은 일을 하고 서로 연결됩니다.

고객 문의

데이터를 받아 옴

AI

문의 내용을 분석

Google Sheets

결과를 저장

Email

담당자에게 전달

비유하자면: 식당 주방과 같습니다. 재료 손질 담당, 굽기 담당, 담기 담당이 각자 한 가지 일을 하고 다음 사람에게 넘깁니다. Node는 이 담당자 한 명, Workflow는 주방 전체의 순서입니다.

Trigger — 언제 시작할까?

Trigger (트리거)

Workflow가 언제 시작되는지 정하는 시작점입니다. Workflow를 움직이게 하는 신호라고 생각하면 됩니다.

Trigger의미
버튼 클릭사용자가 버튼을 누르면 실행
이메일 도착새 이메일이 오면 실행
신청서 제출새 신청이 들어오면 실행
오전 9시정해진 시간에 실행
새 데이터 등록데이터가 추가되면 실행

Workflow를 설계할 때 가장 먼저 던질 질문은 "이 자동화는 언제 시작되어야 하는가?"입니다.

7.Input · Output과 데이터의 이동

Node는 혼자 움직이지 않습니다. 대부분의 Node는 앞 단계에서 데이터를 받아 일을 처리하고, 결과를 다음 단계로 넘깁니다.

Input (입력)

Node로 들어오는 데이터

"AI Agent는 다양한 Tool을 이용하여 사용자의 목표를 수행할 수 있습니다…"

Process (처리)

Node가 하는 작업

내용을 분석하고 핵심만 요약

Output (출력)

작업을 마친 결과

"AI Agent는 목표 달성을 위해 여러 Tool을 활용하는 AI 시스템입니다."

앞 Node의 Output이 다음 Node의 Input이 됩니다.

Workflow를 이해할 때 가장 중요한 한 문장입니다. 앞으로 n8n을 쓸 때도 이 원리는 똑같습니다.

데이터는 Node를 따라 이동하며 계속 바뀐다

8.Node를 여러 개로 나누는 이유

AI에게 한 번에 이렇게 요청할 수도 있습니다.

"이 글을 요약하고 제목을 만들고 SNS 게시글까지 작성해줘."

하지만 Workflow에서는 이 일을 여러 단계로 나누는 경우가 많습니다.

글 입력 내용 요약 제목 생성 SNS 게시글 작성 Google Sheets 저장

단계를 나누어 두면 중간에 새 기능을 끼워 넣거나 한 단계만 고치기 쉬워집니다. 예를 들어 나중에 "광고 글은 따로 모으기"를 추가하고 싶다면 이렇게 바꿀 수 있습니다.

내용 요약
내용이 광고인지 판단 (새로 추가)
YES → SNS 게시글 작성
NO → 별도 저장
Google Sheets 저장
담당자 이메일 전송

일이 복잡해질수록 작은 기능으로 나누어 생각하는 능력이 중요해집니다. 이렇게 조건에 따라 길이 갈라지는 방법(분기)은 DAY 05에서 자세히 배웁니다.

9.실습: 문장을 Workflow로 바꾸기

자동화를 만들기 전에 프로그램부터 열 필요는 없습니다. 먼저 만들고 싶은 것을 말이나 글로 표현하고, 작업 단위로 나눕니다. 이것을 Flow(흐름)를 설계한다고 합니다.

목표 문장

고객이 문의를 남기면 AI가 내용을 확인하고 담당자에게 전달한다.

작업 단위로 나누면
  1. 고객이 문의 작성
  2. 문의 데이터 가져오기
  3. AI가 문의 내용 읽기
  4. 문의 종류 판단
  5. 담당자 결정
  6. 담당자에게 전달

문제

연습 ② 나만의 Flow 작성하기

자동화하고 싶은 간단한 일 하나를 떠올려 보세요. 아래 틀의 [ ] 칸을 직접 고쳐 씁니다. 완벽하지 않아도 됩니다. 머릿속 일을 작은 단계로 나누어 적어 보는 것이 목표입니다.

만들고 싶은 자동화: 네이버 예약 문의가 오면 답장 초안을 받아 보기 ① 무엇이 시작시키는가(Trigger): 새 예약 문의 이메일이 도착했을 때 ② 어떤 정보가 필요한가(Input): 문의한 사람 이름, 날짜, 인원, 문의 내용 ③ 어떤 처리가 필요한가: 이메일에서 날짜·인원만 따로 뽑기 ④ AI의 판단이 필요한가: 단순 예약인지, 단체·대관 문의인지 구분하기 ⑤ 어떤 행동을 실행하는가: 예약 내용을 시트에 적고, 답장 초안을 만들어 나에게 보내기 ⑥ 최종 결과는 무엇인가(Output): 시트에 쌓인 예약 목록 + 바로 보낼 수 있는 답장 초안

만들어진 화면에서 입력 단계 · AI 단계 · 출력 단계가 선으로 연결된 모습을 찾아보세요. 이 칸 하나하나가 1교시에 배운 Node입니다.

담을 내용예시

② 원래 원한 결과사용자가 입력한 글이 AI 처리 단계로 전달되어야 합니다.
③ 지금 생긴 문제AI 단계에서 사용자의 입력 내용이 전달되지 않습니다.

⑤ 원하는 도움초보자가 따라 할 수 있게 확인할 곳을 순서대로 설명해 주세요.
