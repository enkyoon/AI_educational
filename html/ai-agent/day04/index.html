DAY 04AI 에이전트 · 트리거와 실무 Node

트리거와 실무 Node로 만드는 자동화

신청 폼이 들어올 때, 메일이 올 때, 아침 9시가 될 때 — 시작 방법이 다른 자동화 여섯 개를 만들어 봅니다. Google 시트 · Gmail · 캘린더 · 드라이브까지 실제 업무에서 자주 쓰는 Node를 함께 씁니다.

1.수업 구성

오늘의 핵심목표

폼 · 메일 · 시간으로 시작하는 자동화를 직접 만들고, 상황에 맞는 트리거와 Node를 고를 수 있다.

1교시

Flow 1 신청 폼 · Flow 2 주문 메일 · Flow 3 아침 할 일 메일

2교시

Flow 4 예약 → 캘린더 · Flow 5 파일 → 드라이브 · Flow 6 단체 메일

기본 Flow Flow 1~4는 모두 함께, 더 만들기 Flow 5 · 6과 도전은 진도에 맞춰 이어 갑니다. Flow마다 새 Workflow로 처음부터 만듭니다.

시작 전에 Google 드라이브에 새 스프레드시트 AI_AGENT_DAY04를 하나 만들어 둡니다. Flow마다 탭을 하나씩 더해 씁니다. Google 시트 · Gmail 연결이 없다면 DAY 03 · Credential부터 만드세요.

2.트리거 — 언제 시작할까

Workflow의 첫 Node인 트리거가 "언제 시작할지"를 정합니다. 지금까지는 내가 실행 버튼을 눌렀다면(Manual), 오늘은 일이 생기면 저절로 시작되게 합니다.

트리거이럴 때 시작오늘 쓰는 곳
Form Trigger누군가 n8n이 만든 입력 폼을 제출하면Flow 1 · 4 · 5
Gmail Trigger내 메일함에 조건에 맞는 새 메일이 오면Flow 2
Schedule Trigger정해진 시간이 되면 (매일 9시 등)Flow 3
Manual Trigger내가 실행 버튼을 누르면Flow 6

만드는 동안에는 테스트 버튼으로 확인하고, 다 만들면 오른쪽 위 Publish(켜기)를 눌러야 실제로 저절로 시작됩니다. 수업이 끝나면 쓰지 않는 Workflow는 다시 꺼 두세요.

3.Flow 1 · 상담 신청 폼 → 시트 → 접수 메일

기본 FlowForm Trigger · Google Sheets · Gmail

상황 — 상담 신청을 받으면 명단에 쌓고, 신청자에게 접수 안내를 보내고 싶다. 신청 페이지는 n8n이 만들어 줍니다.

신청 폼 제출 (Form Trigger) 명단에 저장 (Sheets) 접수 메일 (Gmail)

준비 — 탭 상담신청을 만들고 A1에 붙여 넣기

  1. 1새 Workflow → 첫 Node로 On form submission(Form Trigger). Form Title은 "상담 신청"
  2. 2Form Fields 네 개 — 이름(Text) · 이메일(Email) · 상담분야(Dropdown: 수업 / 결제 / 기타) · 문의내용(Textarea). 모두 Required
  3. 3Execute step → 열린 폼에 내 이름 · 내 이메일로 제출 → OUTPUT에 네 값과 submittedAt(제출 시각)이 보입니다
  4. 4Google Sheets Append row in sheet(탭 상담신청) — 다섯 열에 INPUT 값을 끌어다 놓기 (신청시각 ← submittedAt)
  5. 5Gmail Send a message — To ← 이메일, Subject "상담 신청이 접수되었습니다", Message에 "[이름]님, [상담분야] 상담 신청을 받았습니다. 담당자가 곧 연락드리겠습니다." (대괄호 자리는 끌어다 놓기)
  6. 6Publish → Form Trigger의 Production URL을 새 탭에서 열어 한 번 더 제출합니다

확인 — 시트에 한 줄, 내 메일함에 접수 메일. Production URL은 다른 사람에게 보내도 되는 진짜 신청 페이지입니다.

4.Flow 2 · 주문 메일 자동 기록 · 라벨

기본 FlowGmail Trigger · Google Sheets · Gmail(라벨)

상황 — 제목에 [주문]이 붙은 메일이 오면 주문 기록 시트에 남기고, 메일함에서 찾기 쉽게 라벨을 붙이고 싶다.

[주문] 메일 도착 (Gmail Trigger) 주문 기록 (Sheets) 라벨 붙이기 (Gmail)

준비 — 탭 주문메일의 A1에 붙여 넣고, Gmail 왼쪽 메뉴에서 새 라벨 자동화-주문을 만들어 둡니다.

  1. 1내 메일 주소로 제목 [주문] 머그컵 2개, 본문 "토요일까지 받을 수 있을까요?"인 메일을 하나 보내 둡니다
  2. 2새 Workflow → Gmail Trigger(On message received). Poll Times는 Every Minute, Filters의 Search에 subject:[주문]
  3. 3Fetch Test Event → OUTPUT에서 보낸 사람(From) · 제목(Subject) · 내용 미리보기(snippet)를 찾습니다
  4. 4Google Sheets Append(탭 주문메일) — 세 열에 From · Subject · snippet 끌어다 놓기
  5. 5Gmail → Add label to message — Message ID에 Gmail Trigger의 id를 끌어다 놓고, Label은 목록에서 자동화-주문
  6. 6Publish → [주문] 메일을 하나 더 보내고 1~2분 기다립니다

확인 — 시트에 새 줄, 메일에 자동화-주문 라벨. 결과는 Workflow 화면 위쪽 Executions에서도 볼 수 있습니다.

* 조건(subject:[주문])을 꼭 겁니다. 조건 없이 켜 두면 개인 메일까지 모두 시트에 기록됩니다.

5.Flow 3 · 매일 아침 할 일 메일

기본 FlowSchedule Trigger · Google Sheets · Filter · Aggregate · Gmail

상황 — 매일 아침 9시, 할 일 시트에서 아직 끝나지 않은 일만 모아 한 통의 메일로 받고 싶다.

매일 9시 (Schedule) 할 일 불러오기 (Sheets) 진행중만 남기기 (Filter) 한 묶음으로 (Aggregate) 나에게 메일 (Gmail)
Filter — 새 Node

조건에 맞는 줄만 다음으로 보내고 나머지는 버립니다. IF와 달리 길은 하나입니다.

Aggregate — 새 Node

여러 줄을 한 묶음으로 합칩니다. 그래야 메일이 줄마다가 아니라 한 통만 갑니다.

준비 — 탭 할일의 A1에 붙여 넣기

  1. 1새 Workflow → Schedule Trigger — Trigger Interval: Days, Hour: 9am, Minute: 0
  2. 2Google Sheets Get row(s) in sheet(탭 할일) → 실행하면 5 items
  3. 3Filter — 상태 · String → is equal to · 진행중 → 3 items만 남는지 확인
  4. 4Aggregate — Individual Fields에 할일을 끌어다 놓기 → 1 item 안에 할 일 세 개가 묶입니다
  5. 5Gmail Send — To는 내 주소, Subject "오늘 남은 할 일", Message에 "오늘 남은 일: " + 묶인 할일을 끌어다 놓기
  6. 6지금 확인하려면 Execute workflow, 매일 받으려면 Publish

확인 — 메일이 한 통만 오고, 완료된 일은 빠져 있는가? 시트에서 상태를 바꾸고 다시 실행해 보세요.

6.Flow 4 · 예약 폼 → 캘린더 일정

기본 FlowForm Trigger · Google Calendar · Gmail

상황 — 상담 예약을 받으면 내 Google 캘린더에 일정이 바로 생기고, 예약자에게 확인 메일이 가게 하고 싶다.

예약 폼 제출 (Form Trigger) 일정 만들기 (Google Calendar) 확인 메일 (Gmail)
  1. 1새 Workflow → Form Trigger, 제목 "상담 예약" — 이름(Text) · 이메일(Email) · 예약 날짜(Date) · 요청 사항(Textarea)
  2. 2Execute step으로 한 번 제출해 OUTPUT을 만듭니다
  3. 3Google Calendar → Create an event. Credential은 처음 한 번 Sign in with Google로 만들고, Calendar는 내 이메일 주소(기본 캘린더)
  4. 4Start · End 모두에 예약 날짜를 끌어다 놓고, Additional Fields에서 All Day를 Yes, Summary(일정 제목)는 "상담 예약 — [이름]", Description에 요청 사항
  5. 5Gmail Send — To ← 이메일, "[이름]님, [예약 날짜] 상담 예약이 확정되었습니다."
  6. 6Publish → Production URL로 다른 날짜를 두세 번 예약해 봅니다

확인 — Google 캘린더를 열어 그 날짜에 "상담 예약 — 이름" 일정이 생겼는가? 일정 안에 요청 사항이 들어 있는가?

7.Flow 5 · 파일 제출 폼 → 드라이브 저장

더 만들기Form Trigger(파일) · Google Drive · Google Sheets

상황 — 과제나 서류를 폼으로 받으면 드라이브 폴더에 모으고, 누가 냈는지 링크와 함께 시트에 남기고 싶다.

파일 제출 (Form Trigger) 폴더에 올리기 (Google Drive) 제출 기록 (Sheets)

준비 — 드라이브에 폴더 제출파일을 만들고, 탭 제출기록의 A1에 붙여 넣기

  1. 1새 Workflow → Form Trigger, 제목 "과제 제출" — 이름(Text) · 첨부파일(File)
  2. 2아무 이미지나 PDF로 한 번 제출 → OUTPUT의 Binary 탭에서 파일 이름표(예: 첨부파일)를 확인합니다
  3. 3Google Drive → Upload file (Credential은 Sign in with Google). Input Data Field Name에 2번의 파일 이름표를 적고, Parent Folder는 목록에서 제출파일
  4. 4Google Sheets Append(탭 제출기록) — 이름은 Node 선택 목록에서 Form Trigger의 이름, 파일이름 ← Drive OUTPUT의 name, 링크 ← webViewLink

확인 — 드라이브 제출파일 폴더에 파일이 있고, 시트의 링크를 누르면 그 파일이 열리는가?

8.Flow 6 · 명단 전원에게 안내 메일

더 만들기Manual Trigger · Google Sheets · Gmail

상황 — 명단에 있는 사람 모두에게 이름을 넣은 개별 안내 메일을 한 번에 보내고 싶다.

실행 (Manual) 명단 불러오기 (Sheets) 한 명씩 메일 (Gmail)

준비 — 탭 명단의 A1에 붙여 넣고 "내아이디"를 내 Gmail 아이디로 바꿉니다. 모두 내 메일함으로 옵니다.

  1. 1새 Workflow → Manual Trigger → Google Sheets Get row(s)(탭 명단) → 실행하면 5 items
  2. 2Gmail Send — To ← 이메일, Subject "[안내] 다음 주 수업 일정", Message "[이름]님, 다음 주 수업은 화요일 저녁 7시입니다."
  3. 3실행 → Gmail Node에 5 items, 메일함에 이름이 다른 메일 다섯 통

Node는 하나인데 줄이 다섯이면 다섯 번 실행됩니다. 명단이 100명이어도 같은 Workflow입니다.

9.막혔을 때

이런 모습이면확인할 것
폼을 냈는데 Workflow가 안 돎테스트 중이면 Execute step을 누른 뒤 열린 폼으로 냈는지, 실제 주소로 냈다면 Publish했는지
Gmail Trigger가 메일을 못 찾음Search 조건과 메일 제목이 맞는지([주문] 대괄호까지), Fetch Test Event를 다시 눌렀는지
9시가 됐는데 메일이 안 옴Publish했는지, n8n 설정의 시간대(Timezone)가 서울인지
캘린더 · 드라이브 Node 오류서비스마다 Credential이 따로 필요합니다. Sign in with Google로 그 서비스용을 만들었는지
드라이브 업로드에서 파일이 없다고 나옴Input Data Field Name이 Form OUTPUT의 Binary 탭 이름표와 똑같은지
메일이 여러 통 감 / 한 통만 감앞 Node의 items 수를 봅니다. 묶으려면 Aggregate, 한 명씩이면 묶지 않기
