DAY 06AI 에이전트

Webhook으로 웹사이트 응답 자동 저장하기

초대장 웹사이트에서 손님이 [참여하기]를 누르면, n8n의 Webhook이 그 내용을 받아 Google Sheets에 한 줄씩 쌓습니다. 지금까지는 내가 버튼을 눌러 Workflow를 시작했다면, 오늘은 바깥의 웹사이트가 Workflow를 시작시킵니다. 완성한 뒤에는 IF를 끼워 넣어 참석과 불참을 나눠 저장하도록 고쳐 봅니다.

4.오늘 만들 Workflow

초대장 [참여하기] Webhook Edit Fields Google Sheets

Webhook (웹훅)

바깥의 웹사이트나 서비스가 n8n에 데이터를 보내면서 Workflow를 실행시키는 입구입니다. n8n이 주소를 하나 만들어 주고, 그 주소로 데이터가 들어오면 Workflow가 시작됩니다.

비유하자면: 가게 앞에 주문 접수함을 하나 달아 두는 것과 같습니다. 손님이 주문서를 넣으면(참여하기), 가게 안에서 정해진 순서대로 일이 시작됩니다(Workflow).

7.실습: Test URL로 연결 확인

Webhook 화면 위쪽에는 Test URL과 Production URL 두 주소가 있습니다. 만드는 동안에는 Test URL을 씁니다. 주소 가운데에 /webhook-test/가 들어 있으면 Test URL입니다.

1Webhook Node에서 Listen for Test Event 누르기 → 데이터를 기다리는 상태
2실습용 초대장 주소 뒤에 ?webhook= + 내 Test URL을 붙여 새 탭에서 열기
3이름 · 참석 여부 · 인원 · 메시지 입력 → [참여하기]
4n8n으로 돌아와 Webhook의 OUTPUT 확인
2번에서 여는 주소 = 실습용 초대장 주소 + ?webhook= + 내 Test URL
https://workproai.kr/html/test/invitation/?webhook=https://내계정.app.n8n.cloud/webhook-test/rsvp

?webhook= 뒤에는 반드시 내 n8n 주소를 붙입니다. 붙이지 않고 초대장 주소만 열면 강사의 n8n으로 보내집니다.

들어온 데이터는 body 안에 있다

OUTPUT에 데이터가 보이면 연결 성공입니다. 이때 값이 바로 name으로 들어오는 것이 아니라 body 안에 들어 있습니다.

body
 ├─ event
 ├─ name
 ├─ attend
 ├─ guests
 ├─ message
 └─ submitted_at
그래서 이름을 가져오는 식은 {{ $json.body.name }}

끌어다 놓으면 이 모양이 자동으로 만들어집니다.

8.실습: Edit Fields로 데이터 정리

Webhook 오른쪽 + → Edit Fields를 추가하고, Mode는 Manual Mapping으로 둡니다. body 안의 값을 꺼내 쓰기 편한 이름으로 정리하는 단계입니다. 아래 네 칸을 만듭니다.

NameValue (끌어다 놓기)
name{{ $json.body.name }}
attend{{ $json.body.attend }}
guests{{ $json.body.guests }}
message{{ $json.body.message }}
정리 전 (Webhook)

body.name · body.attend · body.guests · body.message

정리 후 (Edit Fields)

name · attend · guests · message

9.실습: Google Sheets에 한 줄 추가

1Edit Fields 오른쪽 + → Google Sheets → Append row in sheet
2Credential 선택, 5번에서 만든 스프레드시트와 탭 고르기
3Map Each Column Manually로 네 열 연결
시트 열값
name{{ $json.name }}
attend{{ $json.attend }}
guests{{ $json.guests }}
message{{ $json.message }}

왜 여기서는 body가 없을까?

Google Sheets 바로 앞 Node는 Webhook이 아니라 Edit Fields입니다. Edit Fields에서 이미 body 밖으로 꺼내 정리했으므로 {{ $json.name }}을 씁니다. Webhook 바로 다음이었다면 {{ $json.body.name }}입니다.

11.실습: Publish하고 실제 주소로 받기

1Webhook Node에서 Production URL을 골라 복사
2Workflow 오른쪽 위 Publish (켜기)
3초대장 주소 + ?webhook= + 내 Production URL로 열어 응답 보내기
https://workproai.kr/html/test/invitation/?webhook=https://내계정.app.n8n.cloud/webhook/rsvp
  • · Publish해 두면 더 이상 Listen for Test Event를 누르지 않아도 됩니다. 옆자리 사람에게 이 주소를 보내 응답을 받아 보세요.
  • · 결과는 편집 화면이 아니라 Executions에서 Webhook ✓ → Edit Fields ✓ → Google Sheets ✓로 확인합니다.
  • · 버전에 따라 Publish 대신 활성화(Active) 스위치로 보일 수 있습니다.

12.실습: IF로 참석 · 불참 나눠 저장

지금 Workflow는 모든 응답을 한 탭에 쌓습니다. 이제 이미 만든 Workflow를 고쳐서, 참석 응답은 "참석자" 탭에, 불참 응답은 "축하 메시지" 탭에 따로 쌓아 봅니다. 새로 만드는 것이 아니라 중간에 IF 하나를 끼워 넣는 수정입니다.

지금

Webhook → Edit Fields → Google Sheets

고친 뒤

Webhook → Edit Fields → IF
├ 참석 → Google Sheets (참석자 탭) └ 불참 → Google Sheets (축하 메시지 탭)

STEP 1. 시트에 탭 두 개 만들기

같은 스프레드시트 아래쪽 +로 탭을 두 개 더 만들고, 이름과 1행 제목을 넣습니다.

탭 이름: 참석자

탭 이름: 축하 메시지

* 탭마다 필요한 칸만 둡니다. 불참은 인원이 늘 0이라 축하 메시지 탭에는 guests가 없습니다.

STEP 2. Edit Fields와 Google Sheets 사이에 IF 넣기

1Edit Fields와 Google Sheets 사이 연결선에 마우스를 올리기
2선 가운데 나타나는 + → If 검색해 추가
3IF가 사이에 들어가고, 기존 Google Sheets는 IF의 true 쪽에 이어짐

* 선 위에 + 가 보이지 않으면 연결선을 지우고, Edit Fields → IF → Google Sheets 순서로 직접 이어도 됩니다.

STEP 3. 조건 정하기 — "참석이면 true"

왼쪽 값 (끌어다 놓기)비교 방법오른쪽 값 (직접 입력)
{{ $json.attend }}String → is equal to참석

IF 바로 앞은 Edit Fields이므로 body 없이 {{ $json.attend }}입니다. 오른쪽의 참석은 초대장이 보내는 글자와 띄어쓰기 하나까지 똑같아야 합니다.

STEP 4. 두 갈래에 Google Sheets 연결하기

true 쪽 — 기존 Node 고치기

기존 Google Sheets의 Sheet를 참석자로 바꾸고 열을 다시 연결합니다.

name ← {{ $json.name }}
guests ← {{ $json.guests }}
message ← {{ $json.message }}

false 쪽 — 새 Node 붙이기

false 출구 + → Google Sheets → Append row in sheet, Sheet는 축하 메시지.

name ← {{ $json.name }}
message ← {{ $json.message }}

왜 IF 뒤에서도 $json.name일까?

IF는 데이터를 바꾸지 않고 길만 나눕니다. 그래서 IF를 지나도 Edit Fields가 정리한 모양(name · attend · guests · message)이 그대로라, 두 Google Sheets 모두 {{ $json.name }}을 씁니다.

13.테스트하고 다시 Publish

테스트 1 · 참석 Listen for Test Event → Test URL 초대장에서 참석할게요로 보내기 → 참석자 탭에 새 줄
테스트 2 · 불참 다시 Listen → 어려워요로 축하 메시지 보내기 → 축하 메시지 탭에 새 줄

실행한 화면에서 IF의 어느 쪽 길만 초록색으로 지나갔는지 보면, 데이터가 어디로 갔는지 한눈에 보입니다.

고친 Workflow는 다시 Publish해야 반영됩니다

11번에서 이미 Publish한 Workflow를 고쳤습니다. 다시 Publish하지 않으면 손님 응답은 여전히 예전 방식(한 탭에 모두)으로 쌓입니다.

다시 Publish → Production URL 초대장에서 참석 · 불참 한 번씩 → Executions와 두 탭에서 결과 확인. 버전에 따라 저장만 해도 반영되거나 활성화(Active) 스위치로 보일 수 있습니다.

14.내 초대장 만들기 (짧은 주소)

실습용 초대장 대신 내 행사에 맞는 초대장을 ChatGPT로 만들어 봅니다. 결혼식, 돌잔치, 칠순잔치, 집들이, 모임처럼 원하는 행사로 바꿔 쓰세요. 내 초대장에는 내 Production URL을 기본값으로 넣어 두기 때문에, 손님에게는 ?webhook=이 없는 짧은 주소만 보내면 됩니다.

손님에게초대장 주소만 보내면 기본값(내 Production URL)으로 저장됩니다.
내가 시험할 때주소 뒤에 ?webhook=Test URL을 붙이면 그 주소가 기본값보다 우선합니다.
  • · 받은 파일을 내 컴퓨터에서 열어 참여하기를 눌러 보고, 시트에 줄이 생기는지 확인합니다.
  • · 인터넷에 올리는 방법(AI SPACE 배포)은 강사 안내에 따라 진행합니다.
  • · 이 주소는 페이지 코드에서 누구나 볼 수 있습니다. 비밀번호처럼 숨겨지는 주소가 아니므로, 공개 초대장 같은 용도에만 씁니다.

15.오류가 날 때 확인할 것

이런 문제가 보이면확인할 것
Webhook에 아무것도 안 들어온다Test URL이라면 Listen for Test Event를 누른 상태인지, 초대장 주소의 ?webhook= 뒤가 내 주소인지 확인합니다.
값 자리에 undefined · 빈칸이 나온다Webhook 바로 다음이면 {{ $json.body.name }}, Edit Fields 다음이면 {{ $json.name }}입니다. 바로 앞 Node가 무엇인지 확인합니다.
시트에 줄이 안 생긴다Append row in sheet를 골랐는지, 스프레드시트와 탭이 맞게 선택됐는지 확인합니다.
초대장에 "전송하지 못했습니다"가 나온다Workflow가 Publish(켜짐) 상태인지, Test URL을 쓰는데 Listen이 끝나 버리지 않았는지 확인합니다. 그래도 안 되면 Webhook의 Options에서 Allowed Origins (CORS)가 *인지 봅니다.
테스트는 되는데 실제 주소는 안 된다/webhook/rsvp(Production)를 붙였는지, Workflow를 Publish했는지 확인합니다.
(IF) 참석인데 축하 메시지 탭으로 간다IF 오른쪽 값이 참석과 글자 · 띄어쓰기까지 같은지, 비교 방법이 is equal to인지, 왼쪽 값이 {{ $json.attend }}인지 확인합니다.
(IF) 테스트는 나뉘는데 실제 응답은 한 탭에 쌓인다고친 Workflow를 다시 Publish하지 않아 예전 버전이 실행되고 있습니다.
실습용 초대장 주소만 보냈더니 내 시트에 안 쌓인다실습용 초대장은 기본값이 강사 주소입니다. ?webhook=내 Production URL을 붙이거나, 14번에서 만든 내 초대장을 씁니다.
