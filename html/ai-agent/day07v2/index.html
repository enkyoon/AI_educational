4.실습: 입력부터 결과까지 흐름 정리하기

흐름 (User Flow)

사용자가 무엇을 하면 → 시스템이 무엇을 하고 → 결과가 어떻게 나오는지를 순서대로 적은 것입니다. Node 이름을 몰라도 우리말로 쓰면 됩니다.

Input — 들어오는 것

사용자가 주는 정보, 외부에서 오는 데이터
예: 이름 · 이메일 · 문의 내용

처리 — 그 사이에서 하는 일

요약 · 분류 · 계산 · 판단
예: AI가 문의 종류를 판단

Output — 나가는 것

저장되는 것, 보내지는 것, 보여 주는 것
예: 시트 한 줄 · 알림 메일

먼저 우리말로 적습니다. 단계 수는 내 흐름에 맞게 늘리거나 줄이고, 필요 없는 단계는 지우세요.

■ 시작할 때 주는 정보 입력할 내용: 고객 이름과 후기 내용 입력하는 곳: Edit Fields의 name과 review ■ 처리할 순서 1. 시작: 내가 Execute를 누른다. 2. 입력 준비: Edit Fields에 적은 이름과 후기를 사용한다. 3. 핵심 처리: AI가 후기를 긍정·중립·부정 중 하나로 분류한다. 4. 결과 저장: 이름·후기·감정을 reviews 탭에 저장한다. 5. 마무리: 부정 후기일 때만 내 주소로 메일을 보낸다. ■ 마지막에 확인할 결과 저장할 내용: reviews 탭에 name·review·sentiment 한 줄 알려 줄 내용: 부정 후기의 이름과 내용을 내 메일로 알림

5.실습: 어떤 구조가 필요한가?

구조이럴 때예
일반 Workflow항상 같은 순서신청서 → 시트 저장 → 확인 메일
조건 Workflow (IF · Switch)정해진 몇 갈래로 나뉨금액별 · 종류별 처리
AI Workflow순서는 같고 중간에 AI가 읽고 씀문의 요약 → 저장
AI Agent요청에 따라 AI가 연결된 Tool을 골라야 함채팅으로 조회 · 메일 중 골라서 (DAY 06)

구조 고르기 체크

  • 할 일의 순서가 매번 같은가? → 예라면 Workflow
  • 조건에 따라 정해진 몇 갈래로만 나뉘는가? → 조건 Workflow
  • 요청에 따라 AI가 조회·메일 같은 Tool을 골라 실행해야 하는가? → Agent를 고려
  • Agent가 아니면 정말 안 되는가? 더 단순한 방법은 없는가?

저장·계산·조건 비교만 필요하면 일반 또는 조건 Workflow로 시작합니다. 글을 읽거나 쓰는 단계에 AI를 넣고, Tool 선택까지 맡길 때 Agent를 고려합니다.

네 구조는 서로 완전히 나뉜 종류가 아닙니다. AI Workflow에도 IF를 넣을 수 있고, AI Agent도 Workflow 안에서 동작합니다. 위 표는 내 작업에서 어떤 처리가 필요한지 고르기 위한 안내입니다.

내 프로젝트의 수준 고르기

어느 수준이든 완성하면 좋은 프로젝트입니다. 지금까지 따라온 정도를 보고 다음 시간까지 끝까지 돌릴 수 있는 수준을 고르세요. 기본형을 먼저 완성하고 시간이 남으면 한 단계 올려도 됩니다.

수준구조예시시작 프로젝트 (8번)
기본형Workflow 또는 조건 Workflow신청 내용을 시트에 저장하고 확인 메일 보내기—
응용형AI Workflow (+ 조건)후기를 AI가 판단해 저장하고, 부정이면 알림A 후기 감정 알림 · B 학습 정리 AI
도전형AI Agent + Tool채팅으로 요청하면 조회 · 메일 중 골라 실행C 수강생 관리 Agent

앞의 구조 비교표에서 내 작업에 필요한 처리를 골라 적습니다. AI가 필요 없다면 AI에게 맡길 일에는 없음이라고 써도 됩니다.

■ 내가 만들 구조 프로젝트 수준: 응용형 처리 구조: AI Workflow에 IF 조건을 함께 사용 선택 이유: 처리 순서는 같지만 후기의 감정은 AI가 읽고 판단해야 한다. ■ 역할 나누기 AI에게 맡길 일: 긍정·중립·부정 감정 분류 정해진 규칙으로 처리할 일: 시트 저장, 부정인지 비교, 메일 발송 ■ 연결할 곳 사용할 서비스: Google Sheets, Gmail 저장할 위치: AI_AGENT_DAY07 파일의 reviews 탭

7.실습: 시험할 입력과 기대 결과 정하기

만들기 전에 "무엇이 들어오면 무엇이 나와야 성공인지"를 정해 둡니다. 만든 뒤 이 메모와 실제 결과를 비교합니다.

실제로 넣어 볼 값과 확인할 결과를 적습니다. 직접 확인하는 것과 자동으로 처리하는 것을 구분하세요. 자동으로 빈칸을 막으려면 IF 조건이나 Agent의 추가 질문까지 만들어야 합니다.

■ 확인 1. 대표적인 입력 넣어 볼 값: name=김민지, review=배송도 빠르고 품질도 좋아요. 기대하는 결과: 긍정으로 분류해 시트에 저장. 메일은 오지 않음 확인할 곳: reviews 탭과 받은 메일 ■ 확인 2. 다른 결과가 나와야 하는 입력 넣어 볼 값: name=이준호, review=두 번이나 고장 났어요. 환불하고 싶습니다. 기대하는 결과: 부정으로 분류해 시트에 저장. 내 주소로 메일 발송 확인할 곳: reviews 탭과 받은 메일 ■ 확인 3. 필요한 정보가 빠진 입력 빠진 정보: review가 빈칸 처리 방법: 실행 전에 내가 후기 입력 칸을 직접 확인 기대하는 결과: 후기를 채우기 전에는 실행하지 않음. 자동 차단 기능을 만든 것은 아님 ■ 완성 확인 이름·후기·감정이 같은 기록으로 저장되고 부정 후기일 때만 메일이 온다.

판단 결과 정리 — Edit Fields에 아래 세 항목을 만듭니다. 원래 값이 보이지 않으면 INPUT 위의 Node 선택에서 후기 입력을 골라 가져옵니다.

저장·분기 — 후기 저장에서 세 항목을 같은 이름의 시트 열에 연결합니다. IF의 비교 값은 판단 결과 정리의 sentiment에서 가져와 부정과 비교합니다. true 쪽만 Gmail에 연결하고 받는 사람은 내 주소로 정합니다.

확인 — 이름·후기·감정이 같은 기록으로 저장됐는지 봅니다. AI가 감정 단어 외에 다른 내용을 붙였다면 먼저 응답을 정리한 뒤 조건을 비교합니다. 알림까지 완성한 뒤에는 긍정·중립에 메일이 오지 않고 부정에만 오는지 확인합니다.

흐름 — Manual Trigger → 공부 내용(Edit Fields: topic·note) → AI 요약(Gemini) → AI 복습 질문(Gemini) → 학습 기록 저장(Sheets) → 정리 메일(Gmail)

메일 — 시트에 저장한 주제·요약·복습 질문을 본문에 넣고 받는 사람은 내 Gmail 주소로 고정합니다. 응답 필드 이름을 짐작해서 입력하지 말고 각 Node의 OUTPUT에서 글이 들어 있는 값을 확인해 가져옵니다.

확인 — 한 행에 같은 주제의 요약과 질문이 저장됐는지, 질문이 원문만으로 답할 수 있는지 확인합니다.

10.실습: n8n에 뼈대 세우기

이제 n8n을 엽니다. 먼저 만들 흐름의 Node를 순서대로 놓기만 합니다. 설정은 다음 섹션에서 한 칸씩 합니다. Agent 프로젝트의 Chat Model과 Tool은 주 흐름 옆이 아니라 AI Agent 아래 전용 연결에 붙입니다.

STEP 1새 Workflow 만들기

  1. n8n 왼쪽 위 + → Workflow
  2. 왼쪽 위 이름을 눌러 DAY07_[프로젝트 이름]으로 바꿉니다.

STEP 2Node를 순서대로 놓기

  1. Add first step을 눌러 기획서의 시작(트리거)을 고릅니다.
  2. Node 오른쪽 +를 눌러 기획서 순서대로 다음 Node를 붙입니다. 아직 설정은 비워 둡니다.
  3. Node를 하나씩 선택하고 F2를 눌러 이름을 역할대로 바꿉니다 (예: 후기 입력 · AI 감정 판단 · 후기 저장 · 부정 후기 확인 · 알림 메일).
  4. Canvas 빈 곳을 오른쪽 클릭 → Add sticky note(또는 Shift + S)로 메모를 붙이고 한 줄 설명을 적습니다.

Canvas만 보고 처음부터 끝까지 흐름을 읽었을 때 기획서와 같으면 성공입니다.

데이터 이름표 정하기

Node끼리 주고받을 데이터 이름을 지금 정해 두면 만들면서 헷갈리지 않습니다. 배운 예시처럼 name·review·sentiment 등 짧은 영어 이름을 정합니다.

같은 데이터는 처음 정한 이름을 계속 사용합니다. 항목이 더 필요하면 묶음을 복사해 추가하세요.

■ 데이터 항목 1 이름표: name 뜻: 고객 이름 값을 만드는 곳: 후기 입력(Edit Fields) 예시 값: 김민지 ■ 데이터 항목 2 이름표: review 뜻: 고객이 쓴 후기 내용 값을 만드는 곳: 후기 입력(Edit Fields) 예시 값: 배송도 빠르고 품질도 좋아요. ■ 데이터 항목 3 이름표: sentiment 뜻: AI가 분류한 감정 값을 만드는 곳: 판단 결과 정리(Edit Fields). AI 감정 판단의 응답을 가져옴 예시 값: 긍정

11.실습: 한 단계 설정하고, 실행 결과 확인하기

앞에서 놓은 Node를 처음부터 하나씩 설정합니다. 한 단계가 끝날 때마다 그 단계까지 실행해 OUTPUT을 확인하고 다음으로 넘어갑니다.

순서하나 설정하고, 한 번 실행하기

  1. 시작 방식에 맞는 입력을 준비합니다. Manual Trigger 방식은 뒤의 Edit Fields에 값을 넣고, Chat Trigger 방식은 채팅으로 요청합니다.
  2. 입력 Node를 실행한 뒤 OUTPUT에서 기획한 데이터가 들어왔는지 확인합니다.
  3. AI를 사용하는 프로젝트는 AI Node를 실행하고 실제 응답을 확인합니다. AI가 필요 없는 흐름은 이 단계를 건너뜁니다.
  4. 저장 Node(Google Sheets)를 붙이고 Execute step → 시트 확인
  5. 조건 분기는 선택한 갈래로 흘러가는지 확인합니다. Agent의 Tool은 채팅으로 요청한 뒤 실행 기록에서 사용 여부와 결과를 확인합니다.
  6. 메일 같은 외부 발송은 맨 마지막에 붙입니다.

실습 01 · 입력부터 확인

  • Trigger 뒤 첫 Node의 OUTPUT에 내가 넣은 데이터가 그대로 있는가?
  • 데이터 이름표가 기획서와 같은가? (name인데 다른 곳에서 customer_name으로 쓰지 않았는가?)

이름표가 섞이면 뒤 Node에서 값이 비어 버립니다. 처음 정한 이름을 끝까지 그대로 씁니다.

실습 02 · AI 단계 확인

AI Node를 붙였으면 서로 다른 입력 세 개로 실행해 보고, 결과가 기대와 다르면 Prompt에 들어간 원문과 요청·결과 형식부터 고칩니다.

오류 (Error) — 실행이 멈춤

빨간 표시, 연결 실패, 값 없음
→ Credential · 연결 · 데이터 확인

품질 문제 — 실행은 되는데 결과가 아쉬움

분류가 틀림, 너무 김, 모양이 들쭉날쭉
→ Prompt · 결과 모양 · 예외 설명 확인
