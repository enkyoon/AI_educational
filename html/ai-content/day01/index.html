4.생성형 AI와 콘텐츠 시장의 흐름

1교시 · 15분

생성형 AI

말로 요청하면 글·이미지·영상·음악 같은 새로운 결과물을 만들어 주는 AI입니다.

① AI는 어떻게 바뀌어 왔나

1. 검색내가 찾아 보기
2. 대화물어보면 답해 줌
3. 결과물글·이미지·영상·음악을 만들어 줌
4. 대신 일하기여러 단계를 스스로 처리 ("에이전트")

콘텐츠 쪽에서는 글 → 이미지 → 영상 → 음악 순서로 빠르게 넓어졌습니다. 지금은 한 사람이 기획·이미지·영상·음악·편집을 모두 해 볼 수 있는 시대입니다.

② 이 과정에서 쓰는 도구

Gemini

글, 이미지 만들기·고치기, 음악 만들기(Lyria)

Google Flow

글이나 이미지로 짧은 영상 만들기

CapCut

영상 자르기·잇기·자막·음악 넣기 (편집 프로그램)

Google 슬라이드

카드뉴스 글자, 만화 말풍선 배치

그 밖에 많이 쓰는 도구 (이름만 알아 두기)
이미지 — ChatGPT, Midjourney 영상 — Runway, Kling 음악 — Suno 디자인 — Canva

도구는 계속 바뀝니다. "어떻게 설명하고, 결과를 보고 어떻게 고치는지"는 어느 도구에서나 통합니다. 이 과정은 Google AI Pro 계정으로 진행하며, 다른 유료 도구는 더 높은 품질을 원하는 사람만 개인적으로 선택하면 됩니다.

③ 콘텐츠 일은 어떻게 바뀌나

빨라진 것

시안 만들기, 여러 버전 비교, 배경·소품 촬영, 간단한 영상

사람이 할 일

무엇을 만들지 정하기, 여러 결과 중 고르기, 어색한 곳 찾기, 최종 판단

"AI가 다 만들어 준다"가 아니라 "고르고 고치는 눈이 있는 사람이 잘 만든다"

최근 AI 광고·뮤직비디오 사례와 관련 기사는 수업 시간에 그날 기준으로 함께 살펴봅니다.

5.안전 수칙 — 저작권·초상권·개인정보

1교시 · 10분

AI 콘텐츠는 쉽게 만들고 쉽게 퍼집니다. 그래서 만들기 전에 지킬 것이 있습니다.

하지 않기

  • · 실제 연예인·유명인·지인의 얼굴을 넣어 만들기 (초상권)
  • · 남이 찍은 사진·그린 그림을 허락 없이 참고 이미지로 올리기
  • · 실제 브랜드 로고·상표·캐릭터를 넣어 광고처럼 만들기
  • · 특정 작가·스튜디오·가수 이름으로 "○○풍으로" 요청하기
    → 대신 특징을 말로 설명하기 (예: "부드러운 수채화, 따뜻한 색, 손으로 그린 느낌")
  • · 실제 제품에 없는 효능·성능·수치를 광고 문구에 넣기

올리기 전에 확인

  • · 내 얼굴·아이 얼굴 사진을 올릴 때는 신중하게 (필요할 때만)
  • · SNS에 올릴 때 AI로 만든 콘텐츠라는 표시가 필요한지 확인 (플랫폼마다 규칙이 있음)
  • · 판매·광고 등 돈을 버는 데 쓸 때는 도구의 이용 약관 확인

먼저 생각해 보기 — 괜찮을까?

각 상황을 읽고 먼저 판단한 뒤 눌러서 확인하세요.

상황 ①좋아하는 배우 얼굴로 광고 모델 이미지를 만들어 가게 SNS에 올린다 생각 정리 보기

안 됨 — 실제 사람의 얼굴은 초상권이 있습니다. 가상의 인물로 만들거나, 허락받은 사진만 씁니다.

상황 ②내가 직접 찍은 우리 가게 빵 사진을 올려 배경만 바꾼 광고 이미지를 만든다 생각 정리 보기

괜찮음 — 내가 찍은 사진은 참고 이미지로 써도 됩니다. DAY 03에서 이 방법을 배웁니다.

상황 ③유명 애니메이션 스튜디오 이름을 넣어 "○○풍으로 그려줘"라고 요청한다 생각 정리 보기

바꿔서 요청 — 이름 대신 원하는 특징(색감, 선, 분위기)을 말로 설명합니다. 결과도 더 내 뜻대로 나옵니다.

상황 ④AI로 만든 음료 광고에 "피로 회복 효과 100%"라는 문구를 넣는다 생각 정리 보기

안 됨 — 확인되지 않은 효능·수치는 과장 광고입니다. 분위기·느낌을 전하는 문구로 바꿉니다.

AI 쓰기 전 3초 체크

1남의 얼굴·작품·상표가 들어가지 않았나?
2사실이 아닌 내용이 들어가지 않았나?
3마지막에 내가 확인했나?

8.AI를 대하는 마음가짐 3가지

2교시 · 10분

① AI는 "하버드를 나온 신입 사원"이다

  • · 아는 것도 많고 손도 빠르다
  • · 하지만 내가 머릿속에 그린 장면, 이 이미지를 어디에 쓸지는 전혀 모른다
  • · "예쁘게 만들어 줘" 한마디만 하면? → AI가 생각하는 "예쁨"을 가져온다

→ 똑똑한 신입에게 일을 맡기듯, 무엇을·어디에·어떤 느낌으로 쓸지 설명해 주기

② AI랑 싸우지 마라

  • · "아니 그게 아니라고!", "왜 말귀를 못 알아들어?"
  • · 다그치는 말은 AI를 가르치는 게 아니라 대화의 맥락을 흐리는 행동
  • · 대화가 꼬이면 AI는 앞의 틀린 결과와 화난 말까지 참고해서 더 헷갈린다

→ "무엇은 그대로 두고, 무엇만 바꿔 줘"라고 차분하게 한 가지씩 말하기
→ 너무 꼬였다면 새 채팅에서 제대로 된 요청으로 다시 시작

③ 원하는 결과가 안 나오면 AI 탓이 아니라 내 요청 탓

  • · "AI 별로네"가 아니라 "내가 무엇을 덜 알려줬지?"를 먼저 생각하기
  • · 대부분은 대상·장소·구도·분위기·용도 중 하나가 빠져 있다

→ 이어서 배울 "이미지 프롬프트 6칸"이 그 빠진 것을 채우는 방법

AI는 똑똑한 신입, 싸우지 말고 설명하고, 안 되면 내 요청부터 돌아보기

9.프롬프트 사용 요령 — 콘텐츠 편

2교시 · 5분

① 구체적으로

"강아지 그려줘" → "잔디밭에서 공을 물고 뛰는 갈색 푸들"

② 용도를 알려주기

"인스타 프로필용", "쇼핑몰 대표 사진용", "포스터 배경용"

③ 모양을 정하기

비율(정사각형·세로·가로), 사진인지 그림인지

④ 한 번에 다 하려 하지 않기

처음 결과를 보고 이어서 고치기

⑤ 고칠 때는 "유지할 것 + 바꿀 것"

"강아지는 그대로, 배경만 바닷가로"

⑥ 결과는 내가 확인하기

손가락·글자·물건 모양이 이상하지 않은지

10.실습: 짧게 vs 자세히 비교하기

2교시 · 10분 · 실습 SET 02

두 요청을 각각 새 채팅에서 보내고 결과를 비교합니다.

A — 짧은 요청
상자를 클릭하면 바로 복사돼요

커피 사진 만들어줘.

AI가 장소·빛·구도·분위기를 마음대로 정합니다.

B — 자세한 요청
상자를 클릭하면 바로 복사돼요

카페 창가 나무 테이블 위에 놓인 따뜻한 라테 한 잔 사진을 만들어줘. 아침 햇살이 옆에서 들어오고, 잔 위로 김이 살짝 올라와. 컵은 화면 가운데, 배경은 흐릿하게. 카페 인스타그램에 올릴 편안한 분위기로, 정사각형으로 만들어줘.

내가 정한 대로 나올 가능성이 높습니다.

11.이미지 프롬프트 기본 구조 6칸

2교시 · 5분

B 요청이 잘 나온 이유는 아래 6칸이 채워져 있었기 때문입니다.

칸무엇을 쓰나예
무엇을주인공노란 우비를 입은 아이
어디서장소·배경비 오는 골목길
어떻게구도·거리전신이 보이게, 눈높이에서
빛·색조명과 색감흐린 날 부드러운 빛, 파스텔 톤
느낌분위기·스타일동화책 삽화 같은, 따뜻한
용도어디에 쓸지·비율인스타 피드용 세로 4:5
  • · 6칸을 매번 다 채우지 않아도 됩니다. 처음엔 3~4칸만 채우고, 결과를 보며 더합니다.
  • · 구도·조명·화풍 키워드는 DAY 02에서 자세히 배웁니다.

12.실습: 6칸 채워 만들고 이어서 고치기

2교시 · 10분 · 실습 SET 03

고를 수 있는 주제 예시 (하나 고르기)

비 오는 날의 작은 서점 캠핑장의 밤, 모닥불과 텐트 바닷가 카페의 여름 오후 눈 내리는 시골 마을 기차역 벚꽃 길을 산책하는 강아지 내가 좋아하는 음식이 차려진 식탁
모닥불과 작은 텐트 이미지를 만들어줘. 장소는 숲속 캠핑장이고, 텐트와 모닥불이 함께 보이게 조금 멀리서. 밤, 모닥불의 주황빛과 별빛. 아늑하고 조용한 분위기의 사진. 블로그 대표 이미지로, 가로 16:9로 만들어줘.

같은 채팅에서 하나씩 이어서 요청하기

① "[유지할 것]은 그대로 두고, 시간만 [바꿀 것 — 예: 새벽]으로 바꿔줘"
② "사진 말고 [그림 느낌 — 예: 따뜻한 수채화]로 바꿔줘"
③ "세로 비율(9:16)로 다시 만들어줘"

확인하기

  • 이어서 고칠 때 "유지할 것"이 정말 유지되었나?
  • 이상한 부분(물건 모양, 손가락, 글자)은 없나?

13.실습: 내 SNS 프로필 이미지 만들기

2교시 · 15분 · 실습 SET 04

방법 ① 사진 없이 말로 설명하기 (추천)

나의 생김새를 글로 설명해서 만듭니다.

방법 ② 내 사진을 올려서 바꾸기 (선택)

올려도 괜찮은 사진만 사용합니다.

스타일 예시 (하나 고르기)

둥근 얼굴의 3D 캐릭터 부드러운 수채화 인물화 단순한 선과 몇 가지 색의 일러스트 점토 인형 느낌 따뜻한 색연필 그림 동물 캐릭터로 바꾼 나
SNS 프로필 이미지를 만들어줘. 인물: 짧은 단발머리, 둥근 안경, 줄무늬 티셔츠를 입은 30대 여성 표정·동작: 활짝 웃으며 손을 흔드는 배경: 연한 하늘색 단색 배경 스타일: 둥근 얼굴의 3D 캐릭터 프로필 사진 동그라미 안에 잘 들어가도록 얼굴이 가운데 오게, 정사각형으로 만들어줘.

이어서 요청하기

"표정만 [예: 윙크하는] 표정으로 바꿔줘"
"배경색만 [예: 연두색]으로 바꿔줘"

마음에 드는 것 하나를 "프로필_이름"으로 저장하세요. 빨리 끝났다면 스타일 3가지로 만들어 비교해 보세요.

14.나에게 맞게 설정하기 — 맞춤 지침

2교시 · 5분

맞춤 지침

설정 → "나에 대한 정보(맞춤 지침)"에 적어 두면, 매번 설명하지 않아도 Gemini가 나에게 맞게 답합니다.

나는 동네 꽃집의 SNS 홍보를 맡고 있어. 주로 홍보 이미지, 카드뉴스 문구, 짧은 영상 아이디어에 사용할 거야. 답변은 핵심부터 짧게, 선택지가 있으면 3개 정도로 줘. 영어 전문용어는 쉬운 우리말로 바꿔서 써줘.

확인하기 — 설정 전에 했던 질문을 새 채팅에서 다시 보내 답이 어떻게 달라졌는지 비교합니다.
