DAY 02AI 콘텐츠제작

여러 구도 · 여러 콘셉트로 바꾸기

이미지 한 장을 만들고 끝내지 않습니다. 같은 제품을 여러 구도로, 여러 콘셉트로 바꿔 보며 키워드 하나로 결과가 얼마나 달라지는지 직접 확인하고, 같은 스타일의 아이콘 세트까지 만듭니다.

1.오늘의 수업

수업 난이도

Gemini로 이미지를 만들어 본 초보자

수업방식

키워드를 익히고 같은 제품을 여러 버전으로 바꿔 보는 실습

핵심목표

제품은 유지하고 구도·빛·콘셉트·화풍만 바꿔 원하는 방향으로 이미지를 다듬기

새봄스튜디오 오늘의 의뢰

가상의 텀블러 브랜드 '하루잔'이 새 텀블러 사진을 요청했습니다.

"쇼핑몰, 인스타그램, 계절 이벤트에 쓸 사진이 여러 장 필요해요. 실제 촬영 대신 AI로 다양한 버전을 먼저 보고 싶어요."

'하루잔'은 수업용 가상 브랜드입니다. 원하면 내 물건이나 다른 제품으로 바꿔도 됩니다.

3.구도가 바뀌면 이야기가 바뀐다

1교시 · 5분

사진작가는 같은 제품도 여러 각도에서 찍습니다. 같은 텀블러라도 어떻게 보여 주느냐에 따라 전하는 말이 달라집니다.

이렇게 보면전하는 말어디에 쓸까
정면에서"이런 제품입니다"쇼핑몰 대표 사진
위에서 내려다보면"이런 일상에 어울려요"인스타 피드
아주 가까이"이런 질감이에요"상세 페이지
멀리서 넓게"이런 공간에 있어요"배너·광고

구도는 "무엇을 보여 줄지"를 정하는 일입니다.

4.실습: 기본 제품 사진 만들기

1교시 · 8분 · 실습 SET 01

무광 민트색 스테인리스 텀블러, 뚜껑은 흰색인 제품 사진을 만들어줘. 배경: 밝은 회색 단색 배경 구도: 정면, 제품이 가운데 빛: 부드러운 스튜디오 조명 쇼핑몰 대표 사진으로 쓸 수 있게 깔끔하게, 정사각형으로 만들어줘. 로고나 글자는 넣지 말아줘.

마음에 드는 결과 하나를 "기본 사진"으로 정하고 저장하세요. 앞으로 이 채팅에서 계속 이어서 요청합니다. 같은 채팅이어야 제품 모양이 유지되기 쉽습니다.

5.실습: 같은 제품 6가지 구도로 만들기

1교시 · 25분 · 실습 SET 02

쓰기 전에 알아둘 키워드 — 구도

거리 — 얼마나 가까이서 볼까
아주 가까이 (매크로) 표면 질감, 물방울가까이 (클로즈업) 제품이 화면을 꽉 채움중간 제품 + 주변 소품 조금멀리 넓게 (와이드) 공간 전체, 제품은 작게
각도 — 어디서 볼까
정면 (눈높이) 가장 기본, 형태가 잘 보임45도 비스듬히 입체감, 쇼핑몰에서 많이 씀위에서 내려다보기 (탑뷰) 책상 위 물건들과 함께펼쳐 놓고 위에서 (플랫레이) 소품을 가지런히 늘어놓은 구성아래에서 올려다보기 (로우앵글) 크고 당당해 보임
배치 — 화면 어디에 둘까
가운데 두기한쪽에 두고 여백 많이 글자 넣을 자리배경 흐리게 제품만 또렷하게손에 들고 있는 모습 사용 장면

용어를 몰라도 괜찮아요. "조금 더 가까이", "위에서 내려다보게"처럼 쉬운 말로 써도 AI가 알아듣습니다.

같은 채팅에서 구도만 바꿔 요청합니다.

방금 만든 텀블러의 색, 모양, 뚜껑은 그대로 두고 구도만 위에서 내려다보기로 바꿔줘. 노트북과 다이어리가 놓인 책상 위에 있게 해줘.

6가지 해 보기

  • ① 45도 비스듬히
  • ② 아주 가까이 — 표면 질감과 물방울
  • ③ 위에서 내려다보기 — 노트북·다이어리가 놓인 책상 위
  • ④ 펼쳐 놓고 위에서 — 텀블러와 소품(열쇠, 이어폰, 선글라스)을 가지런히
  • ⑤ 아래에서 올려다보기 — 파란 하늘 배경
  • ⑥ 한쪽에 두고 여백 많이 — 오른쪽에 글자 넣을 빈자리

마음에 안 드는 한 장만 골라 고치기

"[몇 번] 사진에서 [문제 — 예: 텀블러 색이 파랗게 바뀌었어]. 색은 기본 사진과 같은 민트색으로 다시 만들어줘."

정리하기 — 어디에 쓸까?

6장을 보고 용도에 맞는 번호를 짝지어 봅니다.

쇼핑몰 대표[   ]번
상세 페이지[   ]번
인스타 피드[   ]번
광고 배너[   ]번

확인하기

  • 6장 모두 같은 제품처럼 보이나? (색·모양·뚜껑)
  • 이상하게 바뀐 곳이 있으면 "그 부분만" 고쳐 달라고 했나?

6.실습: 같은 구도, 빛만 바꾸기

1교시 · 12분 · 실습 SET 03

쓰기 전에 알아둘 키워드 — 조명과 색감

조명
부드러운 스튜디오 조명 그림자 적고 깔끔창가 자연광 편안하고 일상적역광 뒤에서 비치는 빛, 테두리가 빛남노을빛 따뜻하고 낭만적어두운 배경에 한 줄기 빛 고급스럽고 극적네온 조명 밤, 도시, 젊은 느낌
색감
파스텔 톤선명한 원색흑백·모노톤따뜻한 톤차가운 톤빈티지 필름 느낌

세 가지 비교하기

창가 자연광
+ 따뜻한 톤
어두운 배경에 한 줄기 빛
+ 차가운 톤
네온 조명
+ 선명한 원색

같은 구도라도 빛이 바뀌면 "어떤 사람에게 팔 제품인지"까지 달라 보입니다.

7.콘셉트 = 분위기 + 계절 + 화풍

2교시 · 3분

콘셉트

구도와 빛이 "어떻게 찍을까"라면, 콘셉트는 "어떤 세계에 놓을까"입니다.

분위기

미니멀 / 빈티지 / 고급 / 자연 / 미래 / 귀여운

계절

봄 / 여름 / 가을 / 겨울 / 명절·기념일

화풍

사진 → 그림·3D·점토 등 표현 방식 자체를 바꾸기

8.실습: 분위기 바꾸기

2교시 · 10분 · 실습 SET 04

분위기 예시 — 3개 골라 해 보기

미니멀 흰 배경, 소품 없이, 넓은 여백
빈티지 낡은 나무 테이블, 오래된 책, 필름 사진 느낌
고급 대리석, 금색 포인트, 어두운 배경
자연 이끼 낀 바위, 나뭇잎, 흐르는 물
미래 반짝이는 금속 공간, 파란 빛
귀여운 알록달록 풍선, 사탕, 파스텔
기본 사진의 텀블러는 그대로 두고 고급 콘셉트의 광고 사진으로 바꿔줘. 배경과 소품: 대리석 테이블, 금색 스푼, 어두운 배경 30대 직장인에게 어울리는 느낌으로 만들어줘.

확인하기 — 분위기가 바뀌어도 텀블러는 같은 제품인가요?

9.실습: 계절 버전 만들기

2교시 · 10분 · 실습 SET 05

계절 이벤트용 사진 4장을 만듭니다.

봄벚꽃, 연한 분홍, 피크닉 매트
여름바닷가 모래, 파란 하늘, 얼음
가을단풍잎, 따뜻한 니트, 창밖 비
겨울눈 쌓인 창가, 털장갑, 따뜻한 조명

이어서 요청 — 4장을 한 세트로 맞추기

"4장 모두 [통일할 것 — 예: 텀블러 위치를 화면 가운데로] 맞춰서 다시 만들어줘."

여러 장을 한 세트로 쓸 때는 "통일할 것"을 따로 말해 줍니다.

10.실습: 화풍 바꾸기

2교시 · 12분 · 실습 SET 06

쓰기 전에 알아둘 키워드 — 화풍

따뜻한 수채화 연필 스케치 부드러운 3D 캐릭터풍 점토(클레이) 인형 단순한 평면 일러스트 픽셀 아트 옛날 게임 그림 종이를 오려 붙인 느낌 유화 만화책 펜 선 스티커 느낌 흰 테두리

작가 이름 대신 특징으로

"○○ 작가 풍", "○○ 스튜디오 풍"처럼 실제 이름은 쓰지 않습니다. 대신 "부드러운 파스텔 수채화, 손으로 그린 따뜻한 선"처럼 특징을 설명합니다.

기본 사진의 텀블러를 사진이 아닌 점토(클레이) 인형 스타일로 다시 그려줘. 민트색과 흰 뚜껑은 그대로 두고, 배경은 연한 노란색 단색.

세 가지 이상 비교하고 한 줄 적기

  • 따뜻한 수채화
  • 점토 인형 느낌
  • 픽셀 아트
  • (자유) 키워드 상자에서 하나

11.실습: 같은 스타일의 아이콘 세트

2교시 · 15분 · 실습 SET 07

아이콘은 여러 개가 "같은 스타일"이어야 한 세트처럼 보입니다. 새 채팅에서 시작하세요.

주제 예시 (하나 고르기)

하루잔 쇼핑몰 안내 배송, 교환, 세척 방법, 보온, 선물 포장, 문의
카페 메뉴 아메리카노, 라테, 케이크, 샌드위치, 주스, 쿠키
나의 하루 기상, 출근, 점심, 운동, 독서, 잠
여행 준비물 여권, 캐리어, 카메라, 선글라스, 지도, 비행기
날씨 맑음, 흐림, 비, 눈, 바람, 번개
하루잔 쇼핑몰 안내 아이콘 6개를 한 장에 만들어줘. 아이콘: 배송, 교환, 세척 방법, 보온, 선물 포장, 문의 스타일: 둥근 모서리의 단순한 평면 일러스트, 선 굵기 같게 색: 민트색과 흰색 두 가지 색만 배경은 흰색, 아이콘끼리 간격을 넓게, 글자는 넣지 말아줘.

이어서 요청하기

① "[아이콘 이름]만 더 단순하게 다시 그려줘"
② "같은 스타일로 [아이콘 2개]를 더 만들어줘"
③ "색만 [다른 색 조합]으로 바꾼 버전도 만들어줘"

확인하기

  • 6개의 선 굵기·색·모서리가 같은가?
  • 작게 줄여도 무엇인지 알아볼 수 있나?
