3.참고 이미지 = "이걸 보고 해 줘"

1교시 · 3분

참고 이미지

말로 설명하는 대신 사진을 함께 올려 "이걸 보고 만들어 줘"라고 하는 방법입니다. 올릴 때는 "이 사진에서 무엇을 참고할지"를 꼭 말합니다.

"이 사진의 컵 모양을 참고해서" → 물건
"이 사진의 색감을 참고해서" → 분위기
"이 사진의 구도를 참고해서" → 배치
"첫 번째 사진의 빵, 두 번째 사진의 배경" → 여러 장은 번호로
올려도 되는 사진

내가 찍은 사진, 내가 만든 이미지, AI로 만든 이미지

올리면 안 되는 사진

인터넷에서 가져온 남의 사진·그림, 실제 브랜드 광고, 다른 사람 얼굴

4.실습: 내 사진 분석받고 배경 바꾸기

1교시 · 10분 · 실습 SET 01

STEP 01 사진 찍기 (2분)

책상 위 물건 하나를 휴대폰으로 찍습니다. (컵, 펜, 안경, 이어폰, 과자 봉지 등)

  • · 물건이 화면 가운데, 너무 어둡지 않게
  • · 휴대폰 Gemini 앱에서 바로 올려도 되고, PC로 옮겨서 올려도 됩니다

STEP 02 바로 고치지 말고 먼저 분석받기

AI가 무엇을 보고 있는지 먼저 확인하면, 무엇을 유지하고 무엇을 바꿀지 말하기 쉬워집니다.

STEP 03 배경 바꾸기 — 같은 채팅에서 이어서

첨부한 사진의 머그컵은 모양·색·손잡이를 그대로 유지해줘. 배경만 햇살이 드는 카페 창가 나무 테이블로 바꿔서 인스타 광고 사진처럼 만들어줘.

확인하기 — 물건의 모양·글자·색이 원래 사진과 같은가요?

5.실습: 일부분만 고치기

1교시 · 5분 · 실습 SET 02

전체를 다시 만들지 않고 한 부분만 고칠 수 있습니다. 아래 기본형을 기억해 두면 앞으로 계속 씁니다.

해 보기 — 2개 이상

① "[물건] 옆에 [추가할 것 — 예: 작은 화분]을 하나 놓아줘"
② "[지울 것 — 예: 뒤쪽의 컵]만 지워줘"
③ "소품이 너무 많아. [물건]과 조명은 그대로, 소품만 1~2개로 줄여줘"
④ "그림자만 조금 더 부드럽게 해줘"

6.실습: 두 장 합치기

1교시 · 7분 · 실습 SET 03

STEP 01 재료 두 장 만들기 — 새 채팅에서

재료 A — 소금빵
상자를 클릭하면 바로 복사돼요

갓 구운 소금빵 3개가 나무 도마 위에 놓인 사진을 만들어줘. 배경은 흰색.

재료 B — 빵집 진열대
상자를 클릭하면 바로 복사돼요

아침 햇살이 드는 작은 동네 빵집 진열대 사진을 만들어줘. 사람은 없이.

두 장 모두 다운로드해 둡니다.

STEP 02 합치기 — 각 이미지의 역할을 번호로 말하기

새 채팅에 A를 먼저, B를 두 번째로 첨부하고 요청합니다.

첫 번째 이미지의 소금빵과 도마는 형태를 최대한 유지해줘. 두 번째 이미지에서는 배경과 조명을 참고해줘. 아침 햇살, 따뜻한 톤으로 맞추고, 빵집 광고 사진처럼 만들어줘. 빵이 가장 눈에 띄게 해줘.

확인하기

  • 두 사진의 빛 방향이 어색하지 않은가?
  • 빵 크기가 배경에 비해 너무 크거나 작지 않은가?

마음에 드는 결과를 "소금빵_광고"로 저장하세요. 오늘 SET 04 · 05에서 계속 씁니다.

8.실습: 같은 제품, 여러 결과물로 바꾸기

1교시 · 15분 · 실습 SET 04

"소금빵_광고" 이미지를 첨부하고, 아래 중 3가지를 골라 만듭니다. 각 번호마다 먼저 만들고, 이어서 한 번 더 바꿔 봅니다.

  • ① 패키지 → 실물처럼 — 빵 봉투를 디자인하고, 이어서 "이 봉투가 실제 매장 진열대에 놓인 사진처럼" (/packaging → /mockup)
  • ② 잡지 표지 → 화보 — 동네 빵집 특집 잡지 표지(위쪽 제목 자리), 이어서 "표지 말고 안쪽 화보 한 페이지로" (/magazinecover → /editorial)
  • ③ 옥외 광고판 → 3D 옥외 광고 — 도심 건물 외벽 광고판, 이어서 "거대한 소금빵이 광고판 밖으로 튀어나오게" (/billboard → /3d billboard)
  • ④ 메뉴판 — 소금빵·크루아상·식빵 3가지가 들어간 가게 메뉴판, 가격 칸은 비워 두기 (/menu)
  • ⑤ 여러 방향에서 — 소금빵을 위·옆·자른 단면으로 한 화면에 (/360view)
(/magazinecover) 첨부한 이미지의 소금빵 모양과 따뜻한 색감은 그대로 두고 동네 빵집 특집 잡지 표지로 만들어줘. 위쪽 1/3은 잡지 제목 자리로 비워 두고, 소금빵은 아래쪽 가운데에 크게. 따뜻하고 여유로운 주말 아침 느낌으로.

비교하기 — 한 줄씩 적기

같은 소금빵이 결과물 형태에 따라 어떻게 달라졌나요? 예) 패키지 — 가게 이름이 중심 / 3D 광고 — 눈길을 끄는 크기와 입체감

글자와 숫자 주의

  • · 메뉴판·패키지의 글자가 틀리면 글자 없이 만들고, 2교시의 "슬라이드로 글자 넣기"로 넣습니다
  • · 가격·영양 정보처럼 받지 않은 숫자는 만들지 않게 합니다

9.실습: SNS 광고 · 홈페이지 첫 화면 — 용도별 비율

1교시 · 10분 · 실습 SET 05

같은 광고라도 올리는 곳마다 모양이 다릅니다.

올리는 곳비율
인스타 피드세로 4:5 (또는 정사각 1:1)
인스타 스토리·릴스세로 9:16 (휴대폰 화면 가득)
홈페이지 첫 화면·배너가로 16:9
가게 포스터세로 3:4 (A4에 가깝게)

비율만 바꾸면 끝이 아닙니다. 글자 넣을 자리(여백)와 제품 위치도 다시 정합니다.

만들 것 — 2가지

SNS 광고 · 세로 4:5빵은 오른쪽 아래, 왼쪽·위쪽에 글자 자리 (/meta ad)
홈페이지 첫 화면 · 가로 16:9빵은 오른쪽, 왼쪽에 가게 이름·제목·버튼 자리 (/heroimage)

문구 넣기 — 둘 중 하나에만

"이미지에 [문구 — 예: 오늘 아침 갓 구운 소금빵]이라는 글자를 넣어줘. 글꼴은 [예: 둥글고 굵은 손글씨 느낌], 색은 [예: 흰색]으로, [위치]에 넣어줘."

글자가 틀리게 나오면 2교시의 "슬라이드로 글자 넣기" 방법을 씁니다.

광고 문구에는 확인되지 않은 효능·수치("살 안 찌는", "1위")를 넣지 않습니다.

10.카드뉴스란?

2교시 · 5분

카드뉴스

여러 장의 이미지를 옆으로 넘기며 읽는 인스타그램 게시물입니다. 한 장에 한 가지 내용, 글은 짧게, 모든 장이 같은 디자인입니다.

기본 구성 — 5장

1장 · 표지눈길을 끄는 제목 (넘겨 보고 싶게)
2~4장 · 본문한 장에 한 가지 정보
5장 · 마무리정리 한 줄 + 다음 행동 (예: "매장에서 만나요", "저장해 두세요")

잘 만든 카드뉴스의 특징

  • · 표지 제목만 봐도 무엇에 대한 글인지 안다
  • · 한 장에 글이 3줄을 넘지 않는다
  • · 색·글꼴·배치가 5장 모두 같다

11.실습: 주제 고르고 5장 문구 짜기

2교시 · 10분 · 실습 SET 06

주제 예시 — 하나 고르기

보리밭베이커리 소금빵을 더 맛있게 먹는 방법 3가지
보리밭베이커리 빵을 오래 보관하는 요령
나들이 봄 나들이 도시락 챙길 것 5가지
집콕 비 오는 날 집에서 할 수 있는 일
식물 초보 식집사를 위한 화분 물 주기 요령
동네 우리 동네 산책로 소개 (가상의 동네)
인스타그램 카드뉴스 5장의 문구를 만들어줘. 주제: 보리밭베이커리 — 소금빵을 더 맛있게 먹는 방법 3가지 읽는 사람: 빵을 좋아하는 20~30대 구성: 1장 표지 / 2~4장 본문 / 5장 마무리 장마다 제목 한 줄 + 설명 2줄 이내로 짧게 써줘. 사실이 확실하지 않은 내용은 [확인 필요]로 표시해줘.

이어서 요청하기

① "표지 제목을 더 궁금하게 5가지 버전으로"
② "본문 설명을 더 짧게, 한 줄씩"
③ "장마다 어울리는 그림 설명도 한 줄씩 붙여줘"

최종 문구와 그림 설명을 메모장이나 Google 문서에 붙여 둡니다.

12.실습: 같은 스타일의 이미지 5장

2교시 · 15분 · 실습 SET 07

5장이 한 세트로 보이려면 "스타일 고정 문장"을 한 번 정해 두고 매번 붙입니다.

카드뉴스 2장 이미지를 만들어줘. 내용: 반으로 자른 소금빵을 토스터에 살짝 데우는 모습 스타일: 부드러운 파스텔 평면 일러스트, 크림색·갈색·연두색, 크림색 단색 배경, 세로 4:5, 글자는 넣지 말 것, 위쪽 1/3은 비워 둘 것

확인하기

  • 5장의 색·화풍·배경이 같은가?
  • 모든 장에 글자 넣을 빈자리가 있는가?
  • 튀는 한 장이 있으면 "1장과 같은 스타일로" 다시 만들기

13.실습: 글자 넣어 완성하기

2교시 · 15분 · 실습 SET 08

방법 A — Gemini가 글자까지 넣기 (빠름)

"이 이미지 [위치 — 예: 위쪽 빈자리]에 "[문구]"라는 글자를 넣어줘. 글꼴은 [예: 굵은 고딕], 색은 [예: 진한 갈색]."

한글이 틀리거나 뭉개지면 방법 B로

방법 B — Google 슬라이드로 글자 넣기 (정확, 추천)

이미지는 AI가, 글자는 내가 넣습니다. 글자가 틀릴 걱정이 없고 5장의 글자 위치를 똑같이 맞출 수 있습니다.

방법 B 따라 하기

  1. 1새 Google 슬라이드 → 이름 "03_카드뉴스_이름"
  2. 2파일 → 페이지 설정 → 맞춤 → 1080 × 1350 픽셀 (세로 4:5) — 단위가 인치로 나오면 목록에서 "픽셀" 선택
  3. 3장마다 이미지 넣기 — 삽입 → 이미지 → 컴퓨터에서 업로드 → 화면 가득 늘리기
  4. 4텍스트 상자로 제목·설명 넣기 — 5장 모두 같은 글꼴·크기·색·위치. 첫 장 글자 상자를 복사해서 다음 장에 붙여넣으면 위치가 같아집니다
  5. 5장마다 이미지로 저장 — 파일 → 다운로드 → PNG 이미지 (지금 보고 있는 장이 저장됨)

메뉴 이름은 업데이트에 따라 다를 수 있습니다. 막히면 Gemini에게 "Google 슬라이드에서 페이지 크기를 1080×1350으로 바꾸는 순서를 알려줘"라고 물어보세요.

최종 점검

  • 표지 제목이 한눈에 읽히는가?
  • 한 장에 글이 3줄 이내인가?
  • 5장 모두 글자 위치·색이 같은가?
  • 확인 안 된 내용이 들어가지 않았나?
