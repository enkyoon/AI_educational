DAY 03AI 스마트스튜디오

AI 광고 이미지 제작 · 기획부터 수정까지

무엇을 먼저 정하고, 어떤 조건을 요청에 넣고, 결과를 어떻게 고칠지 배웁니다. 각자 고른 주제로 광고를 만들며 같은 방법을 다른 이미지 작업에도 적용해 봅니다.

1.이미지 수업이 영상으로 이어지는 이유

앞으로는 원하는 캐릭터·제품·배경을 이미지로 먼저 준비하고, 그 이미지에 움직임을 더해 영상 장면을 만드는 방식을 배웁니다. 이를 이미지 투 비디오(image-to-video)라고 합니다.

먼저 준비하기원하는 모습의 이미지

대상의 형태 · 배경 · 구도 · 빛

영상에서 더하기대상과 카메라의 움직임

무엇이 어떻게 움직일지 요청하기

영상의 출발이 되는 이미지에서 제품 모양이 달라지거나 주인공이 잘 보이지 않으면, 원하던 영상을 만들기 어렵습니다. 제품 모양이 정확하고, 주인공과 배경이 원하는 모습으로 보이는 이미지를 먼저 준비해야 합니다. 그래서 이미지를 만들고 고치는 방법을 먼저 배우고 있습니다.

글만으로 영상을 만드는 방법도 있습니다. 이 과정에서는 이미지로 모습을 먼저 정하고 영상으로 연결하는 방법을 함께 배웁니다. 이미지를 준비한 뒤에는 대상과 카메라가 어떻게 움직일지 정합니다.

요청 순서와 조건 정하기

참고 사진에서 무엇을 가져올지 지정하고, 사진을 확인한 뒤 문구를 넣습니다. 문제가 생기면 고칠 부분을 좁혀 요청합니다.

오늘의 핵심은 원하는 결과를 얻기 위해 요청을 나누는 방법입니다. 참고할 부분과 유지할 모습을 먼저 정하고, 결과를 확인한 뒤 필요한 부분만 고쳐 광고를 완성합니다.

2.좋은 결과를 얻기 위한 요청 순서

원하는 장면을 구체적으로 설명하고, 나온 결과를 기준과 비교하며 고치는 방법을 배웁니다. 오늘은 다음 순서로 광고를 만듭니다.

목적 정하기 → 참고 사진 확인하기 → 유지할 것과 배치 요청하기 → 사진 확인하고 고치기 → 문구 넣고 확인하기
요청하기 전에 정할 것요청에 넣는 이유
누구에게 무엇을 보여 줄지광고를 볼 사람과 소개할 내용을 알려 주면 배경과 문구를 고를 기준이 생깁니다.
각 사진에서 참고할 부분제품 모양을 가져올 사진과 배경을 참고할 사진을 나눠 알려 줍니다. 꼭 유지할 특징도 함께 적습니다.
대상 위치·글자 자리·비율사진을 만들 때부터 제목을 놓을 자리를 비워 둡니다. 주인공을 가리거나 사진을 다시 만드는 일을 줄이려는 준비입니다.
사진을 확인한 뒤 넣을 문구먼저 대상의 모양과 합성 상태를 확인합니다. 사진을 골랐으면 확정한 문구와 위치를 정해 글자를 넣습니다.

완성 예시에서 요청할 조건 찾아보기

아래는 가상 향수 브랜드 ‘초록결’의 원본 사진과 완성 광고입니다. 어떤 모습을 유지했고, 제목 자리는 어디에 두었는지 살펴보세요. 이미지를 누르면 크게 볼 수 있습니다.

이 광고를 요청한다면 병 모양·은색 뚜껑·연두색 액체를 유지할 조건으로 적고, 제목 위치와 글자 색을 따로 정해야 합니다. 내 광고에서도 꼭 유지할 특징과 글자 넣을 자리를 먼저 골라 보세요.

연습 결과물은 세로 4:5 광고 이미지 한 장과 게시글 본문입니다. 글자 없는 사진과 수정 가능한 슬라이드도 저장합니다. 도구는 Gemini와 Google 슬라이드를 사용하며, 이전 수업에서 만든 파일은 없어도 됩니다.

4.실습: 광고에서 전할 내용 정하기

실습 SET 01

사진을 만들기 전에 누구에게, 무엇을, 어떤 이유로 소개할지 정합니다. 같은 카페라도 출근길 음료를 소개할지, 쉬어 갈 공간을 소개할지에 따라 장면이 달라집니다. AI에게 먼저 방향을 제안받고, 목적에 맞는 하나를 골라 사진과 문구의 기준으로 사용합니다.

STEP 01 내 광고의 방향 정하기 — 새 채팅에서

인스타그램 광고 게시물을 기획하려고 해. 가게 또는 활동: 가상의 향수 브랜드 '초록결' 소개할 것: 시트러스 향수 보는 사람: 새로운 향을 찾는 사람 전할 내용: 직접 향을 비교하고 고르는 즐거움 마무리 안내: 제품 소개 보기 확정된 정보: 시트러스 향수 컬렉션을 소개한다는 것 광고 방향 3가지를 핵심 메시지와 사진 장면으로 제안해줘. 가격·할인·효능·운영 정보는 만들지 말아줘.

접힌 예시는 목록에 없는 향수 광고입니다. 문장 구조를 보고, 내용은 내가 고른 주제로 바꿔 쓰세요.

5.실습: 참고 사진 준비하고 분석받기

실습 SET 02

사진을 첨부한 뒤에는 대상의 형태·색·배경을 먼저 확인합니다. AI가 다르게 설명한 부분은 바로잡고, 내 광고에서 꼭 유지할 특징을 고릅니다. 이 특징을 다음 합성 요청에 넣어 원본과 비교할 기준으로 씁니다.

STEP 01 광고의 주인공이 될 이미지 준비하기

6.실습: 두 이미지에서 필요한 요소 가져오기

실습 SET 03

첫 번째 이미지에서는 대상, 두 번째 이미지에서는 배경이나 분위기를 가져옵니다. “두 사진을 합쳐 줘”라고만 하면 어느 사진의 무엇을 사용할지 정해지지 않습니다. 가져올 대상·유지할 특징·참고할 배경·새 배치를 나눠서 요청합니다.

STEP 01 광고에 어울리는 배경 이미지 준비하기 — 같은 채팅에서

빵집·카페는 테이블이나 진열 공간, 운동센터·공방은 도구가 놓일 수업 공간처럼 고른 광고에 맞는 배경을 준비합니다. 이미 공간 사진을 주인공으로 골랐다면 두 번째 이미지는 색감이나 배치 참고용으로 써도 됩니다.

배경 이미지도 내려받아 둡니다. 다음 단계에서 주인공 사진과 배경 사진을 함께 첨부합니다.

STEP 02 두 사진의 역할을 지정해 합성하기 — 새 채팅에 두 장 첨부

주인공 사진을 먼저, 배경이나 분위기 사진을 두 번째로 첨부합니다. 사진 순서와 요청의 번호가 맞는지 확인하세요. 첫 번째 사진을 언급할 때는 유지할 대상과 특징을, 두 번째 사진을 언급할 때는 가져올 배경이나 색감을 적습니다.

두 이미지를 활용해 인스타그램 광고 사진 한 장을 만들어줘. 첫 번째 이미지의 연두색 향수병은 사각 형태와 은색 뚜껑을 유지해줘. 두 번째 이미지의 젖은 바위와 폭포 배경을 활용해줘. 향수병은 아래쪽 가운데에 놓고 위쪽은 제목 자리로 비워줘. 빛 방향과 그림자를 자연스럽게 맞추고, 시원하고 깨끗한 분위기로 해줘. 새로운 향을 찾는 사람에게 시트러스 향수를 소개할 광고, 세로 4:5. 글자는 넣지 말아줘.

STEP 03 합성이 자연스러운지 확인하기

두 사진이 한 장면처럼 보이나요?

  • 대상의 형태와 색이 원본과 같은가요?
  • 배경에 비해 대상이 지나치게 크거나 작지 않나요?
  • 대상과 배경의 빛 방향·그림자가 어울리나요?

10.실습: 글자를 넣어 광고 이미지 완성하기

실습 SET 07

먼저 글자 없는 사진을 확정하고, 그다음 정확한 문구와 위치를 정해 글자를 넣습니다. 이 실습에서는 Google 슬라이드에서 글자를 직접 입력하고 수정합니다. Gemini로 글자까지 넣고 싶다면 아래의 다른 방법을 사용하세요.

STEP 01 세로 광고 화면 준비하기

  1. 새 Google 슬라이드를 엽니다.
  2. 파일 이름을 03_인스타광고_이름으로 바꿉니다.
  3. 기본 제목과 부제목 상자를 지웁니다.
  4. 파일 → 페이지 설정을 엽니다.
  5. 크기 목록에서 맞춤을 선택합니다.
  6. 단위를 픽셀로 바꿉니다.
  7. 너비 1080, 높이 1350을 입력합니다.
  8. 적용을 누릅니다.

STEP 02 사진과 문구 배치하기

  1. 삽입 → 이미지 → 컴퓨터에서 업로드에서 광고 사진을 넣습니다.
  2. 사진 모서리를 끌어 세로 화면에 맞춥니다.
  3. 삽입 → 텍스트 상자를 선택합니다.
  4. 비워 둔 제목 자리에 상자를 그립니다.

  6. 제목의 글자 크기와 색을 조절합니다.
  7. 새 텍스트 상자에 짧은 설명을 넣습니다.
  8. 새 텍스트 상자에 마무리 안내를 넣습니다.

제목을 가장 크게, 설명과 안내는 그보다 작게 둡니다. 글꼴은 한두 가지로 맞추고, 화면 가장자리에 글자를 붙이지 않습니다. 실제 연락처나 주소를 넣으려면 확인된 정보만 사용하세요.

글자가 틀리거나 읽기 어려울 때 고치기

슬라이드에서 입력한 글자는 해당 텍스트 상자를 직접 고칩니다. AI가 이미지 안에 그린 글자는 바꿀 위치와 정확한 문구 전체를 알려 줍니다. 글자가 작거나 배경에 묻힌다면 크기·색·위치 중 바꿀 조건도 지정합니다.

이미지 위쪽의 한글 제목 전체를 정확히 "나에게 어울리는 향을 찾아보세요"로 교체해줘. 진한 초록색으로 한 줄에 읽히게 넣어줘. 향수병 모양, 배경, 조명, 영어 제목과 아래쪽 안내 문구는 유지해줘.

수정한 문구를 원문과 한 글자씩 비교하고, 사진의 다른 부분도 달라지지 않았는지 확인합니다. 글자가 계속 틀리거나 제품 모양까지 바뀌면 저장해 둔 글자 없는 사진으로 돌아가 슬라이드에서 문구를 직접 넣습니다.

크기가 다른 결과물은 기존 광고 파일의 파일 → 사본 만들기에서 별도 파일을 만들어 작업합니다. 사본에서 파일 → 페이지 설정을 열어 크기를 바꾸세요. 페이지 크기는 파일 안의 모든 장에 적용됩니다. 완성한 이미지는 03_포스터_이름 또는 03_홈페이지_이름으로 저장합니다.
