DAY 06AI 콘텐츠제작

캐릭터 · 이모티콘 · 4컷 만화

가게·기관·브랜드는 캐릭터 하나로 훨씬 친근해집니다. 하지만 AI로 캐릭터를 만들 때 가장 어려운 것은 "다음 그림에서도 같은 캐릭터로 나오게 하는 것"입니다. 오늘은 캐릭터를 기획하고 설정표를 만들어 이모티콘 세트를 만들고, 그 캐릭터로 홍보용 4컷 만화를 완성합니다.

1.오늘의 수업

수업 난이도

이미지 요청에 익숙해진, 캐릭터는 처음인 초보자

수업방식

캐릭터 기획 → 설정표 → 이모티콘 → 4컷 만화

핵심목표

"고정 문장 + 설정표 + 같은 스타일 문장"으로 같은 캐릭터를 유지하며 여러 그림 만들기

오늘 쓰는 도구

Gemini (글·이미지), Google 슬라이드 (만화 칸 나누기·말풍선), CapCut (선택)

새봄스튜디오 오늘의 의뢰

가상의 '햇살구립도서관'이 홍보 캐릭터를 원합니다.

"아이부터 어른까지 좋아할 캐릭터를 만들어 주세요. 그 캐릭터로 도서관 이용 안내 4컷 만화도 부탁해요."

수업용 가상 기관입니다. 내 가게·회사 주제로 바꿔도 됩니다. 영상 크레딧은 쓰지 않습니다.

3.좋은 캐릭터의 조건

1교시

한눈에 기억나는 특징 1~2개예: 책갈피 모양 깃털, 큰 동그란 안경
단순한 모양여러 번 그려도 같은 모습이 나오기 쉬움
정해진 색 2~3가지색이 많을수록 그림마다 달라지기 쉬움
성격이 있음표정과 행동이 정해짐

이미 있는 유명 캐릭터와 비슷하게 만들지 않습니다. 캐릭터 이름을 넣어 "○○처럼"이라고 요청하지 않습니다.

4.실습: 캐릭터 아이디어 받기

1교시 · 실습 SET 01

주제를 하나 고르세요 — 햇살구립도서관 홍보 캐릭터 / 동네 빵집 마스코트 / 우리 회사·가게 캐릭터 / 반려동물을 닮은 캐릭터 / 가상의 지역 축제 캐릭터 / 나를 닮은 캐릭터

이어서 요청 — "[몇 번] 아이디어가 좋아. 생김새를 그림으로 그리기 쉽게 3줄로 구체적으로 적어줘. 색, 모양, 소품처럼 눈에 보이는 것만."

캐릭터 고정 문장

여기서 받은 생김새 3줄이 앞으로 모든 그림에 붙일 캐릭터 고정 문장입니다. 메모장에 복사해 두세요.
예) 둥근 몸통의 작은 부엉이, 크림색 몸에 남색 날개. 큰 동그란 안경, 머리 위에 빨간 책갈피 모양 깃털. 짧은 다리.

5.실습: 캐릭터 설정표 만들기

1교시 · 실습 SET 02

설정표 = 한 캐릭터를 앞·옆·뒤에서 본 그림을 한 장에 모은 것. 다음 그림을 만들 때 매번 첨부하는 기준 이미지입니다.

확인하기

  • 앞·옆·뒤가 같은 캐릭터인가? (색, 안경, 깃털 위치)
  • 너무 복잡해서 다시 그리기 어려운 부분은 없나? → 있으면 "더 단순하게"

마음에 들면 다운로드 → 이름 캐릭터_설정표

6.같은 캐릭터를 유지하는 요령

1교시

  1. 1캐릭터 고정 문장을 매번 붙이기 (복사 → 붙여넣기)
  2. 2설정표를 매번 첨부 — "첨부한 캐릭터와 똑같은 모습으로 [장면]을 그려줘". 첨부를 빠뜨리면 그 그림만 다른 캐릭터가 나옵니다
  3. 3스타일 문장도 매번 같게 (예: 두꺼운 선의 귀여운 2D 일러스트)
  4. 4한 번에 하나만 바꾸기 (표정만, 또는 동작만)
  5. 5너무 달라지면 싸우지 말고 새 채팅에서 설정표를 올려 다시 시작

AI가 알아서 기억해 주지 않습니다. 기준을 매번 다시 보여 주는 것이 요령입니다.

8.실습: 이모티콘 세트 만들기

1교시 · 실습 SET 04

이모티콘 = 표정 + 동작 + 짧은 글자. 문구 6개를 고르세요 — 안녕! / 고마워 / 최고! / 미안해 / 잘 자 / 파이팅 / 축하해 / 알겠어 / 헉! / 배고파

이어서 요청 — "[몇 번]만 동작을 더 크게" / 글자가 틀리면 "글자 없이 다시" → 글자는 슬라이드에서 넣어도 됩니다.

실제 메신저에 판매·등록하려면 각 플랫폼의 AI 이미지 규정을 따로 확인해야 합니다. 오늘은 내 대화방에서 쓰는 연습용입니다.

10분 휴식

9.4컷 만화의 구조

2교시

1컷 시작누가, 어디서
2컷 전개무슨 일이 생김
3컷 반전예상 밖의 일·해결
4컷 마무리웃음·전할 한마디
  • · 전하고 싶은 정보는 딱 1개 (예: "책은 2주 동안 빌릴 수 있어요")
  • · 대사는 한 칸에 1~2개, 짧게
  • · 마지막 칸에 정보가 자연스럽게 나오게

10.실습: 4컷 이야기 짜기

2교시 · 실습 SET 05

주제 예 — 책 반납 날짜를 잊어버린 부엉이 / 도서관에서 조용히 해야 하는 이유 / 갓 구운 빵이 나오는 시간 / 월요일 아침 알람과의 전쟁 / 다이어트 결심과 야식

이어서 요청 — ① "3컷 반전을 더 재밌게 다른 버전 2개" ② "대사를 더 짧게" ③ "칸마다 그림 요청에 쓸 장면 설명을 한 줄로 따로 정리해줘"

11.실습: 칸별 그림 만들기

2교시 · 실습 SET 06

한 칸씩 만듭니다. 4칸을 한 장에 요청하면 칸마다 캐릭터가 달라지기 쉽습니다. 칸마다 설정표를 첨부하세요.

4칸을 나란히 놓고 확인

  • 4칸 모두 같은 캐릭터인가?
  • 그림 스타일·색이 같은가?
  • 말풍선 넣을 빈자리가 있나?
  • 튀는 칸은 "1컷과 같은 스타일로" 다시

12.실습: 슬라이드로 칸 나누고 말풍선 넣기

2교시 · 실습 SET 07

AI는 그림 속 글자를 자주 틀립니다. 그래서 글자와 말풍선은 Google 슬라이드에서 직접 넣습니다.

  1. 1새 Google 슬라이드 → 이름 "06_4컷만화_이름"
  2. 2파일 → 페이지 설정 → 맞춤 → 1080 × 1350 픽셀 (인스타 세로)
  3. 3이미지 4장을 2 × 2로 놓기 (칸 사이 흰 여백은 똑같이). 세로로 한 칸씩 길게 놓아도 됩니다
  4. 4칸마다 검은 테두리: 이미지 선택 → 테두리 색·두께
  5. 5말풍선: 삽입 → 도형 → 설명선 → 흰색 채우기, 검은 테두리. 노란 점을 끌어 꼬리를 말하는 캐릭터 쪽으로
  6. 6말풍선 안에 대사, 4칸 모두 같은 글꼴·크기
  7. 7맨 위 제목 한 줄, 맨 아래 도서관 이름(작게)
  8. 8파일 → 다운로드 → PNG 이미지

최종 점검

  • 대사를 읽는 순서가 헷갈리지 않는다 (왼쪽 위 → 오른쪽 위 → 왼쪽 아래 → 오른쪽 아래)
  • 말풍선이 캐릭터 얼굴을 가리지 않는다
  • 전하고 싶은 정보가 들어 있다

막히면 Gemini에게 "Google 슬라이드에서 말풍선 도형을 넣는 순서를 알려줘"

13.더 해 보기 (선택) — 움직이는 만화

빨리 끝났다면 4칸 그림을 CapCut에서 한 칸씩 이어 짧은 영상으로 만들어 봅니다. DAY 05에 오지 못했어도 아래 순서만 따라 하면 됩니다.

  1. 1CapCut 프로젝트 만들기 → 말풍선 넣은 칸별 이미지 4장 가져오기 → 순서대로 타임라인에
  2. 2비율 9:16, 칸당 2~3초 (클립 끝을 끌어 길이 조절)
  3. 3칸마다 설정 창 애니메이션에서 "확대" 하나 (Pro 표시 없는 것)
  4. 4재료 창 오디오에서 짧은 배경음악이나 효과음 (예: 놀라는 칸에 "뿅")
  5. 5오른쪽 위 내보내기 → "06_움직이는만화_이름"

또는 캐릭터로 도서관 안내 포스터 한 장 만들기.
