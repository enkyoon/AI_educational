DAY 08AI 콘텐츠제작 · 최종 실습

뮤직비디오 또는 자유 주제 — 골라서 완성하기

마지막 시간입니다. 내 캐릭터 장면에 AI 노래를 입혀 애니메이션 뮤직비디오를 완성하거나, 광고·카드뉴스·만화·애니메이션 중 하나를 골라 기획부터 완성까지 혼자 만듭니다. 지난 결과물이 없어도 오늘 처음부터 시작합니다.

1.오늘의 수업

수업방식

고르기 → 기획표 → 제작 → 중간 점검 → 완성·제출

오늘 쓰는 도구

지금까지 배운 전부 — Gemini(이미지·글·음악), Flow, CapCut, Google 슬라이드

핵심목표

무엇을 만들지, 무엇을 고를지, 언제 줄일지 — 모두 내가 판단해서 한 편 완성하기

AI 작업은 기획이 80~90%입니다.

만들기 버튼을 누르는 순간부터는 결과를 기다릴 뿐입니다. 그래서 오늘도 기획표부터 씁니다.

크레딧 — 영상 장면을 만드는 종류(광고 영상·애니메이션·영상 버전 뮤직비디오)만 약 60~120크레딧. 시작 전에 Flow에서 남은 크레딧을 확인하세요. 카드뉴스·만화·그림 컷 뮤직비디오는 크레딧이 들지 않습니다.

2.실습: 무엇을 만들까 고르기

1교시 · 실습 SET 01

M. 애니메이션 뮤직비디오

캐릭터 장면(그림 컷 또는 영상) + 어울리는 AI 노래 + 컷 편집. 가사와 장면을 맞출 필요 없음. 그림 컷이면 크레딧 0 (3번)

B. 인스타 카드뉴스 처음이면 추천

정보·홍보 카드 5장 (+ 이미지 릴스) · DAY 03·05

C. 캐릭터 만화 처음이면 추천

캐릭터 + 4컷 만화 (+ 이모티콘) · DAY 06

A. 광고 영상

제품·가게 15초 영상 (+ 썸네일) · DAY 04·05

E. 짧은 애니메이션

캐릭터 3~4장면 + 내레이션 · DAY 07

F. 섞어서

예) 카드뉴스 + 같은 내용 릴스 / 광고 영상 + 썸네일

오늘 수업 안에 끝낼 수 있는 크기로

  • · 영상 장면을 만드는 종류(A·E, 영상 버전 M)는 하나에 몇 분씩 기다립니다. 장면은 3~4개로 잡으세요.
  • · 처음이라 걱정되면 B나 C — 기다리는 시간이 없습니다.
  • · 실제 브랜드 로고·연예인 얼굴·남의 작품·유명 노래 가사는 넣지 않습니다.

3.M. 애니메이션 뮤직비디오 진행 순서

뮤직비디오를 고른 사람

애니메이션 뮤직비디오 = 장면 + 어울리는 노래 + 컷 편집

가사와 장면을 하나하나 맞출 필요가 없습니다. 내 캐릭터가 나오는 장면들에 분위기가 어울리는 노래를 입히고, 노래의 리듬에 맞춰 장면을 바꿔 주면 됩니다. 노래 만들기(DAY 05), 캐릭터 장면(DAY 06·07), CapCut 편집(DAY 05)을 조합하는 일입니다.

① 장면 재료 준비 — 둘 중 하나

쉬운 버전 — 그림 컷 (크레딧 0)

같은 캐릭터가 나오는 그림 6~8장. DAY 06 만화 칸·이모티콘을 써도 되고, 설정표나 히어로샷을 첨부해 Gemini·Flow 이미지로 새로 만들어도 됩니다. 기다리는 시간이 없습니다.

영상 버전 — 움직이는 장면

DAY 07 애니메이션 장면을 쓰거나, 히어로샷을 첨부해 Flow 에이전트로 장면 영상 3~4개를 새로 만듭니다. "카메라 고정", 길이는 내가 판단.

장면 아이디어가 없으면 — "[캐릭터]가 나오는 짧은 뮤직비디오용 장면 8개를 한 줄씩 제안해줘. 하루의 흐름처럼 이어지게."

② 장면에 어울리는 노래 만들기 (Gemini → + 도구 → 음악 만들기)

가사는 직접 쓰지 않아도 됩니다. 분위기만 설명하면 AI가 가사까지 붙여 줍니다. 가사 없는 연주곡이어도 괜찮습니다.

Gemini 노래는 약 30초입니다. 더 긴 곡은 Suno가 강하지만 무료 계정은 내려받기가 제한됩니다.

③ CapCut에서 노래에 맞춰 컷 편집

  1. 1새 프로젝트(9:16) → 노래를 먼저 소리 줄에 놓기 — 영상 길이는 노래 길이에 맞춥니다
  2. 2그림이나 장면 영상을 순서대로 놓습니다. 노래를 들으며 박자가 강한 곳·분위기가 바뀌는 곳에서 다음 컷으로 바뀌게 길이를 맞춥니다 (그림 한 장당 대략 2~4초)
  3. 3그림 컷이면 설정 창 애니메이션에서 "확대" 같은 움직임 하나씩 (Pro 표시 없는 것)
  4. 4후렴이 시작되는 순간에 가장 좋은 장면을 놓으면 확 살아납니다
  5. 5첫 화면에 제목 1~2초, 끝에 음악 페이드 아웃 → 내보내기 "08_뮤직비디오_이름"

가사 자막은 넣지 않아도 됩니다. 박자 표시 기능은 Pro일 수 있으니, 노래를 들으며 손으로 맞추는 방법이 기본입니다. (선택) 앨범 커버 — "[노래 제목]의 앨범 커버, [스타일], 정사각형, 위쪽에 제목"

4.실습: 기획표 쓰고 점검받기 (모든 종류 공통)

1교시 · 실습 SET 02

받은 체크리스트를 옆에 띄워 두고 하나씩 지우며 진행합니다.

5.다른 종류의 진행 순서 (참고용)

1교시

내가 고른 종류만 보면 됩니다. 막히면 그 종류를 배운 날의 페이지를 열어 보세요.

A. 광고 영상
  1. 1장면 구성 3~4개 (역할·움직임 1개·카메라)
  2. 2제품 이미지 (Flow 이미지, 크레딧 0)
  3. 3Flow 동영상 → 프레임 — 유지 문장 매번, "카메라 고정"
  4. 4광고 문구(확인 안 된 효능 빼기) + AI 배경음악
  5. 5CapCut: 자르기 → 순서 → 자막 → 음악 → 내보내기
B. 인스타 카드뉴스
  1. 15장 문구 (표지·본문·마무리)
  2. 2스타일 고정 문장 → 이미지 5장 (글자 자리 비우기)
  3. 3Google 슬라이드 1080 × 1350 → 글자 → PNG
  4. 4(선택) CapCut 이미지 릴스 + 배경음악
C. 캐릭터 만화
  1. 1캐릭터 아이디어 → 고정 문장 → 설정표
  2. 24컷 이야기 (전할 정보 1개, 마지막 칸)
  3. 3칸별 그림 — 설정표 매번 첨부, 한 칸씩
  4. 4Google 슬라이드로 칸 배치 + 말풍선 → PNG
E. 짧은 애니메이션
  1. 1스토리 3~4장면 (행동으로 이해되게)
  2. 2히어로샷 + 생김새 3줄
  3. 3에이전트로 장면 — 히어로샷 매번 첨부, 길이는 내가 판단
  4. 4내레이션 (녹음 또는 ElevenLabs·타입캐스트 무료 플랜)
  5. 5CapCut: 잇기 → 내레이션·음악 → 페이드 → 내보내기

6.실습: 제작 1부

1교시 · 실습 SET 03

체크리스트 순서대로 진행합니다. 1교시가 끝날 때 목표 — 재료(노래·이미지·영상·문구)의 절반 이상 준비.

AI가 써 준 프롬프트는 초안꾸미는 말이 많거나 한 장면에 행동이 여러 개면 지우고 하나만 남깁니다.
기다리는 시간 활용영상이 만들어지는 동안 다음 장면 요청문이나 자막을 미리 씁니다.
