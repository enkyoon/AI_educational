4.Canvas란?

Canvas

결과물을 오른쪽 화면에 문서처럼 띄워 두고, 대화로 계속 고치거나 원하는 부분만 골라 수정할 수 있는 기능입니다.

켜는 곳 — Gemini 입력창 아래 도구 → Canvas (메뉴 이름은 업데이트에 따라 다를 수 있음)

채팅

고칠 때마다 전체가 새로 나옴 → 어디가 바뀌었는지 찾기 어려움

Canvas

문서 하나를 계속 고쳐 나감 → 바뀐 곳만 바뀜, 직접 타이핑도 가능

5.자료를 읽고 목차부터 설계하기

제품 카드 · 수업용 가상 자료

상품: 해오름 다회용 컵, 스테인리스 350ml. 공급가: 개당 4,500원(부가세 별도). 로고 인쇄 최소 100개, 인쇄비 별도 견적. 최소 주문: 50개. 배송비·정확한 납기는 주문 수량별 확인 필요. 확인된 것: 손세척 가능. 식기세척기 사용 가능 여부는 시험 중. 친환경 인증은 받지 않음. 경쟁사 대비 절감액을 계산한 자료는 없음.

Gemini 새 채팅에 위 제품 카드를 먼저 붙여 넣고, 그 아래에 이어서 요청문을 붙여 보냅니다. 오늘은 바로 본문을 쓰지 않고, 읽는 사람이 궁금해할 것과 목차부터 정합니다.

  1. Gemini가 제안한 목차를 읽고, 구매 담당자가 먼저 알고 싶을 순서인지 봅니다.
  2. 바꿀 곳이 있으면 같은 대화에서 "○○를 맨 앞으로 옮겨줘"처럼 고쳐 달라고 합니다.
  3. 목차가 정해지면 입력창 아래 도구 → Canvas를 켭니다.
  4. 같은 대화에서 아래 요청을 보냅니다. 오른쪽에 문서가 열리면 성공입니다.

6.실습: 부분만 골라 고치기

Canvas에서 문장이나 문단을 마우스로 드래그해 선택하면 그 부분에 대해서만 요청할 수 있습니다.

연습 — 한 번에 한 곳씩

① 첫 상품 소개 문단 선택 → "구매 담당자 입장에서 얻는 이점 중심으로 바꿔줘. 확인되지 않은 효과는 넣지 마."
② 구매 조건 표 선택 → 아래 "고치는 요청의 틀"로 직접 써서 요청
③ 첫 인사 선택 → "더 짧고 부드럽게"
④ 회사 연락처는 AI에게 시키지 않고 직접 타이핑으로 넣기

왜 한 곳씩? 여러 곳을 한 번에 고치면 어디가 바뀌었는지 놓치고, 고치지 말아야 할 곳까지 바뀝니다. 오탈자 하나는 요청하는 것보다 직접 고치는 편이 빠릅니다.

고칠 곳: 구매 조건 표 이렇게 바꿔줘: 최소 주문 50개와 로고 인쇄 최소 100개가 한 칸에 섞여 있으니 서로 다른 줄로 나눠줘. 더할 것: 배송비·납기·인쇄비는 수량을 확인한 뒤 따로 견적을 드린다는 안내 한 줄. 그대로 둘 것: 제품 규격, 공급가 4,500원, 부가세 별도, 식기세척기 "시험 중" 표시. 다른 부분은 바꾸지 말고, 바꾼 곳을 목록으로 알려줘.

7.문서 종류별 구조

문서는 "읽는 사람이 가장 먼저 알고 싶은 것"이 앞에 옵니다.

문서순서
보고서결론(한 줄) → 근거 → 제안
안내문무엇을 → 언제·어디서 → 해야 할 일 → 문의처
업무 매뉴얼목적 → 준비물 → 순서(1, 2, 3…) → 자주 하는 실수 → 담당자
결과 보고계획 → 실제 결과 → 잘된 점·아쉬운 점 → 다음 계획
거래처 주문 접수 업무 매뉴얼을 쓰려고 해. 읽을 사람은 새로 들어온 영업지원팀 직원이고 가장 궁금한 것은 주문이 들어왔을 때 무엇부터 해야 하는지야. 본문을 쓰기 전에 목차와 목차별 들어갈 내용 한 줄씩만 먼저 제안해줘.

목차를 보고 순서를 바꾸거나 뺀 다음 "이 목차로 본문을 써줘"라고 요청합니다. 긴 문서는 목차부터 받는 것이 가장 빠릅니다.

같은 자료, 읽는 사람에 따라 다른 문서

읽는 사람필요한 문서가장 먼저 알고 싶은 것
구매 담당자상품 소개서 (지금 만든 문서)우리 회사에 맞는 상품인가
회사 내부 직원상품 안내 매뉴얼문의가 오면 무엇을 어떻게 답하나
거래처주문 조건 안내 메일얼마나, 몇 개부터 살 수 있나
팀장판매 검토 보고서팔아도 되는가, 무엇을 더 확인하나
  1. 표에서 구매 담당자를 뺀 세 사람 중 한 명을 고릅니다.
  2. 새 채팅을 엽니다. 지금 Canvas의 상품 소개서가 바뀌지 않게 하기 위해서입니다.
  3. 5번의 제품 카드를 붙여 넣고, 이어서 아래 작성 틀을 채워 보냅니다.
위 제품 카드만 근거로 처음 거래하는 회사의 구매 담당자에게 보낼 주문 조건 안내 메일을 써줘. 이 사람이 가장 먼저 알아야 할 것: 공급가와 최소 주문 수량 나눠서 적을 것: 확정된 내용(공급가 · 최소 주문 · 로고 인쇄 최소 수량) / 추가 확인이 필요한 내용(배송비 · 납기 · 인쇄비) 카드에 없는 인증이나 할인 혜택은 쓰지 마.

8.Google 문서 화면과 앱 바로가기 익히기

Canvas에서 내보낸 문서는 Google 문서에서 다듬습니다. 빈 문서부터 시작하려면 docs.google.com을 엽니다.

앱 버튼을 열고 연필 모양의 편집 버튼을 누릅니다. 자주 쓸 Docs·Slides·Sheets·Notebook을 즐겨찾기에 배치해 두면 다시 찾기 쉽습니다. 화면에 보이는 앱과 배치는 계정에 따라 다를 수 있습니다.

10.실습: Google 문서에서 다듬기

내보낸 문서가 회사의 양식과 읽는 사람에게 맞는지 직접 확인하며 마무리합니다.

  • 제목 스타일 — 제목·소제목에 "제목 1 / 제목 2" 적용 → 왼쪽 "문서 개요"에 목차가 생김
  • 표 다듬기 — 머리 행 색 넣기, 칸 너비 맞추기
  • 머리글·바닥글 — 회사 이름, 작성일, 쪽 번호
  • 이미지 — 삽입 → 이미지 (로고나 상품 사진 자리)
  • 인쇄 미리보기 — 2장 안에 들어오는지 확인
모르는 기능은 Gemini에게

"Google 문서에서 [하고 싶은 것 — 예: 2쪽부터 쪽 번호 넣기]를 하려면 어떤 메뉴를 눌러야 해? 순서대로 알려줘."

문서 안 Gemini 패널 (지원 계정)

문서 오른쪽 위 Gemini 아이콘 → 패널에서 바로 요청. 예) "이 표를 3줄로 요약해서 표 아래에 넣어줘"

11.문서 안에서 Gemini에 요청하고 확인하기

문서 오른쪽 위 Gemini 아이콘을 누르면 현재 문서 옆에 요청할 패널이 열립니다. 지원되는 계정에서 사용할 수 있습니다.

이 소개서의 구매 조건을 처음 거래하는 회사 담당자가 이해하기 쉽게 표 아래 세 줄로 요약해줘. 공급가의 부가세 별도 조건과 최소 주문·로고 인쇄 최소 수량은 바꾸지 마. 자료에 없는 내용은 추가하지 마.

답을 읽고 필요한 내용만 반영한 뒤 가격·수량·미정 정보가 그대로인지 확인합니다. 아이콘이 없으면 Gemini 채팅에 문서 내용을 붙여 같은 작업을 합니다.

12.실습: 까다로운 검토자에게 피드백 받기

Google 문서 내용을 복사해 Gemini 새 채팅에 붙여넣거나, + 버튼으로 문서를 첨부합니다.

너는 처음 거래를 검토하는 회사의 구매 담당자야. 아래 소개서를 견적을 요청할지 정하기 전에 읽는다고 생각하고 검토해줘. 무조건 칭찬하지는 마. [소개서 붙이기] 검토 기준: 주문 조건이 서로 맞지 않는 곳 / 사실보다 부풀린 표현 / 견적에 꼭 필요한데 빠진 정보 / 읽고 나서 무엇을 하면 되는지 분명한가 표로 정리: 어디가 / 무엇이 문제인지 / 어떻게 고치면 좋을지 / 우리 회사에 확인할 질문 소개서에 없는 회사 정책을 대신 만들지 말고, 꼭 고쳐야 할 문제와 고치면 더 좋은 표현을 나눠서 알려줘. 아직 문서는 고치지 마. 반영할 의견은 내가 고를게.
동의하는 것 2~3개만 골라 고치기 — 다 따를 필요 없음, 판단은 내가
고칠 때는 Canvas로 돌아가거나, 문서에서 직접 고치기

14.프롬프트 역설계 — 자료와 판단까지 설계하기

원하는 결과의 일부와 원자료를 보고 요청을 거꾸로 설계합니다. 예시와 문장을 똑같이 만드는 것이 아니라, 근거·조건·판단 한계를 빠뜨리지 않는 것이 목표입니다. 결과를 그대로 받아쓰지 말고, 자료에서 쓸 것과 제외할 것·부족한 정보·확인 방법을 먼저 판단하세요. 필요한 요청을 직접 쓰고 실행한 뒤 한 번 이상 고칩니다.

역설계 1 · 충돌하는 제품 정보로 문서 설계

받은 자료 · 수업용 가상 자료

승인 카드: 컵 350ml, 4,500원 부가세 별도, 인쇄 최소 100개. 옛 소개서: 400ml, 4,000원, 인쇄 50개. 영업 메모: 다음 달 할인 검토 중.

만들어야 할 결과의 일부 · 나머지는 직접 설계하기

구매 담당자용 목차와 확인 목록이 먼저 나옵니다. 옛 가격·용량과 검토 중 할인은 확정 상품 정보로 들어가지 않습니다.

나는 기업 총무 담당자에게 컵 소개서를 보낼 영업지원 사원이야. 자료를 먼저 대조해 값이 다른 항목과 승인 상태를 표로 정리해줘. 승인 카드를 현재 기준으로 삼고 옛 소개서의 수치를 섞지 마. 할인은 검토 중이므로 확정 조건으로 쓰지 마. 본문 전에 구매 판단에 필요한 목차와 각 항목의 근거·누락 정보를 제안해줘. 자료의 최신 승인 여부를 확인할 질문을 남겨줘. 내가 목차를 고른 뒤에만 본문을 써줘. ■ 설계 포인트 출처 우선순위가 명시됐는지, 문서 작성 전에 충돌을 발견하는지 확인하세요.

표로 옮기며 새 비용 조건을 만들어 넣지 않으려면 무엇을 명시해야 하나요?

위 원문의 구매 조건 부분만 표로 고쳐줘. 표는 항목 / 확인된 조건 / 문의할 내용으로 구성해줘. 공급가·부가세·인쇄 최소 수량·인쇄비를 서로 다른 항목으로 보여줘. 원문과 승인 카드에 없는 할인·납기·배송비는 새로 정하지 마. 제품 소개 문단과 제목은 그대로 유지하고 문의 안내만 마지막에 추가해줘. 수정 전후 달라진 항목과 사실을 유지한 항목을 따로 알려줘. ■ 설계 포인트 수정 범위를 벗어난 변경이 없는지, 별도 견적을 무료로 바꾸지 않았는지 확인하세요.
