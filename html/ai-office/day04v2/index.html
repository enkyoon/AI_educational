결정을 돕는 보고 슬라이드 만들기

주어진 요약표로 결론과 근거를 구성하고 Google 슬라이드에서 끝까지 완성하기

1.오늘의 수업

수업방식

구성 짜기 → 제목을 결론으로 → Canvas 초안 → 슬라이드에서 완성

오늘 쓰는 도구

Gemini (+ Canvas) · Google 슬라이드 · Google 시트

핵심목표

한 장에 한 메시지, 제목이 곧 결론인 보고 슬라이드 만들기

해오름상사 오늘의 상황

서울·부산·대구 세 지점에서 친환경 사무용품을 팔고 있습니다.

팀장님 — "상반기 판매 실적을 임원 회의에서 보고할 슬라이드로 만들어 주세요."

보고할 데이터는 아래 "준비 자료"에 있습니다. 지난 시간 결과물이 없어도 됩니다.

3.실습: 준비 자료 붙여넣기

  1. 1새 Google 시트 → 이름 "04_상반기판매실적_이름"
  2. 2표 ①을 복사해 A1 칸에, 표 ②는 G1 칸에 붙여넣기 (칸이 자동으로 나뉩니다)
  3. 3숫자가 오른쪽 정렬인지 확인 (왼쪽이면 글자로 들어간 것)

오늘은 이 페이지의 작은 요약표로 진행합니다. 대량 데이터의 정리·집계·피벗은 뒤의 시트 수업에서 다룹니다.

4.좋은 보고 슬라이드의 조건

한 장에 메시지 하나슬라이드 제목이 곧 결론
글은 줄이고숫자·차트·그림으로
궁금한 순서로결론 → 근거 → 제안
마지막 장"그래서 무엇을 결정해 달라는지"
나쁜 예

문서 문단을 그대로 붙여넣은 슬라이드, 제목이 "현황" "분석"

좋은 예

제목 "서울점, 6개월 연속 매출 증가" + 꺾은선 차트 하나 + 숫자 한 줄

보고 슬라이드 순서 예 — 표지 → 한 장 요약 → 근거(차트) 2~3장 → 제안 → 결정 요청

5.실습: 슬라이드 구성 짜기

준비 자료(표 두 개 + 결론 3가지)를 붙여넣거나, 방금 만든 시트를 첨부합니다.

점검

  • 제목만 이어 읽어도 이야기가 되는가
  • 한 장에 메시지가 하나인가
  • 숫자가 모두 준비 자료에 있는 숫자인가

6.제목은 결론, 결론에는 근거와 한계

같은 숫자, 다른 주장

자료로 가능: 서울점 매출은 1월 620 → 6월 890만 원, 약 43.5% 증가. 자료로 불가: 광고 효과로 서울점 이익이 43.5% 증가. 자료로 가능한 제안: 증가 요인을 확인해 다른 지점 적용 여부를 검토하자.

7.실습: Canvas로 슬라이드 초안 만들기

Canvas에서 한 장씩 넘겨 보며 확인하고, 고칠 곳은 한 장씩 — "[몇 번] 슬라이드 — 문제: [글이 많음] — 이렇게: [숫자 하나만 크게]"

8.Google 슬라이드로 옮기기

  1. 1Canvas 공유 및 내보내기 → Google 슬라이드로 내보내기
  2. 2파일 이름 "04_판매실적보고_이름"

메뉴 이름은 계정·업데이트에 따라 다를 수 있습니다. 내보내기가 안 보이면 Google 슬라이드에서 새 파일을 만들고 구성을 보며 직접 옮겨 적습니다.

9.실습: 시트에서 차트 만들어 연결하기

STEP 01 시트에서 차트 두 개

  • 표 ① 선택 → 삽입 → 차트 → 꺾은선 (지점별 월 매출 변화)
  • 표 ② 선택 → 삽입 → 차트 → 막대 (품목별 매출 비교)
  • 차트 제목을 결론으로 (예: "서울점, 6개월 만에 매출 44% 증가")

STEP 02 슬라이드로 옮기기

  1. 시트에서 차트를 한 번 눌러 선택하고 Ctrl + C로 복사합니다.
  2. 슬라이드 탭으로 가서 차트를 넣을 장을 열고 Ctrl + V로 붙여 넣습니다.
  3. 뜨는 창에서 스프레드시트에 연결을 고르고 붙여넣기를 누릅니다.
  4. 나중에 시트 숫자가 바뀌면, 슬라이드 차트 오른쪽 위 업데이트를 한 번 누르면 반영됩니다.

모르면 Gemini에게 — "Google 시트에서 [범위]로 꺾은선 차트를 만드는 순서를 알려줘." 차트 옆 글은 한 줄만, 차트가 말하게 합니다.

10.더 해 보기 — 표지·제안 슬라이드 이미지

표지용"가로 16:9, 오른쪽에 그림, 왼쪽은 제목 자리"
물건만 따로"흰 단색 배경에 [물건]만" — 슬라이드 위에 얹기 좋음
구조 설명"위에서 비스듬히 본 입체 그림으로 [서비스 흐름]"
아이콘 3개글자는 슬라이드에서 직접 (AI 글자는 틀리기 쉬움)

AI 이미지는 실제 상품 사진이 아닙니다. 거래처 자료에는 "예시 이미지"라고 표시하거나 실제 사진으로 바꿉니다.

11.디자인 다듬기

  • 테마 하나로 통일 (슬라이드 → 테마 변경)
  • 글꼴 두 가지 이하, 제목 크기 통일
  • 강조 색 하나만
  • 모든 장 같은 위치에 쪽 번호
  • 보기 → 슬라이드쇼로 처음부터 넘겨 보기

모르는 기능은 Gemini에게 — "Google 슬라이드에서 [하고 싶은 것 — 예: 모든 제목 글꼴을 한 번에 바꾸기] 방법을 순서대로 알려줘."

12.실습: 발표자 메모와 예상 질문

화면에는 짧게, 말할 내용은 슬라이드 아래 발표자 메모에. 파일로 보낼 때도 설명 자료가 됩니다.

답하기 어려운 질문이 있으면 그 슬라이드를 보강합니다.

13.프롬프트 역설계 — 자료와 판단까지 설계하기

원하는 결과의 일부와 원자료를 보고 요청을 거꾸로 설계합니다. 예시와 문장을 똑같이 만드는 것이 아니라, 근거·조건·판단 한계를 빠뜨리지 않는 것이 목표입니다. 결과를 그대로 받아쓰지 말고, 자료에서 쓸 것과 제외할 것·부족한 정보·확인 방법을 먼저 판단하세요. 필요한 요청을 직접 쓰고 실행한 뒤 한 번 이상 고칩니다.

역설계 1 · 같은 실적, 다른 결정 요청

받은 자료 · 수업용 가상 자료

1월→6월 서울 매출 620→890만 원. 대구 480→495만 원. 광고비·이익 자료 없음. 임원은 다음 조사 우선순위를, 영업팀은 거래처에 설명할 내용을 원함.

만들어야 할 결과의 일부 · 나머지는 직접 설계하기

임원용은 확인할 원인과 조사 승인, 영업팀용은 말해도 되는 실적과 금지할 과장 표현이 중심입니다.
막히면 생각할 지점 보기

독자가 바뀌면 어떤 근거를 남기고 어떤 행동으로 끝내야 하나요?

위 실적을 두 독자에게 각각 전달할 구성을 만들어줘. 임원용 3장은 결론·실적 근거·추가 조사와 결정 요청으로. 영업팀용은 고객 설명에 쓸 확인된 사실·주의할 표현·추가 확인 질문으로. 매출 증가를 광고 효과나 이익 증가로 바꾸지 마. 각 구성에 제목·필요한 근거·마지막 행동을 적어줘. 왜 정보 순서를 달리했는지 설명하고 자료에 없는 숫자는 만들지 마. ■ 설계 포인트 말투만 달라진 것이 아니라 마지막 결정·행동이 독자에 맞는지 확인하세요.

역설계 2 · 틀린 제목과 차트 설계 고치기

받은 자료 · 수업용 가상 자료

초안 제목: “전 지점 급성장”. 표: 서울 +43.5%, 부산 +11.1%, 대구 +3.1%. 차트는 0을 생략한 막대로 격차를 과장. 제목 아래 “프로모션 성공” 문구가 있으나 프로모션 자료 없음.

만들어야 할 결과의 일부 · 나머지는 직접 설계하기

수정 제목은 지점별 성장 차이를 드러내고, 원인 단정은 삭제합니다. 차트의 축과 단위도 점검합니다.
막히면 생각할 지점 보기

사실·시각적 과장·원인 추측을 각각 어떻게 고치겠어요?

위 보고 초안을 사실과 차트 표현 두 측면에서 검토해줘. 전 지점 급성장과 프로모션 성공이 자료로 가능한 주장인지 나눠 판단해줘. 수정 제목 3개와 각 제목이 필요한 근거를 제안해줘. 차트는 비교에 적절한 축 범위·단위·기간·주석을 정해줘. 차트 그림을 새로 지어내지 말고 실제 표에서 만드는 방법을 알려줘. 수정 뒤에도 남는 판단 한계를 발표자 메모에 넣어줘. ■ 설계 포인트 제목·차트·설명에서 과장이 함께 제거됐는지 확인하세요.

역설계 3 · 예상 질문을 보고서 보완으로 연결

받은 자료 · 수업용 가상 자료

보고안은 대구점 판촉 확대 제안. 질문: 왜 대구인가? 현재 거래처 계약은? 얼마가 드나? 자료에는 매출만 있고 계약·판촉 비용·이익 없음.

만들어야 할 결과의 일부 · 나머지는 직접 설계하기

답변표는 가능한 답과 확인할 자료를 분리합니다. 제안은 즉시 확대에서 원인 확인 후 소규모 시험 검토로 조정될 수 있습니다.
막히면 생각할 지점 보기

답이 없을 때 그럴듯한 설명 대신 결정 범위를 어떻게 바꿀까요?

임원의 세 질문에 현재 자료만으로 답할 수 있는지 검토해줘. 표: 질문 / 근거 있는 답 / 부족한 자료 / 확인 부서 / 수정할 장. 계약·비용·이익을 추정해 확정 답으로 쓰지 마. 근거가 부족하면 즉시 판촉 확대 대신 무엇을 먼저 확인해야 하는지 제안해줘. 내가 반영할 내용을 고르면 결론과 결정 요청을 함께 수정해줘. 확정 실적 숫자는 유지하고 변경 목록을 남겨줘. ■ 설계 포인트 질문 목록 작성으로 끝나지 않고 본문과 결정 요청을 보완하는지 확인하세요.
