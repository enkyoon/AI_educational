1.오늘의 수업

수업 난이도

함수를 몰라도 되는 스프레드시트 초보자

수업방식

말로 요청해서 표 · 함수 · 피벗 테이블 · 차트를 만들고 대시보드로 모으기

핵심목표

데이터 위치와 하고 싶은 계산을 말로 설명해서 결과를 얻고, AI가 말한 숫자는 시트에서 직접 확인하기

오늘 쓰는 도구

Gemini, Google 시트 (Google AI Pro 계정이면 시트 오른쪽의 Gemini 패널에서 바로 요청할 수 있어요)

해오름상사 상황

서울·부산·대구 세 지점에서 친환경 사무용품 8가지(재생 용지, 다회용 컵, 친환경 세제 등)를 팔고 있습니다. 오늘은 1~3월 판매 기록을 분석합니다. 팀장님 요청 — "지점별로 얼마나 팔렸는지 한눈에 볼 수 있게 대시보드로 만들어 주세요."

2.오늘의 작업 순서

결정할 질문에서 대시보드까지

팀장 요청 해석 → 내 분석 계획 → 데이터 준비(직접 만들기 또는 준비 파일) → 진단·정리 → 함수·피벗 → 검산 → 차트 → 대시보드·보고. 계산 전에 질문과 제외 기준을 정하고, 결과를 본 뒤 지원 후보를 판단합니다.

3.시트에서 AI에게 맡길 일

AI에게 맡길 수 있는 일
  • · 어떤 칸(열)이 필요한지 표 설계
  • · 연습용 · 예시 데이터 만들기
  • · 날짜 · 이름 · 단위가 제각각인 데이터 정리
  • · 함수 만들기와 설명, 오류 원인 찾기
  • · 피벗 테이블 · 차트 만들기, 요약과 분석
사람이 할 일
  • · 실제 숫자가 맞는지 확인하기
  • · 결과 중 몇 개는 직접 검산하기
  • · 무엇을 알고 싶은지(질문) 정하기

숫자 몇 개를 더하는 일은 직접 해도 충분합니다. 3,000줄을 지점 · 월별로 나눠 계산하고 보고용으로 정리하는 일부터 AI의 도움이 커집니다. 어느 쪽이든 AI가 계산한 숫자는 원본과 비교합니다.

AI에게 요청하는 곳 두 가지

① 시트 오른쪽 Gemini 패널

지금 열린 시트를 보고 바로 만들어 줍니다. (Pro 계정)

② Gemini 앱 (gemini.google.com)

데이터를 붙여넣거나 시트를 첨부해서 요청합니다.

메뉴 이름과 위치는 업데이트에 따라 다를 수 있습니다. 패널이 안 보이면 ②로 해도 같은 결과를 얻을 수 있어요.

4.먼저 분석 계획 세우기 — 무엇을 결정할 것인가

팀장 요청

다음 분기에 어느 지점의 어떤 품목을 먼저 지원할지 정하고 싶어요. 매출이 큰 곳만 고르지 말고 최근 변화도 함께 봐 주세요.

위 칸은 지금 직접 채워 둡니다. 아래 점검 요청은 5번에서 데이터 파일을 준비한 뒤, 내가 쓴 계획과 파일을 함께 Gemini에 보낼 때 씁니다.

5.분석할 판매 데이터 준비하기

분석할 판매 기록을 준비합니다. 아래 두 방법 중 하나를 고르세요. 정리 연습을 하도록 실수가 조금 섞인 수업용 가상 자료입니다.

A · 직접 만들어 보기 (선택)

아래 요청으로 Gemini에게 엑셀 파일을 만들게 합니다. AI가 조건을 다 지키지 못할 수도 있고, 사람마다 숫자가 달라집니다.

B · 준비 파일로 시작하기

어렵거나 A로 만든 파일이 잘 안 나왔다면, 강사가 준비한 파일을 내려받아 씁니다. 모두 같은 데이터라 결과를 서로 비교하기 쉽습니다.

A · 직접 만들어 보기 (선택)

  1. Gemini 새 채팅을 엽니다.
  2. 아래 요청을 붙여 넣어 보냅니다. 파일을 만드는 데 시간이 조금 걸립니다.
  3. 답에 나온 다운로드 링크를 눌러 .xlsx 파일을 내려받습니다.

파일이 안 만들어지거나, 내려받은 파일의 기록 수가 너무 적거나 품목이 빠져 있으면 고치려고 애쓰지 말고 B · 준비 파일로 넘어가세요.

B · 준비 파일로 시작하기

04_판매분석_준비자료.xlsx 내려받기

내려받은 파일을 Google 시트로 열기 (A · B 공통)

  2. "AI오피스실무" 폴더를 열고, 내려받은 .xlsx 파일을 드라이브 화면으로 끌어다 놓습니다.

엑셀 파일 그대로는 시트 안 Gemini 패널이 잘 동작하지 않을 수 있어서 Google 스프레드시트로 바꿔서 씁니다.

6.문제 진단 → 정리 기준 선택 → 원본과 비교

고치기 전에 원래 자료를 따로 남겨 둡니다.

  1. 맨 아래 판매기록 탭을 마우스 오른쪽 버튼으로 누르고 복제를 고릅니다.
  2. 새로 생긴 "판매기록 사본" 탭 이름을 두 번 눌러 원본으로 바꿉니다. 이 탭은 보관용이라 손대지 않습니다.
  3. 판매기록 탭 이름은 정리본으로 바꿉니다. 오늘 정리와 계산은 모두 이 탭에서 합니다.
  4. 시트 오른쪽 위 Gemini 아이콘을 눌러 패널을 열고 아래 요청을 보냅니다. (패널이 없으면 Gemini 앱에 파일을 첨부해 보냅니다.)

정리가 끝나면 정리본의 마지막 기록이 몇 행인지 확인해 적어 둡니다(다음 함수 요청에 씁니다). '확인 필요' 줄은 분석에서 빼고, 몇 줄을 왜 뺐는지 메모해 둡니다(보고할 때 씁니다).

7.함수 요청과 각자 응용하기

함수 이름을 몰라도 됩니다. 어느 칸에서, 무엇을, 어떤 조건으로 계산해 어디에 넣을지 말하면 됩니다. 먼저 결과를 넣을 요약 탭을 만듭니다.

  1. 맨 아래 왼쪽 +(시트 추가)를 누르고, 새 탭 이름을 요약으로 바꿉니다.
  2. A1에 지점, B1에 매출 합계를 씁니다.
  3. A2 · A3 · A4에 서울점 · 부산점 · 대구점을 씁니다.
  4. 아래 요청의 [ ]에 정리본의 마지막 행 번호를 넣어 보냅니다.

AI가 말한 숫자와 시트의 수식은 다릅니다

답에 적힌 숫자는 그 순간의 계산 결과입니다. 시트에 들어간 수식은 자료가 바뀌면 결과도 다시 계산됩니다. 함수를 몰라도 어느 쪽인지 확인할 수 있습니다.

  1. 받은 함수를 요약 탭 B2에 붙여 넣고 B4까지 아래로 채웁니다. 패널이 직접 넣었다면 다음으로 넘어갑니다.
  2. B2를 누르고 위쪽 수식 입력줄을 봅니다. =로 시작하면 수식, 숫자만 있으면 결과 값입니다.
  3. 숫자만 있으면 "결과 숫자 말고 실제 함수로 다시 넣어줘"라고 보냅니다.
  4. 정리본에서 서울점 줄의 금액 하나를 다른 숫자로 바꿉니다.
  5. 요약 탭 B2가 따라서 바뀌었는지 봅니다.
  6. Ctrl + Z를 눌러 금액을 되돌립니다.

지점별 · 월별로 나눠 보기

서울점 · 부산점 · 대구점의 1~3월 매출을 한 표로 비교합니다. 아래 칸을 채워 요청을 직접 쓴 뒤, 예시와 비교합니다.

정리본 탭의 B열 날짜, C열 지점, G열 금액으로 2026년 1~3월 지점별 월매출 표를 요약 탭 D1부터 만들고 싶어. 행에는 지점명, 열에는 1월 · 2월 · 3월, 맨 아래와 맨 오른쪽에는 합계를 넣어줘. 빼야 할 줄: 금액이 '확인 필요'인 줄, 원본 탭의 기록 결과 숫자만 넣지 말고 실제 함수로 넣어줘. 직접 넣을 수 없으면 칸별로 붙여 넣을 함수를 알려줘. 함수가 하는 일을 한 줄로 설명하고, 검산 방법도 알려줘. ■ 이런 모양의 함수가 나오면 맞는 방향입니다 (외우지 않아도 됩니다) 서울점 3월: =SUMIFS(정리본!G:G,정리본!C:C,"서울점",정리본!B:B,">="&DATE(2026,3,1),정리본!B:B,"<"&DATE(2026,4,1))

각자 해보기

  1. 아래 표에서 해 볼 일을 하나 고릅니다.
  2. 열 위치 · 계산 조건 · 넣을 칸을 넣어 요청을 직접 씁니다.
  3. 결과 칸이 수식인지 봅니다.
  4. 표의 "확인할 것"을 직접 확인합니다.
해 볼 일요청에 담을 말AI가 쓸 함수 (참고)확인할 것
판매량과 건수품목별 수량 합계와 기록 건수를 각각 구하고 차이를 설명SUMIFS · COUNTIFS건수를 모두 더하면 정리본 기록 수와 같은가
금액 검사빈 열에 수량×단가와 금액을 비교한 결과. 숫자가 아닌 칸이 있으면 '확인 필요'IF · COUNT'불일치' 줄을 임의로 고치지 않았는가
원가 찾아오기품목 이름으로 제품목록의 개당 원가를 빈 열에. 없는 품목은 '확인 필요'XLOOKUP품목 두세 개의 원가가 제품목록과 같은가
품목별 매출총이익금액 − 원가×수량. 품목별 매출 · 원가 합계 · 매출총이익 · 이익률 표SUMIFS · IFERROR원가가 '확인 필요'인 줄을 0원으로 계산하지 않았는가. 운영비를 뺀 게 아니므로 "순이익"이라고 쓰지 않기
금액 검사: =IF(COUNT(E2:G2)<3,"확인 필요",IF(G2=E2*F2,"정상","불일치")) 원가 찾아오기: =XLOOKUP(D2,제품목록!A:A,제품목록!D:D,"확인 필요")

함수를 넣었는데 #N/A · #VALUE! 같은 표시가 나오면, 넣은 함수 · 나온 표시 · 원하던 결과를 함께 Gemini에게 보여 주고 원인을 물어보세요.

8.계획에 맞는 피벗 테이블 두 개 만들기

먼저 '확인 필요' 줄을 뺀 분석용 탭을 만듭니다.

  1. 정리본 탭을 마우스 오른쪽 버튼으로 누르고 복제를 고릅니다.
  2. 새 탭 이름을 분석용으로 바꿉니다.
  3. 분석용 탭을 연 채로 Gemini 패널에 "이 탭에서 '확인 필요'가 들어 있는 줄을 모두 지우고, 지운 줄 수를 알려줘."라고 보냅니다.
  4. 패널이 직접 지우지 못하면 Ctrl + F로 확인 필요를 찾고, 찾은 줄의 행 번호를 마우스 오른쪽 버튼으로 눌러 행 삭제를 합니다. 더 찾을 것이 없을 때까지 반복합니다.
  5. 지운 줄 수를 6번에서 적은 '확인 필요' 줄 수와 비교합니다.
  6. Gemini 패널에 아래 요청을 보냅니다. 패널이 적용 전 미리보기를 보여 주면, 범위가 분석용 탭인지 확인하고 넣습니다.

패널이 안 되면 분석용 탭에서 삽입 → 피벗 테이블 → 새 시트로 직접 만들고, 오른쪽 편집기에서 위와 같은 행 · 열 · 값을 고릅니다. 다 만든 뒤에는 지점월별 피벗의 숫자가 7번 지점별 월매출 표와 같은지, 두 피벗의 총합이 서로 같은지 확인합니다. 다르면 7번 계산에 '확인 필요' 줄이 들어갔는지부터 봅니다.

9.실습: 분석 요청하고 검산하기

Gemini 패널에서 바로 요청하거나, Gemini 앱에 시트를 첨부합니다.

분석용 탭을 기준으로 다음을 계산해줘. 1. 지점별 월 매출과, 1월 대비 3월에 얼마나(금액 · %) 늘거나 줄었는지 2. 지점마다 가장 많이 팔린 품목 3개와 그 매출 3. 다음 분기에 먼저 지원할 후보 2개(지점 · 품목)와 각 후보의 숫자 근거, 결정 전에 더 확인할 것 결과는 질문마다 한 줄 답 + 근거 숫자로 정리해줘. 기록에서 계산한 사실과, 원인에 대한 추측은 나눠서 적어줘. 1월 매출이 아주 작으면 증가율이 부풀려 보일 수 있으니 금액 차이도 함께 보여줘. 가장 중요한 숫자 두 개는 어느 범위로 계산했는지도 알려줘.

11.분석 질문에 맞는 차트 두 개 만들기

지점월별 피벗으로 월별 금액 추이 꺾은선, 품목별 피벗으로 품목 매출 비교 막대를 만듭니다. 차트가 각각 어떤 질문에 답하는지 먼저 적으세요.

패널에서 적용이 안 되면 해당 피벗 범위를 선택 → 삽입 → 차트에서 종류를 지정합니다. 총합·합계 행이 개별 지점이나 품목으로 중복 표시되지 않는지 확인합니다.

12.대시보드란?

대시보드

한 화면만 보면 현재 상황이 다 보이는 요약판입니다. 자동차 계기판처럼 "핵심 숫자 + 차트 + 필터"를 한 탭에 모읍니다. 보고할 때는 이 탭 하나만 보여 주면 됩니다.

1위 품목○○○
지점 선택 · 적용 범위 확인
꺾은선 차트
막대 차트

13.질문에 답하는 대시보드 완성하기

새 대시보드 탭에 전체 매출·우선 검토 지점·주력 품목, 지점월별 꺾은선과 품목별 막대 차트를 배치합니다. 핵심 숫자는 정리본이 아니라 분석용 데이터로 계산하세요.

  1. 맨 아래 +로 새 탭을 만들고 이름을 대시보드로 바꿉니다.
  2. Gemini가 알려 준 칸에 핵심 숫자 함수를 붙여 넣습니다.
  3. 11번에서 만든 차트를 한 번 눌러 선택하고 Ctrl + C로 복사합니다.
  4. 대시보드 탭으로 와서 Ctrl + V로 붙여 넣고, 차트를 끌어 자리를 잡습니다. 원래 피벗 탭은 지우지 않습니다.
  5. 다른 차트도 같은 방법으로 옮깁니다.
  6. 숫자 카드 하나를 골라, 피벗 탭의 같은 숫자와 맞는지 확인합니다.

지점을 골라 보는 선택 상자(필터)를 붙이면, 선택에 따라 바뀌는 숫자와 안 바뀌는 숫자가 섞일 수 있습니다. 붙였다면 지점을 바꿔 보며 각 숫자가 어느 범위를 보여 주는지 꼭 확인하세요.

15.막힌 지점 확인하기 · 더 해 보기

실제 문제가 생겼을 때

합계가 다름: 원본·정리본·분석용 데이터 중 어느 범위를 썼는지와 집계 제외 조건 확인. 피벗이 개수를 셈: 값의 집계 방식이 합계인지, 금액이 숫자인지 확인. 파일·패널 적용 불가: Google 스프레드시트로 저장했는지 확인. Gemini 채팅으로 함수를 받아 직접 넣을 수도 있음. #N/A · #VALUE! 같은 표시: 정리 연습용으로 섞여 있던 오류가 남았을 수 있음. 그 칸과 함수를 Gemini에게 보여 주고 원인 묻기. 필터 후 카드가 그대로: 카드가 전체 합계인지 선택 지점 기준인지 표시와 수식 확인.

더 해 보기: 지점별 원가를 반영한 매출총이익을 비교하고, 원가가 없는 품목은 제외 건수와 함께 보고하세요. 원가만 뺀 결과를 순이익이라고 부르지 않습니다.

내 직무로 바꿔 보기 (선택)

오늘 파일에 없는 자료가 필요한 일입니다. 회사 자료 대신 연습용 가상 자료로 해 봅니다. 함수 이름 없이, 찾고 싶은 조건만 말로 씁니다.

회계: 거래처별 미수금 표에서 납부기한이 오늘보다 지났고 미수금이 0보다 큰 거래처만 찾아줘. 구매 · 물류: 재고가 안전 재고보다 적거나, 납기일이 지났는데 입고되지 않은 주문을 찾아줘. 인사: 실적과 근태 기준에 따라 직원을 분류해줘. 기준에 맞지 않는 칸은 '확인 필요'로 두고, 최종 평가는 사람이 해.

16.프롬프트 역설계 — 자료와 판단까지 설계하기

원하는 결과의 일부와 원자료를 보고 요청을 거꾸로 설계합니다. 예시와 문장을 똑같이 만드는 것이 아니라, 근거·조건·판단 한계를 빠뜨리지 않는 것이 목표입니다. 결과를 그대로 받아쓰지 말고, 자료에서 쓸 것과 제외할 것·부족한 정보·확인 방법을 먼저 판단하세요. 필요한 요청을 직접 쓰고 실행한 뒤 한 번 이상 고칩니다.

역설계 1 · 중복과 정상 주문을 구분하기

받은 자료 · 수업용 가상 자료

열: 주문번호·날짜·지점·품목·수량·단가·금액. O01은 컵 2개 9,000원과 용지 1개 6,000원 두 줄. 컵 줄이 완전히 같은 값으로 한 번 더 있음. O02는 수량·금액 빈칸.

만들어야 할 결과의 일부 · 나머지는 직접 설계하기

정상 O01의 두 품목은 남고 완전 중복 컵 줄만 제거. O02는 확인 필요로 남기고 집계 제외. 확정 금액 합계는 15,000원.
막히면 생각할 지점 보기

주문번호만으로 중복을 지우면 어떤 일이 생기나요?

위 기록의 정리 문제를 먼저 진단하고 아직 수정하지 마. 주문번호가 같아도 품목이 다르면 정상 기록일 수 있어. 모든 열이 같은 완전 중복만 제거 대상으로 분류해줘. 수량·금액 빈칸은 추정하지 말고 확인 필요로 남겨줘. 내가 기준을 확인한 뒤 정리본과 수정 내역을 보여줘. 정상·삭제·집계 제외 기록 수와 확정 금액 합계를 각각 검산해줘. ■ 설계 포인트 중복 삭제 후 두 품목이 남는지, 미확정 금액을 0원 매출로 해석하지 않는지 확인하세요.

역설계 2 · 성장률만으로 지원 대상을 고르지 않기

받은 자료 · 수업용 가상 자료

1월→6월 매출(만 원): 서울 600→900, 부산 20→60, 대구 500→450. 지원 목적은 다음 분기 판매 기회와 운영 문제를 함께 검토하는 것. 원가·광고·재고 자료는 없음.

만들어야 할 결과의 일부 · 나머지는 직접 설계하기

부산 성장률이 가장 높아도 단독 지원 확정으로 결론내리지 않습니다. 증감액·규모·비교 한계와 추가 확인을 함께 봅니다.
막히면 생각할 지점 보기

성장률 200%와 증감액 40만 원을 어떻게 함께 보여줄까요?

위 지점 매출로 다음 분기 지원 후보를 검토해줘. 현재 규모·증감액·증감률을 같은 표로 계산하고 비교 기간과 단위를 표시해줘. 작은 기준 매출의 높은 성장률만으로 순위를 확정하지 마. 후보를 두 곳 제안하되 자료에 따른 이유와 추가 확인할 재고·원가·운영 정보를 나눠줘. 매출만으로 이익·수요·광고 효과를 단정하지 마. 계산식과 직접 검산할 숫자 두 개를 알려줘. ■ 설계 포인트 규모·변화율·절대 변화가 구분됐는지와 원인 단정이 없는지 확인하세요.

역설계 3 · 대시보드의 숫자 불일치 추적

받은 자료 · 수업용 가상 자료

피벗 총합 150만 원, 카드 총합 165만 원. 카드는 원본을, 피벗은 중복 제거 정리본을 사용. 지점 선택 후 차트만 바뀌고 카드는 그대로.

만들어야 할 결과의 일부 · 나머지는 직접 설계하기

원인 진단 → 범위 통일 → 필터 적용 범위 표시 → 같은 지점·기간의 숫자를 재검산하는 순서가 필요합니다.
막히면 생각할 지점 보기

오류라고 단정하기 전에 데이터와 필터 범위 중 무엇을 비교해야 하나요?

대시보드의 두 합계가 다르니 바로 숫자를 덮어쓰지 말고 원인을 진단해줘. 각 카드·피벗·차트의 원본 탭·범위·중복 처리·필터 조건을 대조할 표를 만들어줘. 원본과 정리본의 차이, 필터 적용 대상의 차이를 구분해줘. 분석용 데이터로 범위를 통일하는 수정 순서를 알려줘. 전체 값인 카드에는 전체라고 표시하거나 선택 지점을 참조하는 방식으로 바꿔줘. 같은 지점·기간으로 재검산하는 확인 절차까지 제안해줘. ■ 설계 포인트 보여 주는 범위를 먼저 맞추고 숫자를 고치는지 확인하세요.
