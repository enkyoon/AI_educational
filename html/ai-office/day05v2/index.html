7.조건별 집계표 만들고 수식 확인하기

함수 이름을 몰라도 됩니다. 어느 칸에서, 무엇을, 어떤 조건으로 계산해 어디에 넣을지 말하면 됩니다. 먼저 결과를 넣을 요약 탭을 만듭니다.

  1. 맨 아래 왼쪽 +(시트 추가)를 누르고, 새 탭 이름을 요약으로 바꿉니다.
  2. A1에 지점, B1에 매출 합계를 씁니다.
  3. A2 · A3 · A4에 서울점 · 부산점 · 대구점을 씁니다.
  4. 아래 요청의 [ ]에 정리본의 마지막 행 번호를 넣어 보냅니다.

AI가 말한 숫자와 시트의 수식은 다릅니다

답에 적힌 숫자는 그 순간의 계산 결과입니다. 시트에 들어간 수식은 자료가 바뀌면 결과도 다시 계산됩니다. 함수를 몰라도 어느 쪽인지 확인할 수 있습니다.

  1. 받은 함수를 요약 탭 B2에 붙여 넣고 B4까지 아래로 채웁니다. 패널이 직접 넣었다면 다음으로 넘어갑니다.
  2. B2를 누르고 위쪽 수식 입력줄을 봅니다. =로 시작하면 수식, 숫자만 있으면 결과 값입니다.
  3. 숫자만 있으면 "결과 숫자 말고 실제 함수로 다시 넣어줘"라고 보냅니다.
  4. 정리본에서 서울점 줄의 금액 하나를 다른 숫자로 바꿉니다.
  5. 요약 탭 B2가 따라서 바뀌었는지 봅니다.
  6. Ctrl + Z를 눌러 금액을 되돌립니다.

지점별 · 월별로 나눠 보기

서울점 · 부산점 · 대구점의 1~3월 매출을 한 표로 비교합니다. 아래 칸을 채워 요청을 직접 쓴 뒤, 예시와 비교합니다.

정리본 탭의 B열 날짜, C열 지점, G열 금액으로 2026년 1~3월 지점별 월매출 표를 요약 탭 D1부터 만들고 싶어. 행에는 지점명, 열에는 1월 · 2월 · 3월, 맨 아래와 맨 오른쪽에는 합계를 넣어줘. 빼야 할 줄: 금액이 '확인 필요'인 줄, 원본 탭의 기록 결과 숫자만 넣지 말고 실제 함수로 넣어줘. 직접 넣을 수 없으면 칸별로 붙여 넣을 함수를 알려줘. 함수가 하는 일을 한 줄로 설명하고, 검산 방법도 알려줘. ■ 이런 모양의 함수가 나오면 맞는 방향입니다 (외우지 않아도 됩니다) 서울점 3월: =SUMIFS(정리본!G:G,정리본!C:C,"서울점",정리본!B:B,">="&DATE(2026,3,1),정리본!B:B,"<"&DATE(2026,4,1))

8.확인이 필요한 기록만 따로 찾기

확인할 기록을 사람이 한 줄씩 찾는 대신, 필요한 조건과 남길 열을 설명합니다. 정상·불일치·확인 필요를 나누는 기준도 직접 정합니다.

정리본은 A 주문번호 B 날짜 C 지점 D 품목 E 수량 F 단가 G 금액이야. H열에 금액 검사 결과를 실제 수식으로 넣어줘. E:G 중 숫자가 아닌 칸이 있으면 '확인 필요', G가 E×F와 다르면 '불일치', 나머지는 '정상'이야. H가 불일치 또는 확인 필요인 기록만 확인목록 탭에 A:H와 확인 이유를 모아줘. 원본과 정리본의 값은 임의로 고치지 마. 전체 기록 수와 상태별 건수, 추출 건수가 맞는지 확인하는 방법도 알려줘.
Google 시트 수식 참고 — 외우지 않아도 됩니다

마지막 행이 3001행이고 H열에 상태가 있을 때의 예입니다. 실제 범위로 바꾸세요. Google 시트 FILTER의 뒤 인수에는 추가 조건이 들어갑니다.

=IF(COUNT(E2:G2)<3,"확인 필요",IF(G2=E2*F2,"정상","불일치"))
=IFNA(FILTER(정리본!A2:H3001,정리본!H2:H3001<>"정상"),"대상 없음")

정리가 잘 끝나 확인 목록이 비어 있어도 정상입니다. 연습하려고 정리본에 새 오류를 만들 필요는 없습니다.

9.다른 표에서 필요한 정보 연결하기

판매기록에 없는 원가는 제품목록에서 가져옵니다. 어떤 열을 기준으로 연결할지와 값이 없을 때 처리할 방법을 먼저 정합니다.

정리본 D열 품목과 제품목록 A열 품목을 연결해 제품목록 D열 개당 원가를 정리본 I열에 실제 함수로 넣어줘. 제품목록의 품목 중복과 원가 빈칸을 먼저 확인해줘. 일치 품목이 없거나 원가가 비어 있으면 '확인 필요'로 남겨줘. 판매단가와 금액은 유지해줘. 제품 두세 개의 원가를 제품목록에서 직접 대조하는 방법을 알려줘.

매출총이익 분석은 이 연결 결과를 활용하는 추가 실습입니다. 원가 미확인 기록은 0원 원가로 계산하지 않습니다.

10.계획에 맞는 피벗 테이블 두 개 만들기

먼저 '확인 필요' 줄을 뺀 분석용 탭을 만듭니다.

  1. 정리본 탭을 마우스 오른쪽 버튼으로 누르고 복제를 고릅니다.
  2. 새 탭 이름을 분석용으로 바꿉니다.
  3. 분석용 탭을 연 채로 Gemini 패널에 "이 탭에서 '확인 필요'가 들어 있는 줄을 모두 지우고, 지운 줄 수를 알려줘."라고 보냅니다.
  4. 패널이 직접 지우지 못하면 Ctrl + F로 확인 필요를 찾고, 찾은 줄의 행 번호를 마우스 오른쪽 버튼으로 눌러 행 삭제를 합니다. 더 찾을 것이 없을 때까지 반복합니다.
  5. 지운 줄 수를 정리할 때 적은 '확인 필요' 줄 수와 비교합니다.
  6. Gemini 패널에 아래 요청을 보냅니다. 패널이 적용 전 미리보기를 보여 주면, 범위가 분석용 탭인지 확인하고 넣습니다.

패널이 안 되면 분석용 탭에서 삽입 → 피벗 테이블 → 새 시트로 직접 만들고, 오른쪽 편집기에서 위와 같은 행 · 열 · 값을 고릅니다. 다 만든 뒤에는 지점월별 피벗의 숫자가 함수로 만든 지점별 월매출 표와 같은지, 두 피벗의 총합이 서로 같은지 확인합니다. 다르면 집계표 계산에 '확인 필요' 줄이 들어갔는지부터 봅니다.

11.실습: 분석 요청하고 검산하기

Gemini 패널에서 바로 요청하거나, Gemini 앱에 시트를 첨부합니다.

분석용 탭을 기준으로 다음을 계산해줘. 1. 지점별 월 매출과, 1월 대비 3월에 얼마나(금액 · %) 늘거나 줄었는지 2. 지점마다 가장 많이 팔린 품목 3개와 그 매출 3. 다음 분기에 먼저 지원할 후보 2개(지점 · 품목)와 각 후보의 숫자 근거, 결정 전에 더 확인할 것 결과는 질문마다 한 줄 답 + 근거 숫자로 정리해줘. 기록에서 계산한 사실과, 원인에 대한 추측은 나눠서 적어줘. 1월 매출이 아주 작으면 증가율이 부풀려 보일 수 있으니 금액 차이도 함께 보여줘. 가장 중요한 숫자 두 개는 어느 범위로 계산했는지도 알려줘.

12.프롬프트 역설계 — 자료와 판단까지 설계하기

원하는 결과의 일부와 원자료를 보고 요청을 거꾸로 설계합니다. 예시와 문장을 똑같이 만드는 것이 아니라, 근거·조건·판단 한계를 빠뜨리지 않는 것이 목표입니다. 결과를 그대로 받아쓰지 말고, 자료에서 쓸 것과 제외할 것·부족한 정보·확인 방법을 먼저 판단하세요. 필요한 요청을 직접 쓰고 실행한 뒤 한 번 이상 고칩니다.

역설계 1 · 중복과 정상 주문을 구분하기

받은 자료 · 수업용 가상 자료

열: 주문번호·날짜·지점·품목·수량·단가·금액. O01은 컵 2개 9,000원과 용지 1개 6,000원 두 줄. 컵 줄이 완전히 같은 값으로 한 번 더 있음. O02는 수량·금액 빈칸.

만들어야 할 결과의 일부 · 나머지는 직접 설계하기

정상 O01의 두 품목은 남고 완전 중복 컵 줄만 제거. O02는 확인 필요로 남기고 집계 제외. 확정 금액 합계는 15,000원.
막히면 생각할 지점 보기

주문번호만으로 중복을 지우면 어떤 일이 생기나요?

위 기록의 정리 문제를 먼저 진단하고 아직 수정하지 마. 주문번호가 같아도 품목이 다르면 정상 기록일 수 있어. 모든 열이 같은 완전 중복만 제거 대상으로 분류해줘. 수량·금액 빈칸은 추정하지 말고 확인 필요로 남겨줘. 내가 기준을 확인한 뒤 정리본과 수정 내역을 보여줘. 정상·삭제·집계 제외 기록 수와 확정 금액 합계를 각각 검산해줘. ■ 설계 포인트 중복 삭제 후 두 품목이 남는지, 미확정 금액을 0원 매출로 해석하지 않는지 확인하세요.

역설계 2 · 성장률만으로 지원 대상을 고르지 않기

받은 자료 · 수업용 가상 자료

1월→6월 매출(만 원): 서울 600→900, 부산 20→60, 대구 500→450. 지원 목적은 다음 분기 판매 기회와 운영 문제를 함께 검토하는 것. 원가·광고·재고 자료는 없음.

만들어야 할 결과의 일부 · 나머지는 직접 설계하기

부산 성장률이 가장 높아도 단독 지원 확정으로 결론내리지 않습니다. 증감액·규모·비교 한계와 추가 확인을 함께 봅니다.
막히면 생각할 지점 보기

성장률 200%와 증감액 40만 원을 어떻게 함께 보여줄까요?

위 지점 매출로 다음 분기 지원 후보를 검토해줘. 현재 규모·증감액·증감률을 같은 표로 계산하고 비교 기간과 단위를 표시해줘. 작은 기준 매출의 높은 성장률만으로 순위를 확정하지 마. 후보를 두 곳 제안하되 자료에 따른 이유와 추가 확인할 재고·원가·운영 정보를 나눠줘. 매출만으로 이익·수요·광고 효과를 단정하지 마. 계산식과 직접 검산할 숫자 두 개를 알려줘. ■ 설계 포인트 규모·변화율·절대 변화가 구분됐는지와 원인 단정이 없는지 확인하세요.

역설계 3 · 대시보드의 숫자 불일치 추적

받은 자료 · 수업용 가상 자료

피벗 총합 150만 원, 카드 총합 165만 원. 카드는 원본을, 피벗은 중복 제거 정리본을 사용. 지점 선택 후 차트만 바뀌고 카드는 그대로.

만들어야 할 결과의 일부 · 나머지는 직접 설계하기

원인 진단 → 범위 통일 → 필터 적용 범위 표시 → 같은 지점·기간의 숫자를 재검산하는 순서가 필요합니다.
막히면 생각할 지점 보기

오류라고 단정하기 전에 데이터와 필터 범위 중 무엇을 비교해야 하나요?

대시보드의 두 합계가 다르니 바로 숫자를 덮어쓰지 말고 원인을 진단해줘. 각 카드·피벗·차트의 원본 탭·범위·중복 처리·필터 조건을 대조할 표를 만들어줘. 원본과 정리본의 차이, 필터 적용 대상의 차이를 구분해줘. 분석용 데이터로 범위를 통일하는 수정 순서를 알려줘. 전체 값인 카드에는 전체라고 표시하거나 선택 지점을 참조하는 방식으로 바꿔줘. 같은 지점·기간으로 재검산하는 확인 절차까지 제안해줘. ■ 설계 포인트 보여 주는 범위를 먼저 맞추고 숫자를 고치는지 확인하세요.
