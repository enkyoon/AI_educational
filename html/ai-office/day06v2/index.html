3.준비 자료로 시작하기

정리된 판매기록과 제품목록을 함께 제공하므로 앞 수업에 빠졌어도 시작할 수 있습니다. 표의 날짜 범위와 금액 단위를 먼저 확인합니다.

정리된 판매기록 내려받기
  1. 1.파일을 Google 드라이브에 올립니다.
  2. 2.Google 스프레드시트로 엽니다.
  3. 3.파일 메뉴에서 Google 스프레드시트로 저장합니다.
  4. 4.정리본·제품목록·정리기록 탭을 확인합니다.
  5. 5.정리기록의 제외 기준과 남은 건수를 읽습니다. 원본 3,008줄에서 완전 중복 8줄과 미확인 10줄을 제외해 집계 대상은 2,990줄입니다.

자기 정리본을 써도 됩니다. 그 경우 준비 자료와 처리 기준이 다를 수 있으므로 합계가 같아야 한다고 가정하지 마세요. 정산 대조와 파일 통합 연습은 제공한 준비 자료를 기준으로 합니다.

4.두 자료를 같은 기준으로 대조하기

회사 판매기록과 거래처 정산 자료가 같은지 확인합니다. 주문번호가 같아도 품목별 여러 줄이 있을 수 있으므로 먼저 양쪽 자료가 주문별 합계인지 품목별 기록인지 봅니다.

  1. 1.정리된 판매기록에서 아래 회사 대조표의 주문번호에 해당하는 기록을 확인합니다.
  2. 2.회사대조 탭을 만들고 아래 회사 대조표를 A1에 붙입니다.
  3. 3.거래처정산 탭을 만들고 거래처 자료를 A1에 붙입니다.
  4. 4.주문번호가 중복되면 정상 분할인지 오류인지 먼저 확인합니다.
  5. 5.양쪽 주문번호 전체를 기준으로 대조합니다.

이번 대조의 범위는 아래 회사 주문 20건과 거래처가 보낸 정산 목록입니다. 회사대조는 정리된 판매기록의 해당 주문을 주문번호별로 합친 표입니다. 전체 판매기록에 이 대조표를 추가하지 않습니다.

회사 대조표 · 주문별 금액 · 수업용 가상 자료

거래처 정산 자료 · 받은 그대로 · 수업용 가상 자료

회사대조와 거래처정산 탭은 A 주문번호 B 금액(원)이야. 양쪽의 전체 주문번호를 기준으로 비교해줘. 중복 주문번호를 먼저 확인하고 임의로 첫 줄을 선택하지 마. 중복 의미가 불명확하면 그 주문은 중복 확인으로 남겨줘. 결과는 주문번호 / 회사 금액 / 거래처 금액 / 회사−거래처 차액 / 상태 / 확인 이유로 정리해줘. 상태는 금액 일치·금액 불일치·회사에만 있음·거래처에만 있음·중복 확인이야. 금액이 둘 다 확정된 건만 차액을 계산하고, 한쪽에 없으면 미등록으로 남겨줘. 양방향 누락과 상태별 건수를 확인하는 방법도 알려줘.

XLOOKUP으로 회사 쪽에서 찾는 것만으로는 거래처에만 있는 주문을 발견할 수 없습니다. 양쪽 주문번호가 모두 결과에 나타나는지 직접 확인하세요.

5.지점별 파일을 하나로 합치고 확인하기

같은 정리본을 지점별로 나눈 세 파일입니다. 별도 통합 연습에서만 사용합니다. 전체 정리본에 다시 덧붙이면 같은 매출이 두 번 들어갑니다.

서울점 파일 내려받기부산점 파일 내려받기대구점 파일 내려받기
  1. 1.새 Google 시트 파일을 만들고 이름을 06_지점통합_이름으로 정합니다.
  2. 2.각 CSV를 파일 → 가져오기에서 선택합니다.
  3. 3.각 파일을 별도 새 시트로 가져오고 지점 이름으로 탭 이름을 바꿉니다.
  4. 4.각 탭의 열 제목과 날짜·숫자 형식을 확인합니다.
  5. 5.원본 파일명을 남기는 열을 추가하고 통합 탭으로 세 표를 합칩니다.
  6. 6.통합 전후 건수·금액과 지점별 합계를 비교합니다.
서울점·부산점·대구점 탭의 A:G 판매기록을 새 통합 탭에 합쳐줘. 열은 주문번호 / 날짜 / 지점 / 품목 / 수량 / 단가 / 금액이야. 출처파일 열을 추가해줘. 제목은 한 번만 넣고 빈 행과 합계 행을 판매기록처럼 추가하지 마. 원본 탭은 유지해줘. 직접 적용이 안 되면 Google 시트 수식 또는 가져오기 방법을 알려줘. 지점별 원본 건수·금액과 통합 후 건수·금액을 나란히 비교해 누락과 중복을 확인하게 해줘.

검증 수치가 같아도 어떤 기록이 합쳐졌는지 표본을 확인합니다. 날짜가 글자로 들어왔다면 날짜 형식을 정리한 뒤 월별 집계를 합니다.

6.차트에 쓸 요약표 만들기

정리본만 복제해 분석용 탭을 만듭니다. 보관용 원본과 제품목록을 합계 범위에 함께 넣지 않습니다. 시트의 피벗 메뉴에서 아래 표대로 설정합니다.

피벗행열값

품목별품목지점금액의 합계

피벗이 합계가 아니라 개수로 표시되면 금액의 자료 형식과 값의 집계 방식을 확인합니다. 두 피벗의 총합을 정리본의 금액 합계와 비교합니다.

8.분석 질문에 맞는 차트 두 개 만들기

지점월별 피벗으로 월별 금액 추이 꺾은선, 품목별 피벗으로 품목 매출 비교 막대를 만듭니다. 차트가 각각 어떤 질문에 답하는지 먼저 적으세요.

패널에서 적용이 안 되면 해당 피벗 범위를 선택 → 삽입 → 차트에서 종류를 지정합니다. 총합·합계 행이 개별 지점이나 품목으로 중복 표시되지 않는지 확인합니다.

10.질문에 답하는 대시보드 완성하기

새 대시보드 탭에 전체 매출·우선 검토 지점·주력 품목, 지점월별 꺾은선과 품목별 막대 차트를 배치합니다. 핵심 숫자는 정리본이 아니라 분석용 데이터로 계산하세요.

  1. 맨 아래 +로 새 탭을 만들고 이름을 대시보드로 바꿉니다.
  2. Gemini가 알려 준 칸에 핵심 숫자 함수를 붙여 넣습니다.
  3. 8번에서 만든 차트를 한 번 눌러 선택하고 Ctrl + C로 복사합니다.
  4. 대시보드 탭으로 와서 Ctrl + V로 붙여 넣고, 차트를 끌어 자리를 잡습니다. 원래 피벗 탭은 지우지 않습니다.
  5. 다른 차트도 같은 방법으로 옮깁니다.
  6. 숫자 카드 하나를 골라, 피벗 탭의 같은 숫자와 맞는지 확인합니다.

지점을 골라 보는 선택 상자(필터)를 붙이면, 선택에 따라 바뀌는 숫자와 안 바뀌는 숫자가 섞일 수 있습니다. 붙였다면 지점을 바꿔 보며 각 숫자가 어느 범위를 보여 주는지 꼭 확인하세요.

12.한 번에 맡긴 결과를 내가 확인한 값과 비교하기

지금까지 단계별로 확인한 숫자가 비교 기준입니다. 새 채팅에 같은 준비 파일을 넣고 업무 전체를 한 번에 요청해 봅니다. 잘못된 답을 만들기 위한 활동이 아니라, 어디를 확인해야 결과를 믿을 수 있는지 익히는 활동입니다.

첨부한 정리된 판매기록으로 2026년 1~3월의 지점별·품목별 실적을 분석해줘. 정리본 탭만 집계하고 원본과 제품목록은 판매기록처럼 합치지 마. 지점별 월매출, 품목별 매출 비교, 전체 합계와 자료 범위를 보여주는 대시보드를 만들어줘. 실제 수식·차트 원본 범위와 건수·총액 검증 결과를 남겨줘. 원인 추측은 사실과 구분해줘. 직접 적용할 수 없는 작업은 내가 따라 할 순서로 알려줘.
비교할 것확인 방법
기록 수·총액정리기록·정리본 합계와 비교
지점·월별 숫자직접 만든 피벗에서 같은 범위와 조건으로 비교
기간·단위·제외 조건차트·표·설명에 같은 기준을 썼는지 확인
원인과 제안계산 사실과 추측을 구분했는지 확인

모두 맞아도 성공입니다. 차이가 있으면 사용한 탭·범위·제외 조건부터 확인하고 해당 부분만 수정 요청합니다.

14.막힌 지점 확인하기 · 더 해 보기

실제 문제가 생겼을 때

합계가 다름: 원본·정리본·분석용 데이터 중 어느 범위를 썼는지와 집계 제외 조건 확인. 피벗이 개수를 셈: 값의 집계 방식이 합계인지, 금액이 숫자인지 확인. 파일·패널 적용 불가: Google 스프레드시트로 저장했는지 확인. Gemini 채팅으로 함수를 받아 직접 넣을 수도 있음. #N/A · #VALUE! 같은 표시: 정리 연습용으로 섞여 있던 오류가 남았을 수 있음. 그 칸과 함수를 Gemini에게 보여 주고 원인 묻기. 필터 후 카드가 그대로: 카드가 전체 합계인지 선택 지점 기준인지 표시와 수식 확인.

더 해 보기: 지점별 원가를 반영한 매출총이익을 비교하고, 원가가 없는 품목은 제외 건수와 함께 보고하세요. 원가만 뺀 결과를 순이익이라고 부르지 않습니다.

회계: 거래처별 미수금 표에서 납부기한이 오늘보다 지났고 미수금이 0보다 큰 거래처만 찾아줘. 구매 · 물류: 재고가 안전 재고보다 적거나, 납기일이 지났는데 입고되지 않은 주문을 찾아줘. 인사: 실적과 근태 기준에 따라 직원을 분류해줘. 기준에 맞지 않는 칸은 '확인 필요'로 두고, 최종 평가는 사람이 해.
