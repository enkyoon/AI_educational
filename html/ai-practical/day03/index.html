DAY 03AI 실무활용

Canvas로 문서 쓰기 → Google 문서로 완성

A4 몇 장짜리 문서는 채팅으로 주고받으면 금방 뒤죽박죽이 됩니다. Canvas에 문서를 띄워 두고 AI와 함께 고쳐 나가는 방법을 익히고, Google 문서로 옮겨 회사에서 쓸 수 있는 모양으로 완성합니다.

4.Canvas란?

1교시 · 5분

Canvas

결과물을 오른쪽 화면에 문서처럼 띄워 두고, 대화로 계속 고치거나 원하는 부분만 골라 수정할 수 있는 기능입니다.

켜는 곳 — Gemini 입력창 아래 도구 → Canvas (메뉴 이름은 업데이트에 따라 다를 수 있음)

채팅

고칠 때마다 전체가 새로 나옴 → 어디가 바뀌었는지 찾기 어려움

Canvas

문서 하나를 계속 고쳐 나감 → 바뀐 곳만 바뀜, 직접 타이핑도 가능

5.실습: Canvas로 상품 소개서 초안 쓰기

1교시 · 15분 · 실습 SET 01

Canvas에서 거래처에 보낼 상품 소개서를 써줘. 회사: 생활용품 유통회사 해오름상사 읽을 사람: 거래처 총무·구매 담당자 소개할 상품: 다회용 컵, 재생 용지, 친환경 세제 목적: 우리 회사에서 친환경 사무용품을 사도록 관심 끌기 구성: 인사 / 왜 친환경 사무용품인가 / 상품별 소개 / 주문 방법 / 문의처 조건: A4 2장 이내, 가격은 [가격 확인 필요]로 비워 두기, 과장된 표현 쓰지 않기

확인하기

  • 내가 주지 않은 숫자·인증·수상 경력이 들어가지 않았나? (있으면 [확인 필요]로)
  • 읽을 사람이 궁금한 것(가격·주문 방법)이 빠지지 않았나?

6.실습: 부분만 골라 고치기

1교시 · 10분

Canvas에서 문장이나 문단을 마우스로 드래그해 선택하면 그 부분에 대해서만 요청할 수 있습니다.

연습 — 한 번에 한 곳씩

① "왜 친환경 사무용품인가" 문단 선택 → "거래처 담당자 입장에서 얻는 이익 중심으로"
② 상품 소개 부분 선택 → "상품마다 특징 / 이런 회사에 추천 / 주문 단위 표로"
③ 첫 인사 선택 → "더 짧고 부드럽게"
④ 회사 연락처는 AI에게 시키지 않고 직접 타이핑으로 넣기

왜 한 곳씩? 여러 곳을 한 번에 고치면 어디가 바뀌었는지 놓치고, 고치지 말아야 할 곳까지 바뀝니다.

고칠 곳: 상품별 소개 부분 이렇게 바꿔줘: 상품마다 특징 / 이런 회사에 추천 / 주문 단위를 칸으로 나눈 표로 그대로 둘 것: 상품 이름과 [가격 확인 필요] 표시

7.문서 종류별 구조

1교시 · 10분

문서는 "읽는 사람이 가장 먼저 알고 싶은 것"이 앞에 옵니다.

문서순서
보고서결론(한 줄) → 근거 → 제안
안내문무엇을 → 언제·어디서 → 해야 할 일 → 문의처
업무 매뉴얼목적 → 준비물 → 순서(1, 2, 3…) → 자주 하는 실수 → 담당자
결과 보고계획 → 실제 결과 → 잘된 점·아쉬운 점 → 다음 계획
거래처 주문 접수 업무 매뉴얼을 쓰려고 해. 읽을 사람은 새로 들어온 영업지원팀 직원이고 가장 궁금한 것은 주문이 들어왔을 때 무엇부터 해야 하는지야. 본문을 쓰기 전에 목차와 목차별 들어갈 내용 한 줄씩만 먼저 제안해줘.

목차를 보고 순서를 바꾸거나 뺀 다음 "이 목차로 본문을 써줘"라고 요청합니다. 긴 문서는 목차부터 받는 것이 가장 빠릅니다.

선택 실습 — 같은 방법으로 "거래처 주문 접수 업무 매뉴얼" 목차 받아 보기

8.Google 문서로 내보내기

2교시 · 5분

  1. 1Canvas 오른쪽 위 공유 및 내보내기 → Google 문서로 내보내기
  2. 2새 문서가 열리면 파일 → 이동 → "AI실무활용" 폴더
  3. 3파일 이름 : 03_친환경용품소개서_이름

메뉴 이름은 계정·업데이트에 따라 조금씩 다를 수 있습니다.

9.실습: Google 문서에서 다듬기

2교시 · 15분

AI가 못 하는 "회사 문서 모양"은 사람이 맞춥니다.

  • 제목 스타일 — 제목·소제목에 "제목 1 / 제목 2" 적용 → 왼쪽 "문서 개요"에 목차가 생김
  • 표 다듬기 — 머리 행 색 넣기, 칸 너비 맞추기
  • 머리글·바닥글 — 회사 이름, 작성일, 쪽 번호
  • 이미지 — 삽입 → 이미지 (로고나 상품 사진 자리)
  • 인쇄 미리보기 — 2장 안에 들어오는지 확인
모르는 기능은 Gemini에게

"Google 문서에서 [하고 싶은 것 — 예: 2쪽부터 쪽 번호 넣기]를 하려면 어떤 메뉴를 눌러야 해? 순서대로 알려줘."

문서 안 Gemini 패널 (Pro 계정)

문서 오른쪽 위 Gemini 아이콘 → 패널에서 바로 요청. 예) "이 표를 3줄로 요약해서 표 아래에 넣어줘"

10.실습: 까다로운 검토자에게 피드백 받기

2교시 · 15분 · 실습 SET 02

Google 문서 내용을 복사해 Gemini 새 채팅에 붙여넣거나, + 버튼으로 문서를 첨부합니다.

지금부터 너는 거래처의 깐깐한 구매 담당 과장이야. 무조건 칭찬하지 말고, 이 소개서를 받았을 때 사고 싶어지는가 / 궁금한데 빠진 정보 / 믿기 어려운 표현으로 검토해줘. 문제점마다 어디가 / 왜 문제인지 / 어떻게 고치면 좋을지를 표로 적어줘.
동의하는 것 2~3개만 골라 고치기 — 다 따를 필요 없음, 판단은 내가
고칠 때는 Canvas로 돌아가거나, 문서에서 직접 고치기
