4.실습: 표 설계하고 데이터 붙여넣기

1교시 · 실습 SET 01

STEP 01 표 설계 — Gemini 앱에 입력하기

나는 해오름상사 영업지원팀 직원이야. 친환경 사무용품 지점별 판매 내역 표를 만들려고 해. 이 표로 알고 싶은 것: 지점별·품목별·월별 매출, 잘 팔리는 품목 필요한 칸(열)을 제안하고, 칸마다 이름 / 넣을 값의 예 / 입력 규칙을 표로 정리해줘. 7개 이내로, 날짜와 따로 '월' 칸도 넣어줘.

STEP 02 연습용 데이터 만들기 — 같은 채팅에서 이어서

이 칸 구성으로 연습용 데이터를 40줄 만들어줘. 기간: 2026년 3월~8월 특징: 서울점은 꾸준히 늘고, 부산점은 여름(7~8월)에 줄어들고, 대구점은 비슷하게 유지되게 금액은 수량 × 단가로 맞게 계산해줘. Google 시트에 바로 붙여넣을 수 있는 표로, 실제 회사·사람 이름은 쓰지 말아줘.

STEP 03 시트에 붙여넣기

  1. 1새 Google 시트 → 이름 "04_친환경용품판매_이름" → "AI오피스실무" 폴더로 이동
  2. 2Gemini가 만든 표를 복사 → A1 칸에 붙여넣기
  3. 3아래쪽 탭 이름을 "데이터"로 바꾸기 (탭을 두 번 누르면 이름이 바뀜)

붙여넣은 뒤 확인하기

  • 칸이 제대로 나뉘었나? (한 칸에 몰려 있지 않은가)
  • 숫자가 오른쪽 정렬인가? 왼쪽이면 글자로 들어간 것 — 쉼표·"원"이 붙어 있는지 확인
  • 날짜 형식이 모두 같은가?
  • 첫 줄 고정 — 보기 → 고정 → 1행 (아래로 내려도 제목 줄이 보임)

6.실습: 함수를 말로 요청하기

1교시 · 실습 SET 03

함수

시트에게 "이 칸들을 이렇게 계산해 줘"라고 시키는 짧은 명령입니다. 이름을 외울 필요는 없습니다. 말로 설명하면 AI가 알맞은 함수를 골라 줍니다.

AI가 정확한 함수를 만들려면 네 가지가 필요합니다.

①데이터 위치
열, 줄 범위
②하고 싶은 계산
말로
③조건
예: 서울점만
④결과를 넣을 칸
예: H2
Google 시트에서 쓸 함수를 만들어줘. 데이터 위치: A열 날짜, B열 월, C열 지점, D열 품목, E열 수량, F열 금액, 2행~41행 하고 싶은 계산: 지점별 금액 합계 조건: 서울점만 결과를 넣을 칸: I2 함수와 함께, 초보자도 이해하게 한 줄씩 뜻을 설명해줘.

Gemini 패널에서는 데이터 위치를 몰라도 됩니다. "C열 지점별로 F열 금액 합계를 I열에 만들어줘"처럼 말하면 됩니다.

오늘 만들 함수 (최소 3개)

  • 지점별 매출 합계 → SUMIF
  • 품목별 판매 건수 → COUNTIF
  • 매출 목표 달성 여부 표시 — 예: 지점 합계가 [기준 금액] 이상이면 "달성" → IF
  • (선택) 조건 두 개 합계 — 예: 서울점 + 다회용 컵 → SUMIFS

회색 글씨의 함수 이름은 몰라도 됩니다. 말로 설명하면 AI가 골라 줍니다.

함수가 틀렸을 때

직접 검산 — 결과 중 1개는 손으로(또는 계산기로) 더해서 맞는지 확인합니다. 시트에서 숫자 칸 여러 개를 드래그하면 오른쪽 아래에 합계가 바로 보입니다.

7.실습: 피벗 테이블 만들기

1교시 · 실습 SET 04

피벗 테이블

긴 데이터를 "지점 × 월"처럼 원하는 기준으로 묶어 합계를 보여 주는 요약표입니다. 함수를 하나도 쓰지 않고, 기준만 바꾸면 표가 바로 바뀝니다.

방법 A — Gemini 패널에 말로 요청 (추천)

"데이터" 탭에서 [행 기준 — 예: 지점]을 행으로, [열 기준 — 예: 월]을 열로 해서 [계산 — 예: 금액 합계] 피벗 테이블을 새 탭에 만들어줘.

방법 B — 메뉴의 추천 기능

데이터 범위 선택 → 삽입 → 피벗 테이블 → 새 시트 → 오른쪽 편집기의 "추천" 목록에서 원하는 요약 누르기

이어서 바꿔 보기 — 기준만 바꾸면 표가 바뀌는 것 확인

  • 행을 "지점" → "품목"으로 바꾸기 (다시 "지점"으로 돌려놓기)
  • 금액 "합계" → "평균"으로 바꿔 보고 다시 합계로
  • 탭 이름을 "피벗"으로 바꾸기

검산 — 피벗 테이블의 서울점 합계가 SET 03에서 만든 지점별 합계(SUMIF) 결과와 같은가요? 이 피벗 테이블로 2교시에 차트와 대시보드를 만듭니다.

12.대시보드란?

2교시

지점 필터 (슬라이서)
꺾은선 차트
막대 차트

13.실습: 대시보드 만들기

2교시 · 실습 SET 07

STEP 01 탭 만들고 배치 정하기

아래쪽 + 버튼으로 새 탭을 만들고 이름을 "대시보드"로 바꾼 뒤, Gemini에게 배치를 묻습니다.

STEP 02 핵심 숫자 3칸

전체 매출 합계
매출 1위 지점 이름
매출 1위 품목 이름

숫자는 크게(글꼴 크기 24 이상), 위 칸에 작은 제목("총매출" 등)을 달아 줍니다.

STEP 03 차트 옮기기

SET 06의 차트 두 개를 잘라내서 "대시보드" 탭에 붙여넣고 크기를 맞춥니다. 차트 오른쪽 위 ⋮ 메뉴의 이동 기능을 써도 됩니다. 차트는 원래 표를 계속 보고 있으므로 "피벗" 탭은 지우지 않습니다.

STEP 04 필터(슬라이서) 넣기

슬라이서

버튼처럼 눌러서 "서울점만", "부산점만" 골라 볼 수 있게 해 주는 필터입니다.

  1. 1데이터 → 슬라이서 추가 → 기준 열 "지점"
  2. 2슬라이서에서 "서울점"만 골라 차트가 서울점 기준으로 바뀌는지 확인

메뉴를 못 찾거나 차트가 바뀌지 않으면 Gemini에게 물어보세요.
"Google 시트에서 슬라이서를 넣고, 다른 탭의 피벗 테이블과 차트에도 적용되게 하는 순서를 알려줘."
함수로 만든 핵심 숫자는 슬라이서를 눌러도 바뀌지 않을 수 있어요. 정상입니다.

STEP 05 보기 좋게 다듬기

16.프롬프트 역설계 — AI가 틀릴 곳을 미리 막기

실습 · 진도에 맞춰 하고 싶은 만큼

  1. 결과를 읽고, 이 결과가 나오려면 무엇을 요청했어야 할지 생각합니다
  2. "내 프롬프트" 칸에 쓰고, Gemini 새 채팅에 보내 봅니다
  3. 내 결과와 문제의 결과를 비교합니다 — 문장이 똑같을 필요는 없고, 빠진 요소가 없으면 됩니다
  4. 마지막에 예시 답안을 펼쳐 내 프롬프트와 비교합니다

예시 답안은 정답이 아니라 한 가지 예입니다. 세 문제는 진도에 맞춰 하고 싶은 만큼 풀면 됩니다.

오늘의 생각 훈련

숫자 일에서 AI는 기준이 애매한 곳에서 틀립니다. 연도가 없는 날짜, 단위가 섞인 금액, 빈 칸, 열 위치를 모를 때가 그렇습니다. 요청하기 전에 "AI가 어디서 헷갈릴까?"를 먼저 생각하고, 그 기준을 요청에 넣으세요. 그리고 내가 확인할 방법도 함께 받습니다.

역설계 ① 지저분한 판매 기록 정리하기

상황 — 지점마다 판매 기록을 다르게 적어 보냈습니다. 시트에 붙여 넣기 전에 형식을 통일하려고 합니다.

함께 준 자료 — 지점에서 받은 기록 (그대로 붙여 넣어 쓰세요)

아래 판매 기록을 시트에 붙여 넣기 좋게 정리해줘. [기록 붙여넣기] 기준: - 날짜는 2026-09-03처럼 "연-월-일"로 통일 (연도가 없으면 2026년) - 지점 이름은 서울점·부산점·대구점처럼 "○○점"으로 통일 - 금액은 단위 없이 숫자만 (8만 → 80000) - 빈 칸은 절대 채우지 말고 "확인 필요"라고 표시 정리한 표 아래에 무엇을 어떻게 바꿨는지 목록으로 적어줘.

역설계 ② 함수를 말로 요청하기

상황 — "요약" 탭에 지점별 9월 매출 합계를 수식으로 넣으려고 합니다. 함수 이름은 몰라도 됩니다.

AI가 만든 결과

지점별 9월 매출 합계 수식 B2 칸에 넣을 수식: =SUMIFS(판매기록!C:C, 판매기록!B:B, A2, 판매기록!A:A, ">="&DATE(2026,9,1), 판매기록!A:A, "<="&DATE(2026,9,30)) 수식 풀이 - 판매기록 탭 C열(금액) 중에서 - B열(지점)이 A2 칸의 지점 이름과 같고 - A열(날짜)이 9월 1일부터 9월 30일까지인 것만 더합니다 B2를 아래로 끌어 채우면 부산점, 대구점도 계산됩니다. 검산 방법 판매기록 탭에서 필터로 서울점 9월 기록만 남기고, 금액을 직접 더해 수식 결과와 같은지 확인하세요.

이 결과가 나오도록 내 프롬프트를 써 보세요.

예시 프롬프트 (정답이 아니라 한 가지 예)

Google 시트 수식을 알려줘. "판매기록" 탭: A열 날짜, B열 지점, C열 금액 (첫 줄은 제목) "요약" 탭: A2부터 지점 이름(서울점, 부산점, 대구점)이 있고, B2에 9월 매출 합계를 넣고 싶어. 조건: 지점이 같고, 날짜가 2026년 9월인 금액만 더하기 B2에 넣고 아래로 끌어 채울 수 있게 해줘. 수식이 무슨 뜻인지 쉬운 말로 풀어 주고, 내가 직접 검산하는 방법도 알려줘.
