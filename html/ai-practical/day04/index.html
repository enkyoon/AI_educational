4.실습: 표 설계하고 데이터 붙여넣기

1교시 · 12분 · 실습 SET 01

STEP 01 표 설계 — Gemini 앱에 입력하기

나는 해오름상사 영업지원팀 직원이야. 친환경 사무용품 지점별 판매 내역 표를 만들려고 해. 이 표로 알고 싶은 것: 지점별·품목별·월별 매출, 잘 팔리는 품목 필요한 칸(열)을 제안하고, 칸마다 이름 / 넣을 값의 예 / 입력 규칙을 표로 정리해줘. 7개 이내로, 날짜와 따로 '월' 칸도 넣어줘.

STEP 02 연습용 데이터 만들기 — 같은 채팅에서 이어서

이 칸 구성으로 연습용 데이터를 40줄 만들어줘. 기간: 2026년 3월~8월 특징: 서울점은 꾸준히 늘고, 부산점은 여름(7~8월)에 줄어들고, 대구점은 비슷하게 유지되게 금액은 수량 × 단가로 맞게 계산해줘. Google 시트에 바로 붙여넣을 수 있는 표로, 실제 회사·사람 이름은 쓰지 말아줘.

STEP 03 시트에 붙여넣기

  1. 1새 Google 시트 → 이름 "04_친환경용품판매_이름" → "AI실무활용" 폴더로 이동
  2. 2Gemini가 만든 표를 복사 → A1 칸에 붙여넣기
  3. 3아래쪽 탭 이름을 "데이터"로 바꾸기 (탭을 두 번 누르면 이름이 바뀜)

붙여넣은 뒤 확인하기

  • 칸이 제대로 나뉘었나? (한 칸에 몰려 있지 않은가)
  • 숫자가 오른쪽 정렬인가? 왼쪽이면 글자로 들어간 것 — 쉼표·"원"이 붙어 있는지 확인
  • 날짜 형식이 모두 같은가?
  • 첫 줄 고정 — 보기 → 고정 → 1행 (아래로 내려도 제목 줄이 보임)

6.실습: 함수를 말로 요청하기

1교시 · 15분 · 실습 SET 03

함수

시트에게 "이 칸들을 이렇게 계산해 줘"라고 시키는 짧은 명령입니다. 이름을 외울 필요는 없습니다. 말로 설명하면 AI가 알맞은 함수를 골라 줍니다.

AI가 정확한 함수를 만들려면 네 가지가 필요합니다.

①데이터 위치
열, 줄 범위
②하고 싶은 계산
말로
③조건
예: 서울점만
④결과를 넣을 칸
예: H2
Google 시트에서 쓸 함수를 만들어줘. 데이터 위치: A열 날짜, B열 월, C열 지점, D열 품목, E열 수량, F열 금액, 2행~41행 하고 싶은 계산: 지점별 금액 합계 조건: 서울점만 결과를 넣을 칸: I2 함수와 함께, 초보자도 이해하게 한 줄씩 뜻을 설명해줘.

Gemini 패널에서는 데이터 위치를 몰라도 됩니다. "C열 지점별로 F열 금액 합계를 I열에 만들어줘"처럼 말하면 됩니다.

오늘 만들 함수 (최소 3개)

  • 지점별 매출 합계 → SUMIF
  • 품목별 판매 건수 → COUNTIF
  • 매출 목표 달성 여부 표시 — 예: 지점 합계가 [기준 금액] 이상이면 "달성" → IF
  • (선택) 조건 두 개 합계 — 예: 서울점 + 다회용 컵 → SUMIFS

회색 글씨의 함수 이름은 몰라도 됩니다. 말로 설명하면 AI가 골라 줍니다.

함수가 틀렸을 때

직접 검산 — 결과 중 1개는 손으로(또는 계산기로) 더해서 맞는지 확인합니다. 시트에서 숫자 칸 여러 개를 드래그하면 오른쪽 아래에 합계가 바로 보입니다.

7.실습: 피벗 테이블 만들기

1교시 · 10분 · 실습 SET 04

피벗 테이블

긴 데이터를 "지점 × 월"처럼 원하는 기준으로 묶어 합계를 보여 주는 요약표입니다. 함수를 하나도 쓰지 않고, 기준만 바꾸면 표가 바로 바뀝니다.

방법 A — Gemini 패널에 말로 요청 (추천)

"데이터" 탭에서 [행 기준 — 예: 지점]을 행으로, [열 기준 — 예: 월]을 열로 해서 [계산 — 예: 금액 합계] 피벗 테이블을 새 탭에 만들어줘.

방법 B — 메뉴의 추천 기능

데이터 범위 선택 → 삽입 → 피벗 테이블 → 새 시트 → 오른쪽 편집기의 "추천" 목록에서 원하는 요약 누르기

이어서 바꿔 보기 — 기준만 바꾸면 표가 바뀌는 것 확인

  • 행을 "지점" → "품목"으로 바꾸기 (다시 "지점"으로 돌려놓기)
  • 금액 "합계" → "평균"으로 바꿔 보고 다시 합계로
  • 탭 이름을 "피벗"으로 바꾸기

검산 — 피벗 테이블의 서울점 합계가 SET 03에서 만든 지점별 합계(SUMIF) 결과와 같은가요? 이 피벗 테이블로 2교시에 차트와 대시보드를 만듭니다.

12.대시보드란?

2교시 · 3분

대시보드

지점 필터 (슬라이서)
꺾은선 차트
막대 차트

13.실습: 대시보드 만들기

2교시 · 17분 · 실습 SET 07

STEP 01 탭 만들고 배치 정하기 (3분)

아래쪽 + 버튼으로 새 탭을 만들고 이름을 "대시보드"로 바꾼 뒤, Gemini에게 배치를 묻습니다.

배치 묻기
상자를 클릭하면 바로 복사돼요

팀장에게 보여줄 판매 대시보드를 Google 시트 한 탭에 만들려고 해. 핵심 숫자 3개, 차트 2개, 지점 필터를 넣을 거야. 어느 칸에 무엇을 두면 보기 좋을지 칸 주소로 알려줘.

STEP 02 핵심 숫자 3칸 (5분)

전체 매출 합계
매출 1위 지점 이름
매출 1위 품목 이름

숫자는 크게(글꼴 크기 24 이상), 위 칸에 작은 제목("총매출" 등)을 달아 줍니다.

STEP 03 차트 옮기기 (3분)

SET 06의 차트 두 개를 잘라내서 "대시보드" 탭에 붙여넣고 크기를 맞춥니다. 차트 오른쪽 위 ⋮ 메뉴의 이동 기능을 써도 됩니다. 차트는 원래 표를 계속 보고 있으므로 "피벗" 탭은 지우지 않습니다.

STEP 04 필터(슬라이서) 넣기 (4분)

슬라이서
