DAY 07AI 실무활용

기획안 작성과 고도화 + 업무 자동화 첫걸음

시장 조사 요약, 판매 실적, 거래처 의견을 Gemini Notebook에 모으고, 이것을 근거로 하반기 판매 확대 기획안을 만듭니다. 기획은 한 번에 완성되지 않습니다. 단계마다 사람이 방향을 고르고 AI와 주고받으며 다듬습니다. 마지막에는 Apps Script로 시트 명단에 메일이 자동으로 나가게 해 봅니다.

1.오늘의 수업

수업방식

문제 찾기 → 아이디어 → 구체화 → 목차 → 초안 → 검토·수정 → 자동화

오늘 쓰는 도구

Gemini Notebook · Gemini (+ Canvas) · Google 문서 · Google 시트(Apps Script)

핵심목표

근거에서 출발한 기획안을 검토받으며 다듬고, 반복 업무 하나를 말로 자동화하기

해오름상사 오늘의 상황

팀장님 — "상반기 실적과 시장 흐름을 보고, 하반기에 판매를 늘릴 기획안을 만들어 주세요."

자료는 아래 준비 자료로 제공됩니다. 지난 시간 Notebook이나 조사 자료가 있으면 함께 넣어도 됩니다.

4.기획안이란? — 차이는 "근거"

1교시

"왜(문제·목표) → 무엇을(내용) → 어떻게(실행) → 얼마나(예산·일정) → 그래서(기대효과)"를 읽는 사람이 한 번에 이해하고 결정할 수 있게 정리한 문서입니다.

아쉬운 기획안

"친환경이 대세이므로 판매를 늘리자"

좋은 기획안

"재생 용지가 매출의 절반 이상인데(판매 실적), 거래처들은 매번 주문하는 것을 번거로워한다(거래처 의견) → 재생 용지 정기 배송 상품 제안"

9.Apps Script란?

2교시

Apps Script

Google 시트·문서·Gmail에 "이 일을 자동으로 해줘"라고 시킬 수 있는 기능입니다. 반복 작업을 해 주는 "매크로"와 비슷하고, 추가 비용이나 설치가 없습니다.

①Gemini에게 말로 요청
②코드를 복사해 붙여넣기
③실행 버튼

안전 약속

  • · 받는 사람은 내 메일 주소로만. 실제 동료·거래처에게 보내지 않습니다.
  • · 개인 Google 계정은 자동 메일을 하루에 보낼 수 있는 수에 제한이 있습니다. 연습에는 충분합니다.
  • · 코드를 이해할 필요는 없지만, 무엇을 하는 코드인지는 Gemini에게 물어 확인하고 실행합니다.

10.실습: 예제 ① 나에게 테스트 메일 한 통

2교시 · 실습 SET 04

  1. 1새 Google 시트 → 이름 "07_자동메일연습_이름"
  2. 2위쪽 메뉴 확장 프로그램 → Apps Script → 새 탭의 코드 편집 화면에서 이미 적힌 function myFunction() { }을 모두 지우기
  3. 3아래 요청문을 Gemini 새 채팅에 보내 코드 받기
  4. 4코드 붙여넣기 → 저장(Ctrl + S)
  5. 5위쪽 함수 선택 칸에 "sendTestMail"이 보이는지 확인 → ▶ 실행
  6. 6권한 허용 (처음 한 번만) — 아래 상자 참고
  7. 7실행 로그에 "실행 완료" → Gmail 받은편지함 확인

권한 허용 — 가장 많이 막히는 곳

  • ① "승인 필요" 창 → 권한 검토 → 내 Google 계정 선택
  • ② "Google에서 확인하지 않은 앱" 화면 → 놀라지 않기 (내가 만든 코드라서 나오는 화면)
  • ③ 왼쪽 아래 고급 → "(프로젝트 이름)(으)로 이동(안전하지 않음)" → 허용

11.실습: 예제 ② 시트 명단으로 맞춤 메일 보내기

2교시 · 실습 SET 05

오늘 만든 기획안을 관련 담당자들에게 이름을 넣어 안내하는 상황입니다.

STEP 01 같은 시트에 명단 만들기

A 이름B 이메일C 부서D 보낸 상태
김하늘내주소+kim@gmail.com영업팀
이바다내주소+lee@gmail.com서울점
박나무내주소+park@gmail.com부산점

Gmail은 주소 뒤에 +글자를 붙여도 모두 내 받은편지함으로 옵니다. 예) mymail@gmail.com → mymail+kim@gmail.com. 실제로는 나에게 3통이 오지만 3명에게 보낸 것처럼 연습할 수 있습니다. (회사 메일은 안 될 수 있으니 개인 Gmail로)

STEP 02 코드 요청

  1. 3예제 ① 코드 아래에 이어 붙여넣기 → 저장
  2. 4함수 선택 칸에서 "sendMails" → ▶ 실행 (권한 창이 또 나오면 같은 순서로 허용)
  3. 5받은편지함에 메일 3통(이름·부서가 각각 다르게), 시트 D열에 "보냄" 확인

더 해 보기 (선택) — 메일 내용에 기획안 Google 문서 링크 넣기 / 시트 위쪽 메뉴에 "메일 보내기" 버튼 만들기

12.자주 막히는 곳

증상해결
함수 선택 칸에 이름이 안 보임저장(Ctrl + S)을 안 함 → 저장 후 다시
"승인 필요"에서 멈춤창 왼쪽 아래 "고급" → "(프로젝트 이름)으로 이동"
빨간 오류 메시지오류 문장을 복사해 Gemini에 "이 오류가 났어, 고친 코드 전체를 다시 줘"
메일이 안 옴스팸함 확인, B열 주소 오타 확인
'보냄'이 다른 칸에 적힘시트 칸 순서가 요청과 다름 → 실제 칸 순서를 다시 알려 주기

코드를 고치려 하지 말고, "무슨 일이 일어났는지"를 Gemini에게 말하면 됩니다.
