AI 활용 기초와 학원 자료 분석

시험지·교재 같은 학원 자료를 Claude에 올리고, 필요한 문항을 찾고, 단원과 출제 내용을 표로 정리합니다. AI가 만든 표를 원문과 맞춰 보고 고치는 방법까지 익혀, 다음에도 그대로 쓸 수 있는 "나만의 분석 요청문"을 완성합니다.

내 학원 시험지가 없으면 아래 시험지를 씁니다. 쪽마다 내려받기를 눌러 저장한 뒤, Claude에 모든 쪽을 한 번에 올리세요. 사진을 누르면 크게 볼 수 있어요. 수업 실습용 자료이므로 다른 곳에 올리거나 나눠 주지 않습니다.

올리기 전에 확인

  • · 학생 이름·학교·연락처가 적힌 시험지는 그 부분을 가리거나 지우고 올립니다
  • · 출판사 교재는 수업 준비용으로만 쓰고, 분석 결과를 그대로 외부에 배포하지 않습니다

4.학원 자료, AI에게 무엇을 맡길까?

1교시 · 5분

생성형 AI는 질문에 답하는 도구를 넘어, 주어진 자료를 읽고 정리하는 도구로 쓸 수 있습니다.

교재·시험지 내용 확인 특정 단원·개념 문항 찾기 문항별 단원·출제 내용 정리 객관식·서술형 골라내기 여러 문항의 공통점 정리 결과를 표로 만들기
"이 자료를 분석해줘"가 아니라
무엇을 보고 → 어떤 기준으로 → 어떤 형태로 정리할지 알려 주기

5.실습: 분석 전에 자료부터 확인하기

1교시 · 10분 · 실습 01

바로 분석을 시키지 말고, AI가 자료를 제대로 읽었는지 먼저 확인합니다. 페이지가 빠지거나 수식이 잘못 읽히면 그 뒤의 분석이 모두 틀어집니다.

자료 확인 요청 — 시험지를 올린 채팅에 입력
상자를 클릭하면 바로 복사돼요

첨부한 자료의 전체 구성을 먼저 설명해주세요. 다음 항목만 확인해주세요. 1. 학년 2. 과목 3. 시험 범위 4. 전체 문항 수 5. 객관식과 서술형 문항 수 추가 분석은 아직 하지 말아주세요.

시험지와 맞춰 보기

  • 전체 페이지가 다 읽혔다
  • 전체 문항 수가 맞다
  • 문항 번호가 순서대로 빠짐없다
  • 수식·기호가 크게 틀리게 읽히지 않았다
  • 객관식과 서술형이 구분된다

적어 두기

  • 전체 문항 수 : ____
  • 객관식 / 서술형 : ____ / ____
  • 시험 범위 : ____________
  • 확인된 주요 단원 : ____________

"첨부한 중2 수학 시험지를 기준으로"
③ 기준어떤 항목으로 나눌지

④ 결과 형식어떤 모양으로 받을지

단순한 요청

"이 시험지를 분석해줘."

기준이 없어서 결과가 길어지거나, 필요 없는 내용이 들어가거나, 원하는 항목이 빠집니다.

구체적인 요청

7.실습: 필요한 문제 찾기

1교시 · 15분 · 실습 02

AI는 단어를 찾는 것뿐 아니라 조건에 맞는 문항을 골라내는 일도 잘합니다. 아래에서 하나를 골라 작성 틀을 채워 보세요.

특정 단원 '삼각형의 성질' 단원 문항만
특정 개념 내심 또는 외심의 성질을 쓰는 문항
문항 형태 서술형 문항만
풀이 도구 삼각형의 합동 조건을 쓰는 문항
첨부한 시험지에서 삼각형의 합동 조건을 활용하는 문항을 모두 찾아주세요. 문항번호와 각 문항에서 어떤 합동 조건(SSS, SAS, ASA, RHA, RHS)이 필요한지 정리해주세요. 결과는 표로 작성해주세요.

결과가 나오면 시험지에서 직접 두세 문항을 찾아 맞는지 확인합니다. 빠진 문항이 있으면 "빠진 문항이 없는지 다시 확인해주세요"라고 이어서 요청합니다.

9.실습: 항목 추가하고 모양 바꾸기

2교시 · 10분 · 실습 03 이어서

기본 표가 맞으면 학원에서 쓰는 방식에 맞게 항목을 한 번에 하나씩 늘립니다.

객관식 / 서술형 배점 문제 유형 주요 개념 계산 중심 / 개념 이해 중심 교재 페이지

같은 내용, 다른 모양으로 받아 보기

① 단원별 정리표 — "문항별 결과를 다시 묶어서, 단원별 문항 수와 해당 문항번호를 정리해주세요."
② 핵심 개념 목록 — "반복해서 등장하는 주요 개념을 개념명 / 관련 문항번호 / 출제 횟수 표로 정리해주세요."

11.잘못된 결과는 그 부분만 고치기

2교시 · 10분 · 실습 04 이어서

틀린 곳을 찾았다고 처음부터 다시 요청할 필요는 없습니다. 문제가 있는 곳만 짚어서 고칩니다. 찾은 문제에 맞는 것을 골라 쓰세요.

특정 문항 다시 확인
상자를 클릭하면 바로 복사돼요

4번 문항의 출제단원을 다시 확인해주세요. 문제 원문에 근거하여 판단하고, 왜 그렇게 분류했는지 이유도 함께 설명해주세요.

빠진 문항 확인
상자를 클릭하면 바로 복사돼요

전체 문항 수와 현재 분석된 문항 수를 비교해주세요. 누락된 문항이 있다면 해당 문항만 추가로 분석해주세요.

추측 줄이기
상자를 클릭하면 바로 복사돼요

문제에서 명확하게 확인되지 않는 내용은 추측하지 말아주세요. 판단이 어려운 경우에는 '확인 필요'라고 표시해주세요.

형식은 두고 일부만 수정
상자를 클릭하면 바로 복사돼요

기존 분석표의 형식은 그대로 유지해주세요. 5번과 8번 문항의 출제내용만 다시 확인하여 수정해주세요.

노란색 표시는 내 상황에 맞게 바꿔 쓰는 곳입니다.

13.막혔을 때

이럴 때이렇게
문항 수가 다르게 나와요파일이 끝까지 올라갔는지 확인. 사진이면 빠진 쪽을 추가로 올리고 "추가한 쪽까지 포함해서 다시 확인해주세요"
수식이 이상하게 읽혀요더 밝고 크게 찍은 사진으로 다시 올리기. 해당 문항만 "원문 식을 그대로 옮겨 적어 주세요"로 확인
