학원 홍보 랜딩페이지 제작

코드를 외우지 않고, 원하는 페이지를 설명해서 Claude가 만들게 합니다. 목적과 내용을 먼저 정리하고, 1페이지 웹사이트를 만들어 말로 고친 뒤, 인터넷에 올려 주소로 접속하는 것까지 해 봅니다.

1.오늘의 수업

수업 대상

수업방식

누구에게 무엇을 보여 줄지 먼저 정하고, 고칠 곳을 정확히 짚어 말로 페이지를 완성하기

오늘 쓰는 도구

Claude, 메모장, 인터넷 브라우저, 닷홈(웹 공간), FTP 프로그램

학원 이름·대상·과정·상담 방법 같은 소개 정보. 학원 로고나 사진이 있으면 함께 (없어도 됨)

3.랜딩페이지란?

1교시 · 5분

랜딩페이지

방문자가 특정 목적으로 처음 도착하는 한 페이지짜리 웹페이지입니다. 신규 모집, 설명회 안내, 방학 특강처럼 하나의 목적에 필요한 정보만 담고, 마지막에 상담·신청 같은 하나의 행동으로 이어지게 만듭니다.

구분일반 홈페이지랜딩페이지
구성여러 메뉴와 페이지한 페이지
목적학원 전체 소개특정 과정·상담·모집 안내
방문자의 행동여러 페이지 둘러보기상담·신청 하나로 연결

가장 먼저 정할 것은 디자인이 아니라 목적입니다. 아래 예시에서 골라도 됩니다.

누구에게예비중 학생·학부모 / 중학생 학부모 / 예비고1 / 방학 특강을 찾는 학생

5.실습: 들어갈 내용 정리하기

1교시 · 10분 · 실습 02

바로 "홈페이지 만들어줘"라고 하지 않고, 페이지에 들어갈 문구부터 정리합니다.

정보가 부족하면 질문을 받으세요. "수학학원 랜딩페이지에 필요한 정보를 한 번에 하나씩 질문해주세요. 제가 답하면 마지막에 페이지 문구로 정리해주세요."

6.실습: 페이지 구조 기획하기

1교시 · 5분 · 실습 03

모든 정보를 넣지 않고, 방문자가 위에서 아래로 자연스럽게 읽도록 순서를 정합니다.

1. 첫 화면 — 학원명, 핵심 메시지, 상담 버튼
2. 학원 소개 — 누구를, 어떻게 가르치는지
3. 교육 특징 — 진도·시험 대비·오답 관리
4. 주요 프로그램 — 대상 학년, 과정명, 운영 방식
5. 상담 안내 — 전화, 상담 신청, 위치

같은 채팅에서 "이 내용으로 위 5개 영역을 기획해주세요. 영역마다 제목 / 들어갈 내용 / 버튼을 표로 정리해주세요."라고 이어서 요청합니다.

7.실습: Claude로 1페이지 웹사이트 만들기

1교시 · 10분 · 실습 04

웹페이지 만들기 — 같은 채팅에서 이어서
상자를 클릭하면 바로 복사돼요

위에서 정리한 내용과 구조로 수학학원 홍보용 1페이지 웹사이트를 만들어주세요. 요구사항: - HTML 파일 하나로 실행할 수 있게 작성 - 깔끔하고 전문적인 학원 홈페이지 느낌 - 휴대폰에서도 읽기 편하게 - 첫 화면에 학원명과 핵심 메시지 - 주요 프로그램을 구분해서 표시 - 맨 아래에 상담 문의 영역 - 내용을 쉽게 고칠 수 있도록 코드에 한국어 설명(주석) 달기 전체 코드를 한 번에 주세요.

Claude 화면 오른쪽에 미리보기가 함께 뜨면 바로 모양을 볼 수 있습니다. 미리보기가 없거나 보이지 않아도 괜찮습니다. 다음 단계에서 파일로 저장해 확인합니다.

8.웹페이지 파일, 이것만 알면 된다

1교시 · 5분

코드를 모두 이해할 필요는 없습니다. 고칠 때 "어디를 말하는지" 알 정도면 충분합니다.

HTML — 내용과 뼈대 
<h1>수학의 힘 학원</h1>
<p>학생의 현재 수준에서 시작하는 수학</p>

h1 큰 제목 · p 일반 문장 · button 버튼 · section 페이지의 한 영역

CSS — 옷과 화장 
h1 {
  font-size: 42px;
}

글자 크기, 여백, 배치, 배경색 같은 "보이는 모습"

index.html — 웹 주소로 들어왔을 때 가장 먼저 열리는 기본 페이지의 파일 이름입니다. 오늘 만드는 파일은 꼭 이 이름으로 저장합니다.

9.실습: index.html로 저장하고 열어 보기

1교시 · 10분

  1. 1바탕화면에 my-page 폴더 만들기
  2. 2Claude 코드 상자의 복사 버튼으로 전체 코드 복사 (미리보기 화면에 내려받기 버튼이 있으면 그걸로 저장해도 됨)
  3. 3메모장 열기 → 붙여넣기
  4. 4파일 → 다른 이름으로 저장 → my-page 폴더 → 파일 이름 index.html, 파일 형식 모든 파일, 인코딩 UTF-8
  5. 5저장한 index.html을 더블클릭 → 브라우저에서 열림

첫 확인

  • 한글이 깨지지 않는다 (깨지면 인코딩을 UTF-8로 다시 저장)
  • 영역이 순서대로 보이고 버튼이 보인다
  • 브라우저 창을 좁게 줄여도(휴대폰 크기) 읽을 만하다
10분 휴식

10.실습: 말로 고치기 — 한 번에 한 곳씩

2교시 · 15분 · 실습 05

화면을 보고 마음에 안 드는 곳을 Claude에게 말로 설명합니다. 고친 코드를 받으면 index.html에 덮어써 저장하고 브라우저에서 새로고침합니다.

좋지 않은 요청

"전체적으로 더 좋게 만들어줘."

고칠 곳을 짚은 요청

첫 화면만 수정해주세요. 1. 제목을 더 짧게 2. 설명을 2줄 이내로 3. 상담 버튼을 제목 아래에 다른 영역은 바꾸지 말아주세요.

고쳐 볼 거리 — 2개 이상

문구 "첫 화면 문장이 너무 광고 같아요. 전문적이지만 과장되지 않게"
순서 "교육 방식 영역을 프로그램 영역 위로 옮겨 주세요"
디자인 "여백을 넉넉히, 제목과 본문 크기 차이를 분명하게, 내용은 그대로"
버튼 "마지막 버튼 문구를 '상담 문의하기'로, 더 눈에 띄게"
로고·학원 사진 넣기 (선택) 클릭해서 펼치기 ▾접기 ▴ 
my-page/
├─ index.html
└─ images/
   ├─ logo.png
   └─ academy.jpg

my-page 안에 images 폴더를 만들고 사진을 넣은 뒤 요청합니다. "images 폴더의 academy.jpg를 학원 소개 영역에 넣어 주세요. 너무 크지 않게, 휴대폰에서도 화면 밖으로 넘치지 않게." 파일 이름은 영어 소문자로 짓는 것이 안전합니다.

11.올리기 전 최종 점검

2교시 · 5분

내용

  • 학원명·과정명·학년이 정확
  • 날짜·연락처 오류 없음
  • "OOO" 같은 임시 문구 없음
  • 사실과 다른 홍보 표현 없음

화면

  • 제목과 본문 구분이 분명
  • 버튼·이미지가 제대로 보임
  • 휴대폰 크기에서도 읽힘

파일

  • 이름이 index.html
  • 필요한 파일이 my-page 한 폴더에

12.인터넷에 보이게 하려면 — 웹 서버와 FTP

2교시 · 5분

내 컴퓨터에서 연 index.html은 내 컴퓨터에서만 보입니다. 다른 사람이 주소로 들어오게 하려면 파일을 웹 서버에 올려야 합니다.

내 컴퓨터의 my-page 폴더
FTP 프로그램으로 서버에 올리기
웹 주소로 누구나 접속

웹 서버 (웹 공간)

인터넷에 항상 켜져 있는 컴퓨터의 한 칸입니다. 오늘은 닷홈의 웹 공간을 씁니다.

FTP

내 컴퓨터의 파일을 웹 서버로 보내는 방법입니다. 서버 주소·아이디·비밀번호가 필요합니다.

13.실습: 닷홈에 올리고 접속하기

2교시 · 20분 · 실습 06

닷홈과 FTP 프로그램의 메뉴 이름·위치는 바뀔 수 있습니다. 화면이 다르면 강사 안내를 따르거나 Claude에게 "닷홈에서 FTP 접속 정보를 확인하는 순서를 알려줘"라고 물어보세요.

STEP 1 웹 공간 준비하고 접속 정보 확인

닷홈에 로그인 → 사용할 웹 공간(호스팅)을 준비 → 관리 페이지에서 아래 정보를 확인해 적어 둡니다.

FTP 서버 주소 : ____________  /  FTP 아이디 : ____________  /  업로드 폴더 : ____________  /  내 웹 주소 : ____________

FTP 비밀번호는 종이에 적어 두거나 다른 사람과 공유하지 않습니다. AI 채팅에도 입력하지 않습니다.

STEP 2 FTP 프로그램으로 서버에 접속

강사가 안내하는 FTP 프로그램(예: 무료 프로그램 FileZilla)을 실행하고 호스트(서버 주소)·사용자명(아이디)·비밀번호를 넣어 접속합니다.

화면이 둘로 나뉩니다. 보통 왼쪽은 내 컴퓨터, 오른쪽은 서버입니다.

STEP 3 파일 올리기

  1. 1오른쪽(서버)에서 관리 페이지에 적힌 업로드 폴더로 들어가기
  2. 2왼쪽(내 컴퓨터)에서 my-page 폴더 안의 index.html (와 images 폴더)를 오른쪽으로 끌어다 놓기
  3. 3같은 이름의 파일이 있다고 물으면 덮어쓰기

STEP 4 웹 주소로 접속해 확인

  • 웹 주소가 열리고 index.html이 첫 화면으로 보인다
  • 글자·이미지가 깨지지 않는다
  • 버튼·링크가 작동한다
  • 내 휴대폰으로도 주소를 열어 봤다

14.안 보일 때 확인할 것

2교시 · 5분

이럴 때확인할 것
페이지가 안 보여요파일 이름이 정확히 index.html인가 · 올바른 업로드 폴더에 올렸나 · 업로드가 끝났나
이미지가 안 보여요images 폴더도 올렸나 · 파일 이름(대소문자 포함)이 코드와 같은가 · images/파일명 경로가 맞나
