DAY 03수학의 힘 AI 교육특강

학원 홍보 랜딩페이지 제작

코드를 한 줄도 쓰지 않고, 원하는 페이지를 설명해서 Claude가 만들게 합니다. 목적과 학원 정보를 정리하고, 1페이지 홍보 페이지를 만들어 말로 고친 뒤, 파일질라로 닷홈에 올려 내 휴대폰으로 열어 봅니다.

1.오늘의 수업

수업 대상

웹사이트를 직접 만들어 본 적 없는 원장님·강사님

수업방식

기획 → Claude로 만들기 → 말로 고치기 → 인터넷에 올리기

핵심목표

누구에게 무엇을 보여 줄지 먼저 정하고, 고칠 곳을 짚어 말로 페이지를 완성해 인터넷에 올리기

오늘 쓰는 도구

Claude, 메모장, 닷홈(무료 호스팅), 파일질라(FileZilla — FTP 프로그램)

미리 해 왔나요?

닷홈 회원가입. 아직이면 9번 실습을 시작할 때 가입부터 합니다 (본인 인증용 휴대폰 필요).

2.오늘 배우는 내용 & 전체 흐름

1목적 · 학원 정보 카드
2페이지 구조 기획
3Claude로 만들기
4index.html로 저장
5말로 고치기
6닷홈 무료 호스팅 신청
7파일질라로 올리기
8내 휴대폰으로 열어 보기

3.랜딩페이지란?

랜딩페이지

한 가지 목적을 위한 한 페이지짜리 웹페이지입니다. 필요한 정보만 담고, 마지막에 상담·신청 같은 하나의 행동으로 이어지게 만듭니다.

겨울방학 특강 모집
예비고1 설명회 신청
신규 반 개설 안내

과정마다 페이지를 하나씩 만들어 문자·SNS에 주소만 보내면 됩니다. 오늘 방법을 익히면 다음 페이지는 요청문만 바꿔 만들 수 있습니다.

4.실습: 목적 정하고 학원 정보 카드 만들기

실습 01

디자인보다 먼저 정할 것은 누구에게 · 무엇을 · 마지막에 무엇을 하게 할지입니다.

다 채운 카드는 복사해서 메모장에 저장해 두세요. 정보가 부족하면 Claude에게 "랜딩페이지에 필요한 정보를 한 번에 하나씩 질문해주세요"라고 해도 됩니다.

5.실습: 페이지 구조 기획

실습 02

표가 나오면 틀린 사실(과정명·연락처)부터 고치고 넘어갑니다.

6.실습: Claude로 1페이지 웹사이트 만들기

실습 03

Claude 화면 오른쪽에 미리보기가 뜹니다. 코드를 한 줄도 쓰지 않았는데 학원 페이지가 나왔습니다.

HTML — 내용과 뼈대 
<h1>수학의 힘 학원</h1>
<p>학생의 현재 수준에서 시작하는 수학</p>

h1 큰 제목 · p 문장 · button 버튼

CSS — 보이는 모습 
h1 {
  font-size: 42px;
}

글자 크기, 색, 여백, 배치

코드를 외울 필요는 없습니다. 고칠 때 "어디를 말하는지" 알 정도면 충분합니다.

7.실습: index.html로 저장하고 열어 보기

index.html은 인터넷 주소로 들어왔을 때 가장 먼저 열리는 파일 이름입니다. 꼭 이 이름으로 저장합니다.

  1. 1바탕화면에 my-page 폴더 만들기
  2. 2Claude 코드의 복사 버튼으로 전체 복사 (미리보기에 내려받기 버튼이 있으면 그걸로 저장해도 됨)
  3. 3메모장 → 붙여넣기 → 다른 이름으로 저장: 파일 이름 index.html, 파일 형식 모든 파일, 인코딩 UTF-8
  4. 4index.html 더블클릭 → 브라우저에서 확인. 창을 좁혀 휴대폰 크기로도 보기

한글이 깨져 보이면 메모장에서 인코딩을 UTF-8로 다시 저장하세요.

8.실습: 말로 고치기 — 한 번에 한 곳씩

실습 04

외주 업체에 부탁하던 수정을 직접 합니다. 고친 코드를 받으면 index.html에 덮어써 저장하고 브라우저를 새로고침합니다.

어디가 바뀔지 모르는 요청

"전체적으로 더 좋게 만들어줘."

고칠 곳을 짚은 요청

"첫 화면만. 제목은 짧게, 설명은 2줄 이내, 상담 버튼은 제목 아래로. 다른 영역은 그대로."

고쳐 볼 거리 — 2개 이상

문구 — 광고 같은 문장을 차분하게
순서 — 교육 방식을 프로그램 위로
버튼 — "상담 문의하기"로, 더 눈에 띄게
디자인 — 여백 넉넉히, 제목·본문 크기 차이 분명하게

9.실습: 닷홈 무료 호스팅 신청

실습 05

웹 서버 (호스팅)

내 컴퓨터의 파일은 나만 봅니다. 인터넷에 늘 켜져 있는 컴퓨터(웹 서버)에 올려야 누구나 볼 수 있습니다. 닷홈은 그 공간을 무료로 빌려줍니다.

FTP

내 컴퓨터의 파일을 웹 서버로 보내는 방법입니다. 오늘은 무료 프로그램 파일질라로 보냅니다.

  1. 1닷홈 로그인 (가입 안 했다면 지금 가입)
  2. 2무료 호스팅 신청
  3. 3관리 페이지에서 아래 정보를 확인해 적어 두기
FTP 주소 : ____________  /  FTP 아이디 : ____________  /  업로드 폴더 : ____________  /  내 웹 주소 : ____________

메뉴 이름·위치는 바뀔 수 있습니다. 막히면 Claude에게 "닷홈 무료 호스팅에서 FTP 접속 정보를 확인하는 순서를 알려줘"라고 물어보세요.

10.실습: 파일질라로 FTP 연결하고 올리기

실습 06

STEP 1 파일질라 설치

  1. 1filezilla-project.org 접속 → FileZilla Client 내려받기 (Server가 아니라 Client)
  2. 2설치 — 중간에 다른 프로그램을 함께 설치하라는 화면이 나오면 체크 해제

STEP 2 빠른 연결

파일질라를 실행하면 맨 위에 빠른 연결 줄이 있습니다.

칸넣을 것
호스트닷홈에서 적어 둔 FTP 주소
사용자명FTP 아이디
비밀번호FTP 비밀번호
포트비워 두기 (기본값 21)

→ 빠른 연결 버튼. 연결되면 아래 창이 둘로 나뉩니다. 왼쪽 = 내 컴퓨터, 오른쪽 = 서버.

FTP 비밀번호는 다른 사람과 공유하지 않고, AI 채팅에도 넣지 않습니다.

STEP 3 끌어다 놓기

  1. 1오른쪽(서버)에서 닷홈 관리 페이지에 적힌 업로드 폴더로 들어가기
  2. 2왼쪽(내 컴퓨터)에서 바탕화면 → my-page 폴더 안의 index.html을 찾기
  3. 3index.html을 오른쪽 창으로 끌어다 놓기 — 같은 이름이 있다고 물으면 덮어쓰기

STEP 4 내 휴대폰으로 열어 보기

  • PC 브라우저에서 내 웹 주소가 열린다
  • 내 휴대폰으로도 주소를 열어 봤다
  • 글자가 깨지지 않고 버튼이 보인다

11.안 보일 때 확인할 것

이럴 때확인할 것
파일질라 연결이 안 돼요호스트·아이디·비밀번호 오타, 무료 호스팅 신청이 끝났는지 확인
페이지가 안 보여요파일 이름이 정확히 index.html인가, 올바른 업로드 폴더에 올렸나
고쳤는데 그대로예요다시 저장 → 파일질라로 다시 올려 덮어쓰기 → 새로고침
한글이 깨져요메모장에서 UTF-8로 다시 저장해 올리기

12.더 해 보기 (선택)

필수는 아닙니다. 시간이 남을 때 골라서 해 보세요.

로고·사진 넣기, 두 번째 페이지, 다시 쓸 요청문 클릭해서 펼치기 ▾접기 ▴
로고·사진 — my-page 안에 images 폴더를 만들고 사진을 넣은 뒤 "images 폴더의 academy.jpg를 학원 소개 영역에 넣어 주세요. 휴대폰에서도 넘치지 않게." 올릴 때 images 폴더도 함께 끌어다 놓기. 파일 이름은 영어 소문자로.
두 번째 페이지 — 학원 정보 카드의 목적만 바꿔서(예: 설명회 신청) 같은 순서로 만들어 보기
다시 쓸 요청문 — "수학학원 홍보용 1페이지 랜딩페이지를 만들어주세요. [학원 정보 카드] 순서: 첫 화면 / 소개 / 특징 / 프로그램 / 상담. HTML 파일 하나, 휴대폰에서도 편하게, 과장 없이, 한국어 주석, 전체 코드."
