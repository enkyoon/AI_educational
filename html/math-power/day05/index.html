3.AI 에이전트란?

1교시

업무 에이전트

매번 같은 설명을 입력하는 대신, 정해진 업무를 일정한 기준과 형식으로 처리하도록 미리 설정해 둔 AI입니다. 학생 정보만 넣으면 같은 구조의 결과가 나옵니다.

일반 AI 대화

"학생이 72점을 받았고 함수 단원에서 많이 틀렸어요. 피드백 써주세요."

학생이 바뀔 때마다 조건과 형식을 다시 설명해야 함 → 결과 모양이 매번 다름

업무 에이전트

무엇을 입력받고, 어떤 기준으로 처리해, 어떤 형식으로 낼지 미리 정해 둠

학생 정보만 넣으면 됨 → 결과 모양이 늘 같음

4.실습: 에이전트로 만들 업무 고르기

1교시 · 실습 01

이런 업무가 알맞아요

  • · 자주 반복된다
  • · 들어오는 정보의 형식이 비슷하다
  • · 처리 기준을 말로 설명할 수 있다
  • · 원하는 결과 형식이 어느 정도 정해져 있다

학원 업무 예시

학습 피드백 초안 시험 결과 정리 오답 문항 요약 취약 단원 정리 상담 전 학생 정보 요약 수업 후 학습 상태 정리

내 학원의 반복 업무 3가지를 적어 보고, 그중 하나를 고릅니다. 오늘 실습은 학생 평가 피드백으로 함께 진행하고, 마지막 설계서는 내가 고른 업무로 씁니다.

6.실습: 입력값 정하기

1교시 · 실습 02

입력값은 실제로 판단에 필요한 정보만 고릅니다. 많이 넣는다고 좋은 결과가 나오지 않습니다.

입력 항목필요한 이유예시
학년범위와 표현 수준중학교 2학년
시험 점수전체 상태 파악72점
오답 문항반복되는 약점 찾기4, 7, 12, 15번
취약 단원복습 우선순위삼각형의 성질
교사 메모점수에 안 보이는 모습개념은 알지만 응용문제에서 시간이 오래 걸림

학생 개인정보

이름은 피드백 내용에 꼭 필요하지 않습니다. "학생 A · 학생 B"처럼 쓰고, 학교·연락처·주소 같은 정보는 넣지 않습니다.

7.실습: 출력값 정하기

1교시 · 실습 03

출력 형식이 정해져 있지 않으면 결과가 매번 다른 모양으로 나옵니다. 제목까지 정해 두세요.

[현재 학습 상태]
[주요 취약점]
[우선 복습 내용]
[다음 학습 방향]
[학부모 전달용 피드백]

내가 고른 업무라면 어떤 결과 칸이 필요할지 3~5개 적어 봅니다.

8.업무 지시문 쓰기

1교시 · 실습 04

지시문은 역할 → 할 일 → 입력 → 출력 형식 → 주의사항 순서로 씁니다.

처음부터 너무 많이

"수준을 5단계로 나누고, 성향도 분석하고, 다음 시험 예상점수도 내고, 상담문과 문자와 수업계획까지 만들어줘."

업무 하나부터

"시험 결과와 교사 메모로 현재 학습 상태와 다음 지도 방향을 정리해줘." — 정확히 되면 조건을 하나씩 늘립니다.

9.AI SPACE에서 에이전트 만들기

1교시

화면 구성과 버튼 이름은 강사 안내를 따릅니다. 아래는 어느 화면에서든 같은 순서입니다.

  1. 1새 에이전트 만들기 — 이름 예: "평가 피드백 도우미"
  2. 2업무 지시(지침) 칸에 8번에서 완성한 지시문 붙여넣기
  3. 3입력 항목이나 출력 형식을 따로 정하는 칸이 있으면 5~7번에서 정한 내용 넣기
  4. 4저장 → 다음 단계에서 샘플로 테스트

AI SPACE를 쓸 수 없을 때 — Claude의 프로젝트 기능에서 새 프로젝트를 만들고, 프로젝트 지침(설명) 칸에 같은 지시문을 넣으면 비슷하게 쓸 수 있습니다. 그 프로젝트 안에서 새 채팅마다 학생 정보만 넣으면 됩니다.

10분 휴식

10.실습: 샘플 3명으로 테스트하기

2교시 · 실습 05

한 명만 해 보고 끝내지 않습니다. 조건이 서로 다른 샘플을 넣어 결과가 일정하게, 그러면서도 학생마다 다르게 나오는지 봅니다. (수업용 가상 자료입니다.)

결과 확인

  • 입력한 정보가 정확히 반영됐다
  • 입력하지 않은 내용을 만들지 않았다
  • 출력 항목의 순서가 세 명 모두 같다
  • 학생마다 다른 내용이 나온다
  • 결과가 지나치게 길지 않다
  • 학부모용 문장이 이해하기 쉽다

11.문제가 보이면 지시문 고치기

2교시 · 실습 05 이어서

결과가 마음에 들지 않으면 결과를 손으로 고치지 말고 지시문에 문장을 추가합니다. 그래야 다음 학생부터 좋아집니다. 고친 뒤 같은 샘플로 다시 테스트합니다.

이런 결과가 나오면지시문에 추가할 문장
"꾸준히 복습하고 취약 부분을 보완할 필요가 있습니다" 같은 뻔한 말일반적인 학습 조언보다 입력된 취약 단원과 오답 특징을 근거로 구체적인 복습 방향을 작성해주세요.
너무 길다각 항목은 2~3문장 이내로, 반복되는 설명은 빼주세요.
입력하지 않은 성향·태도를 씀제공하지 않은 학생의 성향, 학습 태도, 가정환경, 능력 수준은 추측하지 마세요.
학부모용 문장이 어렵다학부모 전달용 피드백에서는 교육 전문 용어를 줄이고 실제 학습 상황을 쉽게 알 수 있게 써주세요.
정보가 빠졌는데 그냥 채움필수 정보가 없으면 결과를 완성하지 말고, 부족한 항목을 먼저 알려주세요.

정보 부족 테스트 — 샘플 A에서 "교사 메모" 줄을 지우고 넣어 보세요. '확인 필요'로 표시하는지, 없는 내용을 지어내는지 확인합니다.

13.실습: 대시보드로 결과 모아 보기

2교시 · 실습 06

대시보드

여러 업무 결과를 한 화면에서 확인하기 쉽게 모은 요약판입니다. 에이전트가 한 번에 한 학생을 처리한다면, 대시보드는 여러 학생의 결과를 모아서 봅니다.

학생 정보 입력
에이전트가 피드백 생성 (한 명씩)
결과 저장·정리
대시보드에서 여러 명을 한눈에
학생학년점수주요 취약단원피드백 상태
학생 A중278사각형의 성질완료
학생 B중291삼각형의 성질완료
학생 C중263삼각형의 성질확인 필요
한눈에 — 긴 설명 말고 상태와 핵심 숫자
자주 보는 것 먼저 — 매주 확인하는 항목을 앞에
요약과 상세 구분 — 자세한 피드백은 따로
상태 표시 — 완료 / 확인 필요 / 재검토 / 미처리

샘플 A·B·C의 피드백 결과를 Claude 새 채팅에 붙여넣고 요약표를 받아 봅니다.

5회차 전체 과정

회차주제흐름
DAY 01AI 활용 기초와 학원 자료 분석자료 올리기 → 찾기 → 분류 → 원문 대조
DAY 02시험지·기출문제 분석문항 분석 → 난이도 → 출제 비중 → 기출 비교 → 지도 방향
DAY 03학원 홍보 랜딩페이지기획 → 만들기 → 고치기 → 인터넷에 올리기
DAY 04PPT·마케팅 콘텐츠원본 정보 → PPT → 안내문·SNS → 영상 프롬프트
DAY 05업무 에이전트와 대시보드업무 설계 → 에이전트 → 테스트 → 결과 관리
과정을 마치며

새 기능보다, 목적과 기준

자료 업무(교재·시험지 정리), 분석 업무(기출 분석과 지도 방향), 홍보 업무(랜딩페이지·PPT·홍보문구), 반복 업무(피드백 에이전트) 모두 같은 원리입니다. 학원 업무의 목적과 기준을 먼저 분명히 정하고, AI가 그 업무를 돕도록 요청하세요. 오늘까지 만든 요청문과 설계서를 저장해 두고 다음 시험, 다음 설명회에 그대로 다시 쓰면 됩니다.
