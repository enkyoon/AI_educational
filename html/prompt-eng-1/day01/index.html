3.생성형 AI란?

1교시 · 생성형 AI의 이해와 AI 윤리

생성형 AI

사용자의 요청을 바탕으로 새로운 결과물을 만들어주는 인공지능입니다. 글 작성, 요약, 아이디어 제안, 이미지 생성, 표 만들기, 번역, 질문 답변 등을 할 수 있습니다.

기존 프로그램

정해진 메뉴와 버튼으로 정해진 기능을 실행하는 도구

예: 엑셀의 합계 버튼, 워드의 글자 크기 메뉴

생성형 AI

평소 말하듯 요청하면 요청을 해석해 결과를 만들어주는 도구

예: "이 내용을 표로 정리해줘", "공지문으로 바꿔줘"

서비스마다 기능과 특징은 조금씩 다르지만, 사용하는 방식은 거의 같습니다.

4.AI는 어떻게 답변을 만들까?

ChatGPT는 사람처럼 생각해서 정답을 찾는다기보다, 입력한 내용을 바탕으로 다음에 어떤 내용이 이어질 가능성이 높은지 예측하며 글을 만들어냅니다.

사용자의 요청

"직장인 대상으로 AI 교육을 기획해줘."

요청의 의미와 맥락 파악
관련된 내용을 조합
새로운 결과 생성

자연스럽게 말한다고 사실은 아니에요

AI는 그럴듯한 문장을 만드는 데 능숙합니다. 그래서 문장이 매끄러워도 내용이 항상 사실인 것은 아닙니다.

같은 질문을 하면 항상 같은 답이 나올까?

아닙니다. 같은 질문을 입력해도 표현, 구성, 추천 내용이 조금씩 달라질 수 있습니다. 또 내가 어떤 정보를 주느냐에 따라 결과도 달라집니다.

정보가 적은 요청

"여행 계획 만들어줘."

정보가 많은 요청

"부산으로 2박 3일 여행을 갈 거야. 대중교통을 이용하고 카페와 맛집 중심으로 일정을 만들어줘."

오늘은 요청에 따라 결과가 달라진다는 점만 기억해 두세요. 요청을 잘 쓰는 방법은 DAY 02에서 자세히 배웁니다.

5.AI가 잘하는 일 · 어려워하는 일

AI가 잘하는 일

  • 초안 만들기 — 처음부터 쓰기 어려울 때 출발점을 만들어줌
  • 내용 정리하기 — 긴 내용을 요약하거나 항목별로 나눔
  • 아이디어 넓히기 — 하나의 생각에서 여러 방향을 제안
  • 형태 바꾸기 — 긴 글을 표·목록·발표자료·이메일로 변환
  • 반복 수정하기 — "더 짧게", "더 쉽게", "표로" 요청을 계속 받아줌

AI가 어려워하는 일

  • 사실이 아닌 내용을 자연스럽게 작성하기도 함
  • 최신 정보가 필요한 질문에서 부정확한 내용을 줄 수 있음
  • 내가 알려주지 않은 정보를 추측해서 채움
  • 복잡한 상황을 지나치게 단순하게 정리하기도 함

AI의 답변 ≠ 무조건 정답

AI를 사용하는 사람의 역할

AI가 많은 일을 도와주지만, 최종 판단은 사용자가 합니다.

AI의 역할사람의 역할
아이디어 제안목적 정하기
초안 작성필요한 정보 제공하기
내용 정리결과 확인하고 틀린 내용 찾기
다른 관점 제안필요한 결과 고르기
반복 작업 돕기최종 판단하기

핵심 — AI가 만들고, 사람이 판단한다. 이 두 과정이 함께 있어야 합니다.

7.사실 확인 · 저작권 · 편향

② AI의 결과를 그대로 믿지 않기

AI가 이렇게 말했다고 생각해 봅시다.

"2026년 직장인의 82%가 생성형 AI 교육을 원합니다."

(설명을 위해 만든 예시 문장입니다)

숫자가 구체적이라고 해서 사실이라는 뜻은 아닙니다. 중요한 정보라면 다음을 확인합니다.

출처가 있는가?
언제 조사했는가?
누구를 조사했는가?
원문에서 확인되는가?

③ 저작권과 다른 사람의 결과물

AI를 사용한다고 해서 다른 사람이 만든 결과물을 마음대로 써도 되는 것은 아닙니다. 다음은 특히 조심하세요.

  • 다른 사람의 글 전체를 그대로 사용하기
  • 유료 자료를 그대로 복제하기
  • 남의 콘텐츠를 내가 만든 것처럼 사용하기
  • 특정 창작물을 그대로 베껴 돈을 버는 데 사용하기

출처와 사용 목적을 확인하고, 필요하면 직접 고치고 다시 구성하는 과정을 거칩니다.

④ AI의 편향 생각하기

AI의 결과에도 특정 관점으로 치우친 내용(편향)이 들어 있을 수 있습니다. 예를 들어 "좋은 직장인의 특징을 알려줘."라고 물었을 때 나온 특징이 모든 직장과 사람에게 똑같이 맞는 것은 아닙니다.

나는 오늘 ChatGPT를 처음 사용하고 있어. ChatGPT를 처음 배우는 사람이 업무나 일상에서 활용하기 좋은 방법을 5가지 알려줘. 각각 간단한 예시도 함께 알려줘.

첫 번째 답변이 마지막 답변은 아니다

ChatGPT는 한 번 묻고 끝나는 도구가 아닙니다. 결과를 본 뒤 같은 대화에서 계속 요청하며 결과를 발전시킬 수 있습니다.

"회사에서 활용할 수 있는 것만 골라줘." "학생이 사용할 수 있는 예시로 바꿔줘." "표로 정리해줘." "설명을 조금 더 쉽게 해줘." "핵심만 남겨서 줄여줘."

맞춤 지침

ChatGPT가 여러 대화에서 답할 때 참고할 내용을 미리 적어 두는 칸입니다. 매번 "나는 강사야, 쉽게 설명해줘"라고 말하지 않아도 됩니다.

맞춤 지침 예시 나는 초보자 대상의 강의를 자주 만든다.
설명은 어려운 용어보다 쉬운 표현을 사용해줘.
업무 자료는 핵심부터 보여줘.
예시가 필요한 경우 실제 상황을 함께 보여줘.

어떤 설정이 가장 좋은지가 아니라, "ChatGPT가 나에게 어떻게 답해주면 좋을까?"를 생각하는 것이 중요합니다.

13.실습: 나만의 맞춤 지침 만들기

처음부터 지침을 직접 쓰기 어렵다면 ChatGPT에게 먼저 초안을 부탁합니다. 아래 표에서 나에게 가까운 항목을 골라 프롬프트의 [ ] 칸을 채워 보세요.

[내가 하는 일]
회사원 사무직 학생 강사 마케터 디자이너 기획자 자영업자 프리랜서 취업준비생 개발자 콘텐츠 제작자
[AI를 활용하고 싶은 작업]
업무 이메일 보고 자료 아이디어 기획 자료 요약 공부 콘텐츠 제작 일정 정리 글쓰기 문장 수정 정보 비교
[원하는 답변 방식]
핵심부터 설명 초보자도 이해하기 쉽게 너무 길지 않게 예시와 함께 적절하면 표로 정리 전문적인 표현 단계별로 설명
상자를 클릭하면 바로 복사돼요
실습 프롬프트 ④ — [ ] 칸을 내 내용으로 바꿔 입력

나는 ChatGPT를 내 업무와 일상에서 자주 활용하려고 해. 주로 하는 일은 [내가 하는 일]이고, ChatGPT는 주로 [AI를 활용하고 싶은 작업]에 사용하고 싶어. 답변은 [원하는 답변 방식]으로 받는 것을 좋아해. 이 내용을 바탕으로 ChatGPT 맞춤 지침에 넣을 수 있는 간단한 내용을 작성해줘. 너무 많은 조건을 넣지 말고 실제로 자주 사용할 내용만 정리해줘.

* 이 요청에도 개인정보(실명, 회사명, 연락처)는 넣지 않아도 충분합니다.

나는 성인 초보자를 대상으로 AI와 디자인 관련 수업을 진행하는 강사야.
ChatGPT를 주로 수업 자료 작성 / 실습 아이디어 기획 / 설명문 작성에 활용해.
설명할 때는 초보자가 이해하기 쉬운 표현을 사용하고, 가능하면 실제 예시와 함께 설명해줘.
교육 자료를 만들 때는 내용이 한눈에 들어오도록 제목과 항목을 구분해서 정리해줘.
