3.좋은 데이터 표의 규칙

1교시 · AI로 Excel 데이터 만들기

열 (세로줄)항목 하나 — 날짜, 매장, 제품, 수량
행 (가로줄)기록 하나 — 한 번의 판매
셀 (칸)열과 행이 만나는 한 칸 — 예: B3

AI가 분석하기 좋은 표, 사람이 보기만 좋은 표

X 이런 표는 분석이 어렵습니다
  • • 제목 줄이 두세 줄이고 칸을 합쳐 놓음
  • • 한 칸에 "크루아상 3개, 식빵 2개"처럼 여러 정보
  • • "시내점", "시내 점", "시내"처럼 같은 것을 다르게 씀
  • • 중간중간 빈 줄과 소계 줄
O 이런 표가 좋습니다
  • • 맨 윗줄 한 줄만 항목 이름
  • • 한 칸에 정보 하나
  • • 같은 것은 늘 같은 이름으로
  • • 빈 줄 없이 기록이 쭉 이어짐

합계 · 소계는 표 안에 섞지 않고, 함수나 요약표로 따로 만듭니다. 이 규칙만 지켜도 AI 분석이 훨씬 정확해집니다.

4.SET 01. 업무용 가상 데이터 만들기

새 채팅을 엽니다. 실제 회사 자료를 올리는 대신 연습용 데이터를 만들어 씁니다 (DAY 01에서 배운 "회사 자료 · 개인정보는 입력하지 않기"). 일부러 정리할 거리를 섞어 달라고 요청하는 것이 포인트입니다.

1답 안의 파일 링크 눌러 내려받기
2Excel로 열어 맨 윗줄 · 아래 끝까지 훑어보기
3파일 이름을 "원본"으로 바꿔 보관

파일 링크가 안 보이면 "다운로드할 수 있게 다시 만들어줘"라고 한 번 더 요청하세요. 사람마다 데이터 내용은 조금씩 다릅니다. 괜찮습니다.

5.SET 02. 지저분한 데이터 정리하기

실제 업무 데이터는 처음부터 깨끗하지 않습니다. 바로 고치게 하지 말고 문제부터 찾게 한 다음, 확인하고 정리합니다.

받은 파일 이름은 "정리본"으로 바꿉니다. 원본과 정리본을 나눠 두면, 정리가 잘못되었을 때 언제든 처음으로 돌아갈 수 있습니다.

6.SET 03. 함수 만들어 직접 넣기

함수 이름을 몰라도 됩니다. "어느 칸에 · 무엇을 · 어떤 조건으로" 계산하고 싶은지만 설명하면 AI가 함수를 만들어 줍니다. 받은 함수는 Excel에 직접 붙여 넣어 봅니다.

자주 쓰는 함수 — 외우지 말고 "이런 게 있구나"만

SUM 더하기 AVERAGE 평균 COUNTIF 조건에 맞는 개수 세기 SUMIF 조건에 맞는 것만 더하기 IF 조건에 따라 다른 값 넣기 XLOOKUP · VLOOKUP 다른 표에서 찾아오기

이름을 몰라도 "시내점 판매금액만 더하고 싶어"라고 말하면 AI가 맞는 함수를 골라 줍니다.

· J3, J4에 대학가점 · 주택가점 판매금액 합계도 구하고 싶어 (같은 함수를 이어서 쓰는 법) · 제품별로 몇 번 팔렸는지 세고 싶어 · 판매금액이 10만 원 이상이면 '큰 주문', 아니면 '일반'이라고 H열에 표시하고 싶어 · 다른 시트의 제품 목록에서 제품별 원가를 찾아오고 싶어

직접 넣어 보기 — 정리본을 Excel로 열고, 알려 준 칸을 클릭한 뒤 함수를 붙여 넣고 Enter. 결과가 나오면 다른 매장 칸에도 같은 방식으로 넣어 보세요.

7.함수 오류가 나면 — 오류 표시를 그대로 보여 주기

#N/A찾는 값이 없음 — 이름 표기가 다를 때 자주 생김
#VALUE!숫자 자리에 글자가 들어감
#NAME?함수 이름 오타 · 내 Excel에 없는 함수

화면을 캡처해서 함께 올리면 더 정확합니다. #NAME?가 나오면 쓰는 Excel 버전을 알려 주고 "이 버전에서 되는 함수로 바꿔줘"라고 요청하세요.

2교시 · Excel 데이터 분석과 업무 활용

새 채팅을 열고 정리본 파일을 입력창의 +로 올립니다. 처음에는 분석을 시키지 말고 무엇이 들어 있는지부터 확인합니다.

추천 질문 중에 점장님 요청("어느 매장 · 어떤 빵이 잘 팔렸나")에 맞는 것을 골라 다음 SET에서 씁니다.

9.SET 05. 질문으로 요약표 만들기

요약표 (Excel에서는 피벗 테이블)

150줄짜리 기록을 "매장별 합계", "월별 합계"처럼 기준에 따라 한눈에 보이게 묶은 표입니다. AI에게 질문하면 바로 만들어 주고, Excel에서 직접 만드는 방법도 물어볼 수 있습니다.

시간이 있다면 알려 준 순서대로 Excel에서 피벗 테이블을 직접 만들어 보고, AI가 만든 표와 숫자가 같은지 비교해 보세요.

10.SET 06. 차트 만들기

막대 차트항목끼리 크기 비교 — 매장별 매출
꺾은선 차트시간에 따른 변화 — 월별 추이
원 차트전체 중 비율 — 분류별 비중 (항목 5개 이하일 때)

차트의 한글이 깨져 보이면 "한글이 깨지지 않게 다시 만들어줘"라고 요청하거나, Excel에서 데이터를 선택하고 삽입 → 차트로 직접 만들어도 됩니다.

11.SET 07. 숫자는 믿기 전에 직접 검산하기

AI가 만든 표는 대부분 맞지만, 조건을 잘못 이해하거나 일부 줄을 빠뜨릴 수 있습니다. 보고에 쓰기 전에 숫자 1~2개는 내가 직접 확인합니다.

1요약표에서 숫자 하나 고르기 (예: 시내점 8월)
2Excel에서 필터나 SET 03의 함수로 직접 계산
3다르면 AI에게 알려 주고 다시 계산

12.SET 08. 보고 문장 만들기

표와 차트만 보내면 받는 사람이 직접 해석해야 합니다. 핵심을 문장으로 정리해서 함께 보냅니다. 이때 원인은 추측이라고 표시하게 하는 것이 중요합니다.

"더 짧게", "숫자는 표로", "제안을 하나 더"처럼 이어서 고쳐 보세요. 메일에 쓴 숫자가 SET 07에서 검산한 숫자와 같은지도 확인합니다.
