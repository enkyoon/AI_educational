Gemini의 기본 개념

Gems란?

Gem의 기본 개념

특정한 역할·목적·작업방식을 미리 설정해놓은 맞춤형 Gemini

일반 Gemini 사용

매번 같은 조건을 반복해서 입력

"너는 SNS 마케팅 전문가야. 20~30대를 대상으로 작성해줘. 제목 5개를 만들어줘. 지나치게 광고성 표현은 사용하지 마."

Gem 사용

처음 한 번 역할 + 목적 + 작업규칙 + 출력형식 설정 후, 이후에는 핵심 내용만 입력

"신제품 수분크림 SNS 콘텐츠 만들어줘."

핵심 이해: Gem = 반복적으로 사용하는 프롬프트와 작업방식을 미리 설정해놓은 맞춤형 AI

실습 ①

기본 SNS 콘텐츠 기획 Gem 만들기

사용자가 제품이나 서비스를 입력하면 기본적인 SNS 콘텐츠 아이디어를 만들어주는 Gem 제작하기

STEP 01. 새로운 Gem 만들기

Gems → Gem 만들기 → 이름 입력하기 (예: SNS 콘텐츠 기획 도우미)

STEP 02. Instructions 작성하기
상자를 클릭하면 바로 복사돼요

너는 SNS 콘텐츠를 기획하는 마케팅 전문가야. 사용자가 제품, 서비스 또는 브랜드에 대한 정보를 입력하면 해당 내용을 바탕으로 SNS 콘텐츠 아이디어를 만들어줘. 먼저 해당 제품이나 서비스에 관심을 가질 가능성이 높은 주요 타깃을 간단하게 정리해줘. 그 다음 타깃이 관심을 가질 만한 콘텐츠 아이디어를 5개 제안해줘. 각각의 콘텐츠에는 콘텐츠 제목, 콘텐츠의 핵심 내용, 이 콘텐츠가 타깃에게 효과적인 이유를 포함해줘. 지나치게 과장된 광고 표현은 사용하지 말고 실제 SNS 콘텐츠 기획에 활용할 수 있도록 작성해줘.

역할SNS 기획 전문가
목적콘텐츠 아이디어 생성
작업타깃 분석 + 아이디어
출력제목+내용+이유
STEP 03. 첫 번째 테스트하기 — 주제 중 하나 선택
① 카페 — 대구에 새로 오픈한 개인 카페, 대표 메뉴는 수제 티라미수와 크림라떼 ② 화장품 — 20~30대를 위한 저자극 수분크림 ③ 헬스장 — 직장인 대상 24시간 헬스장 ④ 여행상품 — 제주도 2박 3일 소규모 감성 여행 ⑤ 자유주제
STEP 04. 결과 확인하기
타깃이 적절하게 설정되었는가? 콘텐츠 아이디어가 서로 다른가? 제목이 실제 SNS에서 사용할 수 있는 수준인가? 결과가 너무 길거나 짧지 않은가? 출력형식이 일정한가?

아직 수정하지 않기 — 먼저 현재 결과의 아쉬운 점 2개 이상 직접 찾아보기

너는 20~30대를 대상으로 SNS 콘텐츠를 기획하는 디지털 마케팅 전문가야. 사용자가 제품, 서비스 또는 브랜드 정보를 입력하면 Instagram을 중심으로 활용할 수 있는 콘텐츠를 기획해줘. 먼저 주요 타깃, 타깃이 관심을 가질 만한 핵심 포인트, 제품이나 서비스에서 강조할 만한 장점을 간단하게 분석해줘. 분석이 끝나면 서로 다른 방향의 콘텐츠 아이디어를 5개 제안해줘. 콘텐츠 5개가 모두 비슷해지지 않도록 정보형, 공감형, 후기형, 참여형, 제품소개형 등 서로 다른 접근방식을 사용해줘. 결과는 [콘텐츠 번호] / 제목 / 콘텐츠 유형 / 핵심 내용 / 추천 게시물 형식 / 예상 타깃 반응 형식으로 작성해줘. 제목은 SNS에서 바로 활용할 수 있도록 너무 길지 않게 작성해줘. 지나치게 과장된 광고 표현이나 확인되지 않은 효과는 작성하지 마. 전체적으로 친근하지만 전문적인 문체를 사용해줘.

STEP 01. 실습용 브랜드 예시 — 모닝포레스트

모닝포레스트는 20~30대 직장인을 위한 작은 라이프스타일 브랜드입니다. 바쁜 일상 속에서도 잠시 쉬어갈 수 있는 편안한 경험을 전달하는 것을 목표로 합니다. 대표 제품은 향초, 룸스프레이, 디퓨저이며, 주요 색상은 아이보리·세이지그린·우드 브라운입니다. 브랜드 문체는 차분하고 따뜻하지만 지나치게 감성적인 표현은 사용하지 않으며, '최고', '완벽한', '무조건', '인생템' 같은 과장된 표현은 사용하지 않습니다. 주요 고객은 25~39세 직장인이며 집에서 보내는 휴식시간과 공간 꾸미기에 관심이 많습니다.

STEP 02~03. Knowledge 추가 & Instructions에 활용 조건 추가

SNS 콘텐츠 기획 도우미 → Knowledge에 브랜드 자료 추가 → Gem 이름 변경(모닝포레스트 SNS 콘텐츠 기획자)

기존 Instructions 마지막에 추가: "Knowledge에 제공된 브랜드 자료가 있는 경우 해당 자료를 우선적으로 참고하여 콘텐츠를 작성해줘. 브랜드의 주요 고객, 문체, 제품정보, 색상과 분위기를 결과에 반영해줘. 브랜드 자료에 없는 제품의 특징이나 효능은 임의로 만들어내지 마. Knowledge의 내용과 사용자의 요청이 충돌하는 경우에는 임의로 결정하지 말고 어떤 부분이 충돌하는지 먼저 알려줘."
