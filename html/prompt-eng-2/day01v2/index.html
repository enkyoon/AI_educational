03
Definition

Gemini란?

Gemini는 Google의 생성형 AI입니다. 질문에 답하는 것뿐만 아니라 다양한 업무에 활용할 수 있습니다.

아이디어 기획 글 작성과 수정 자료 요약과 정리 정보 비교 표와 데이터 구성 이미지 생성 업무자료 제작 Google 서비스와 연계한 작업

이번 과정에서는 Gemini를 단순히 "질문하면 답을 알려주는 AI"로 사용하지 않습니다.
하나의 업무를 Gemini에서 시작하고, 결과를 수정하며 다른 Google 도구와 연결해 실제 업무 결과물로 발전시키는 방법을 경험합니다.

예를 들어 이런 업무를 맡았다고 생각해봅니다

"다음 달 신입사원 교육을 준비해야 한다."

교육 아이디어 만들기
기획안 작성하기
준비 일정 정리하기
발표자료 구성하기
참석자 안내하기

기존에는 각각의 결과물을 따로 작성했다면, AI를 활용하면 하나의 정보를 계속 발전시키며 여러 업무에 재활용할 수 있습니다. 오늘은 이 과정을 직접 경험합니다.

Gemini와 첫 대화 해보기

실습 프롬프트 ①
상자를 클릭하면 바로 복사돼요

나는 오늘 Gemini를 처음 사용하고 있어. Gemini를 처음 배우는 사람이 업무나 일상에서 활용하기 좋은 방법을 5가지 정도 추천해줘. 각각 간단한 예시도 함께 알려줘.

결과를 확인합니다. 사람마다 결과의 표현이나 예시는 조금씩 다르게 나올 수 있습니다. 여기서 중요한 것은 첫 번째 답변을 그대로 사용하는 것이 아닙니다.

결과를 원하는 방향으로 수정하기

같은 대화에서 조건을 추가합니다.

상자를 클릭하면 바로 복사돼요

방금 추천한 내용 중에서 회사 업무에 활용할 수 있는 방법만 다시 골라줘. 이번에는 활용상황 / Gemini에게 요청할 내용 / 기대결과 3가지 항목으로 표로 정리해줘.

대화를 이어서 결과 발전시키기

처음부터 긴 프롬프트를 다시 작성할 필요는 없습니다. 이미 생성된 결과를 보면서 짧게 수정 요청을 할 수 있습니다.

"3번째 방법을 조금 더 자세히 설명해줘."
"초보자가 바로 따라할 수 있는 예시로 바꿔줘."
"설명이 너무 길어. 핵심만 3줄로 줄여줘."
"회사 보고자료에 들어갈 표현으로 바꿔줘."
AI 활용에서 중요한 것은 한 번의 질문으로 완성하기보다 결과를 확인하면서 계속 방향을 조정하는 것입니다.

Hands-on Practice · 1교시

실습: 하나의 업무를 Gemini와 함께 기획하기

오늘 사용할 상황

"나는 회사의 교육 담당자입니다. 신입사원을 대상으로 생성형 AI 활용 미니 세미나를 준비해야 합니다."

바로 최종 기획안을 만들기보다 먼저 아이디어를 정리합니다.

실습 프롬프트 ③
상자를 클릭하면 바로 복사돼요

나는 회사의 교육 담당자야. 신입사원을 대상으로 '업무에 활용하는 생성형 AI'라는 주제로 2시간짜리 사내 미니 세미나를 기획하려고 해. 참석자는 약 30명이고 생성형 AI를 거의 사용해보지 않은 초보자가 대부분이야. 세미나 기획안을 만들기 전에 1. 교육 목표 2. 주요 교육내용 3. 실습 아이디어 4. 진행 시 주의할 점 을 먼저 제안해줘. 아직 최종 기획안은 작성하지 말고 아이디어를 검토할 수 있는 수준으로 정리해줘.

왜 바로 최종 결과물을 만들지 않을까?

AI에게 처음부터 "기획안 만들어줘"라고 요청할 수도 있지만, 중요한 업무에서는 먼저 방향을 확인하는 것이 좋습니다.

아이디어 생성
내용 검토
수정 요청
최종 결과물 제작

이런 순서로 진행하면 원하는 방향의 결과물을 만들기 쉽습니다.

기획 방향 수정하기

AI가 만든 결과가 마음에 들지 않는다면 다시 요청합니다.

실습이 너무 어려운 경우

"실습이 조금 어려운 것 같아. AI를 처음 사용하는 직장인도 강사의 화면을 보면서 바로 따라할 수 있는 수준으로 실습 내용을 다시 제안해줘."

내용이 너무 많은 경우

"2시간 안에 진행하기에는 내용이 많은 것 같아. 반드시 알아야 하는 핵심내용만 남겨서 교육내용을 다시 구성해줘."

여기까지 진행했다면 하나의 업무를 AI에게 설명 → 아이디어 생성 → 검토 → 수정하는 기본 흐름을 경험한 것입니다.

실습: 하나의 내용을 여러 업무자료로 확장하기

첫 번째 시간에는 Gemini와 함께 세미나 아이디어를 만들었습니다. 이제 같은 내용을 실제 업무자료로 발전시켜봅니다. 회사에서는 하나의 업무에도 여러 결과물이 필요합니다.

기획을 승인받을 때문서
준비과정을 관리할 때시트
내용을 발표할 때슬라이드

중요한 것은 각각을 처음부터 새로 만드는 것이 아니라, 하나의 원본 정보를 목적에 맞게 변환하여 활용하는 것입니다.

Google 문서용 기획안 만들기

실습 프롬프트 ④
상자를 클릭하면 바로 복사돼요

지금까지 정리한 내용을 바탕으로 사내 결재용 교육 기획안 초안을 작성해줘. 제목은 '신입사원 생성형 AI 활용 미니 세미나 기획안'으로 하고 다음 항목으로 구성해줘. 1. 교육 목적 2. 교육 대상 3. 교육 개요 4. 주요 교육내용 5. 기대효과 Google 문서에 바로 옮겨 사용할 수 있도록 간결한 회사 문서 형태로 작성해줘.

생성된 내용을 Google Docs로 옮겨봅니다. 이번 실습의 목적은 Google Docs 기능을 배우는 것이 아니라 AI에서 만든 내용을 실제 업무 문서로 연결하는 것입니다.

같은 내용을 일정관리표로 바꾸기

실습 프롬프트 ⑤
상자를 클릭하면 바로 복사돼요

방금 만든 교육 기획안을 바탕으로 행사 준비용 일정표를 만들어줘. 다음 항목을 포함해줘. 업무 / 담당자 / 시작일 / 마감일 / 진행상태 / 비고 행사 준비 기간은 2주라고 가정하고 필요한 준비업무를 10개 정도 만들어줘. Google Sheets에 바로 붙여넣기 좋은 표 형식으로 작성해줘.

결과를 Google Sheets로 옮겨봅니다.

관리할 항목도 AI에게 제안받기

"이 일정표를 실제 회사에서 관리한다고 했을 때 추가하면 좋은 항목이 있을까? 너무 복잡하지 않게 3개 정도 추천하고 이유도 알려줘."

AI는 단순히 결과물을 만드는 도구뿐 아니라, 업무에 필요한 요소를 함께 생각하는 도구로도 활용할 수 있습니다.

발표자료 구성으로 바꾸기

이번에는 같은 기획안을 팀장에게 설명한다고 가정합니다.

실습 프롬프트 ⑥
상자를 클릭하면 바로 복사돼요

지금까지 만든 교육 기획안을 팀장에게 설명하기 위한 발표자료로 구성해줘. 전체 슬라이드는 5장으로 하고 슬라이드 번호 / 제목 / 핵심내용 형태로 정리해줘. 한 슬라이드에 내용이 너무 많지 않도록 하고 약 5분 정도 설명하는 발표자료를 기준으로 만들어줘.

결과를 Google Slides에 옮겨봅니다.
