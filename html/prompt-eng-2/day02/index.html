Definition · 1교시

Gem이란?

Gem은 특정한 목적과 역할을 미리 설정하여 반복해서 사용할 수 있는 나만의 Gemini입니다.

일반 Gemini — 매번 반복 입력

"나는 마케팅 담당자야. 회사 업무에 사용할 수 있게 작성해줘. 너무 장황하지 않게 설명해줘."

Gem — 미리 설정해두는 것
어떤 역할을 할 것인지 어떤 작업을 도와줄 것인지 어떤 방식으로 답할 것인지 무엇을 주의해야 하는지

어떤 Gem을 만들 수 있을까?

업무나 일상에서 반복해서 사용하는 작업이 있다면 Gem으로 만들어볼 수 있습니다.

업무 문서 작성 도우미 SNS 콘텐츠 기획 도우미 회의록 정리 도우미 블로그 글 작성 도우미 여행 일정 기획 도우미 보고서 요약 도우미 상품 아이디어 기획 도우미 공부 계획 도우미 면접 준비 도우미 아이디어 브레인스토밍 도우미

오늘은 기능만 확인하고 끝내지 않고, 실제 수업이 끝난 뒤에도 활용할 수 있는 Gem 하나를 같이 완성해봅니다.

04
Hands-on Practice

실습: 나만의 Gem 만들기

오늘 함께 만들 Gem

업무 문서·보고 도우미

회사 업무에서 자주 발생하는 이메일 작성, 보고내용 정리, 공지문 작성, 회의내용 요약, 핵심 정리, 문장 수정, 문서형태 변환을 도와주는 Gem입니다.

Gem을 만들기 전에 역할 정하기

Gem 이름

업무 문서·보고 도우미

Gem의 역할

회사에서 사용하는 문서와 보고내용을 정리하고, 상황에 맞는 형태로 작성해주는 AI 도우미

주요 작업
이메일 작성 공지문 작성 보고내용 정리 회의내용 요약 문장 수정 긴 내용 요약
답변 방식
  • • 정중하고 자연스러운 회사 표현 사용
  • • 중요한 내용부터 작성, 불필요하게 장황하지 않게
  • • 필요한 경우 제목과 항목 구분
  • • 확인되지 않은 정보는 임의로 생성하지 않기

Gem 지침을 AI에게 작성시키기

Gem 지침을 처음부터 직접 작성할 필요는 없습니다. 어떤 Gem을 만들고 싶은지 Gemini에게 알려주고 지침 초안을 먼저 만들어봅니다.

상자를 클릭하면 바로 복사돼요
실습 프롬프트 ①

회사 업무에서 반복적으로 사용할 '업무 문서·보고 도우미' Gem을 만들려고 해. 이 Gem은 다음 작업을 도와줘야 해. - 업무 이메일 작성 - 공지문 작성 - 보고내용 정리 - 문장 수정 - 긴 내용 요약 - 회의내용 정리 답변은 회사 업무에 사용할 수 있도록 정중하고 간결하게 작성하고, 사용자가 제공하지 않은 날짜, 숫자, 사람 이름 등은 임의로 만들어내지 않도록 하고 싶어. Gem의 지침으로 사용할 수 있도록 역할 / 주요 작업 / 답변방식 / 주의사항이 명확하게 드러나는 형태로 작성해줘.

결과를 확인한 뒤 필요한 부분을 수정합니다.

Gem에 지침 입력하기

생성된 지침을 Gem 설정에 입력합니다. 예를 들어 다음과 같은 형태로 구성할 수 있습니다.

상자를 클릭하면 바로 복사돼요
Gem Instructions 예시 (그대로 입력 가능)

너는 회사 업무에 필요한 문서와 보고내용을 정리해주는 '업무 문서·보고 도우미'야. 사용자가 전달하는 업무 상황과 내용을 바탕으로 실제 회사에서 사용할 수 있는 형태의 결과물을 작성해줘. 주요 역할은 다음과 같아. 1. 업무 이메일 작성 2. 보고내용 정리 3. 공지문 및 안내문 작성 4. 회의내용 요약 5. 긴 문장의 핵심내용 정리 6. 문장을 자연스럽고 명확하게 수정 7. 같은 내용을 상황에 맞는 다른 문서형식으로 변환 답변할 때는 다음 기준을 지켜줘. - 회사 업무에 적합한 정중하고 자연스러운 표현 사용 - 중요한 내용부터 먼저 보여주기 - 내용이 길어질 경우 제목이나 항목을 나누어 정리하기 - 사용자가 원하는 결과물의 형식을 제시하면 그 형식에 맞추기 - 불필요하게 장황한 설명은 줄이기 다음 내용은 특히 주의해줘. - 사용자가 제공하지 않은 날짜, 금액, 사람 이름, 회사명 등은 임의로 만들지 않기 - 확인되지 않은 사실을 사실처럼 작성하지 않기 - 중요한 정보가 부족하면 먼저 필요한 내용을 질문하기 사용자가 어떤 문서로 만들어야 할지 잘 모르는 경우에는 상황에 적절한 결과물 형태를 2~3개 추천해줘.

Gem의 이름과 지침을 저장합니다.

실습: 만든 Gem 테스트하기

Gem을 만들었다면 실제로 사용해봅니다.

테스트 ① 업무 이메일 상자를 클릭하면 바로 복사돼요

내일 오후 2시에 예정되어 있던 팀 회의가 오후 4시로 변경됐어. 팀원들에게 보내는 안내메일을 작성해줘.

테스트 ② 보고내용 정리 상자를 클릭하면 바로 복사돼요

이번 달 신규 고객 문의는 38건이었고 지난달은 27건이야. 계약은 이번 달 9건, 지난달 6건이야. 팀장에게 간단하게 보고할 수 있도록 정리해줘.

테스트 ③ 결과물 형태 변경 상자를 클릭하면 바로 복사돼요

방금 내용을 이메일이 아니라 회의에서 1분 정도 보고할 수 있는 형태로 바꿔줘.

같은 Gem이 상황에 따라 어떻게 결과를 바꾸는지 확인합니다.

Gemini 이미지 생성 시작하기

이제 오늘 수업의 메인 실습인 이미지 생성으로 넘어갑니다. AI 이미지 생성이라고 하면 처음부터 굉장히 긴 프롬프트를 작성해야 한다고 생각할 수 있지만, 꼭 그렇지는 않습니다. 먼저 간단하게 이미지를 만든 다음 "배경을 바꿔줘", "제품을 조금 크게 해줘", "분위기를 더 고급스럽게 해줘"처럼 결과를 보면서 계속 수정할 수 있습니다.

무엇을

어디에

STEP 02 배경 추가하기 상자를 클릭하면 바로 복사돼요

향수 제품은 유지하고 배경을 어두운 검정색 스튜디오로 바꿔줘. 제품 아래에는 검은색 대리석 받침대를 추가해줘.

STEP 03 조명 추가하기 상자를 클릭하면 바로 복사돼요

제품의 왼쪽 뒤에서 부드러운 빛이 들어오도록 해줘. 향수병 유리에 빛이 자연스럽게 반사되고 고급스럽고 신비로운 분위기로 만들어줘.

STEP 04 광고용 구도 만들기 상자를 클릭하면 바로 복사돼요

고급 향수 브랜드의 상업용 광고사진처럼 만들어줘. 향수는 화면 오른쪽에 배치하고 왼쪽에는 광고 문구를 넣을 수 있도록 충분한 여백을 만들어줘.

같은 제품을 다른 콘셉트로 바꾸기

이번에는 같은 제품을 유지하면서 분위기만 변경합니다.

STEP 01 봄 시즌 상자를 클릭하면 바로 복사돼요

같은 향수 제품을 유지하고 봄 시즌 광고 이미지로 바꿔줘. 밝은 자연광과 연한 핑크색 꽃잎을 활용해서 화사하고 부드러운 분위기로 만들어줘.

STEP 02 여름 시즌 상자를 클릭하면 바로 복사돼요

같은 향수 제품을 유지하면서 이번에는 여름 시즌 광고로 바꿔줘. 투명한 물과 얼음, 시원한 하늘색 계열을 활용해서 청량한 느낌을 만들어줘.

STEP 03 럭셔리 콘셉트 상자를 클릭하면 바로 복사돼요

같은 향수 제품을 유지하고 럭셔리 브랜드 광고처럼 바꿔줘. 검정과 골드 계열을 사용하고 조명은 강하고 드라마틱하게 연출해줘.

같은 제품이라도 색감 / 계절 / 분위기 / 콘셉트를 변경하면 전혀 다른 결과물을 만들 수 있습니다.

Image Build-up · SET 03 · 2교시

기존 사진을 광고 이미지로 바꾸기

이번에는 AI가 처음부터 이미지를 만드는 것이 아니라 기존 이미지를 활용합니다. 강사가 준비한 제품사진(예: 흰 배경에 촬영된 음료 제품사진)을 함께 사용합니다.

STEP 01 이미지 먼저 분석하기 상자를 클릭하면 바로 복사돼요

이 이미지에 있는 제품과 현재 사진의 특징을 설명해줘. 제품의 형태와 주요 특징, 배경, 조명, 구도를 중심으로 알려줘.

AI가 현재 이미지를 어떻게 이해하고 있는지 먼저 확인합니다.

STEP 02 배경만 변경하기 상자를 클릭하면 바로 복사돼요

제품 자체의 형태와 디자인은 유지하고 배경만 여름 해변의 테이블 위로 바꿔줘. 밝은 햇빛이 들어오는 청량한 음료 광고 느낌으로 만들어줘.

여기서 중요한 표현은 "제품은 유지하고 배경만 바꿔줘"입니다.

STEP 03 주변 요소 추가하기 상자를 클릭하면 바로 복사돼요

제품 주변에 얼음과 물방울, 레몬 조각을 자연스럽게 추가해줘. 제품이 가장 눈에 띄도록 해줘.

STEP 04 광고용 구도 만들기 상자를 클릭하면 바로 복사돼요

SNS 광고 이미지로 사용할 수 있도록 제품을 화면 중앙보다 약간 오른쪽에 배치하고 왼쪽에는 제목이나 광고문구를 넣을 수 있는 깔끔한 여백을 만들어줘.

11
Image Build-up · SET 04

두 개의 레퍼런스를 활용하기

이번에는 이미지 두 장을 함께 활용합니다.

이미지 A사용할 제품 이미지
이미지 B원하는 분위기나 스타일의 레퍼런스 이미지
STEP 01 두 이미지의 역할 알려주기 상자를 클릭하면 바로 복사돼요

첫 번째 이미지의 제품을 사용하고 두 번째 이미지의 분위기와 배경 연출을 참고해서 새로운 광고 이미지를 만들어줘. 제품의 형태와 디자인은 첫 번째 이미지를 최대한 유지해줘.

STEP 02 결과 수정하기

결과를 보고 원하는 부분을 다시 요청합니다.

상자를 클릭하면 바로 복사돼요

제품이 배경에 비해 너무 작아 보여. 제품의 크기를 조금 키우고 화면의 중심에 더 가깝게 배치해줘.

상자를 클릭하면 바로 복사돼요

배경이 너무 복잡해. 제품 주변의 요소를 조금 줄이고 제품에 시선이 집중되도록 만들어줘.

한 번의 프롬프트로 끝내지 않고 계속 디렉팅합니다.

12
Key Concept

이미지 생성에서 중요한 '디렉팅'

좋은 결과를 만들기 위해 모든 조건을 처음부터 입력할 필요는 없습니다. 결과를 보면서 다음과 같이 요청할 수 있습니다.

"조금 더 밝게 만들어줘."
"제품의 크기를 키워줘."
"배경을 조금 단순하게 해줘."
"왼쪽에 여백을 만들어줘."
"카메라가 조금 더 가까운 느낌으로 만들어줘."
"전체적으로 더 고급스럽게 바꿔줘."
"제품은 그대로 유지해줘."
AI에게 이미지를 만드는 것뿐 아니라 수정 방향을 설명하는 것도 중요한 이미지 활용 방법입니다.

Image Build-up · SET 05

하나의 이미지를 여러 용도로 바꾸기

이번에는 완성한 이미지를 다른 용도로 변경합니다.

SNS 피드용 이미지 상자를 클릭하면 바로 복사돼요

이 이미지를 SNS 피드용 광고 이미지처럼 다시 구성해줘. 제품이 한눈에 보이도록 하고 깔끔하고 임팩트 있는 구도로 만들어줘.

웹사이트 배너용 이미지 상자를 클릭하면 바로 복사돼요

같은 콘셉트를 유지하면서 웹사이트 메인 배너에 사용할 수 있는 가로형 이미지로 다시 구성해줘. 제품은 오른쪽, 텍스트를 넣을 공간은 왼쪽에 만들어줘.

상세페이지용 이미지 상자를 클릭하면 바로 복사돼요

같은 제품을 활용해서 온라인 쇼핑몰 상세페이지 상단에 들어갈 제품 비주얼처럼 만들어줘. 제품을 크게 보여주고 주변 요소는 최소화해줘.

같은 이미지를 처음부터 새로 만드는 것이 아니라 용도에 맞게 다시 구성할 수 있습니다.

Hands-on Practice

실습: 자유주제로 나만의 광고 이미지 만들기

마지막에는 직접 주제를 하나 선택하여 이미지를 단계적으로 완성합니다. 주제가 떠오르지 않는 경우 다음 중 하나를 선택합니다.

향수 화장품 커피 디저트 탄산음료 운동화 가방 문구류 반려동물 제품 스마트기기 여행상품 인테리어 소품
STEP 01 기본 이미지 상자를 클릭하면 바로 복사돼요

[제품 또는 주제]를 중심으로 깔끔한 제품 이미지를 만들어줘.

STEP 02 콘셉트 추가 상자를 클릭하면 바로 복사돼요

이 제품을 [원하는 분위기]의 광고 이미지로 발전시켜줘. 배경과 조명도 분위기에 맞게 구성해줘.

STEP 03 구도 수정 상자를 클릭하면 바로 복사돼요

제품이 가장 눈에 띄도록 구도를 정리해줘. 광고 문구를 넣을 수 있도록 한쪽에 적당한 여백도 만들어줘.

STEP 04 결과를 보며 직접 수정하기

예를 들어 다음과 같이 요청합니다.

"제품 크기를 조금 키워줘."
"배경이 너무 화려해. 조금 더 단순하게 바꿔줘."
"조명을 조금 더 부드럽게 만들어줘."
"전체적으로 더 고급스러운 광고사진처럼 만들어줘."

Tips

프롬프트 길이 & 수정 표현 정리

처음부터 긴 프롬프트를 써야 할까?

이미지를 생성하는 방법은 한 가지가 아닙니다. 처음부터 주제 + 배경 + 구도 + 조명 + 색감 + 스타일 + 용도를 모두 입력할 수도 있습니다.

하지만 처음 이미지 생성을 배우는 단계에서는 하나씩 발전시키는 방식이 이해하기 쉽습니다. 결과를 직접 보면서 무엇을 유지할지, 무엇을 바꿀지 판단할 수 있기 때문입니다.

특정 요소 유지하기

"제품은 그대로 유지하고 배경만 변경해줘."

특정 부분만 수정하기

"현재 색감은 유지하고 구도만 바꿔줘."

분위기 유지하기

"전체 분위기는 유지하되 조명만 조금 밝게 해줘."

레이아웃 수정하기

"제품은 오른쪽으로 이동하고 왼쪽에 여백을 만들어줘."

복잡도 줄이기

"배경 요소를 줄이고 제품에 시선이 집중되도록 해줘."

핵심 — 유지할 것 + 변경할 것을 구분해서 설명하는 것입니다.
