02
Key Concept

이미지 생성과 영상 제작의 차이

이미지를 만들 때는 "한 장의 화면이 어떻게 보여야 하는가?"를 생각했습니다. 영상에서는 여기에 "이 화면에서 무엇이 움직여야 하는가?"가 추가됩니다.

이미지 프롬프트

"차가운 얼음 위에 놓인 탄산음료 캔. 푸른색 스튜디오 배경. 청량한 상업용 제품광고."

영상 프롬프트

"탄산음료 캔은 고정되어 있고 표면의 물방울이 천천히 흘러내린다. 카메라는 제품을 향해 천천히 가까워진다."

03
Good Source Image

영상용 이미지는 무엇이 다를까

영상으로 활용할 이미지는 무조건 화려하게 만드는 것이 좋은 것은 아닙니다. AI가 무엇을 움직여야 하는지 쉽게 이해할 수 있도록 만드는 것이 중요합니다.

주요 대상이 명확하게 보이는 이미지
제품·인물의 형태가 잘 보이는 이미지
배경과 주요 대상이 잘 구분되는 이미지
움직일 요소를 상상하기 쉬운 이미지
제품 + 수십 개의 소품 + 복잡한 배경
제품 + 단순한 배경 + 몇 개의 소품
04
Practice

실습: 기본 제품 이미지 만들기

오늘의 첫 번째 실습은 '탄산음료 광고'입니다. 최종 영상은 나중에 연결하고, 오늘은 영상을 만들기 위한 이미지와 짧은 영상 클립을 만드는 데 집중합니다. Gemini 이미지 생성 기능을 활용합니다.

실습 프롬프트 ①
상자를 클릭하면 바로 복사돼요

AI 영상 제작에 사용할 탄산음료 제품 이미지를 만들어줘. 은색 탄산음료 캔 하나가 투명한 얼음 위에 세워져 있어. 배경은 시원한 블루 계열의 미니멀한 스튜디오로 만들어줘. 제품의 형태가 명확하게 보이고 배경과 제품이 잘 구분되도록 해줘. 상업용 음료 광고사진처럼 깔끔하고 선명하게 만들어줘. 영상으로 움직이기 쉽도록 주변 요소는 너무 복잡하지 않게 구성해줘.

05
Vary the Source

움직일 요소 생각하고 같은 제품의 변형 이미지 만들기

이미지를 만든 뒤 바로 Flow로 이동하지 않고, 먼저 무엇을 움직일지 생각합니다. 영상에서는 모든 것을 움직일 필요가 없습니다 — 오히려 무엇은 고정하고 무엇만 움직일 것인지 구분하는 것이 중요합니다.

제품 — 고정
물방울 — 천천히 흘러내림
얼음 — 조금씩 움직임
카메라 — 제품을 향해 천천히 가까워짐
실습 프롬프트 ② — 클로즈업 버전
상자를 클릭하면 바로 복사돼요

방금 만든 탄산음료 제품의 형태와 디자인, 블루 계열의 광고 분위기는 유지해줘. 이번에는 카메라가 제품에 조금 더 가까이 있는 클로즈업 광고 이미지로 만들어줘. 캔 표면의 차가운 물방울과 금속 질감이 잘 보이도록 해줘. 배경은 단순하게 유지해줘.

실습 프롬프트 ③ — 물보라 버전
상자를 클릭하면 바로 복사돼요

같은 탄산음료 제품과 전체적인 블루 계열의 분위기는 유지해줘. 이번에는 제품 전체가 화면 중앙에 보이고 제품 뒤쪽에 가벼운 물보라가 있는 광고 이미지로 만들어줘. 제품의 형태가 가장 잘 보이도록 하고 주변 요소는 과하지 않게 만들어줘.

이제 ① 기본 제품 이미지 ② 제품 클로즈업 이미지 ③ 물보라가 있는 제품 이미지, 세 가지 영상소스가 준비되었습니다.

06
Why Multiple Shots

왜 같은 제품을 여러 장 만들까

AI 영상에서는 한 장의 이미지로 모든 장면을 해결할 필요가 없습니다. 목적에 맞는 이미지를 선택할 수 있습니다.

제품 전체를 보여주고 싶을 때 → 기본 이미지
질감을 보여주고 싶을 때 → 클로즈업 이미지
강렬한 움직임을 만들고 싶을 때 → 물보라 이미지

이미지를 많이 만드는 것이 목적이 아니라, 영상에서 어떤 화면이 필요한지 생각하면서 이미지를 준비하는 것이 중요합니다.

기본 이미지 — 카메라가 천천히 가까워지기
클로즈업 — 물방울이 천천히 흘러내리기
물보라 — 배경의 물과 얼음이 움직이기
07
Prompting Guide

영상 프롬프트의 기본 구조

대상+ 행동+ 환경+ 카메라+ 분위기
대상 — 은색 탄산음료 캔
행동 — 캔 표면의 물방울이 천천히 흐른다
환경 — 차가운 얼음이 놓인 블루 스튜디오
카메라 — 제품을 향해 천천히 가까워진다
분위기 — 청량하고 세련된 음료 광고
실습 프롬프트 ④ — Gemini에게 영상 프롬프트 도움받기
상자를 클릭하면 바로 복사돼요

이 이미지를 Google Flow에서 짧은 광고영상으로 만들려고 해. 이미지의 제품과 전체 분위기는 유지하면서 자연스러운 움직임을 추가하고 싶어. 영상에서 사용할 수 있도록 1.제품이나 주변 요소의 움직임 2.카메라 움직임 3.전체 분위기를 제안하고 마지막에는 Google Flow에 입력할 수 있는 영상 생성 프롬프트 하나로 작성해줘. 움직임은 너무 많지 않게 해줘.

08
Google Flow

Google Flow란?

Google Flow는 텍스트나 이미지 등을 활용해 AI 영상 콘텐츠를 제작할 수 있는 도구입니다. 오늘은 Flow의 모든 기능이 아니라 다음 과정에 집중합니다. (여러 영상을 연결하고 길이를 확장하는 과정은 DAY 06에서 진행합니다.)

1프로젝트 만들기
2텍스트로 영상 만들기
3이미지를 영상으로 만들기
4결과를 보고 수정하기
프로젝트 프롬프트 입력 이미지 또는 자료 추가 생성 유형 영상 모델 화면 비율 영상 길이 생성 결과

기능 이름을 모두 외울 필요는 없습니다 — "무엇을 넣어서 어떤 영상을 만들 것인가"를 이해하는 것이 중요합니다.

10
Motion Language

영상 프롬프트에서 중요한 행동 표현 · 움직임 절제하기

영상에서는 "예쁘게 만들어줘"보다 실제로 화면에서 일어나는 행동을 설명하는 것이 중요합니다.

물방울이 천천히 흘러내린다 머리카락이 바람에 살짝 흔들린다 커피에서 따뜻한 김이 올라온다 빛이 창문을 통해 들어온다 카메라가 제품 가까이 다가간다
X 한 장면에 너무 많은 움직임 — "제품이 회전하고 얼음이 폭발하고 물이 튀고 카메라가 빠르게 회전하고 조명이 깜빡이고 배경도 움직이게 해줘." → 결과를 통제하기 어려움

처음에는 주요 움직임 1개 + 보조 움직임 1개 + 카메라 움직임 정도로 시작합니다.

12
Keep vs Move

유지할 것과 움직일 것 구분하기

Image to Video에서는 특히 "무엇을 유지해야 하는지" 명확하게 알려주는 것이 좋습니다.

유지할 것 "제품 형태는 유지해줘." / "제품 위치는 변경하지 말아줘." / "배경의 색감은 유지해줘."
움직일 것 "물방울만 움직여줘." / "배경의 나뭇잎만 흔들리게 해줘." / "카메라만 가까워지게 해줘."
실습 프롬프트 ⑧ — 카메라 고정, 움직임만 변경
상자를 클릭하면 바로 복사돼요

제품과 배경은 그대로 유지해줘. 이번에는 카메라를 움직이지 말고 완전히 고정해줘. 캔 표면의 물방울과 제품 주변의 작은 얼음만 자연스럽게 움직이도록 만들어줘.

실습 프롬프트 ⑨ — 카메라 움직임만 변경
상자를 클릭하면 바로 복사돼요

제품의 형태와 배경은 유지해줘. 제품 주변의 움직임은 최소화하고 카메라가 왼쪽에서 오른쪽으로 아주 천천히 이동하면서 제품을 보여주도록 만들어줘. 제품이 화면에서 벗어나지 않게 해줘.

AI 영상 제작에 사용할 [제품 또는 주제] 이미지를 만들어줘. 주요 대상이 명확하게 보이고 배경과 잘 구분되도록 구성해줘. 전체 분위기는 [원하는 분위기]로 만들어줘. 영상에서 움직임을 추가하기 쉽도록 주변 요소는 너무 복잡하지 않게 만들어줘.

15
Iterate

결과를 보고 한 가지씩 수정하기

원하는 영상이 바로 나오지 않는다면 프롬프트 전체를 처음부터 바꾸지 않습니다. 가장 마음에 들지 않는 부분 하나를 선택합니다.

움직임이 너무 빠를 때 — "현재 제품과 배경은 유지해줘. 움직임의 속도만 지금보다 훨씬 느리고 부드럽게 만들어줘."
카메라 움직임이 클 때 — "제품과 주변 움직임은 유지하고 카메라 움직임만 줄여줘. 제품을 화면 중심에 유지하면서 아주 천천히 움직이도록 해줘."
제품이 많이 변할 때 — "제품의 형태와 디자인을 최대한 유지해줘. 제품 자체는 움직이지 않고 주변 요소와 카메라만 움직이게 해줘."
움직임이 너무 많을 때 — "[유지할 움직임]만 남기고 나머지 움직임은 최소화해줘."

좋은 영상 프롬프트를 만드는 순서

1등장 대상 정하기
2주요 움직임 정하기
3환경 정하기
4카메라 움직임 정하기
5분위기 추가하기
6영상 생성
7결과 확인
8한 가지씩 수정

이미지 생성에서 사용했던 "결과를 보고 디렉팅하는 방법"을 영상에서도 그대로 활용합니다.

오늘 가장 중요한 것은 "이미지를 만들고 영상 버튼을 누르는 것"이 아닙니다. AI 영상에서는 무엇을 보여줄 것인가 → 무엇을 움직일 것인가 → 무엇을 유지할 것인가 → 카메라는 어떻게 움직일 것인가를 구분해서 생각해야 합니다.
