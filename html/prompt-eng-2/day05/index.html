2.이미지 생성과 영상 제작의 차이

이미지를 만들 때는 "한 장의 화면이 어떻게 보여야 하는가?"를 생각했습니다. 영상에서는 여기에 "이 화면에서 무엇이 움직여야 하는가?"가 추가됩니다.

이미지 프롬프트

"차가운 얼음 위에 놓인 탄산음료 캔. 푸른색 스튜디오 배경. 청량한 상업용 제품광고."

영상 프롬프트

"탄산음료 캔은 고정되어 있고 표면의 물방울이 천천히 흘러내린다. 카메라는 제품을 향해 천천히 가까워진다."

3.영상용 이미지는 무엇이 다를까

영상으로 활용할 이미지는 무조건 화려하게 만드는 것이 좋은 것은 아닙니다. AI가 무엇을 움직여야 하는지 쉽게 이해할 수 있도록 만드는 것이 중요합니다.

주요 대상이 명확하게 보이는 이미지
제품·인물의 형태가 잘 보이는 이미지
배경과 주요 대상이 잘 구분되는 이미지
움직일 요소를 상상하기 쉬운 이미지
제품 + 수십 개의 소품 + 복잡한 배경
제품 + 단순한 배경 + 몇 개의 소품

4.실습: 기본 제품 이미지 만들기

오늘의 첫 번째 실습은 '제품 광고 영상'입니다. 최종 영상은 나중에 연결하고, 오늘은 영상을 만들기 위한 이미지와 짧은 영상 클립을 만드는 데 집중합니다. Gemini 이미지 생성 기능을 활용합니다.

어떤 제품으로 할까? — 이런 주제로 해볼 수 있어요

움직임을 넣기 쉬운 제품일수록 영상이 잘 나옵니다. 하나를 골라 아래 작성 틀을 채워 보세요. 고르기 어려우면 ① 탄산음료로 따라 하면 됩니다(예시 보기도 탄산음료 기준).

① 탄산음료 캔 (수업 예시)

얼음 위의 차가운 은색 캔

움직일 것: 흘러내리는 물방울, 튀어 오르는 탄산 · 블루 계열 스튜디오

② 커피

창가 테이블 위 따뜻한 머그컵

움직일 것: 피어오르는 김, 일렁이는 햇살 · 포근한 아침

③ 향수

대리석 위 투명한 유리 향수병

움직일 것: 병에 반사되는 빛, 흩날리는 꽃잎 · 고급스럽고 은은한

④ 운동화

트랙 위에 놓인 새 러닝화

움직일 것: 흔들리는 신발 끈, 날리는 먼지 · 역동적이고 스포티한

⑤ 디저트

나무 접시 위 딸기 케이크

움직일 것: 내려앉는 슈가파우더, 흐르는 시럽 · 달콤하고 따뜻한

AI 영상 제작에 사용할 탄산음료 제품 이미지를 만들어줘. 은색 탄산음료 캔 하나가 투명한 얼음 위에 세워져 있어. 배경은 시원한 블루 계열의 미니멀한 스튜디오로 만들어줘. 제품의 형태가 명확하게 보이고 배경과 제품이 잘 구분되도록 해줘. 상업용 음료 광고사진처럼 깔끔하고 선명하게 만들어줘. 영상으로 움직이기 쉽도록 주변 요소는 너무 복잡하지 않게 구성해줘.

5.움직일 요소 생각하고 같은 제품의 변형 이미지 만들기

이미지를 만든 뒤 바로 Flow로 이동하지 않고, 먼저 무엇을 움직일지 생각합니다. 영상에서는 모든 것을 움직일 필요가 없습니다 — 오히려 무엇은 고정하고 무엇만 움직일 것인지 구분하는 것이 중요합니다.

제품 — 고정
물방울 — 천천히 흘러내림
얼음 — 조금씩 움직임
카메라 — 제품을 향해 천천히 가까워짐

쓰기 전에 알아둘 키워드 — 카메라 거리와 각도

거리 — 얼마나 가까이서 찍을까
익스트림 클로즈업 아주 가까이, 물방울·질감까지클로즈업 제품이 화면을 가득 채움미디엄 샷 제품과 주변이 조금풀 샷 제품 전체와 배경와이드 샷 멀리서, 공간 전체
각도 — 어디에서 바라볼까
아이 레벨 눈높이 정면로우 앵글 아래에서 올려다봄 — 크고 웅장하게하이 앵글 위에서 내려다봄탑뷰 바로 위에서 수직으로45도 사선 입체감이 살아남

용어를 몰라도 괜찮아요. "조금 더 가까이", "위에서 내려다보게"처럼 쉬운 말로 써도 AI가 알아듣습니다.

방금 만든 탄산음료 제품의 형태와 디자인, 블루 계열의 광고 분위기는 유지해줘. 이번에는 카메라가 제품에 조금 더 가까이 있는 클로즈업 광고 이미지로 만들어줘. 캔 표면의 차가운 물방울과 금속 질감이 잘 보이도록 해줘. 배경은 단순하게 유지해줘.
같은 탄산음료 제품과 전체적인 블루 계열의 분위기는 유지해줘. 이번에는 제품 전체가 화면 중앙에 보이고 제품 뒤쪽에 가벼운 물보라가 있는 광고 이미지로 만들어줘. 제품의 형태가 가장 잘 보이도록 하고 주변 요소는 과하지 않게 만들어줘.

이제 ① 기본 제품 이미지 ② 제품 클로즈업 이미지 ③ 물보라가 있는 제품 이미지, 세 가지 영상소스가 준비되었습니다.

6.왜 같은 제품을 여러 장 만들까

AI 영상에서는 한 장의 이미지로 모든 장면을 해결할 필요가 없습니다. 목적에 맞는 이미지를 선택할 수 있습니다.

제품 전체를 보여주고 싶을 때 → 기본 이미지
질감을 보여주고 싶을 때 → 클로즈업 이미지
강렬한 움직임을 만들고 싶을 때 → 물보라 이미지

이미지를 많이 만드는 것이 목적이 아니라, 영상에서 어떤 화면이 필요한지 생각하면서 이미지를 준비하는 것이 중요합니다.

기본 이미지 — 카메라가 천천히 가까워지기
클로즈업 — 물방울이 천천히 흘러내리기
물보라 — 배경의 물과 얼음이 움직이기

8.Google Flow란?

Google Flow는 Google의 생성 모델로 글이나 이미지를 넣어 AI 영상을 만드는 도구입니다. 오늘은 Flow의 모든 기능이 아니라 아래 과정에 집중합니다. (여러 영상을 연결하고 길이를 늘리는 과정은 DAY 06에서 진행합니다.)

1프로젝트 만들기
2텍스트로 영상 만들기
3이미지를 영상으로 만들기
4결과를 보고 수정하기

① 첫 화면 — "Google Flow로 만들기"로 시작

  • • 화면 가운데 Google Flow로 만들기를 누르면 작업 화면으로 들어갑니다.
  • • 쓸 수 있는 기능과 양은 Google AI 구독 등급에 따라 다릅니다.

② 작업 화면 — 오른쪽 대화창에 요청하기

  • • 오른쪽 대화창("무엇을 만들고 싶으신가요?")에 만들고 싶은 영상을 적습니다. 한국어로 써도 잘 알아듣습니다.
  • • 입력창 왼쪽 +로 이미지를 올려 영상의 출발점으로 쓸 수 있습니다.
  • • 만든 영상과 이미지는 가운데 작업 공간과 왼쪽 전체 미디어에 모입니다.

③ 크레딧 승인 — 만들 때마다 크레딧이 쓰여요

  • • 요청을 보내면 "○○ 크레딧을 사용하여 동영상을 생성하시겠습니까?"라고 묻습니다. 승인을 눌러야 만들어집니다.
  • • 크레딧은 정해진 양만 있어서, 대충 여러 번 만드는 것보다 요청을 먼저 잘 다듬는 것이 중요합니다. 오늘 작성 틀로 먼저 쓰는 이유입니다.
  • • 항상 승인을 누르면 다음부터 묻지 않고 바로 크레딧이 쓰이니 주의하세요.

9.텍스트만으로 광고영상 만들기

먼저 이미지를 넣지 않고 텍스트만으로 영상을 만들어봅니다.

차가운 얼음이 깔린 푸른색 스튜디오. 은색 탄산음료 캔 하나가 얼음 위에 세워져 있다. 캔 표면에 맺힌 물방울이 천천히 아래로 흘러내린다. 카메라는 제품을 향해 아주 천천히 가까워진다. 청량하고 세련된 상업용 음료 광고 영상.

물방울이 천천히 흘러내린다 머리카락이 바람에 살짝 흔들린다 커피에서 따뜻한 김이 올라온다 빛이 창문을 통해 들어온다 카메라가 제품 가까이 다가간다

처음에는 주요 움직임 1개 + 보조 움직임 1개 + 카메라 움직임 정도로 시작합니다.

11.이미지에 움직임 만들기

1교시에서 만든 탄산음료 기본 이미지를 Flow에 추가한 뒤 영상으로 만들어봅니다. 작성 틀의 [ ] 칸에 움직임과 카메라를 직접 써 보세요. 같은 이미지라도 이 두 칸만 바꾸면 전혀 다른 영상이 나옵니다.

첨부한 이미지의 탄산음료 제품 형태와 디자인은 유지해줘. 제품 자체는 움직이지 않고 캔 표면의 물방울이 천천히 아래로 흘러내리게 해줘. 주변의 작은 얼음 조각은 아주 미세하게 움직여줘. 카메라는 제품을 향해 천천히 가까워지게 해줘. 전체적으로 청량하고 고급스러운 음료 광고 영상처럼 만들어줘.

12.유지할 것과 움직일 것 구분하기

Image to Video에서는 특히 "무엇을 유지해야 하는지" 명확하게 알려주는 것이 좋습니다.

유지할 것 "제품 형태는 유지해줘." / "제품 위치는 변경하지 말아줘." / "배경의 색감은 유지해줘."
움직일 것 "물방울만 움직여줘." / "배경의 나뭇잎만 흔들리게 해줘." / "카메라만 가까워지게 해줘."
제품과 배경은 그대로 유지해줘. 이번에는 카메라를 움직이지 말고 완전히 고정해줘. 캔 표면의 물방울과 제품 주변의 작은 얼음만 자연스럽게 움직이도록 만들어줘.
제품의 형태와 배경은 유지해줘. 제품 주변의 움직임은 최소화하고 카메라가 왼쪽에서 오른쪽으로 아주 천천히 이동하면서 제품을 보여주도록 만들어줘. 제품이 화면에서 벗어나지 않게 해줘.

13.카메라에 따라 같은 이미지도 달라진다

가까워지기 → 제품 강조
옆으로 이동하기 → 공간과 제품을 함께 보여주기
고정하기 → 제품 주변의 움직임에 집중
멀어지기 → 전체 공간이나 마지막 장면 표현

영상에서는 "무엇이 움직이는가"뿐 아니라 "카메라가 어떻게 보는가"도 중요합니다.

14.다른 주제로 한 번 더 만들어보기

탄산음료가 아닌 다른 주제로 같은 과정을 반복합니다. 작성 틀의 [ ] 칸을 내가 고른 주제로 채우세요. 막히면 "예시 보기"(커피 머그컵 예)를 펼쳐 보세요. 주제가 떠오르지 않으면 아래 중 하나를 선택합니다.

커피향수화장품운동화헤드폰디저트스마트워치자동차호텔여행지가방인테리어 소품
AI 영상 제작에 사용할 창가 나무 테이블 위의 따뜻한 커피 머그컵 이미지를 만들어줘. 주요 대상이 명확하게 보이고 배경과 잘 구분되도록 구성해줘. 전체 분위기는 포근하고 따뜻한 아침으로 만들어줘. 영상에서 움직임을 추가하기 쉽도록 주변 요소는 너무 복잡하지 않게 만들어줘.
첨부한 이미지의 머그컵은 유지해줘. 커피 위로 하얀 김이 천천히 피어오른다. 창밖에서 들어오는 햇살이 부드럽게 일렁인다. 카메라는 머그컵을 향해 아주 천천히 가까워진다. 전체적으로 포근하고 따뜻한 상업용 영상처럼 만들어줘.

15.결과를 보고 한 가지씩 수정하기

원하는 영상이 바로 나오지 않는다면 프롬프트 전체를 처음부터 바꾸지 않습니다. 가장 마음에 들지 않는 부분 하나를 선택합니다.

움직임이 너무 빠를 때 — "현재 제품과 배경은 유지해줘. 움직임의 속도만 지금보다 훨씬 느리고 부드럽게 만들어줘."
카메라 움직임이 클 때 — "제품과 주변 움직임은 유지하고 카메라 움직임만 줄여줘. 제품을 화면 중심에 유지하면서 아주 천천히 움직이도록 해줘."
제품이 많이 변할 때 — "제품의 형태와 디자인을 최대한 유지해줘. 제품 자체는 움직이지 않고 주변 요소와 카메라만 움직이게 해줘."
움직임이 너무 많을 때 — "[유지할 움직임]만 남기고 나머지 움직임은 최소화해줘."

좋은 영상 프롬프트를 만드는 순서

1등장 대상 정하기
2주요 움직임 정하기
3환경 정하기
4카메라 움직임 정하기
5분위기 추가하기
6영상 생성
7결과 확인
8한 가지씩 수정

이미지 생성에서 사용했던 "결과를 보고 디렉팅하는 방법"을 영상에서도 그대로 활용합니다.
