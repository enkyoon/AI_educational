03
Definition

바이브코딩이란?

바이브코딩(Vibe Coding)의 기본 개념

사용자가 원하는 결과와 기능을 자연어로 설명하고, 생성형 AI가 이를 바탕으로 코드를 생성·수정하도록 하면서 개발을 진행하는 방식

기존 방식

사람이 코드 문법을 이해하고 직접 작성하기

AI 활용 방식
사람이 원하는 결과와 기능 설명하기
AI가 코드 생성하기
실행 결과 확인하기
수정사항 다시 요청하기
원하는 결과가 나올 때까지 반복하기

바이브코딩의 특징

  • 자연어를 활용하여 코드 생성 요청하기
  • 완성된 코드를 처음부터 직접 작성하는 부담 줄이기
  • 원하는 결과를 설명하는 능력 중요하게 활용하기
  • 생성된 결과를 직접 확인하고 수정 방향 결정하기
  • AI와 지속적으로 대화하며 결과물 발전시키기
핵심 구조
생각하기 → 요청하기 → 확인하기 → 수정하기 → 반복하기

바이브코딩을 단순한 'AI 코드 생성'이 아닌 AI와 함께 결과물을 반복적으로 만들어가는 과정으로 이해하기

HTML — 웹페이지의 구조 만들기

HTML의 역할: 웹페이지에 어떤 콘텐츠와 요소를 배치할 것인지 구성하기

대표 요소
제목 문장 이미지 버튼 링크 입력창 목록 영역
간단한 예시 
<h1>재윤 카페</h1>
<p>대구에서 운영하는 작은 카페입니다.</p>

HTML을 활용하여 구성할 수 있는 내용
  • <h1> → 큰 제목 만들기
  • <p> → 문장 작성하기
  • <img> → 이미지 넣기
  • <button> → 버튼 만들기
  • <a> → 링크 연결하기
💡 핵심 이해: HTML = 웹페이지의 뼈대와 콘텐츠 구성. 코드 문법 자체를 외우기보다 HTML이 어떤 역할을 담당하는지 파악하기.

CSS — 웹페이지 디자인 만들기

CSS의 역할: HTML로 구성한 요소의 시각적인 모습과 배치 설정하기

CSS를 활용하여 변경할 수 있는 내용
글자 크기 글꼴 텍스트 색상 배경색 이미지 크기 요소 간 간격 정렬 위치 테두리 버튼 형태 전체 레이아웃
간단한 예시 
<!-- HTML 예시 -->
<h1>재윤 카페</h1>
<p>대구에서 운영하는 작은 카페입니다.</p>
<button>메뉴 보기</button>

/* CSS 예시 */
<style>
h1 {
  font-size: 40px;
  text-align: center;
}
p {
  color: #555555;
  font-size: 16px;
}

button {
  background-color: #8B5A2B;
  color: white;
  padding: 10px 20px;
  border: none;
  border-radius: 10px;
}
</style>
동일한 HTML + 다른 CSS 같은 콘텐츠라도 색상 변경하기, 폰트 변경하기, 여백 변경하기, 요소 배치 변경하기 → 전혀 다른 분위기의 웹사이트 제작 가능
💡 핵심 이해: CSS = 웹사이트의 시각적 완성도와 분위기 결정

프롬프트 작성 시 포함할 5가지 요소

① 무엇을 만들 것인지 정하기
카페 홈페이지 개인 포트폴리오 청첩장 브랜드 홈페이지 상품 소개 페이지
② 누구를 위한 사이트인지 정하기

사이트를 실제로 이용할 사용자 정의하기

예시) 카페 홈페이지: → 방문 예정 고객

포트폴리오: → 채용 담당자 또는 클라이언트

청첩장: → 결혼식 참석자

③ 어떤 콘텐츠를 넣을지 정하기
예시 (카페 홈페이지)
매장 소개 대표 메뉴 사진 위치 영업시간 SNS
④ 어떤 디자인을 원하는지 정하기
※ 추상적인 표현 X "예쁘게 만들어줘."
※ 구체적인 표현 O "화이트와 베이지 색상을 중심으로 여백을 넓게 사용하고 사진이 돋보이는 차분한 디자인으로 구성해줘."
디자인 설명에 활용할 수 있는 요소:
색상 분위기 폰트 느낌 이미지 크기 여백 레이아웃 참고 스타일
⑤ 어떤 기능이 필요한지 정하기
메뉴 클릭하기 특정 영역으로 이동하기 이미지 슬라이드 보기 다른 페이지 이동하기 SNS 연결하기 지도 열기 문의하기
※ 기본 프롬프트 구조

1. 사이트 종류 | 2. 목적·사용자 | 3. 콘텐츠 | 4. 디자인 | 5. 기능

프롬프트 예시
상자를 클릭하면 바로 복사돼요

대구에 위치한 개인 카페를 소개하는 홈페이지를 만들어줘. 주요 사용자는 카페 방문을 고민하고 있는 20~30대 고객이야. 메인에는 대표 이미지와 소개 문구를 보여주고, 아래에는 메뉴, 매장소개, 위치, 영업시간 영역을 만들어줘. 전체적으로 아이보리와 브라운 계열을 사용하고 여백이 넓은 따뜻한 분위기로 구성해줘. 상단 메뉴를 누르면 각 콘텐츠 영역으로 이동할 수 있도록 만들어줘.
