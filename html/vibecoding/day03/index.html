STEP 01

가장 기본적인 웹페이지 만들기

아직 디자인을 세세하게 요청하지 않고, 처음에는 웹페이지의 전체 구조부터 만듭니다.

프롬프트 01 — 다 함께 입력하기
상자를 클릭하면 바로 복사돼요

개인 프로필을 소개하는 한 페이지 웹사이트를 만들어줘. HTML, CSS, JavaScript를 각각 index.html, style.css, script.js 파일로 분리해서 작성해줘. 페이지는 다음 순서로 구성해줘. 1. Navigation 2. Hero 3. About 4. Portfolio 5. Contact 6. Footer Navigation에는 About, Portfolio, Contact 메뉴를 넣어줘. Hero에는 이름, 한 줄 소개, 버튼 하나를 넣어줘. Portfolio에는 카드 3개를 만들어줘. 아직 디자인은 화려하게 만들지 말고 흰색 배경의 단순하고 기본적인 형태로 만들어줘. 초보자가 이후 수정하기 쉽도록 코드는 복잡하게 작성하지 마.

결과 확인하기 — Claude Code 작업 완료 → Live Server 실행 → 브라우저 확인
Navigation이 있는가? Hero가 있는가? About Section이 있는가? Portfolio 카드가 3개 있는가? Contact가 있는가? Footer가 있는가?

지금은 예쁜지 평가하는 것이 아니라, 전체 구조가 정상적으로 만들어졌는지 확인합니다.

💡 첫 번째로 이해할 것 — AI에게 처음부터 모든 디자인을 맡기지 않기. "세련되고 감성적이고 예쁘게 만들어줘"라고 한 번에 요청하면 Claude Code가 색상·폰트·여백·버튼·레이아웃·효과를 한꺼번에 결정합니다. 오늘은 구조 → 텍스트 → Typography → Color → Spacing → Image → Interaction 순서로 하나씩 수정하면서, 어떤 프롬프트가 어떤 결과를 바꾸는지 직접 확인합니다.

Portfolio 제목: My Work Portfolio 카드 제목은 각각 Branding Project, Editorial Design, Content Design으로 변경해줘. Contact에는 Email: hello@example.com, Instagram: @mina.design을 넣어줘. 다른 디자인이나 레이아웃은 변경하지 마.

STEP 03~05. Typography · Color · Spacing 수정하기

STEP 03

Typography 수정하기

텍스트 내용은 그대로 유지하고 글자의 디자인만 수정합니다. Typography란 Font·Size·Weight·Line Height·Letter Spacing·Alignment 등 텍스트의 시각적인 표현입니다.

프롬프트 03
상자를 클릭하면 바로 복사돼요

현재 웹페이지의 텍스트 내용과 레이아웃은 그대로 유지해줘. Typography만 수정해줘. 전체적으로 깔끔하고 현대적인 느낌이 나도록 해줘. Hero의 메인 제목은 현재보다 크게 만들어줘. Section 제목은 본문보다 확실히 크게 보이도록 해줘. 본문은 읽기 편하도록 너무 작지 않게 하고 행간을 조금 넓혀줘. 전체적으로 제목, 소제목, 본문의 크기 차이가 명확하게 보이도록 만들어줘. 지나치게 많은 종류의 폰트는 사용하지 말고 전체 사이트에서 일관된 Typography를 사용해줘. 색상과 레이아웃은 변경하지 마.

핵심 — Typography Hierarchy: 중요한 내용은 크게, 부가적인 내용은 작게

STEP 04

Color 수정하기

Typography는 유지하고 전체 Color만 변경합니다.

Background밝은 아이보리
Text짙은 브라운
Point차분한 브라운
프롬프트 04
상자를 클릭하면 바로 복사돼요

현재 웹페이지의 레이아웃과 Typography는 그대로 유지해줘. 이번에는 전체 색상만 변경해줘. 전체 배경은 순백색 대신 아주 밝은 아이보리 계열을 사용해줘. 메인 텍스트는 검정색 대신 짙은 브라운 계열을 사용해줘. 버튼에는 메인 텍스트보다 조금 따뜻한 브라운 계열을 사용해줘. 전체 웹사이트에서 사용하는 주요 색상은 3개를 넘지 않도록 해줘. 전체적으로 따뜻하고 차분한 분위기가 나도록 만들어줘. 기존 텍스트, 폰트 크기, 레이아웃은 변경하지 마.

핵심 — 기존 디자인 전체를 다시 만드는 것이 아니라 Color만 수정

STEP 05

Section 사이 여백 수정하기

웹페이지가 답답해 보이는 경우, 색상보다 Spacing(요소와 요소 사이의 공간) 문제인 경우가 많습니다.

Margin — 요소 바깥쪽 공간
Padding — 요소 안쪽 공간
프롬프트 05
상자를 클릭하면 바로 복사돼요

현재 디자인과 색상은 그대로 유지해줘. 이번에는 웹페이지의 여백만 수정해줘. Hero, About, Portfolio, Contact Section 사이의 위아래 간격을 현재보다 넓혀줘. 각 Section 안쪽에도 충분한 Padding을 넣어줘. Portfolio 카드끼리 너무 붙어 보이지 않도록 카드 사이의 간격도 넓혀줘. 전체적으로 콘텐츠가 답답하지 않고 여유 있게 보이도록 수정해줘. 텍스트 내용, 폰트, 색상은 변경하지 마.

핵심 — 여백도 디자인의 중요한 요소입니다.

STEP 07

이미지 영역 추가하기

Explorer에서 새 폴더 images를 만들고, 강사가 제공하거나 준비된 이미지를 사용합니다.

my-profile

├── style.css
├── script.js
└── images
    ├── profile.jpg
    ├── work01.jpg
    ├── work02.jpg
    └── work03.jpg
프롬프트 07
상자를 클릭하면 바로 복사돼요

images 폴더에 이미지 파일을 추가했어. profile.jpg는 Hero Section의 프로필 이미지로 사용해줘. work01.jpg, work02.jpg, work03.jpg는 각각 Portfolio 카드에 사용해줘. 이미지 비율이 찌그러지지 않도록 해줘. Portfolio 이미지는 카드 상단에 동일한 크기로 배치해줘. 이미지가 영역을 자연스럽게 채울 수 있도록 object-fit: cover를 사용해줘. 기존 텍스트, 색상, Typography, Section 구조는 변경하지 마.

이미지가 나오지 않을 경우 — 바로 전체 코드를 다시 생성하지 않기.
"이미지가 브라우저에서 표시되지 않아. 현재 프로젝트의 images 폴더와 HTML의 이미지 경로를 확인해줘. 파일 이름과 경로에 문제가 있는지 찾아서 이미지가 정상적으로 표시되도록 수정해줘. 이미지 경로와 관련되지 않은 다른 코드는 변경하지 마."

핵심 — 문제가 발생한 영역만 수정하도록 요청하기

STEP 10

Navigation 기능 추가하기

지금까지 메뉴는 보이지만 실제 이동기능이 없을 수 있습니다.

프롬프트 10
상자를 클릭하면 바로 복사돼요

상단 Navigation 메뉴에 이동 기능을 추가해줘. About을 클릭하면 About Section으로 이동하고, Portfolio를 클릭하면 Portfolio Section으로 이동하고, Contact를 클릭하면 Contact Section으로 이동하도록 만들어줘. 이동할 때 화면이 갑자기 바뀌지 않고 부드럽게 스크롤되도록 만들어줘. 메뉴 디자인은 현재 상태를 유지해줘.

핵심 — 지금부터 단순히 보이는 사이트에서 사용자의 행동에 반응하는 사이트로 발전합니다.

STEP 11

Hero 버튼 기능 추가하기

프롬프트 11
상자를 클릭하면 바로 복사돼요

Hero Section의 "작업물 보기" 버튼을 클릭하면 Portfolio Section으로 부드럽게 이동하도록 만들어줘. 현재 버튼 디자인과 다른 Section은 변경하지 마.

STEP 12

Hover 효과 추가하기

Hover란 마우스를 요소 위에 올렸을 때 발생하는 변화입니다.

프롬프트 12
상자를 클릭하면 바로 복사돼요

웹페이지에 간단한 Hover 효과를 추가해줘. Navigation 메뉴에 마우스를 올리면 글자색이 자연스럽게 변경되도록 해줘. Hero 버튼에 마우스를 올리면 배경색이 조금 진해지도록 만들어줘. Portfolio 카드에 마우스를 올리면 카드가 아주 조금 위로 올라오는 느낌과 자연스러운 그림자 효과를 추가해줘. 효과는 부드럽고 과하지 않도록 만들어줘. 기존 레이아웃은 변경하지 마.

핵심 — 작은 Interaction으로 사용자가 클릭하거나 선택할 수 있는 요소임을 알려주기

STEP 13

모바일 화면 수정하기

Responsive Web이란 화면 크기에 따라 웹페이지 구조가 자연스럽게 변화하는 웹사이트입니다. 지금까지 Desktop 중심으로 제작했다면, 이제 모바일에서도 확인합니다.

프롬프트 13
상자를 클릭하면 바로 복사돼요

현재 웹페이지의 데스크톱 디자인은 최대한 유지하면서 모바일 반응형 디자인을 적용해줘. 모바일에서는 Hero Section의 텍스트와 이미지가 좌우 2열이 아니라 위아래로 배치되도록 해줘. Portfolio 카드 3개는 모바일에서 한 줄에 하나씩 보이도록 해줘. 텍스트나 이미지가 화면 밖으로 벗어나지 않도록 해줘. 버튼은 모바일에서도 누르기 편한 크기를 유지해줘. 불필요한 좌우 스크롤이 생기지 않도록 수정해줘.

모바일 화면 확인하기 (브라우저 크기 줄이기 또는 개발자 도구 사용)
☐ Hero가 자연스럽게 보이는가? ☐ 이미지가 화면 밖으로 벗어나지 않는가? ☐ Portfolio 카드가 한 줄씩 보이는가? ☐ 텍스트가 너무 작지 않은가? ☐ 버튼을 누르기 어렵지 않은가? ☐ 좌우 스크롤이 생기지 않는가?

프롬프트 14

지금까지 만든 웹페이지의 전체 코드를 확인해줘. 현재 디자인이나 콘텐츠는 변경하지 말고 오류가 있는지만 점검해줘. 다음 내용을 확인해줘. 1. HTML, CSS, JavaScript가 정상적으로 연결되어 있는지 2. 이미지 경로가 올바른지 3. Navigation과 버튼 이동기능이 정상적인지 4. 불필요하거나 중복된 코드가 심하게 있는지 5. 모바일에서 화면이 깨질 가능성이 있는지 문제가 있다면 어떤 문제인지 먼저 설명한 다음 필요한 부분만 수정해줘. 정상적으로 작동하는 디자인은 변경하지 마.
