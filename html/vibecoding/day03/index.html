STEP 01

가장 기본적인 웹페이지 만들기

처음부터 화려하게 만들지 않고, 먼저 웹페이지의 전체 구조만 제작합니다.

프롬프트 01 — 다 함께 입력하기
상자를 클릭하면 바로 복사돼요

MELLOW BEAN이라는 가상의 카페를 소개하는 한 페이지 웹사이트를 만들어줘. HTML, CSS, JavaScript를 각각 index.html, style.css, script.js 파일로 분리해서 작성해줘. 웹페이지는 다음 순서로 구성해줘. 1. Navigation 2. Hero 3. About 4. Menu 5. Location 6. Contact 7. Footer Navigation에는 About, Menu, Location, Contact 메뉴를 넣어줘. Hero에는 카페 이름, 한 줄 소개, "메뉴 보기" 버튼을 넣어줘. Menu Section에는 메뉴 카드 3개를 만들어줘. 아직 디자인은 화려하게 만들지 말고 흰색 배경을 중심으로 단순하고 기본적인 형태로 만들어줘. 초보자가 이후 수정하기 쉽도록 코드 구조를 너무 복잡하게 만들지 마.

결과 확인하기 — Live Server 실행 → 브라우저 확인
Navigation이 있는가? Hero가 있는가? About이 있는가? Menu 카드가 3개 있는가? Location이 있는가? Contact가 있는가? Footer가 있는가?

지금 단계에서는 예쁜지 확인하는 것이 아니라, 필요한 구조가 모두 만들어졌는지 확인합니다.

💡 오늘 사용할 기본 작업방식 — 프롬프트 입력 → Claude Code 수정 → 브라우저 확인 → 원하는 부분과 다른 부분 찾기 → 다음 프롬프트 입력을 반복합니다 (Prompt → Result → Check → Prompt). 바이브코딩에서는 처음부터 완벽한 프롬프트를 만드는 것보다 결과를 확인하면서 계속 수정하는 과정이 중요합니다.

Claude Code에게 수정범위를 알려주는 방법

"현재 구조는 유지해줘." "다른 Section은 수정하지 마." "디자인은 그대로 유지해줘." "이 부분만 변경해줘."

이유 — AI에게 수정범위를 알려주지 않으면 요청하지 않은 부분까지 바뀔 수 있습니다.

STEP 03~05. Typography · Color · Spacing 수정하기

STEP 03

Typography 수정하기

Typography(타이포그래피)란 글자의 Font, Size, Weight, Line Height, Letter Spacing 등을 조절하여 정보의 중요도와 분위기를 표현하는 것입니다.

프롬프트 03
상자를 클릭하면 바로 복사돼요

현재 웹페이지의 콘텐츠와 Layout은 그대로 유지해줘. 이번에는 Typography만 수정해줘. 전체적으로 카페 브랜드에 어울리는 깔끔하고 편안한 느낌으로 만들어줘. Hero 제목은 현재보다 크게 보여줘. Section 제목은 본문보다 확실히 크게 보이도록 해줘. 본문은 읽기 편하도록 적절한 크기와 행간을 사용해줘. 전체적으로 제목, 소제목, 본문의 크기 차이가 명확하게 보이도록 만들어줘. 너무 많은 종류의 폰트를 사용하지 말고 전체 사이트에서 일관된 Typography를 사용해줘. Color와 Layout은 변경하지 마.

핵심 — 정보의 중요도에 따라 글자 크기와 굵기가 구분되는지 확인하기

STEP 04

오늘 사용할 방향 — Cream + Brown + Dark Brown으로 따뜻한 카페 분위기를 만듭니다.

Background밝은 크림 계열

프롬프트 04
상자를 클릭하면 바로 복사돼요

현재 웹페이지의 Layout과 Typography는 그대로 유지해줘. 이번에는 Color만 수정해줘. 전체 배경은 순백색 대신 밝은 크림 계열을 사용해줘. 메인 텍스트는 검정색 대신 짙은 브라운 계열을 사용해줘. 포인트 컬러는 따뜻한 중간톤의 브라운을 사용해줘. 버튼에도 동일한 포인트 컬러를 적용해줘. 전체 사이트에서 주요 색상은 3개 정도만 사용해줘. 따뜻하고 차분한 카페 분위기가 느껴지도록 만들어줘. 기존 텍스트, Typography, Layout은 변경하지 마.

핵심 — 배경, 텍스트, 버튼, Section 전체 색상이 하나의 브랜드처럼 자연스럽게 연결되는지 확인하기

STEP 05

Section 사이의 여백 수정하기

웹페이지가 답답해 보이지 않도록 콘텐츠 사이에 충분한 공간을 만듭니다.

Margin — 요소 바깥쪽 공간
Padding — 요소 안쪽 공간
프롬프트 05
상자를 클릭하면 바로 복사돼요

현재 디자인과 Color는 그대로 유지해줘. 이번에는 웹페이지 전체의 Spacing만 수정해줘. Hero, About, Menu, Location, Contact Section 사이의 위아래 간격을 현재보다 넓혀줘. 각 Section 내부에도 충분한 Padding을 적용해줘. 콘텐츠가 서로 붙어 보이지 않고 여유 있게 보이도록 만들어줘. 텍스트, Typography, Color는 변경하지 마.

핵심 — Section 사이 여백 증가 → 가독성 증가 → 웹사이트가 정돈되어 보임

STEP 07

Card(카드)는 하나의 메뉴정보를 이미지, 이름, 설명, 가격으로 묶어서 표현하는 UI 요소입니다.

Menu Section의 카드 디자인만 수정해줘. 데스크톱에서는 메뉴 카드 3개가 한 줄에 보이도록 만들어줘. 각 카드는 밝은 배경을 사용하고 모서리를 살짝 둥글게 해줘. 카드 내부에는 충분한 Padding을 넣어줘. 카드 사이에는 일정한 간격을 만들어줘. 메뉴 이름은 조금 강조하고 설명은 읽기 편하게 만들어줘. 가격은 카드 하단에서 쉽게 찾을 수 있도록 보여줘. 그림자는 너무 강하지 않게 아주 약하게 사용해줘. 다른 Section과 전체 Color는 변경하지 마.

여기서 중요한 질문

현재 메뉴가 3개라면 HTML에 직접 작성해도 크게 어렵지 않습니다. 그런데 메뉴가 10개라면? 30개라면? 100개라면? 새로운 메뉴가 나올 때마다 HTML을 직접 수정해야 할까요?

상자를 클릭하면 바로 복사돼요

images 폴더에 카페 이미지를 추가했어. hero.jpg는 Hero Section의 대표 이미지로 사용해줘. cream-latte.jpg는 Cream Latte 카드에 사용해줘. tiramisu.jpg는 Classic Tiramisu 카드에 사용해줘. mellow-ade.jpg는 Mellow Ade 카드에 사용해줘. 메뉴 카드 이미지의 크기를 동일하게 맞춰줘. 이미지 비율이 찌그러지지 않도록 object-fit: cover를 사용해줘. 기존 텍스트와 Color, Typography는 변경하지 마.

이미지가 안 보인다면 이 프롬프트 사용하기

"일부 이미지가 웹페이지에 표시되지 않고 있어. 현재 프로젝트의 images 폴더와 HTML의 이미지 경로를 확인해줘. 파일 이름과 경로가 올바른지 점검해서 이미지가 정상적으로 보이도록 수정해줘. 이미지와 관련되지 않은 다른 코드는 수정하지 마."

STEP 12

Hover 효과 추가하기

Hover(호버)는 사용자가 클릭할 수 있는 요소를 더 쉽게 인식하도록 만드는, 마우스를 올렸을 때 나타나는 변화입니다.

프롬프트 12
상자를 클릭하면 바로 복사돼요

현재 웹페이지에 간단한 Hover 효과를 추가해줘. Navigation 메뉴에 마우스를 올리면 글자색이 자연스럽게 변경되도록 해줘. Hero의 "메뉴 보기" 버튼에 마우스를 올리면 배경색이 조금 진해지도록 만들어줘. Menu 카드에 마우스를 올리면 카드가 아주 조금 위로 올라오고 그림자가 조금 강조되도록 만들어줘. 효과는 부드럽고 과하지 않게 만들어줘. 기존 Layout은 변경하지 마.

모바일 반응형 적용하기

Responsive Web(반응형 웹)은 화면 크기에 따라 구조가 달라지는 웹페이지입니다. 현재는 Desktop 중심이므로 Mobile에서도 자연스럽게 보이도록 수정합니다.

프롬프트 14
상자를 클릭하면 바로 복사돼요

현재 웹페이지의 데스크톱 디자인은 최대한 유지하면서 모바일 반응형 디자인을 적용해줘. 모바일에서는 Hero의 텍스트와 이미지가 좌우 2열이 아니라 위아래로 배치되도록 해줘. Menu 카드 3개는 모바일에서 한 줄에 하나씩 보이도록 해줘. Navigation과 텍스트가 화면 밖으로 벗어나지 않도록 해줘. 이미지가 화면보다 커지지 않도록 해줘. 버튼은 모바일에서도 누르기 편한 크기를 유지해줘. 불필요한 좌우 스크롤이 발생하지 않도록 수정해줘.

Hero가 위아래 구조로 변경되는가? Menu 카드가 한 줄씩 표시되는가? 텍스트가 화면 밖으로 나가지 않는가? 이미지가 깨지지 않는가? 버튼을 누르기 쉬운가? 좌우 스크롤이 생기지 않는가?

DAY 04 연결을 위해 Menu Section을 한 번 더 확인합니다. 현재 메뉴 카드는 이미지 → 메뉴 이름 → 설명 → 가격 순서로 동일한 구조를 사용합니다.

Cream Latte, Classic Tiramisu, Mellow Ade 세 카드는 구조는 동일하고 데이터만 다릅니다. 지금은 이 메뉴정보가 HTML 안에 직접 작성되어 있지만, DAY 04에서는 HTML 안에 메뉴 3개를 직접 작성하는 대신 Database에 메뉴정보를 저장하고 웹사이트가 Database에서 데이터를 가져와 Menu Card를 자동 생성하도록 바꿉니다. 새 메뉴를 추가하고 싶다면 Database에 새 데이터 한 개만 추가하면 웹사이트 새로고침 시 새로운 Menu Card가 표시됩니다.
