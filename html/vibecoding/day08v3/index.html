6.GitHub Pages · 공개 전 안전 점검

GitHub Pages

GitHub Repository에 저장한 HTML · CSS · JS를 무료로 인터넷에 공개해 주는 호스팅입니다. 자물쇠(https)도 자동으로 붙습니다. 화면 파일만 올리는 곳이지만, 데이터와 로그인은 Supabase가 맡고 있으니 우리 사이트는 그대로 동작합니다.

공개하면 Repository의 모든 파일을 누구나 볼 수 있습니다

사이트 화면뿐 아니라 코드 파일까지 보입니다. Publishable Key는 공개되어도 되는 키지만, Secret Key · 구글 클라이언트 보안 비밀 · 개인정보는 절대 있으면 안 됩니다.

Repository가 Private이라면 — 점검을 마친 뒤 Settings → General 맨 아래 Danger Zone → Change visibility → Public. 무료 계정은 Public Repository만 GitHub Pages를 쓸 수 있습니다.

7.STEP 06. GitHub Pages로 공개 · 로그인 주소 등록

  1. GitHub에서 내 Repository를 엽니다.
  2. Settings → 왼쪽 메뉴 Pages를 누릅니다.
  3. Source를 Deploy from a branch로 고릅니다.
  4. Branch를 main, 폴더를 / (root)로 고르고 Save를 누릅니다.
  5. 1~3분 뒤 새로고침하면 위쪽에 주소와 Visit site가 나타납니다.
https://내GitHub아이디.github.io/저장소이름/

로그인이 있는 사람 — 공개 주소를 등록해야 로그인이 됩니다

8.파일 경로와 사이트 주소 — 같은 파일, 주소 세 개

지금 내 index.html에는 주소가 세 개 생겼습니다.

어디서 보나주소 모양누가 볼 수 있나
내 컴퓨터 폴더 (파일 경로)C:\Users\…\my-project\index.html이 컴퓨터만
Live Serverhttp://127.0.0.1:5500/index.html이 컴퓨터만 (내 컴퓨터가 잠깐 서버 역할)
GitHub Pages (사이트 주소)https://아이디.github.io/저장소이름/인터넷의 누구나

파일 경로 = 서랍 속 서류의 위치

내 컴퓨터 안에서만 통합니다. 카톡으로 C:\… 경로를 보내면 상대는 열 수 없습니다. 공유는 항상 https:// 주소로.

사이트 주소 = 가게 주소

서버에 올라간 파일의 위치입니다. 누구나 같은 주소로 같은 화면을 봅니다.

O 세 곳 모두에서 맞음images/a.jpg — "이 파일 옆의 images 폴더" (상대 경로)
X 공개 주소에서 깨짐C:\Users\…\a.jpg 또는 /images/a.jpg (맨 앞 /) — 프롬프트 05의 3번이 이것

내 도메인을 GitHub Pages에 연결하는 순서 — 혼자 해 보기

  1. 도메인 업체에서 도메인을 삽니다 (예: 카페24 도메인).
  2. 업체의 DNS 관리 화면을 엽니다.
  3. 아래 표대로 기록을 추가합니다.

  5. DNS 확인이 끝나면 Enforce HTTPS에 체크합니다. 반영까지 몇 분에서 하루까지 걸릴 수 있습니다.
  6. 로그인이 있다면 Supabase URL Configuration과 Google 승인된 JavaScript 원본에도 새 주소를 추가합니다.

12.MCP — 앞으로 AI를 다른 도구와 연결하기

오늘은 실습 · 시연을 하지 않습니다. 연결할 서비스를 내가 결제 · 구독하고 있어야 하고, 연결하면 AI가 내 계정 권한으로 움직이기 때문입니다. 대신 내 분야에 적용하는 방법을 알고 갑니다.

MCP (Model Context Protocol)

AI 도구가 다른 서비스(구글 드라이브 · Notion · GitHub · 카페24 · Figma …)와 연결할 때 쓰는 공통 규격입니다. 비유하자면 USB-C 단자 — 규격이 하나라 어떤 기기든 같은 방식으로 꽂힙니다. 서비스 회사가 MCP 서버(콘센트)를 만들어 두면, AI 도구는 꽂기만 하면 됩니다.

연결 전

AI는 내 컴퓨터 파일만 봅니다. 다른 서비스의 일은 내가 그 사이트에 들어가서 직접 합니다.

연결 후

"Notion 회의록에서 할 일만 뽑아 표로 만들어줘" → AI가 Notion에서 직접 읽고 정리합니다.

이미 본 적 있습니다

  • • ChatGPT — 설정 → 앱에서 Google Drive · Gmail 등을 연결하는 화면. 이런 연결 상당수가 MCP 방식입니다. 주소를 직접 넣어 연결하는 것은 개발자 모드입니다.
  • • Claude Code — 터미널에 claude mcp add … 한 줄로 연결하고, 입력창의 /mcp에서 로그인 · 승인합니다.
