# 1교시
# 생성형 AI의 이해와 안전한 사용


# 01. 생성형 AI란?

사람처럼 말로 요청하면
글·표·이미지·코드 같은 새로운 결과물을 만들어 주는 AI

기존 프로그램 : 메뉴와 버튼으로 정해진 기능 실행
생성형 AI     : 말로 요청하면 해석해서 결과를 만들어 줌

대표 서비스 : Gemini(이번 과정의 기본 도구), ChatGPT, Claude, Copilot
※ ChatGPT는 더 높은 품질을 원하는 사람만 개인적으로 선택 (수업 중 안내)


# 02. 사무 업무에서 AI가 해 줄 수 있는 일

문서   : 이메일, 공지문, 보고서, 회의록, 안내문
정리   : 긴 글 요약, 표로 정리, 체크리스트
데이터 : 표 설계, 함수 만들기, 데이터 분석 요약
기획   : 아이디어, 기획안 구조, 검토와 피드백
발표   : 슬라이드 구성, 발표 대본

→ 이번 과정 8회 동안 이 순서대로 하나씩 실습합니다.


# 03. AI가 잘하는 일 / 조심할 일

잘하는 일
- 초안 만들기 (빈 화면에서 시작하지 않게 해 줌)
- 긴 내용 정리하기
- 형태 바꾸기 (글 → 표, 이메일 → 공지)
- 반복해서 고치기

조심할 일
- 사실이 아닌 내용을 자연스럽게 만들어 냄 (할루시네이션)
- 최신 정보, 숫자, 회사 내부 사정은 모름
- 내가 알려주지 않은 내용을 추측해서 채움

핵심 : AI가 만들고, 사람이 판단한다.


# 04. 업무에서 AI 쓸 때의 안전 수칙

입력하면 안 되는 것
- 주민등록번호, 계좌번호, 비밀번호
- 고객·직원의 이름과 연락처
- 공개되지 않은 계약, 회사 기밀

바꿔서 넣는 방법
"홍길동 고객 010-1234-5678" → "A고객 (연락처 삭제)"

회사의 AI 사용 규정이 있다면 먼저 확인합니다.


# 실습 SET 01
# 넣어도 될까? 판단 연습

상황을 보고 [그대로 입력 / 고쳐서 입력 / 입력하지 않기] 중 골라 봅니다.

① 내가 쓴 회의 메모를 정리해 달라고 할 때 → 그대로 (개인정보 없음)
② 고객 이름·연락처가 담긴 상담 기록 → 고쳐서 (이름·번호 지우기)
③ 아직 발표 전인 신제품 가격표 → 입력하지 않기 (회사 규정 확인)
④ 인터넷 기사 요약 → 그대로 (요약 결과는 원문과 비교)
⑤ 내 계정 비밀번호가 안전한지 확인 → 입력하지 않기

AI 쓰기 전 3초 체크
① 넣어도 되는 정보인가?  ② 결과를 그대로 믿어도 되나?  ③ 마지막에 내가 확인했나?

# 2교시
# Gemini 시작하기


# 05. Gemini 화면 살펴보기

- 새 채팅 : 새로운 주제로 시작
- 대화 목록 : 지난 대화를 다시 열어 이어가기
- 입력창 : 요청을 쓰는 곳
- + 버튼 : 파일·이미지 추가
- 도구 : Deep Research, Canvas 등 (4·7일차에 사용)
※ 메뉴 이름은 업데이트에 따라 조금씩 달라질 수 있음


# 06. 첫 대화

작성 틀
나는 [나에 대해 한 줄 — 예: 오늘 Gemini를 처음 쓰는 회사원]이야.
[어디에서 — 예: 사무 업무]에 Gemini를 활용할 수 있는 방법을 [몇 가지] 알려줘.
각각 [함께 받고 싶은 것 — 예: 바로 따라 할 수 있는 요청 예시]도 알려줘.

예시
나는 오늘 Gemini를 처음 쓰는 회사원이야.
사무 업무에 Gemini를 활용할 수 있는 방법을 5가지 알려줘.
각각 바로 따라 할 수 있는 요청 예시도 알려줘.


# 07. 같은 대화에서 이어서 고치기

처음 답이 마지막 답이 아닙니다. 새 채팅을 열지 말고 이어서 요청합니다.

- "이 중에서 문서 업무에 쓸 수 있는 것만 골라줘."
- "표로 정리해줘."
- "초보자가 바로 따라 할 수 있게 더 쉽게 써줘."
- "핵심만 3줄로 줄여줘."

새 채팅은 언제? → 주제가 완전히 바뀔 때


# 실습 SET 02
# 같은 내용 여러 형태로 바꾸기

작성 틀
[어디에서 쓸 — 예: 사내] [문서 종류 — 예: 회의 일정 안내문]을 작성해줘.
일시: [언제]
장소: [어디서]
[꼭 넣을 내용 — 예: 준비물]

예시
사내 회의 일정 안내문을 작성해줘.
일시: 이번 주 금요일 오후 3시
장소: 3층 회의실
준비물: 개인 노트북

이어서 요청 (한 번에 하나씩)
① 더 정중하게  ② 절반 길이로  ③ 이메일 제목 붙여서  ④ 사내 메신저용 짧은 공지로

→ 같은 내용을 말투·길이·형태만 바꿔 여러 번 쓸 수 있다는 것을 확인


# 08. 나에게 맞게 설정하기 (맞춤 지침)

Gemini 설정에서 "나에 대해 기억할 내용(맞춤 지침)"을 적어 두면
매번 설명하지 않아도 나에게 맞게 답합니다.

작성 틀
나는 [직무·하는 일]이야.
주로 [AI에게 맡길 일]에 사용할 거야.
답변은 [원하는 방식 — 예: 핵심부터, 너무 길지 않게, 필요하면 표로] 해줘.

예시
나는 중소기업 총무팀에서 일하는 신입 사원이야.
주로 이메일·공지문 작성, 회의록 정리, 자료 요약에 사용할 거야.
답변은 핵심부터 짧게 쓰고, 비교가 필요하면 표로 정리해줘.

※ 설정 전과 후에 같은 질문을 해서 차이를 비교해 봅니다 (새 채팅에서 비교)


# 09. 이번 과정의 설정 — 해오름상사 신입 사원

8회 동안 가상의 회사 '해오름상사'(생활용품 유통 회사) 총무·기획팀 신입 사원이 되어
실제 업무를 AI와 함께 처리합니다.

3일차 : 워크숍 안내 메일, 회의록
4일차 : 시장 조사 보고서
5~6일차 : 매출·비품 데이터 정리와 분석
7일차 : 신규 사업 기획안
8일차 : 기획안 발표자료

※ 자기 실제 업무가 있다면 그 업무로 바꿔서 실습해도 좋습니다.
