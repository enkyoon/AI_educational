# 1교시
# 요청의 구조와 오류 줄이기


# 01. 업무 요청의 5칸 구조 (5분)

역할     : 나는 누구인가 (직무·입장)
목적     : 무엇을 하려는가 / 무엇을 결정하려는가
대상     : 누가 읽는가 / 누구를 위한 결과인가
조건     : 꼭 지킬 것 (분량, 말투, 반드시 넣을 내용, 넣지 말 것)
결과 형식 : 어떤 형태로 받을까 (표, 목록, 이메일, 5줄 요약 …)

처음부터 다 채울 필요는 없습니다.
짧게 요청 → 결과 보기 → 부족한 칸 채우기 를 반복해도 됩니다.


# 실습 SET 01
# 하나의 요청을 칸 하나씩 채우며 발전시키기 (15분)

새 채팅에서 STEP 01, 이후는 같은 대화에서 이어서.

STEP 01 가장 짧게
"사내 워크숍 프로그램을 기획해줘."

STEP 02 역할·대상 추가
나는 [역할]이야. 참석자는 [누가, 몇 명, 어떤 특징]이야.

STEP 03 목적 추가
이번 워크숍의 가장 중요한 목적은 [무엇]이야. 이 목적에 맞게 다시 구성해줘.

STEP 04 조건 추가
다음 조건을 지켜줘.
- [조건 1 — 예: 하루 일정, 오후 6시 전 종료]
- [조건 2 — 예: 1인 예산 5만 원 이내]
- [조건 3 — 예: 몸을 많이 쓰는 활동은 빼기]

STEP 05 결과 형식
[형식 — 예: 시간 / 프로그램 / 목적 / 준비물] 형태의 표로 정리해줘.

→ STEP 01 결과와 STEP 05 결과를 나란히 놓고 비교
  "AI에게 판단 기준을 알려주면 결과가 달라진다"

조건은 구체적으로
"짧게" → "5문장 이내로"   "많이" → "10개"
"쉽게" → "전문용어 없이, 개념마다 예시 하나씩"


# 02. 요청 기법 3가지 (10분)

① 역할 주기 — 어떤 관점에서 볼지 알려주기
   "너는 10년 차 인사팀장이야. 신입 사원 입장에서 이 안내문에 빠진 정보를 찾아줘."

② 예시 보여주기 — 말로 설명하기 어려운 형식·말투
   작성 틀
   [만들 것 — 예: 사내 공지 제목]을 만들어줘. 원하는 형태는 다음과 같아.
   예시 1: [예시]
   예시 2: [예시]
   예시 문장을 그대로 반복하지 말고 구조와 분위기만 참고해줘.
   [대상·개수 — 예: 11월 워크숍 공지 제목 5개]

③ 단계로 나누기 — 복잡한 일은 한 번에 시키지 않기
   "신규 사업 기획해줘" 대신
   문제 찾기 → 아이디어 → 하나 골라 구체화 → 정리 (7일차 기획안에서 다시 사용)


# 03. 할루시네이션 — AI의 그럴듯한 거짓말 (5분)

- 없는 통계, 없는 연구, 없는 규정을 자신 있게 말함
- 이유 : 정답을 찾는 게 아니라 "그럴듯한 다음 말"을 만들기 때문
- 특히 조심 : 법률·세금·계약·통계·최신 정책·회사 규정

직접 확인해 보기
"해오름상사의 작년 매출과 직원 수를 알려줘."
→ 없는 회사인데 어떻게 답하는지 보기


# 실습 SET 02
# 오류를 줄이는 요청 4가지 (15분)

① 정보가 없으면 먼저 묻게 하기
[알고 싶은 것]을 정리하고 싶어.
내가 자료를 아직 주지 않았다면 추측하지 말고,
정확한 답을 위해 내가 어떤 자료를 줘야 하는지 먼저 알려줘.

② 준 정보만 쓰게 하기
아래 정보만 사용해서 [문서 종류]를 작성해줘.
[정보 붙여넣기]
주어지지 않은 [예: 담당자 이름 / 금액 / 신청 방법]은 만들지 말고, 없는 내용은 [확인 필요]로 표시해줘.

③ 사실과 의견 나눠 받기
[주제]에 대해 1. 확인 가능한 사실 2. 그에 대한 해석 3. 아이디어 를 나눠서 쓰고,
확인되지 않은 숫자는 만들지 말아줘.

④ 출처 요청
중요한 숫자에는 출처와 작성 시점을 함께 적어줘.
→ 링크를 직접 눌러 실제로 그런 내용이 있는지 확인

→ ①~④ 중 2개 이상 직접 보내 보고, 쓰기 전과 결과가 어떻게 달라졌는지 적어 두기

# 실습 SET 03
# 업무 메일과 대상별 버전 (15분)

상황 : 11월 사내 워크숍 안내를 전 직원에게 알려야 합니다.

작성 틀
나는 [역할 — 예: 해오름상사 총무팀 신입 사원]이야.
[받는 사람 — 예: 전 직원 60명]에게 보낼 [문서 — 예: 사내 워크숍 안내 메일]을 써줘.
꼭 넣을 정보:
- 일시: [언제]
- 장소: [어디서]
- [그 밖에 — 예: 준비물, 회신 기한]
조건: [예: 한눈에 보이게 항목으로, 5문장 이내, 제목 3개 제안]

이어서 : 대상별로 바꾸기
방금 내용을 바탕으로 다음 세 가지를 각각 써줘.
1. [예: 팀장에게 보고하는 짧은 메일]
2. [예: 사내 게시판 공지]
3. [예: 사내 메신저 한 줄 알림]
받는 사람에 따라 말투와 정보 순서를 다르게 해줘.

이어서 : 곤란한 메일
"장소가 바뀌어서 다시 알려야 해. 혼란을 줄이도록 바뀐 점이 먼저 보이게 정정 메일을 써줘."


# 실습 SET 04
# 메모·녹음으로 회의록 만들기 (15분)

대충 적은 메모(또는 휴대폰 녹음 파일)를 회의록으로 정리합니다.
※ 참석자 실명 대신 직책이나 A·B로 바꿔서 넣기

작성 틀
아래 회의 메모를 [양식 — 예: 사내 회의록]으로 정리해줘.
[회의 메모 붙여넣기 또는 녹음 파일 첨부]
정리 항목: [예: 회의 개요 / 논의 내용 / 결정 사항 / 할 일(담당·기한) / 다음 회의]
메모에 없는 내용은 만들지 말고, 애매한 부분은 [확인 필요]로 표시해줘.

예시 메모 (수업용)
11/3 워크숍 준비회의. 팀장, 김대리, 나.
장소 후보 2곳 - 양평 연수원 vs 가평 리조트. 가격은 양평이 쌈.
버스 대절 필요. 점심 도시락? 식당?
레크리에이션 업체 알아보기 - 김대리
다음주 수요일까지 장소 확정.

이어서
- "할 일만 뽑아서 담당자별 체크리스트로 바꿔줘."
- "결정 안 된 것만 모아서 다음 회의 안건으로 정리해줘."

녹음으로 해 보기 (선택)
휴대폰으로 1분 정도 회의하듯 말하고 녹음 → 파일을 Gemini에 첨부해 같은 틀로 요청


# 04. 나만의 업무 Gem (20분)

Gem이란?
자주 하는 일의 역할·방식·주의사항을 미리 설정해 둔 "나만의 Gemini"
오늘 1교시에 배운 5칸 구조를 매번 쓰지 않도록 "저장"해 두는 것

만드는 곳 : 왼쪽 메뉴 → Gem → 새 Gem
입력하는 칸 : 이름, 요청 사항(지침), 필요하면 참고 파일

STEP 01 지침 초안을 AI에게 부탁
[어디에서 — 예: 총무팀 문서 업무]에 반복해서 쓸 '[Gem 이름]' Gem을 만들려고 해.
이 Gem이 도와줄 일: [자주 하는 일 2~3가지]
답변 방식: [예: 정중하고 간결하게, 중요한 내용부터, 메일은 제목도 함께]
주의할 점: [예: 내가 주지 않은 날짜·금액·이름은 만들지 않기, 정보가 부족하면 먼저 질문]
Gem 지침 칸에 넣을 수 있게 역할 / 할 일 / 답변 방식 / 주의사항으로 정리해줘.

STEP 02 필요 없는 줄은 빼고 내 업무에 맞게 고쳐서 Gem에 붙여넣기

STEP 03 테스트
"[언제] 예정이던 [일정]이 [바뀐 내용]으로 변경됐어. [받는 사람]에게 알릴 메일 써줘."

STEP 04 마음에 안 드는 점을 지침에 추가하고 다시 테스트
- 답이 길다 → "한 화면에 보이는 분량으로"
- 너무 딱딱하다 → "사내 공지는 부드러운 말투로"


# 05. 오늘의 결과물

⑤ 나만의 업무 Gem
