# 1교시
# Canvas로 문서 쓰기


# 01. 드라이브에 과정 폴더 만들기 (5분)

drive.google.com → 새로 만들기 → 폴더 → 이름 "AI실무활용"
과정에서 만드는 문서·시트·슬라이드는 이 폴더에 모아 두면 나중에 찾기 쉽습니다.
(폴더가 없어도 수업 진행에는 지장 없음 — 다른 날 만들어도 됩니다)

파일 이름 규칙 (회사에서도 쓰기 좋은 습관)
[일차]_[내용]_[이름]   예) 03_친환경용품소개서_홍길동


# 02. Canvas란? (5분)

결과물을 오른쪽 화면에 문서처럼 띄워 두고
대화로 계속 고치거나, 원하는 부분만 골라 수정할 수 있는 기능

켜는 곳 : Gemini 입력창 아래 도구 → Canvas

채팅과 차이
채팅   : 고칠 때마다 전체가 새로 나옴 → 어디가 바뀌었는지 찾기 어려움
Canvas : 문서 하나를 계속 고쳐 나감 → 바뀐 곳만 바뀜, 직접 타이핑도 가능


# 실습 SET 01
# Canvas로 상품 소개서 초안 쓰기 (15분)

작성 틀
Canvas에서 [문서 종류 — 예: 거래처에 보낼 상품 소개서]를 써줘.
회사: [예: 생활용품 유통회사 해오름상사]
읽을 사람: [예: 거래처 총무·구매 담당자]
소개할 상품: [예: 다회용 컵, 재생 용지, 친환경 세제]
목적: [예: 우리 회사에서 친환경 사무용품을 사도록 관심 끌기]
구성: [예: 인사 / 왜 친환경 사무용품인가 / 상품별 소개 / 주문 방법 / 문의처]
조건: [예: A4 2장 이내, 가격은 [가격 확인 필요]로 비워 두기, 과장된 표현 쓰지 않기]

확인하기
□ 내가 주지 않은 숫자·인증·수상 경력이 들어가지 않았나 (있으면 [확인 필요]로)
□ 읽을 사람이 궁금한 것(가격·주문 방법)이 빠지지 않았나


# 03. 부분만 골라 고치기 (10분)

Canvas에서 문장이나 문단을 마우스로 드래그해 선택하면
그 부분에 대해서만 요청할 수 있습니다.

연습 (한 번에 한 곳씩)
① "왜 친환경 사무용품인가" 문단 선택 → "거래처 담당자 입장에서 얻는 이익 중심으로"
② 상품 소개 부분 선택 → "상품마다 특징 / 이런 회사에 추천 / 주문 단위 표로"
③ 첫 인사 선택 → "더 짧고 부드럽게"
④ 직접 타이핑으로 회사 연락처 넣기 (AI에게 시키지 않고)

한 곳씩 고쳐야 하는 이유
여러 곳을 한 번에 고치면 어디가 바뀌었는지 놓치고, 고치지 말아야 할 곳까지 바뀝니다.

고치는 요청의 틀
고칠 곳: [어느 부분]
이렇게 바꿔줘: [구체적으로]
그대로 둘 것: [바꾸면 안 되는 부분]


# 04. 문서 종류별 구조 (10분)

문서는 "읽는 사람이 가장 먼저 알고 싶은 것"이 앞에 옵니다.

보고서      : 결론(한 줄) → 근거 → 제안
안내문      : 무엇을 → 언제·어디서 → 해야 할 일 → 문의처
업무 매뉴얼  : 목적 → 준비물 → 순서(1, 2, 3…) → 자주 하는 실수 → 담당자
결과 보고   : 계획 → 실제 결과 → 잘된 점·아쉬운 점 → 다음 계획

작성 틀 (구조 먼저 받기)
[문서 종류] 문서를 쓰려고 해. 읽을 사람은 [누구]이고 가장 궁금한 것은 [무엇]이야.
본문을 쓰기 전에 목차와 목차별 들어갈 내용 한 줄씩만 먼저 제안해줘.

→ 목차를 보고 순서를 바꾸거나 빼고 나서 "이 목차로 본문을 써줘"
   (긴 문서는 목차부터 받는 것이 가장 빠릅니다)

선택 실습 : 같은 방법으로 "거래처 주문 접수 업무 매뉴얼" 목차 받아 보기

# 05. Google 문서로 내보내기 (5분)

Canvas 오른쪽 위 "공유 및 내보내기" → Google 문서로 내보내기
→ 새 문서가 열리면 파일 → 이동 → "AI실무활용" 폴더
→ 파일 이름 : 03_친환경용품소개서_이름
※ 메뉴 이름은 계정·업데이트에 따라 조금씩 다를 수 있음


# 06. Google 문서에서 다듬기 (15분)

AI가 못 하는 "회사 문서 모양"은 사람이 맞춥니다.

□ 제목 스타일 : 제목·소제목에 "제목 1 / 제목 2" 적용 → 왼쪽 "문서 개요"에 목차가 생김
□ 표 다듬기 : 머리 행 색 넣기, 칸 너비 맞추기
□ 머리글·바닥글 : 회사 이름, 작성일, 쪽 번호
□ 이미지 : 삽입 → 이미지 (로고나 상품 사진 자리)
□ 인쇄 미리보기 : 2장 안에 들어오는지 확인

모르는 기능은 Gemini에게
"Google 문서에서 [하고 싶은 것 — 예: 2쪽부터 쪽 번호 넣기]를 하려면 어떤 메뉴를 눌러야 해? 순서대로 알려줘."

※ 계정에 따라 Google 문서 오른쪽에 Gemini 패널이 있으면 문서 안에서 바로 요청도 가능


# 실습 SET 02
# 까다로운 검토자에게 피드백 받기 (15분)

Google 문서 내용을 복사해 Gemini 새 채팅에 붙여넣거나, + 버튼으로 문서를 첨부합니다.

작성 틀
지금부터 너는 [검토자 — 예: 거래처의 깐깐한 구매 담당 과장]이야.
무조건 칭찬하지 말고, 이 소개서를 받았을 때
[기준 — 예: 사고 싶어지는가 / 궁금한데 빠진 정보 / 믿기 어려운 표현]으로 검토해줘.
문제점마다 [어디가 / 왜 문제인지 / 어떻게 고치면 좋을지]를 표로 적어줘.

→ 피드백 중 동의하는 것 2~3개만 골라 고치기 (다 따를 필요 없음, 판단은 내가)
→ 고칠 때는 Canvas로 돌아가거나, 문서에서 직접 고치기


# 07. 공유와 협업 (10분)

□ 공유 버튼 → "링크가 있는 모든 사용자 - 뷰어" / "특정 사람 - 편집자" 차이
□ 댓글 : 문장 선택 → 댓글 추가 → 팀장님 확인 요청
□ 제안 모드 : 오른쪽 위 연필 → "제안" → 고친 흔적이 남음 (상사가 수락/거절)
□ 버전 기록 : 파일 → 버전 기록 → 예전 상태로 되돌리기

실습 : 옆 사람과 링크를 주고받는 대신, 내 다른 메일 주소나 강사 계정에 "뷰어"로 공유해 보기
