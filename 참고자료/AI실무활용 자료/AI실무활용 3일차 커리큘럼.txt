오늘부터 본격적인 사무 실습입니다.
해오름상사 총무팀 신입 사원이 되어

# 1교시
# 이메일 · 공지 · 회의록


# 01. 업무 문서에서 AI가 줄여 주는 것

- 빈 화면에서 첫 문장을 쓰는 시간
- 말투 고민 (정중하게 / 짧게 / 친근하게)
- 같은 내용을 여러 형태로 다시 쓰는 시간
- 긴 메모를 정리하는 시간

사람이 꼭 할 일 : 날짜·금액·이름 같은 사실 확인, 보내기 전 최종 검토


# 실습 SET 01
# 워크숍 안내 메일

상황 : 11월 사내 워크숍 안내 메일을 전 직원에게 보내야 합니다.

작성 틀
나는 [역할 — 예: 해오름상사 총무팀 신입 사원]이야.
[받는 사람 — 예: 전 직원 60명]에게 보낼 [문서 — 예: 사내 워크숍 안내 메일]을 써줘.
꼭 넣을 정보:
- 일시: [언제]
- 장소: [어디서]
- [그 밖에 — 예: 준비물, 회신 기한]
조건: [예: 한눈에 보이게 항목으로, 5문장 이내, 제목 3개 제안]

이어서 고치기
- "제목을 더 눈에 띄게"
- "회신 기한을 맨 위로"
- "참석 여부를 답장으로 받을 수 있게 마지막 문장 추가"


# 02. 받는 사람에 따라 바꾸기

같은 내용, 다른 대상 → 말투와 정보 순서가 달라집니다.

작성 틀
방금 만든 내용을 바탕으로 다음 세 가지를 각각 써줘.
1. [받는 사람 + 형태 — 예: 팀장에게 보고하는 짧은 메일]
2. [받는 사람 + 형태 — 예: 사내 게시판 공지]
3. [받는 사람 + 형태 — 예: 사내 메신저 한 줄 알림]
받는 사람에 따라 말투와 정보 순서를 다르게 해줘.


# 03. 이미 쓴 글 다듬기

작성 틀
아래 글을 [어떻게 — 예: 맞춤법을 고치고, 더 정중하게, 절반 길이로] 다듬어줘.
[내가 쓴 글 붙여넣기]
[지킬 것 — 예: 날짜와 숫자는 바꾸지 말아줘]
고친 부분은 무엇을 왜 바꿨는지 짧게 알려줘.


# 실습 SET 02
# 회의 메모로 회의록 만들기

회의 중에 적은 메모(대충 적은 것)를 붙여넣어 회의록으로 정리합니다.
※ 참석자 실명 대신 직책이나 A·B로 바꿔서 넣기

작성 틀
아래 회의 메모를 [양식 — 예: 사내 회의록]으로 정리해줘.
[회의 메모 붙여넣기]
정리 항목: [예: 회의 개요 / 논의 내용 / 결정 사항 / 할 일(담당·기한) / 다음 회의]
메모에 없는 내용은 만들지 말고, 애매한 부분은 [확인 필요]로 표시해줘.

예시 메모 (수업용)
11/3 워크숍 준비회의. 팀장, 김대리, 나.
장소 후보 2곳 - 양평 연수원 vs 가평 리조트. 가격은 양평이 쌈.
버스 대절 필요. 점심 도시락? 식당?
레크리에이션 업체 알아보기 - 김대리
다음주 수요일까지 장소 확정.

이어서 : "할 일만 뽑아서 담당자별 체크리스트로 바꿔줘."


# 04. Google 문서로 옮겨 마무리

- 또는 Google 문서에서 Gemini 사이드 패널을 열어 바로 다듬기 (계정에 따라 다름)
- 제목·날짜·결재란 등 회사 양식은 사람이 맞추기

# 2교시
# 나만의 업무 Gem 만들기


# 05. Gem이란?

자주 하는 일의 역할·방식·주의사항을 미리 설정해 둔 "나만의 Gemini"
매번 "나는 총무팀이고, 정중하게, 짧게…"를 반복하지 않아도 됩니다.

만드는 곳 : Gemini 왼쪽 메뉴 → Gem 관리자 → 새 Gem
입력하는 칸 : 이름, 요청 사항(Instructions), 필요하면 참고 파일(Knowledge)


# 06. Gem 지침은 AI에게 초안을 부탁

작성 틀
[어디에서 — 예: 회사 문서 업무]에 반복해서 쓸 '[Gem 이름]' Gem을 만들려고 해.
이 Gem이 도와줄 일:
- [자주 하는 일 1]
- [자주 하는 일 2]
- [자주 하는 일 3]
답변 방식: [예: 정중하고 간결하게, 중요한 내용부터]
주의할 점: [예: 내가 주지 않은 날짜·금액·이름은 만들지 않기, 정보가 부족하면 먼저 질문]
Gem의 요청 사항(Instructions)에 넣을 수 있게 역할 / 할 일 / 답변 방식 / 주의사항으로 정리해줘.

→ 결과를 읽고 필요 없는 줄은 빼고, 내 업무에 맞게 더한 뒤 Gem에 붙여넣기


# 07. 참고 파일 넣기 (선택)

회사 문서 양식, 자주 쓰는 인사말, 용어 정리 파일 등을 Knowledge에 넣으면
그 형식에 맞춰 답합니다. ※ 기밀 문서는 넣지 않기


# 실습 SET 03
# Gem 테스트하고 고치기

① 내 실제 업무 상황으로 테스트
"[언제] 예정이던 [일정]이 [바뀐 내용]으로 변경됐어. [받는 사람]에게 알릴 메일 써줘."

② 결과 형태 바꾸기
"방금 내용을 회의에서 1분 동안 말로 보고할 내용으로 바꿔줘."

③ 마음에 안 드는 점을 지침에 추가
- 답이 길다 → "한 화면에 보이는 분량으로"
- 제목이 없다 → "메일은 항상 제목도 함께 제안"
- 너무 딱딱하다 → "사내 공지는 부드러운 말투로"

Gem 만들기 → 써 보기 → 불편한 점 → 지침 고치기 (계속 발전)


# 08. 오늘의 결과물

① 워크숍 안내 메일 + 대상별 3가지 버전
② 다듬은 문서 (교정·요약)
③ 회의 메모로 만든 회의록과 할 일 체크리스트
④ 나만의 업무 Gem
