# 1교시
# Deep Research로 조사하기


# 01. 일반 질문 vs Deep Research

일반 질문   : 빠른 답, 몇 초, 출처가 부족할 수 있음
Deep Research : 여러 자료를 찾아 비교하고 출처를 붙인 조사 보고서, 몇 분 걸림

켜는 곳 : Gemini 입력창 아래 도구 → Deep Research
기다리는 시간이 길기 때문에 "요청을 한 번에 잘 써야" 합니다.


# 02. 리서치 요청의 5칸

역할 / 목적 / 조사할 내용 / 자료 조건 / 결과 형식


# 실습 SET 01
# 리서치 요청 직접 쓰기

작성 틀
역할: [나는 누구인지]
목적: [이 조사로 무엇을 결정하거나 만들려는지]
조사할 내용:
- [가장 궁금한 것]
- [두 번째]
- [세 번째]
- [필요하면 6개까지]
자료 조건: [예: 최근 2년 국내 자료 우선, 중요한 숫자에는 출처 표시]
결과 형식: [예: 팀장 보고에 쓸 수 있게 항목별 정리]

예시
역할: 생활용품 유통회사 해오름상사 기획팀 신입 사원
목적: 사무실 친환경 용품을 새로 판매할지 판단할 기초 자료 만들기
조사할 내용:
- 국내 사무실 친환경 용품 시장의 최근 변화
- 기업이 친환경 용품을 도입하는 이유
- 주요 제품 종류와 가격대
- 경쟁 회사들의 판매 사례
- 도입할 때 걸림돌
자료 조건: 최근 2년 국내 자료 우선, 숫자에는 출처와 작성 시점 표시
결과 형식: 팀장 보고에 쓸 수 있게 항목별로 정리

입력 전 첨삭 체크
□ [ ] 칸이 남지 않았나  □ 목적과 관계없는 항목은 없나  □ 범위가 너무 넓지 않나


# 03. 조사계획 첨삭하기

Deep Research는 바로 조사하지 않고 조사계획을 먼저 보여줍니다.
"계획 수정"을 누르고 빼고 더한 뒤 시작합니다.

작성 틀
지금 조사계획을 아래처럼 고쳐줘.
- 추가할 항목: [빠진 것]
- 뺄 항목: [관계없는 것 — 없으면 이 줄 지우기]
- 좁힐 범위: [기간·지역·대상 — 없으면 이 줄 지우기]
고친 부분만 따로 알려주지 말고, 반영한 전체 조사계획을 처음부터 끝까지 다시 보여줘.
바뀐 항목에는 (추가)·(수정) 표시를 붙여줘.

※ 마지막 두 줄이 없으면 추가한 부분만 보여주고 끝나서 전체를 점검할 수 없습니다.

# 05. NotebookLM이란?

내가 넣은 자료만 바탕으로 답하는 AI 노트
→ 인터넷 전체가 아니라 "내 자료 안에서" 찾기 때문에 근거 확인이 쉬움

넣을 수 있는 자료 : Google 문서, PDF, 웹 주소, 유튜브 링크, 복사한 글


# 06. 자료 모으기

① 새 노트북 만들기 (이름: 예 "친환경 사무용품 조사")
② Deep Research 결과(Docs) 넣기
③ 보고서에 나온 출처 중 중요한 웹 자료 2~3개 추가
④ 관계없는 자료는 빼기


# 실습 SET 02
# 요약 · 비교 · 빠진 내용 찾기

작성 틀 ① 핵심 요약
등록된 자료를 바탕으로 [누가 — 예: 팀장]이 꼭 알아야 할 핵심을 [몇 개]로 정리해줘.
항목마다 [예: 핵심 / 근거 자료 / 우리 회사에 주는 의미]를 적어줘.

작성 틀 ② 자료 비교
자료들이 공통으로 말하는 [찾을 것 — 예: 도입 이유]와 서로 다른 의견을 나눠서 정리해줘.
형식: [예: 항목 / 공통 내용 / 다른 의견 / 관련 자료]

작성 틀 ③ 빠진 내용
지금 자료로 [보고 목적]을 판단하기에 부족한 정보가 무엇인지, 추가로 찾아볼 검색어와 함께 알려줘.


# 07. 출처 확인하기

- 어느 자료에서 나온 말인가? (NotebookLM은 번호를 눌러 원문 위치 확인)
- 언제 작성된 자료인가?
- 조사 대상은 누구인가?
- 원문의 뜻과 AI의 요약이 같은가?

결정에 쓰는 숫자는 반드시 원문까지 확인합니다.
