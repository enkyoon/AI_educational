한 화면에서 모든 것이 보이는 "대시보드"까지 완성합니다.

도구 : Gemini + Google 시트
       (Google AI Pro 계정이면 시트 오른쪽의 Gemini 패널에서 바로 요청할 수 있습니다)

# 01. 시트에서 AI에게 맡길 수 있는 일 (3분)

- 어떤 칸(열)이 필요한지 표 설계
- 연습용·예시 데이터 만들기
- 날짜·이름·단위가 제각각인 데이터 정리
- 함수 만들기와 설명, 오류 원인 찾기
- 피벗 테이블·차트 만들기, 데이터 요약과 분석

AI에게 요청하는 곳 두 가지
① 시트 오른쪽 Gemini 패널 : 지금 열린 시트를 보고 바로 만들어 줌 (Pro 계정)
② Gemini 앱(gemini.google.com) : 데이터를 붙여넣거나 시트를 첨부해서 요청
※ 메뉴 이름과 위치는 업데이트에 따라 다를 수 있습니다.
  패널이 안 보이면 ②로 해도 같은 결과를 얻을 수 있습니다.

사람이 할 일 : 실제 숫자 확인, 결과 중 몇 개는 직접 검산

# 함수를 말로 요청하기 (15분)

AI가 정확한 함수를 만들려면 네 가지가 필요합니다.
① 데이터 위치 (열, 줄 범위)  ② 하고 싶은 계산 (말로)  ③ 조건  ④ 결과를 넣을 칸

작성 틀
Google 시트에서 쓸 함수를 만들어줘.
데이터 위치: [예: A열 날짜, B열 지점, C열 품목, D열 수량, E열 금액, 2행~41행]
하고 싶은 계산: [예: 지점별 금액 합계]
조건: [예: 서울점만]
결과를 넣을 칸: [예: H2]
함수와 함께, 초보자도 이해하게 한 줄씩 뜻을 설명해줘.

※ Gemini 패널에서는 데이터 위치를 몰라도 "B열 지점별로 E열 금액 합계를 H열에 만들어줘"처럼 말하면 됩니다.

오늘 만들 함수 (최소 3개)
□ 지점별 매출 합계          (→ SUMIF)
□ 품목별 판매 건수          (→ COUNTIF)
□ 매출 목표 달성 여부 표시   (→ IF, 예: 50만 원 이상이면 "달성")
□ (선택) 조건 두 개 합계     (→ SUMIFS, 예: 서울점 + 다회용 컵)
※ 함수 이름은 몰라도 됩니다. 말로 설명하면 AI가 골라 줍니다.

함수가 틀렸을 때
이 함수를 넣었더니 [결과 — 예: #N/A 오류 / 0이 나옴]이 나왔어.
함수: [넣은 함수]
데이터 모양: [예: B열에 '서울점'과 '서울 '(뒤에 띄어쓰기)이 섞여 있음]
원인과 고친 함수를 알려줘.

직접 검산 : 결과 중 1개는 손으로(또는 계산기로) 더해서 맞는지 확인

# 피벗 테이블 자동으로 만들기 (10분)

피벗 테이블 = 긴 데이터를 "지점 × 월"처럼 원하는 기준으로 묶어 합계를 보여 주는 요약표
함수를 하나도 쓰지 않고, 기준만 바꾸면 표가 바로 바뀝니다.

방법 A — Gemini 패널에 말로 요청 (추천)
"데이터" 탭에서 [행 기준 — 예: 지점]을 행으로, [열 기준 — 예: 월]을 열로 해서
[계산 — 예: 금액 합계] 피벗 테이블을 새 탭에 만들어줘.

방법 B — 메뉴의 추천 기능
데이터 범위 선택 → 삽입 → 피벗 테이블 → 새 시트
→ 오른쪽 피벗 테이블 편집기의 "추천" 목록에서 원하는 요약을 누르기

이어서 바꿔 보기 (기준만 바꾸면 표가 바뀌는 것 확인)
□ 행을 "지점" → "품목"으로 바꾸기
□ 금액 "합계" → "평균"으로 바꿔 보고 다시 합계로
□ 탭 이름을 "피벗"으로 바꾸기

검산 : 피벗 테이블의 서울점 합계 = SET 03에서 만든 SUMIF 결과와 같은가?

→ 이 피벗 테이블로 2교시에 차트와 대시보드를 만듭니다.

# 03. 어떤 차트를 쓸까? (2분)

시간에 따른 변화      → 꺾은선 차트
항목끼리 크기 비교    → 막대 차트
전체 중 비율          → 원형 차트 (항목 5개 이하일 때만)


# 실습 SET 06
# 차트 추천받아 만들기 (10분)

방법 A — Gemini 패널에 말로 요청

"피벗" 탭의 데이터를 쓰고, 어떤 차트를 골랐는지 이유도 알려줘.

차트 두 개 만들기
□ 지점별 월 매출 변화 (꺾은선)
□ 품목별 매출 비교 (막대)

차트 다듬기 체크
□ 제목에 결론이 보이나 (예: "서울점, 6개월 연속 증가")
□ 단위(원, 개)가 적혀 있나
□ 강조할 선·막대만 색을 다르게 했나


# 04. 대시보드란? (3분)

대시보드 = 한 화면만 보면 현재 상황이 다 보이는 요약판
자동차 계기판처럼 "핵심 숫자 + 차트 + 필터"를 한 탭에 모읍니다.

대시보드 배치 예 (위에서 아래로)
1줄 : 제목 + 한 줄 결론
2줄 : [총매출]  [1위 지점]  [1위 품목]   ← 핵심 숫자 3칸
3줄 : [지점 필터]
4줄 : [꺾은선 차트]  [막대 차트]

보고할 때 이 탭 하나만 보여 주면 됩니다.

# 06. 오늘의 핵심

함수는 외우는 것이 아니라
"데이터 위치 + 하고 싶은 계산 + 조건 + 결과 칸"을 설명하는 것입니다.
피벗 테이블과 차트는 AI와 추천 기능으로 빠르게 만들고,
AI가 말한 숫자는 반드시 시트에서 확인합니다.
보고는 대시보드 한 장으로 합니다.

다음 시간(DAY 05)에는
분석 결과를 보고용 슬라이드로 만드는 방법을 배웁니다.


# 강사용 메모

- 줄여서 진행할 때 : SET 02(지저분한 데이터)는 STEP 02만, SET 07의 STEP 05(다듬기)는 생략
- 빨리 끝난 사람 : 슬라이서를 "품목"으로 하나 더 추가 / 대시보드에 "월별 목표 달성률" 숫자 칸 추가
- 자주 막히는 곳
  · Gemini 패널이 안 보임 → 오른쪽 위 Gemini 아이콘 확인, 없으면 Gemini 앱에서 같은 요청
  · 피벗 테이블 합계가 이상함 → 금액이 글자로 들어간 경우(왼쪽 정렬) 많음, SET 01 확인 항목 다시 보기
  · 차트를 옮겼더니 깨짐 → 차트는 원래 데이터 범위를 그대로 참조하므로 "피벗" 탭을 지우지 않기
