# 실습 SET 01
# 표 설계하고 데이터 붙여넣기 (15분)

STEP 01 표 설계
나는 [역할]이야. [관리할 것 — 예: 친환경 사무용품 지점별 판매 내역] 표를 만들려고 해.
이 표로 알고 싶은 것: [예: 지점별·품목별·월별 매출, 잘 팔리는 품목]
필요한 칸(열)을 제안하고, 칸마다 [이름 / 넣을 값의 예 / 입력 규칙]을 표로 정리해줘.
[조건 — 예: 7개 이내]

STEP 02 연습용 데이터
이 칸 구성으로 연습용 데이터를 [몇 줄 — 예: 40줄] 만들어줘.
기간: [예: 2026년 3월~8월]
특징: [예: 서울점은 꾸준히 늘고, 부산점은 여름에 줄어들게]
Google 시트에 바로 붙여넣을 수 있는 표로, 실제 회사·사람 이름은 쓰지 말아줘.

STEP 03 시트에 붙여넣기
새 Google 시트 → 이름 "04_친환경용품판매_이름" → "AI실무활용" 폴더로 이동
결과 표 복사 → A1 칸에 붙여넣기

붙여넣은 뒤 확인
□ 칸이 제대로 나뉘었나 (한 칸에 몰려 있지 않은가)
□ 숫자가 오른쪽 정렬인가 (왼쪽이면 글자로 들어간 것 — 쉼표·"원" 확인)
□ 날짜 형식이 모두 같은가
□ 첫 줄 고정 : 보기 → 고정 → 1행


# 실습 SET 02
# 지저분한 데이터 정리하기 (15분)

실제 업무 데이터는 제각각입니다.
예) 날짜 : 2026.3.5 / 3월5일 / 2026-03-05
    지점 : 서울점 / 서울 / 서울지점
    금액 : 120,000원 / 12만 / 120000

STEP 01 일부러 지저분한 데이터 받기 (연습용)
방금 데이터 중 10줄을 골라, 실제 업무처럼 날짜·지점 이름·금액 표기를 제각각으로 섞은 버전을 만들어줘.

STEP 02 정리 요청
아래 데이터를 정리해줘.
[데이터 붙여넣기 — 개인정보는 지우고]
정리 규칙:
- [예: 날짜는 YYYY-MM-DD로 통일]
- [예: 지점 이름은 '서울점 / 부산점 / 대구점' 셋 중 하나로]
- [예: 금액은 숫자만 남기기]
바뀐 부분이 있는 줄은 따로 표시해줘.

※ 데이터가 수백 줄이면 AI에게 붙여넣기보다
  "이걸 시트에서 정리하는 방법(함수나 메뉴 순서)"을 물어보는 편이 안전합니다.
  예) "B열 지점 이름을 한 번에 통일하려면? 찾기 및 바꾸기 순서로 알려줘."


# 실습 SET 03
# 함수를 말로 요청하기 (20분)

AI가 정확한 함수를 만들려면 네 가지가 필요합니다.
① 데이터 위치 (열, 줄 범위)  ② 하고 싶은 계산 (말로)  ③ 조건  ④ 결과를 넣을 칸

작성 틀
Google 시트에서 쓸 함수를 만들어줘.
데이터 위치: [예: A열 날짜, B열 지점, C열 품목, D열 수량, E열 금액, 2행~41행]
하고 싶은 계산: [예: 지점별 금액 합계]
조건: [예: 서울점만]
결과를 넣을 칸: [예: H2]
함수와 함께, 초보자도 이해하게 한 줄씩 뜻을 설명해줘.

오늘 만들 함수 (최소 3개)
□ 지점별 매출 합계          (→ SUMIF)
□ 품목별 판매 건수          (→ COUNTIF)
□ 매출 목표 달성 여부 표시   (→ IF, 예: 50만 원 이상이면 "달성")
□ (선택) 조건 두 개 합계     (→ SUMIFS, 예: 서울점 + 다회용 컵)
※ 함수 이름은 몰라도 됩니다. 말로 설명하면 AI가 골라 줍니다.

함수가 틀렸을 때
이 함수를 넣었더니 [결과 — 예: #N/A 오류 / 0이 나옴]이 나왔어.
함수: [넣은 함수]
데이터 모양: [예: B열에 '서울점'과 '서울 '(뒤에 띄어쓰기)이 섞여 있음]
원인과 고친 함수를 알려줘.

직접 검산 : 결과 중 1개는 손으로(또는 계산기로) 더해서 맞는지 확인

한눈에 보기 (조건부 서식, 2분)
"H열에서 '달성'인 칸만 초록 배경으로 하고 싶어. 메뉴 순서를 알려줘."

# 2교시
# 분석과 차트


# 02. 분석은 "질문"에서 시작 (5분)

데이터만 넣고 "분석해줘"라고 하면 뻔한 결과가 나옵니다.
먼저 알고 싶은 것을 질문으로 적습니다.

예) · 어느 지점이 가장 많이 늘었나?
    · 매출이 줄어든 달은 언제인가?
    · 가장 잘 팔리는 품목은? 지점마다 다른가?


# 실습 SET 04
# AI에게 분석 요청하고 검산하기 (15분)

(시트를 파일로 첨부하거나, 데이터를 복사해 붙여넣기)

작성 틀
첨부한 데이터를 분석해줘.
알고 싶은 것:
1. [질문 1 — 예: 지점별 월 매출 변화]
2. [질문 2 — 예: 가장 많이 늘거나 줄어든 지점과 그 크기]
3. [질문 3 — 예: 품목별 매출 순위]
결과는 [형식 — 예: 질문별 한 줄 답 + 근거 숫자 + 요약표]로 정리하고,
데이터에 없는 원인은 "추측"이라고 표시해줘.

이어서 : 요약표를 시트로
"지점(행) × 월(열) 매출 합계 요약표를 만드는 방법을 알려줘.
함수로 만들지, 피벗 테이블로 만들지 초보자에게 쉬운 쪽을 추천하고 순서대로 알려줘."

검산 : AI가 말한 숫자 2개를 오전에 만든 SUMIF 결과와 비교
→ 다르면? AI에게 "이 숫자는 어떻게 계산했어?"라고 되물어 보기


# 03. 어떤 차트를 쓸까? (5분)

시간에 따른 변화      → 꺾은선 차트
항목끼리 크기 비교    → 막대 차트
전체 중 비율          → 원형 차트 (항목 5개 이하일 때만)


# 실습 SET 05
# 차트 만들기 (15분)

작성 틀
[보여주고 싶은 것 — 예: 지점별 6개월 매출 변화]를 [누구 — 예: 팀장]에게 보여주려고 해.
어떤 차트가 알맞은지 이유와 함께 추천해주고,
Google 시트에서 만드는 순서를 알려줘. 데이터 범위는 [범위]야.

차트 두 개 만들기
□ 지점별 월 매출 변화 (꺾은선)
□ 품목별 매출 비교 (막대)

차트 다듬기 체크
□ 제목에 결론이 보이나 (예: "서울점, 6개월 연속 증가")
□ 단위(원, 개)가 적혀 있나
□ 강조할 선·막대만 색을 다르게 했나


# 04. 한 줄 결론으로 정리 (10분)

정보    : "서울점 매출이 6개월간 40% 늘었다."
인사이트 : "서울점의 판매 방식을 다른 지점에도 적용해 볼 만하다."

작성 틀
위 분석 결과로 [누가 — 예: 영업팀장]이 바로 행동할 수 있는 결론을 [몇 개 — 예: 3개] 써줘.
항목마다 [발견한 사실 / 근거 숫자 / 해 볼 만한 일]로 쓰고,
데이터로 확인되지 않는 원인은 "추측"이라고 표시해줘.

→ 결과를 시트의 새 탭 "요약"에 붙여넣고, 차트 두 개를 그 탭으로 옮기기
→ 5일차에 이 차트와 결론으로 슬라이드를 만듭니다.


# 05. 오늘의 결과물

② 규칙에 맞게 정리한 데이터
③ 말로 요청해 만든 함수 3개 이상 (검산 포함)
④ 요약표와 차트 2개
⑤ 결론 3가지가 적힌 "요약" 탭 (04_친환경용품판매)


# 06. 오늘의 핵심

함수는 외우는 것이 아니라
"데이터 위치 + 하고 싶은 계산 + 조건 + 결과 칸"을 설명하는 것입니다.
분석은 질문에서 시작하고, AI가 말한 숫자는 반드시 시트에서 확인합니다.
