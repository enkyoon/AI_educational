# DAY 05
# Google 슬라이드 — 보고용 발표자료 만들기


## 오늘의 수업

회사에서 슬라이드는 "발표용"보다
"보고용"으로 더 자주 씁니다. 회의 화면에 띄우거나, 파일로 보내 읽게 하는 자료입니다.

오늘은 4일차 분석 결과로 "월간 판매 실적 보고" 슬라이드를 만듭니다.
좋은 보고 슬라이드의 원칙을 익히고,
Canvas로 초안을 만든 뒤 Google 슬라이드에서 차트·이미지·메모를 넣어 완성합니다.

오늘 만든 슬라이드는 6일차 Gemini Notebook의 자료로 다시 씁니다.

도구 : Gemini (+ Canvas, 이미지 만들기) + Google 슬라이드 + Google 시트


오늘은 다음 순서로 진행합니다.

좋은 보고 슬라이드의 조건
↓
슬라이드 구성(스토리) 짜기
↓
제목을 "결론"으로 바꾸기
↓
Canvas로 슬라이드 초안 만들기
↓
Google 슬라이드로 옮기기
↓
시트 차트 연결하기
↓
Gemini로 이미지 만들어 넣기
↓
발표자 메모 쓰고 한 장씩 고치기



# 1교시
# 구성과 초안


# 01. 좋은 보고 슬라이드의 조건 (10분)

- 한 장에 메시지 하나 (슬라이드 제목이 곧 결론)
- 글은 줄이고 숫자·차트·그림으로
- 읽는 사람이 궁금한 순서로 (결론 → 근거 → 제안)
- 마지막 장에 "그래서 무엇을 결정해 달라는지"

나쁜 예 : 문서 문단을 그대로 붙여넣은 슬라이드, 제목이 "현황" "분석"
좋은 예 : 제목 "서울점, 6개월 연속 매출 증가" + 꺾은선 차트 하나 + 숫자 한 줄

잘 만든 보고 슬라이드 순서 (예)
1 표지 → 2 한 장 요약 → 3~5 근거(차트) → 6 제안 → 7 결정 요청


# 실습 SET 01
# 슬라이드 구성 짜기 (15분)

4일차 시트의 "요약" 탭 내용(결론 3가지, 주요 숫자)을 복사해 붙여넣거나 시트를 첨부합니다.

작성 틀
아래 분석 결과로 [누구 — 예: 영업팀장과 임원]에게 보고할 슬라이드를 구성해줘.
[분석 결과 붙여넣기 또는 시트 첨부]
슬라이드 수: [예: 6장]
장마다: [슬라이드 제목(결론 한 줄) / 넣을 내용 3줄 이내 / 추천 시각자료]
마지막 장은 [예: 결정해 달라는 사항]으로 끝내줘.
숫자는 내가 준 자료에 있는 것만 쓰고, 없는 숫자는 [확인 필요]로 표시해줘.

점검
□ 제목만 이어 읽어도 이야기가 되는가
□ 한 장에 메시지가 하나인가
□ 숫자가 모두 4일차 시트에 있는 숫자인가


# 02. 제목을 "결론"으로 바꾸기 (5분)

"지점별 현황"   → "서울점이 전체 매출의 절반을 차지"
"품목 분석"     → "다회용 컵, 3개월 만에 매출 1위"
"향후 계획"     → "부산점 여름 재고 문제부터 해결 필요"

작성 틀
지금 구성에서 슬라이드 제목을 모두 "결론이 보이는 한 문장"으로 바꿔줘.
근거 숫자가 있으면 제목에 넣고, 20자 안팎으로.


# 실습 SET 02
# Canvas로 슬라이드 초안 만들기 (15분)

작성 틀
방금 구성으로 Canvas에서 보고용 슬라이드를 만들어줘.
디자인 느낌: [예: 깔끔한 회사 보고용, 흰 배경에 초록 포인트]
조건: [예: 글자는 크게, 장마다 3줄 이내, 핵심 숫자는 크게 강조, 차트 자리는 비워 두기]

→ Canvas에서 한 장씩 넘겨 보며 확인
→ 고칠 곳은 한 장씩: "[몇 번] 슬라이드 — 문제: [글이 많음] — 이렇게: [숫자 하나만 크게]"



# 10분 휴식



# 2교시
# Google 슬라이드에서 완성하기


# 03. Google 슬라이드로 옮기기 (5분)

Canvas "공유 및 내보내기" → Google 슬라이드로 내보내기
→ 파일 이름 "05_월간판매실적보고_이름" → "AI실무활용" 폴더로 이동
※ 메뉴 이름은 계정·업데이트에 따라 다를 수 있음
※ 내보내기가 안 보이면 : Google 슬라이드에서 새 파일을 만들고 구성을 보며 직접 옮겨 적기


# 04. 시트 차트 연결하기 (10분)

4일차 시트에서 차트 클릭 → 복사 → 슬라이드에 붙여넣기 → "스프레드시트에 연결"
→ 시트 숫자가 바뀌면 슬라이드 차트 오른쪽 위 "업데이트" 한 번으로 반영

□ 차트 두 개를 알맞은 슬라이드에 넣기
□ 차트 옆 글은 한 줄만 (차트가 말하게)


# 실습 SET 03
# Gemini로 이미지 만들어 넣기 (10분)

표지나 제안 슬라이드에 넣을 그림을 만듭니다.

작성 틀
보고용 슬라이드에 넣을 이미지를 만들어줘.
내용: [예: 밝은 사무실 책상 위의 다회용 컵과 재생 용지 노트]
느낌: [예: 깔끔하고 밝은 사진 느낌, 초록 포인트]
조건: [예: 글자는 넣지 말 것, 가로로 긴 화면]

→ 이미지 저장 → 슬라이드에 삽입 → 이미지 → 업로드
※ AI 이미지는 실제 상품 사진이 아니므로, 거래처 자료에는 "예시 이미지"라고 표시하거나 실제 사진으로 바꾸기
※ 계정에 따라 Google 슬라이드 안에서 바로 이미지 만들기가 가능한 경우도 있음


# 05. 디자인 다듬기 (10분)

□ 테마 하나로 통일 (슬라이드 → 테마 변경)
□ 글꼴 두 가지 이하, 제목 크기 통일
□ 강조 색 하나만
□ 모든 장에 같은 위치에 쪽 번호
□ 보기 → 슬라이드쇼로 처음부터 넘겨 보기

모르는 기능은 Gemini에게
"Google 슬라이드에서 [하고 싶은 것 — 예: 모든 슬라이드 제목 글꼴을 한 번에 바꾸기] 방법을 순서대로 알려줘."


# 실습 SET 04
# 발표자 메모 쓰기 (10분)

보고 자료는 화면에는 짧게, 말할 내용은 슬라이드 아래 "발표자 메모"에 둡니다.
(파일로 보낼 때 읽는 사람도 메모를 볼 수 있어 설명 자료가 됩니다)

작성 틀
이 슬라이드 구성으로 장마다 [예: 30초] 분량의 설명 문장을 써줘.
말투: [예: 회의에서 보고하듯 자연스럽게]
다음 장으로 넘어가는 연결 문장도 넣어줘.

→ 장마다 슬라이드 아래 메모 칸에 붙여넣기

마지막 점검 (검토자에게)
"너는 [예: 숫자에 깐깐한 임원]이야. 이 슬라이드 내용을 보고 나올 만한 질문 5개와 짧은 답을 정리해줘.
근거가 없는 답은 [확인 필요]로 표시해줘."
→ 답하기 어려운 질문이 있으면 해당 슬라이드를 보강
