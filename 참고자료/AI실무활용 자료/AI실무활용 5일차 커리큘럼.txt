오늘은 함수를 외우지 않고
"무엇을 계산하고 싶은지 말로 설명해서"
AI에게 표를 설계하고, 데이터를 정리하고, 함수를 만들어 달라고 하는 방법을 익힙니다.

해오름상사 상황 :
총무팀에서 관리하는 "사무용품 구매 내역"과 "지점별 월 매출"을 정리해야 합니다.


오늘은 다음 순서로 진행합니다.

AI로 업무용 표 설계하기

# 1교시
# 표 설계와 데이터 정리


# 01. 스프레드시트에서 AI에게 맡길 수 있는 일

- 어떤 칸(열)이 필요한지 표 설계
- 연습용·예시 데이터 만들기
- 날짜·이름·단위가 제각각인 데이터 정리
- 함수 만들기와 설명
- 오류 원인 찾기

사람이 할 일 : 실제 숫자 확인, 계산 결과가 맞는지 몇 개 직접 검산


# 실습 SET 01
# 업무용 표 설계하기

작성 틀
나는 [역할]이야. [어떤 일을 관리할 — 예: 사무용품 구매 내역] 표를 만들려고 해.
이 표로 알고 싶은 것: [예: 월별·부서별 지출, 자주 사는 품목]
필요한 칸(열)을 제안하고, 칸마다 [예: 이름 / 넣을 값의 예 / 입력 규칙]을 표로 정리해줘.
[조건 — 예: 너무 많지 않게 8개 이내]

이어서
"이 칸 구성으로 연습용 데이터를 [몇 줄 — 예: 30줄] 만들어줘.
Google 시트에 바로 붙여넣을 수 있는 표 형식으로.
실제 회사나 사람 이름은 쓰지 말아줘."

→ 결과 표를 복사해 Google 시트 A1 칸에 붙여넣기


# 02. 데이터를 붙여넣을 때 확인할 것

- 칸이 제대로 나뉘었는가 (한 칸에 몰려 있지 않은가)
- 숫자가 글자로 들어가지 않았는가 (쉼표·원 표시)
- 날짜 형식이 모두 같은가


# 실습 SET 02
# 지저분한 데이터 정리하기

실제 업무 데이터는 제각각입니다.
예) 날짜 : 2026.3.5 / 3월5일 / 2026-03-05
    부서 : 총무팀 / 총무 / 총무부

작성 틀
아래 데이터를 정리해줘.
[데이터 붙여넣기 — 개인정보는 지우고]
정리 규칙:
- [예: 날짜는 YYYY-MM-DD로 통일]
- [예: 부서 이름은 '총무팀 / 영업팀 / 기획팀' 셋 중 하나로]
- [예: 금액은 숫자만 남기기]
바뀐 부분이 있는 줄은 따로 표시해줘.

※ 데이터가 많으면 AI에게 "정리하는 방법(함수나 순서)"을 물어보는 편이 더 안전합니다.

# 2교시
# AI에게 함수 만들어 달라고 하기


# 03. 함수를 몰라도 되는 요청 방법

AI가 정확한 함수를 만들려면 이 네 가지가 필요합니다.
① 데이터가 어디에 있는지 (시트 이름, 열, 줄 범위)
② 무엇을 계산하고 싶은지 (말로)
③ 조건이 있다면 무엇인지
④ 결과를 어느 칸에 넣을지


# 실습 SET 03
# 함수 만들기

작성 틀
Google 시트에서 쓸 함수를 만들어줘.
데이터 위치: [예: A열 날짜, B열 부서, C열 품목, D열 금액, 2행~31행]
하고 싶은 계산: [예: 부서별 금액 합계]
조건: [예: 3월 데이터만]
결과를 넣을 칸: [예: G2]
함수와 함께, 초보자도 이해하게 한 줄씩 뜻을 설명해줘.

자주 쓰는 계산 예시 (말로 요청)
- 조건에 맞는 합계  → SUMIF / SUMIFS
- 조건에 맞는 개수  → COUNTIF
- 다른 표에서 값 찾아오기 → VLOOKUP / XLOOKUP
- 조건에 따라 글자 표시 → IF (예: 예산 초과면 "확인 필요")
- 순위 → RANK

※ 함수 이름은 몰라도 됩니다. 말로 설명하면 AI가 골라 줍니다.


# 04. 함수가 틀렸을 때

작성 틀
이 함수를 넣었더니 [결과 — 예: #N/A 오류 / 0이 나옴 / 값이 이상함]이 나왔어.
함수: [넣은 함수]
데이터 모양: [예: A열 날짜가 글자로 입력돼 있음]
원인과 고친 함수를 알려줘.

직접 검산하기 : 결과 중 2~3개는 손으로 계산해 맞는지 확인


# 05. 조건부 서식으로 한눈에 보기

작성 틀
Google 시트에서 [범위 — 예: D2:D31]에 조건부 서식을 넣고 싶어.
[조건 — 예: 10만 원 이상이면 빨간 배경]
메뉴를 어떤 순서로 누르면 되는지 단계별로 알려줘.


# 06. (선택) 시트 안에서 바로 Gemini 쓰기

계정에 따라 Google 시트 오른쪽 Gemini 패널에서
"이 시트의 부서별 합계를 표로 만들어줘"처럼 바로 요청할 수 있습니다.


# 07. 오늘의 결과물

① AI가 설계한 업무용 표 (사무용품 구매 내역)
② 연습용 데이터 30줄
③ 규칙에 맞게 정리한 데이터
④ 직접 요청해 만든 함수 3개 이상 (합계·개수·조건 표시)
⑤ 조건부 서식을 넣은 시트


# 08. 오늘의 핵심

함수는 외우는 것이 아니라
"데이터 위치 + 하고 싶은 계산 + 조건 + 결과 칸"을 설명하는 것입니다.
그리고 결과는 몇 개라도 직접 검산합니다.
