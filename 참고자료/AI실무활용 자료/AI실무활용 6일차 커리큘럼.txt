# 1교시
# 데이터 분석


# 01. 분석은 "질문"에서 시작한다

데이터만 넣고 "분석해줘"라고 하면 뻔한 결과가 나옵니다.
먼저 알고 싶은 것을 질문으로 적습니다.

예) · 어느 지점이 가장 많이 늘었나?
    · 매출이 줄어든 달은 언제이고 왜일까?
    · 품목별로 보면 무엇이 잘 팔리나?


# 실습 SET 01
# 분석용 데이터 준비

작성 틀
[분석할 내용 — 예: 지점별 월 매출] 연습용 데이터를 만들어줘.
기간: [예: 최근 6개월]
칸: [예: 월 / 지점 / 품목 / 판매 수량 / 매출액]
특징: [예: 한 지점은 꾸준히 늘고, 한 지점은 여름에 줄어들게]
Google 시트에 붙여넣을 수 있는 표로, 실제 회사 이름은 쓰지 말아줘.

※ 실제 업무 데이터를 쓸 때는 고객·직원 정보를 지우고 넣습니다.


# 실습 SET 02
# AI에게 분석 요청하기

(Gemini에 데이터를 붙여넣거나 시트 파일을 첨부)

작성 틀
첨부한 데이터를 분석해줘.
알고 싶은 것:
1. [질문 1 — 예: 지점별 6개월 매출 변화]
2. [질문 2 — 예: 가장 많이 늘거나 줄어든 지점과 그 크기]
3. [질문 3 — 예: 품목별 매출 순위]
결과는 [형식 — 예: 질문별 한 줄 답 + 근거 숫자]로 정리하고,
데이터에 없는 이유는 추측이라고 표시해줘.

확인하기 : AI가 말한 숫자 2~3개를 시트에서 직접 찾아 맞는지 확인


# 02. 피벗 테이블로 요약표 만들기

작성 틀
Google 시트에서 피벗 테이블로 [보고 싶은 표 — 예: 행은 지점, 열은 월, 값은 매출 합계]를 만들고 싶어.
데이터 범위는 [범위]야. 메뉴를 누르는 순서대로 알려줘.

# 2교시
# 차트와 보고


# 03. 어떤 차트를 쓸까?

시간에 따른 변화      → 꺾은선 차트
항목끼리 크기 비교    → 막대 차트
전체 중 비율          → 원형 차트 (항목 5개 이하일 때만)
두 값의 관계          → 분산형 차트

작성 틀
[보여주고 싶은 것 — 예: 지점별 6개월 매출 변화]를 [누구 — 예: 팀장]에게 보여주려고 해.
어떤 차트가 가장 알맞은지 이유와 함께 추천해주고,
Google 시트에서 만드는 순서도 알려줘.

차트 다듬기 체크
□ 제목에 결론이 보이나 (예: "B지점, 6개월 연속 증가")
□ 단위(원, 개)가 적혀 있나  □ 강조할 선·막대만 색을 다르게 했나


# 실습 SET 03
# 숫자에서 인사이트 찾기

정보    : "B지점 매출이 6개월간 40% 늘었다."
인사이트 : "B지점의 판매 방식을 다른 지점에도 적용해 볼 만하다."

작성 틀
위 분석 결과를 바탕으로 [누가 — 예: 영업팀장]이 바로 행동할 수 있는 인사이트를 [몇 개] 찾아줘.
항목마다 [예: 발견한 사실 / 근거 숫자 / 해 볼 만한 일]로 써줘.
데이터로 확인되지 않는 원인은 "추측"이라고 표시해줘.


# 04. 한 장 보고서로 정리하기

작성 틀
지금까지의 분석으로 [읽을 사람]에게 올릴 한 장 보고서를 써줘.
구성:
1. 한 줄 결론
2. 핵심 숫자 [몇 개]
3. 차트 설명 (차트는 내가 따로 붙임)
4. 제안 [몇 개]
조건: [예: A4 한 장, 숫자는 데이터에 있는 것만, 쉬운 말로]

→ Google 문서에 붙이고 시트의 차트를 복사해 넣어 완성


# 05. 오늘의 결과물

① 분석용 매출 데이터
② 질문별 분석 결과 (검산한 숫자 포함)
③ 피벗 요약표
④ 결론이 보이는 차트
⑤ 인사이트 3가지
⑥ 한 장 보고서


# 06. 오늘의 핵심

분석은 "무엇을 알고 싶은가"라는 질문에서 시작하고,
보고는 "그래서 무엇을 해야 하는가"로 끝납니다.
AI가 말한 숫자는 반드시 원래 데이터에서 확인합니다.
