# DAY 07
# 기획안 작성과 고도화 — Canvas


## 오늘의 수업

지금까지 문서 작성, 자료 조사, 데이터 분석을 했습니다.
오늘은 이것들을 모아 "기획안"을 만듭니다.

기획은 한 번에 완성되지 않습니다.
문제 찾기 → 아이디어 → 하나 골라 구체화 → 기획안 구조 → 검토와 수정
단계마다 사람이 방향을 고르고, AI와 주고받으며 다듬습니다.

도구 : Gemini (+ Canvas)

해오름상사 상황 :
4일차 조사 결과를 바탕으로 "사무실 친환경 용품 신규 판매" 기획안을 만들어 봅니다.
※ 최종 과제로 각자 "내 업무 하나"를 골라 같은 과정으로 기획안을 만들어도 됩니다.


오늘은 다음 순서로 진행합니다.

문제에서 출발하기
↓
여러 방향의 아이디어 받기
↓
하나 골라 구체화하기 (단점까지)
↓
기획안 구조 잡기
↓
Canvas에서 기획안 쓰기
↓
까다로운 검토자에게 피드백 받기
↓
한 곳씩 고쳐 완성하기



# 1교시
# 아이디어에서 기획으로


# 01. 기획안이란?

"왜(문제·목표) → 무엇을(내용) → 어떻게(실행) → 얼마나(예산·일정) → 그래서(기대효과)"를
읽는 사람이 한 번에 이해하고 결정할 수 있게 정리한 문서


# 실습 SET 01
# 문제에서 출발해 아이디어 받기

STEP 01 문제 찾기
작성 틀
나는 [역할]이야. [대상 — 예: 사무실에서 일하는 직원들]이 [상황 — 예: 일회용품 사용]에서 겪는
불편이나 문제를 [몇 개] 찾아줘. 아직 해결책은 말하지 말아줘.

STEP 02 여러 방향의 아이디어
작성 틀
'[고른 문제]'를 해결할 아이디어를 서로 다른 방향으로 제안해줘.
방향: [예: 비용 절감 / 직원 참여 / 브랜드 이미지 / 편리함]
방향마다 [몇 개]씩, 우리 회사가 [조건 — 예: 6개월 안에, 적은 예산으로] 할 수 있는 것으로.

STEP 03 하나 골라 구체화
작성 틀
[몇 번] 아이디어를 고를게. 다음을 정리해줘.
- 핵심 내용
- 주요 대상
- 기대 효과
- 예상되는 단점과 위험
- 먼저 확인해야 할 것
좋은 점만 쓰지 말고 단점도 솔직하게 써줘.


# 02. 읽는 사람에 따라 기획안 구조가 달라진다

결재권자(팀장·임원) : 결론과 비용·효과부터
실무 협조 부서     : 할 일과 일정부터
외부 제안(거래처)   : 상대가 얻는 이익부터

작성 틀
[아이디어 이름] 기획안의 목차를 만들어줘.
읽을 사람: [누구], 이 사람이 가장 궁금한 것: [예: 비용 대비 효과]
분량: [예: A4 2장]
목차마다 들어갈 내용을 한 줄씩 적어줘.

# 2교시
# Canvas로 기획안 고도화


# 03. Canvas란?

결과물을 오른쪽 화면에 문서처럼 띄워 두고
대화로 계속 고치거나, 원하는 부분만 골라 수정할 수 있는 기능
켜는 곳 : Gemini 입력창 아래 도구 → Canvas


# 실습 SET 02
# Canvas에서 기획안 쓰기

작성 틀
지금까지 정리한 내용으로 Canvas에서 기획안을 써줘.
제목: [기획안 제목]
읽을 사람: [누구]
목차:
1. [추진 배경]
2. [목표]
3. [주요 내용]
4. [실행 계획과 일정]
5. [예산]
6. [기대 효과]
7. [위험과 대응]
조건: [예: A4 2장, 숫자는 내가 준 자료에 있는 것만, 없는 숫자는 [확인 필요]로 표시]

※ 4일차 보고서, 6일차 분석 결과를 붙여넣거나 첨부하면 근거가 탄탄해집니다.


# 실습 SET 03
# 까다로운 검토자에게 피드백 받기

작성 틀
지금부터 너는 [검토자 — 예: 예산을 결정하는 20년 차 임원]이야.
무조건 칭찬하지 말고 이 기획안을 [기준 — 예: 비용 대비 효과, 실행 가능성, 빠진 정보]로 검토해줘.
문제점마다 [예: 어디가 / 왜 문제인지 / 어떻게 고치면 좋을지]를 적어줘.


# 04. 한 곳씩 고치기

작성 틀
고칠 곳: [어느 부분]
이렇게 바꿔줘: [구체적으로]
그대로 둘 것: [바꾸면 안 되는 부분]

- Canvas에서 문장을 드래그해 선택하면 그 부분만 고쳐 달라고 할 수 있음
- 한 번에 여러 곳을 고치면 어디가 바뀌었는지 놓치기 쉬움 → 한 곳씩


# 05. 마지막 점검표

□ 첫 문단만 읽어도 무엇을 하자는지 알 수 있나
□ 숫자마다 근거가 있나 (없으면 [확인 필요])
□ 일정과 담당이 구체적인가
□ 위험과 대응이 있나
□ 읽을 사람이 궁금한 것이 앞에 있나

→ 완성본은 Google 문서로 내보내기


# 06. 오늘의 결과물

③ 읽는 사람에 맞춘 기획안 목차
④ Canvas로 쓴 기획안 초안
⑤ 검토 피드백을 반영한 완성 기획안
