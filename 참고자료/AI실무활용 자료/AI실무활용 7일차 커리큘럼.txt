# 01. 기획안이란? (5분)

"왜(문제·목표) → 무엇을(내용) → 어떻게(실행) → 얼마나(예산·일정) → 그래서(기대효과)"를
읽는 사람이 한 번에 이해하고 결정할 수 있게 정리한 문서

좋은 기획안과 아쉬운 기획안의 차이 = "근거"
아쉬운 기획안 : "친환경이 대세이므로 판매를 늘리자"
좋은 기획안   : "서울점 다회용 컵 매출이 6개월간 40% 늘었고(04 시트),
                거래처들이 세척을 가장 번거로워한다(06 조사) → 세척 대행 묶음 상품 제안"

# 03. Apps Script란? (3분)

Google 시트·문서·Gmail에 "이 일을 자동으로 해줘"라고 시킬 수 있는 기능
(엑셀의 매크로와 비슷, 무료, 설치 필요 없음)

원래는 코드를 짜야 하지만, 이제는
① Gemini에게 말로 요청 → ② 코드를 복사해 붙여넣기 → ③ 실행 버튼
이 세 단계면 됩니다. 코드를 읽거나 이해할 필요는 없습니다.

오늘 할 예제
예제 ① 나에게 테스트 메일 한 통 보내기 (연습 — 실행과 권한 허용 익히기)
예제 ② 시트 명단으로 사람마다 이름이 들어간 메일 보내기 (실무)

안전 약속
- 받는 사람은 "내 메일 주소"로만 (실제 동료·거래처에게 보내지 않기)
- 무료 계정은 하루에 보낼 수 있는 메일 수에 제한이 있음 (연습에는 충분)


# 실습 SET 04
# 예제 ① 나에게 테스트 메일 한 통 (12분)

STEP 01 시트 만들기
새 Google 시트 → 이름 "07_자동메일연습_이름"

STEP 02 Apps Script 열기
시트 위쪽 메뉴 → 확장 프로그램 → Apps Script
→ 새 탭에 코드 편집 화면이 열림
→ 이미 적혀 있는 function myFunction() { } 을 모두 지우기

STEP 03 Gemini에게 코드 요청 (Gemini 새 채팅)
Google Apps Script 코드를 만들어줘.
하고 싶은 일: [나(스크립트를 실행하는 사람)에게 테스트 메일 1통 보내기]
메일 제목: [예: [테스트] Apps Script 첫 메일]
메일 내용: [예: 안녕하세요. Apps Script로 자동 발송한 첫 메일입니다.]
함수 이름은 [sendTestMail]로 해줘.
나는 코딩을 몰라. 붙여넣고 실행하는 순서도 알려줘.

STEP 04 붙여넣고 저장
Gemini가 준 코드 복사 → 편집 화면에 붙여넣기 → 저장(디스크 아이콘 또는 Ctrl+S)

STEP 05 실행
위쪽 함수 선택 칸에 "sendTestMail"이 보이는지 확인 → ▶ 실행

STEP 06 권한 허용 (처음 한 번만 — 가장 많이 막히는 곳)
① "승인 필요" 창 → 권한 검토
② 내 Google 계정 선택
③ "Google에서 확인하지 않은 앱" 화면이 나옴 → 놀라지 않기 (내가 만든 코드라서 나오는 화면)
④ 왼쪽 아래 "고급" → "(프로젝트 이름)(으)로 이동(안전하지 않음)"
⑤ "허용"
※ 화면 문구는 조금씩 다를 수 있음

STEP 07 확인
편집 화면 아래 실행 로그에 "실행 완료" → Gmail 받은편지함에 메일이 왔는지 확인

막혔을 때를 위한 예비 코드 (강사 제공)
function sendTestMail() {
  var me = Session.getActiveUser().getEmail();
  MailApp.sendEmail(me, '[테스트] Apps Script 첫 메일', '안녕하세요. Apps Script로 자동 발송한 첫 메일입니다.');
}


# 실습 SET 05
# 예제 ② 시트 명단으로 맞춤 메일 보내기 (15분)

7일차 기획안을 관련 담당자들에게 이름을 넣어 안내하는 상황입니다.

STEP 01 시트에 명단 만들기 (같은 시트 "07_자동메일연습")
A1 이름 / B1 이메일 / C1 부서 / D1 보낸 상태
2~4행에 연습 명단 3줄
   김하늘 / 내주소+kim@gmail.com / 영업팀
   이바다 / 내주소+lee@gmail.com / 서울점
   박나무 / 내주소+park@gmail.com / 부산점

※ Gmail은 주소 뒤에 +글자를 붙여도 모두 내 받은편지함으로 옵니다.
   예) mymail@gmail.com → mymail+kim@gmail.com
   → 실제로는 나에게 3통이 오지만, 3명에게 보낸 것처럼 연습할 수 있음
   (회사 메일 주소는 이 방법이 안 될 수 있으니 개인 Gmail로)

STEP 02 Gemini에게 코드 요청
Google Apps Script 코드를 만들어줘.
시트 모양: [A열 이름, B열 이메일, C열 부서, D열 보낸 상태, 1행은 제목, 2행부터 명단]
하고 싶은 일: [명단의 사람마다 이름과 부서를 넣은 메일 보내기]
메일 제목: [예: [해오름상사] 하반기 친환경 용품 판매 기획안 안내]
메일 내용: [예: ○○님(부서) 안녕하세요. 하반기 판매 기획안을 공유드립니다. 다음 주 회의 전 확인 부탁드립니다.]
조건: [예: 보낸 줄은 D열에 '보냄'이라고 적기, 이메일 칸이 비어 있으면 건너뛰기]
함수 이름은 [sendMails]로 해줘. 붙여넣고 실행하는 순서도 알려줘.

STEP 03 편집 화면의 예제 ① 코드 아래에 이어 붙여넣기 → 저장
STEP 04 함수 선택 칸에서 "sendMails" 선택 → ▶ 실행
       (권한 창이 또 나오면 예제 ①과 같은 순서로 허용)
STEP 05 확인
□ 받은편지함에 메일 3통 (각각 이름·부서가 다르게 들어갔는지)
□ 시트 D열에 "보냄" 표시

막혔을 때를 위한 예비 코드 (강사 제공)
function sendMails() {
  var sheet = SpreadsheetApp.getActiveSheet();
  var rows = sheet.getDataRange().getValues();
  for (var i = 1; i < rows.length; i++) {
    var name = rows[i][0];
    var email = rows[i][1];
    var dept = rows[i][2];
    if (!email) continue;
    var subject = '[해오름상사] 하반기 친환경 용품 판매 기획안 안내';
    var body = name + '님(' + dept + ') 안녕하세요.\n\n'
             + '하반기 친환경 사무용품 판매 기획안을 공유드립니다.\n'
             + '다음 주 회의 전에 확인 부탁드립니다.\n\n감사합니다.';
    MailApp.sendEmail(email, subject, body);
    sheet.getRange(i + 1, 4).setValue('보냄');
  }
}

더 해 보기 (선택)
- 메일 내용에 기획안 Google 문서 링크 넣기 ("메일 내용에 이 링크를 넣어줘: [링크]")
- 시트 메뉴에 "메일 보내기" 버튼 만들기 ("시트 위쪽 메뉴에 버튼을 추가해 거기서 실행되게 해줘")


# 04. 자주 막히는 곳

증상                              해결
함수 선택 칸에 이름이 안 보임        저장(Ctrl+S)을 안 함 → 저장 후 다시
"승인 필요"에서 멈춤                "고급" → "(프로젝트 이름)으로 이동" 을 못 찾음 → 창 왼쪽 아래 확인
오류 메시지가 빨간 글씨로 나옴        오류 문장을 복사해 Gemini에 "이 오류가 났어, 고친 코드 전체를 다시 줘"
메일이 안 옴                       스팸함 확인, B열 주소 오타 확인
D열에 '보냄'이 다른 칸에 적힘        시트 칸 순서가 요청과 다름 → Gemini에 실제 칸 순서를 다시 알려주기

핵심 : 코드를 고치려 하지 말고, "무슨 일이 일어났는지"를 Gemini에게 말하면 됩니다.
