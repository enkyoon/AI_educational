# 1교시
# 기획안을 발표자료로


# 01. 좋은 발표자료의 조건

- 한 장에 메시지 하나 (슬라이드 제목이 곧 결론)
- 글은 줄이고 숫자·그림·도표로
- 듣는 사람이 궁금한 순서로
- 마지막 장에 "그래서 무엇을 결정해 달라는지"

나쁜 예 : 기획안 문단을 그대로 붙여넣은 슬라이드
좋은 예 : "친환경 컵 도입 시 연간 비용 30% 절감" 한 줄 + 비교 도표


# 실습 SET 01
# 슬라이드 구성 짜기

작성 틀
첨부한(또는 아래) 기획안을 [누구 — 예: 임원 회의]에서 [몇 분] 동안 발표할 슬라이드로 구성해줘.
슬라이드 수: [예: 7장]
장마다: [예: 슬라이드 제목(결론 한 줄) / 넣을 내용 3줄 이내 / 추천 시각자료]
마지막 장은 [예: 결정해 달라는 사항]으로 끝내줘.

점검
□ 제목만 이어 읽어도 이야기가 되는가  □ 한 장에 메시지가 하나인가


# 02. 슬라이드 제목을 "결론"으로 바꾸기

"추진 배경"       → "직원 70%가 일회용품 줄이기에 찬성"
"예산"           → "초기 비용 300만 원, 8개월이면 회수"
※ 숫자는 기획안과 조사 자료에 있는 것만


# 실습 SET 02
# Canvas로 슬라이드 만들기

작성 틀
방금 구성으로 Canvas에서 발표 슬라이드를 만들어줘.
디자인 느낌: [예: 깔끔한 회사 보고용, 흰 배경에 초록 포인트]
조건: [예: 글자는 크게, 장마다 3줄 이내, 숫자는 크게 강조]

→ 내보내기로 Google 슬라이드에 옮기기 (계정에 따라 메뉴 이름이 다를 수 있음)
→ Google 슬라이드에서 회사 로고·날짜·차트(6일차) 넣어 마무리
※ Google 슬라이드 오른쪽 Gemini 패널에서 이미지 만들기·문장 다듬기도 가능 (계정에 따라 다름)


# 03. 고칠 때는 한 장씩

작성 틀
[몇 번] 슬라이드를 고쳐줘.
문제: [예: 글이 너무 많음]
이렇게: [예: 핵심 숫자 하나만 크게, 나머지는 발표 대본으로 옮기기]

# 실습 SET 03
# 발표 대본과 예상 질문

작성 틀 ① 발표 대본
이 슬라이드로 [몇 분] 발표할 대본을 써줘.
말투: [예: 회의에서 말하듯 자연스럽게]
장마다 [예: 30초 분량], 다음 장으로 넘어가는 연결 문장도 넣어줘.

작성 틀 ② 예상 질문
[듣는 사람 — 예: 비용에 민감한 임원]이 이 발표를 듣고 할 만한 날카로운 질문을 [몇 개] 뽑고,
질문마다 짧은 답변과 근거 자료를 정리해줘. 근거가 없는 답은 [확인 필요]로 표시해줘.


# 04. 최종 과제 발표

주제 : 내 업무 하나 (또는 해오름상사 친환경 용품 기획)
발표 : 1인 3분
구성 : 조사 → 기획안 → 발표자료(5~7장)

발표 후 함께 볼 점
□ 한 장에 메시지 하나  □ 숫자에 근거  □ 마지막 장에 결정 요청  □ AI가 만든 것을 사람이 확인·수정했는가
