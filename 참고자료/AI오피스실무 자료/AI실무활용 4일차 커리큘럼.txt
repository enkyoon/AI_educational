1. 오늘의 수업

수업 난이도

수업방식

핵심목표
 데이터 위치와 하고 싶은 계산을 말로 설명해서 결과를 얻고, AI가 말한 숫자는 시트에서 직접 확인하기

오늘 쓰는 도구
 Gemini, Google 시트 (Google AI Pro 계정이면 시트 오른쪽의 Gemini 패널에서 바로 요청할 수 있어요)

해오름상사 상황
 서울·부산·대구 세 지점에서 친환경 사무용품(다회용 컵, 재생 용지, 친환경 세제)을 팔고 있습니다. 팀장님 요청 — "지점별로 얼마나 팔렸는지 한눈에 볼 수 있게 대시보드로 만들어 주세요."

2. 오늘의 작업 순서
 결정할 질문에서 대시보드까지
 팀장 요청 해석 → 내 분석 계획 → 데이터 생성·구조 확인 → 진단·정리 → 함수·피벗 → 검산 → 차트 → 대시보드·보고.
계산 전에 질문과 제외 기준을 정하고, 결과를 본 뒤 지원 후보를 판단합니다.

AI에게 요청하는 곳 두 가지

① 시트 오른쪽 Gemini 패널

② Gemini 앱 (gemini.google.com)

메뉴 이름과 위치는 업데이트에 따라 다를 수 있습니다. 패널이 안 보이면 ②로 해도 같은 결과를 얻을 수 있어요.

4. 먼저 분석 계획 세우기 — 무엇을 결정할 것인가
 팀장 요청
 다음 분기에 어느 지점의 어떤 품목을 먼저 지원할지 정하고 싶어요. 매출이 큰 곳만 고르지 말고 최근 변화도 함께 봐 주세요.

 결정할 것:
비교할 지점·품목·기간:
성장률과 매출 규모를 함께 보는 기준:
제외할 기록과 보고할 제외 건수:
판매 기록만으로 알 수 없는 것:
필요한 요약표와 차트:

 분석 계획은 지금 먼저 적어 두세요. 아래 검토 요청은 다음 단계에서 데이터 파일을 만들고 열 구조를 확인한 뒤, 계획 메모와 파일을 함께 전달할 때 사용합니다.
 위 계획이 팀장의 지원 대상 결정에 도움이 되는지 검토해줘.
첨부 자료의 열로 계산 가능한 지표와 추가 자료가 필요한 지표를 나눠줘.
매출 증가가 이익 증가나 수요 증가와 같다고 단정하지 마.
작은 기준값 때문에 성장률이 과장되는 경우와 빈칸 제외 영향을 짚어줘.
질문 순서를 3~4개로 정리하되 아직 분석은 실행하지 마.

5. 분석할 수 있는 판매 데이터 준비하기
 세 지점의 다음 분기 판매 방향을 결정할 자료를 만듭니다. 1,500건은 실제 회사 전체 매출을 재현한 것이 아니라 수업용 판매 기록입니다. 건수보다 비교할 차이와 정확한 열 구성이 중요합니다.
 해오름상사 친환경 사무용품 판매 분석용 가상 데이터를 만들어줘.
■ 파일
하나의 .xlsx 파일, 판매기록·제품목록 두 시트. 실제 사람·회사 이름은 쓰지 마.
판매기록: A 주문번호, B 날짜, C 지점, D 품목, E 수량, F 단가, G 금액.
제품목록: A 품목, B 분류, C 판매단가, D 개당 원가. 원가는 양수이며 단가보다 낮게.
■ 기록
2026년 1~6월, 서울점·부산점·대구점. 품목은 다회용 컵·재생 용지·친환경 세제 등 6가지.
한 줄은 주문 한 건의 품목 하나. 정상 기록 1,500건을 먼저 만들고, 중복 8줄은 별도 추가해줘.
모든 월·지점·품목에 기록이 있고, 지점별 인기 품목과 월별 증가·감소가 다르게 드러나도록 해줘. 같은 비율을 단순 반복하지 마.
날짜는 계산 가능한 날짜 형식, 수량·단가·금액은 숫자. 금액은 수량×단가.
■ 정리 연습
지점 표기 흔들림 12칸, 수량 빈칸 6칸(해당 금액도 비우기)을 섞어줘. 빈칸과 표기 흔들림은 중복 대상 줄과 겹치지 않게 해줘.
주문번호와 날짜는 비우지 말고 제품목록은 정상으로 유지해줘. 함수 오류는 넣지 마.
문제 위치는 아직 알려주지 말고 건수·시트·제품명·금액 계산만 점검한 뒤 다운로드 링크를 줘.

 Google 드라이브에 파일을 올려 Google 시트로 열고, 파일 → Google 스프레드시트로 저장으로 변환합니다. 파일 이름은 04_판매분석_이름. 제목이 1행, 기록이 2행부터인지와 두 탭을 확인합니다. 파일 생성이 안 되면 같은 열 구성의 CSV 두 파일을 요청해 각각 가져오세요. 1,500줄을 채팅에서 복사하면 누락되기 쉬우므로 파일을 사용합니다.

6. 문제 진단 → 정리 기준 선택 → 원본과 비교
 판매기록 탭을 복제해 원본으로 남깁니다. 원본은 보관용이며 이후 계산 범위에 포함하지 않습니다.
 판매기록의 지점 표기·빈칸·완전히 같은 중복·수량×단가와 다른 금액을 찾아줘.
아직 고치지 말고 문제 종류 / 행 번호 / 해당 값 / 가능한 정리 방법 / 확인할 위험을 표로 보여줘.
주문번호가 같아도 품목이 다르면 정상 주문일 수 있으니 주문번호만으로 중복 삭제하지 마.
제품목록과 대조해 이름·단가가 다른 기록도 알려줘.

 지점은 서울점·부산점·대구점으로 통일하고, 모든 열이 같은 중복만 하나 남겨줘.
수량·금액 빈칸은 평균값으로 채우지 말고 '확인 필요'로 표시해줘.
품목이나 단가의 불일치는 마음대로 바꾸지 말고 별도 확인 목록으로 남겨줘.
정리 결과를 정리본에 저장하고, 수정 건수·남은 기록 수·제외가 필요한 행을 알려줘.
원본과 제품목록은 유지해줘. 실제로 시트를 바꿀 수 없으면 적용 방법과 확인용 목록을 줘.

 정리본의 실제 마지막 행을 확인하고 이후 함수에 사용합니다. 확인 필요인 기록은 분석에서 제외하되 제외 건수와 이유를 별도로 보고하세요.

7. 함수 요청과 각자 응용하기
 정리본의 실제 열과 마지막 행을 확인하고 요청합니다. 함수 이름보다 계산할 조건·범위·결과 위치가 중요합니다.
 Google 시트 정리본은 A 주문번호, B 날짜, C 지점, D 품목, E 수량, F 단가, G 금액이야.
제목은 1행, 데이터는 2행부터 [실제 마지막 행]까지야.
요약 탭 A2의 지점 이름에 맞는 금액 합계를 B2에 계산하고 아래로 채우고 싶어.
금액이 확인 필요인 줄은 제외하고, 원본 탭을 함께 더하지 마.
붙여 넣을 함수, 아래로 채울 때 고정할 범위, 계산 뜻과 검산 방법을 알려줘.

 각자 해보기
 제품별 판매 수량 합계와 판매 기록 건수를 각각 구하고 차이 설명하기.
수량×단가와 금액을 대조하는 검사 열 만들기.
제품목록에서 품목별 원가를 H열에 찾아오기. 확인 필요·없는 품목은 원가도 확인 필요로 표시하기.
조회한 원가로 매출총이익을 계산할 경우 운영비를 뺀 순이익과 다르다는 점 표시하기.

 오류가 실제로 생겼을 때만 함수·오류 표시·열 구조·원하는 결과를 함께 보여 주고 원인을 요청하세요. 정상 계산이면 오류를 일부러 만들 필요는 없습니다.

8. 계획에 맞는 피벗 테이블 두 개 만들기
 정리본의 확인 필요 기록을 제외한 분석용 데이터를 별도 탭에 준비합니다. 삽입 → 피벗 테이블에서 새 시트를 고릅니다. Gemini 패널에서 요청하면 적용 전 미리보기의 범위와 설정을 확인하세요.
 분석용 데이터로 피벗 두 개를 각각 새 탭에 만들어줘.
지점월별: 행 지점, 열 날짜를 월로 묶기, 값 금액 합계.
품목별: 행 품목, 열 지점, 값 금액 합계.
숫자가 텍스트라 개수로 집계되지 않았는지 확인하고 합계로 설정해줘.
원본·정리본·제품목록을 한꺼번에 범위로 잡지 마. 사용한 데이터 범위와 총합을 알려줘.

 메뉴로 만들 때도 행·열·값을 같은 기준으로 지정합니다. 지점월별 합계 하나를 SUMIF 결과와 비교하고, 품목별 피벗의 총합이 같은지도 확인합니다.

9. 실습: 분석 요청하고 검산하기

Gemini 패널에서 바로 요청하거나, Gemini 앱에 시트를 첨부합니다.

정리본을 기준으로 다음을 계산해줘.
1. 지점별 월 매출과 1월 대비 6월 증감액·증감률
2. 지점·품목별 매출 규모와 최근 3개월 변화
3. 지원 후보 2개와 각 후보의 숫자 근거, 추가 확인할 사항
확인 필요인 기록은 제외하고 제외 건수를 알려줘. 기준 매출이 0이면 증감률을 계산 불가로 표시해줘.
기록에서 계산한 사실과 원인에 대한 가설을 나눠줘. 가장 중요한 숫자 두 개의 계산 범위도 보여줘.

이 시트의 데이터를 분석해줘.
알고 싶은 것:
1. 지점별 월 매출 변화
2. 가장 많이 늘거나 줄어든 지점과 그 크기(3월 대비 8월, %)
3. 품목별 매출 순위
결과는 질문별 한 줄 답 + 근거 숫자로 정리하고,
데이터에 없는 원인은 "추측"이라고 표시해줘.

11. 분석 질문에 맞는 차트 두 개 만들기
 지점월별 피벗으로 월별 금액 추이 꺾은선, 품목별 피벗으로 품목 매출 비교 막대를 만듭니다. 차트가 각각 어떤 질문에 답하는지 먼저 적으세요.
 지점월별 피벗으로 지점별 월 매출 변화 차트를 만들어줘.
품목별 피벗으로 품목 매출 비교 차트를 따로 만들어줘.
각 차트의 데이터 범위·기간·단위를 표시하고, 제목은 데이터로 확인된 변화만 담아줘.
금액과 수량을 같은 축에 섞지 마. 품목별 차트에 지점월별 범위를 재사용하지 마.
차트가 질문에 맞지 않거나 데이터가 빠진 경우 먼저 알려줘.

 패널에서 적용이 안 되면 해당 피벗 범위를 선택 → 삽입 → 차트에서 종류를 지정합니다. 총합·합계 행이 개별 지점이나 품목으로 중복 표시되지 않는지 확인합니다.

12. 대시보드란?

대시보드

13. 질문에 답하는 대시보드 완성하기
 새 대시보드 탭에 전체 매출·우선 검토 지점·주력 품목, 지점월별 꺾은선과 품목별 막대 차트를 배치합니다. 핵심 숫자는 정리본이 아니라 분석용 데이터로 계산하세요.
 팀장이 다음 분기 지원 후보를 비교할 대시보드를 만들려고 해.
상단은 전체 매출·집계 기간·분석 제외 건수, 중간은 지점 월별 차트, 하단은 품목별 비교와 제안으로 구성해줘.
각 숫자의 계산 범위와 붙여 넣을 칸을 알려줘. 차트는 지점월별·품목별 피벗에서 가져와줘.
매출 규모와 변화율을 서로 다른 지표로 표시하고, 데이터에서 알 수 없는 원인은 따로 확인 필요로 적어줘.

 차트를 선택해 복사한 뒤 대시보드에 붙여넣고 원래 피벗은 유지합니다. 필터가 필요하면 지점 선택 드롭다운과 그 선택값을 참조하는 요약표를 만들어 차트에 연결하세요. 슬라이서는 적용 대상과 데이터 범위에 제약이 있으므로 다른 탭의 모든 차트·수식이 함께 바뀐다고 가정하지 않습니다. 지점을 바꿨을 때 각 숫자와 차트가 어떤 범위를 보여 주는지 직접 확인하세요.

14. 숫자를 행동 제안과 확인 과제로 바꾸기
 지금 분석으로 팀장에게 보고할 메모를 써줘.
첫 세 줄에 지원 후보·근거 숫자·결정 전에 확인할 것을 요약해줘.
아래 표는 발견 / 실제 수치와 비교 기준 / 해 볼 행동 / 아직 모르는 것 / 확인할 자료로.
목표나 지원 예산을 임의로 정하지 마. 원인은 가설이라고 표시해줘.
확인 필요 기록을 몇 건 제외했는지도 남겨줘.

15. 막힌 지점 확인하기 · 더 해 보기
 실제 문제가 생겼을 때
 합계가 다름: 원본·정리본·분석용 데이터 중 어느 범위를 썼는지와 집계 제외 조건 확인.
피벗이 개수를 셈: 값의 집계 방식이 합계인지, 금액이 숫자인지 확인.
파일·패널 적용 불가: Google 시트로 변환했는지 확인. Gemini 채팅으로 함수를 받아 직접 넣을 수도 있음.
필터 후 카드가 그대로: 카드가 전체 합계인지 선택 지점 기준인지 표시와 수식 확인.

 더 해 보기: 지점별 원가를 반영한 매출총이익을 비교하고, 원가가 없는 품목은 제외 건수와 함께 보고하세요. 원가만 뺀 결과를 순이익이라고 부르지 않습니다.

16. 프롬프트 역설계 — 자료와 판단까지 설계하기
 원하는 결과의 일부와 원자료를 보고 요청을 거꾸로 설계합니다. 예시와 문장을 똑같이 만드는 것이 아니라, 근거·조건·판단 한계를 빠뜨리지 않는 것이 목표입니다.
 역설계 1 · 중복과 정상 주문을 구분하기
 받은 자료 · 수업용 가상 자료
 열: 주문번호·날짜·지점·품목·수량·단가·금액. O01은 컵 2개 9,000원과 용지 1개 6,000원 두 줄. 컵 줄이 완전히 같은 값으로 한 번 더 있음. O02는 수량·금액 빈칸.

 만들어야 할 결과의 일부 · 나머지는 직접 설계하기
 정상 O01의 두 품목은 남고 완전 중복 컵 줄만 제거. O02는 확인 필요로 남기고 집계 제외. 확정 금액 합계는 15,000원.

 결과를 그대로 받아쓰지 말고, 자료에서 쓸 것과 제외할 것·부족한 정보·확인 방법을 먼저 판단하세요. 필요한 요청을 직접 쓰고 실행한 뒤 한 번 이상 고칩니다.

 위 기록의 정리 문제를 먼저 진단하고 아직 수정하지 마.
주문번호가 같아도 품목이 다르면 정상 기록일 수 있어.
모든 열이 같은 완전 중복만 제거 대상으로 분류해줘.
수량·금액 빈칸은 추정하지 말고 확인 필요로 남겨줘.
내가 기준을 확인한 뒤 정리본과 수정 내역을 보여줘.
정상·삭제·집계 제외 기록 수와 확정 금액 합계를 각각 검산해줘.
