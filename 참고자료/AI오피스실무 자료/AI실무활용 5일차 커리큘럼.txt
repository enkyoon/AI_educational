4.먼저 분석 계획 세우기 — 무엇을 결정할 것인가

팀장 요청

다음 분기에 어느 지점의 어떤 품목을 먼저 지원할지 정하고 싶어요. 매출이 큰 곳만 고르지 말고 최근 변화도 함께 봐 주세요.

결정할 것:
비교할 지점·품목·기간:
성장률과 매출 규모를 함께 보는 기준:
제외할 기록과 보고할 제외 건수:
판매 기록만으로 알 수 없는 것:
필요한 요약표와 차트:

위 칸은 지금 직접 채워 둡니다. 아래 점검 요청은 5번에서 데이터 파일을 준비한 뒤, 내가 쓴 계획과 파일을 함께 Gemini에 보낼 때 씁니다.

위 계획이 팀장의 지원 대상 결정에 도움이 되는지 검토해줘.
첨부 자료의 열로 계산 가능한 지표와 추가 자료가 필요한 지표를 나눠줘.
매출 증가가 이익 증가나 수요 증가와 같다고 단정하지 마.
처음 매출이 아주 작아서 증가율이 크게 부풀려 보이는 경우와, 빈칸인 기록을 빼면 결과가 어떻게 달라지는지도 짚어줘.
분석할 질문을 3~4개로 순서대로 정리해 주고, 아직 계산은 하지 마.

5.분석할 판매 데이터 준비하기

분석할 판매 기록을 준비합니다. 아래 두 방법 중 하나를 고르세요. 정리 연습을 하도록 실수가 조금 섞인 수업용 가상 자료입니다.

아래 요청으로 Gemini에게 엑셀 파일을 만들게 합니다. AI가 조건을 다 지키지 못할 수도 있고, 사람마다 숫자가 달라집니다.

B · 준비 파일로 시작하기

어렵거나 A로 만든 파일이 잘 안 나왔다면, 강사가 준비한 파일을 내려받아 씁니다. 모두 같은 데이터라 결과를 서로 비교하기 쉽습니다.

A · 직접 만들어 보기 (선택)

Gemini 새 채팅을 엽니다.

아래 요청을 붙여 넣어 보냅니다. 파일을 만드는 데 시간이 조금 걸립니다.

답에 나온 다운로드 링크를 눌러 .xlsx 파일을 내려받습니다.

수업용으로 사용할 엑셀 자료를 생성할 거야.
해오름상사 친환경 사무용품 판매 분석용 가상 데이터를 만들어줘.

■ 파일
하나의 .xlsx 파일, 판매기록·제품목록 두 시트. 실제 사람·회사 이름은 쓰지 마.
판매기록: A 주문번호, B 날짜, C 지점, D 품목, E 수량, F 단가, G 금액.
제품목록: A 품목, B 분류, C 판매단가, D 개당 원가. 원가는 양수이며 단가보다 낮게.

■ 기록
2026년 1~3월, 서울점·부산점·대구점.
품목은 재생 용지·재생 노트·재활용 볼펜·친환경 형광펜·다회용 컵·친환경 세제·친환경 테이프·재생 종이 파일 총 8가지.
한 줄은 주문 한 건의 품목 하나. 정상 기록 3,000건을 먼저 만들고, 중복 8줄은 별도 추가해줘.
모든 월·지점·품목에 기록이 있고, 지점별 인기 품목과 월별 매출 증가·감소가 다르게 드러나도록 해줘.
실제 기업의 판매 데이터처럼 평일 주문이 많고, 소량 구매와 대량 구매가 혼합되도록 구성해줘. 날짜별 주문량과 품목별 판매량도 자연스럽게 차이가 나도록 해줘.
같은 비율이나 규칙을 단순 반복하지 마.
날짜는 계산 가능한 날짜 형식, 수량·단가·금액은 숫자. 정상 기록의 금액은 수량×단가.

■ 정리 연습
실제 회사에서 발생할 법한 엑셀 오류를 정상 기록 3,000건 중 약 20~30곳에 자연스럽게 포함해줘.
예를 들어 표기 오류, 수식 오류, 빈칸, 단가 오류, 숫자 형식 오류 등이 있어.
제품목록은 정확한 기준정보로 유지하고, 오류는 판매기록에만 넣어줘.
너무 많은 오류를 넣지 말고, 학생들이 필터·함수·중복 제거 등을 통해 발견하고 수정할 수 있도록 구성해줘.

■ 최종 확인
문제 위치는 아직 알려주지 말고, 건수·시트·제품명·금액 계산만 점검한 뒤 다운로드 링크를 줘.

파일이 안 만들어지거나, 내려받은 파일의 기록 수가 너무 적거나 품목이 빠져 있으면 고치려고 애쓰지 말고 B · 준비 파일로 넘어가세요.

B · 준비 파일로 시작하기

 05_판매분석_준비자료.xlsx 내려받기

내려받은 파일을 Google 시트로 열기 (A · B 공통)

새 탭에서 Google 드라이브(drive.google.com)를 엽니다.

올라간 파일을 두 번 눌러 엽니다.

엑셀 파일 그대로는 시트 안 Gemini 패널이 잘 동작하지 않을 수 있어서 Google 스프레드시트로 바꿔서 씁니다.

6.문제 진단 → 정리 기준 선택 → 원본과 비교

고치기 전에 원래 자료를 따로 남겨 둡니다.

맨 아래 판매기록 탭을 마우스 오른쪽 버튼으로 누르고 복제를 고릅니다.

새로 생긴 "판매기록 사본" 탭 이름을 두 번 눌러 원본으로 바꿉니다. 이 탭은 보관용이라 손대지 않습니다.

판매기록 탭 이름은 정리본으로 바꿉니다. 오늘 정리와 계산은 모두 이 탭에서 합니다.

시트 오른쪽 위 Gemini 아이콘을 눌러 패널을 열고 아래 요청을 보냅니다. (패널이 없으면 Gemini 앱에 파일을 첨부해 보냅니다.)

정리본 탭에서 정리가 필요한 기록을 찾아줘.
볼 것: 지점·품목 이름이 다르게 적힌 칸 / 빈칸 / 모든 칸이 똑같은 중복 줄 / 숫자가 글자로 들어간 칸 / 수식 오류 / 금액이 수량×단가와 다른 줄.
아직 고치지 말고 표로 보여줘: 문제 종류 / 행 번호 / 지금 값 / 고치는 방법 / 고칠 때 조심할 점.
주문번호가 같아도 품목이 다르면 정상 주문일 수 있으니 주문번호만으로 중복 삭제하지 마.
제품목록과 비교해 품목 이름이나 단가가 다른 기록도 알려줘.

지점은 서울점·부산점·대구점, 품목은 제품목록의 이름으로 통일해줘.
모든 칸이 똑같은 중복 줄은 하나만 남겨줘.
글자로 들어간 숫자는 숫자로 바꾸고, 단가가 제품목록과 다르면 제품목록 단가로 고친 뒤 금액도 다시 계산해줘.
빈칸은 평균값으로 채우지 말고 '확인 필요'로 표시해줘.
정리본에서만 고치고 원본·제품목록은 그대로 둬. 고친 건수와 남은 기록 수, '확인 필요' 줄 수를 알려줘.
시트를 직접 바꿀 수 없으면 내가 따라 할 방법을 순서대로 알려줘.

정리가 끝나면 정리본의 마지막 기록이 몇 행인지 확인해 적어 둡니다(다음 함수 요청에 씁니다). '확인 필요' 줄은 분석에서 빼고, 몇 줄을 왜 뺐는지 메모해 둡니다(보고할 때 씁니다).

7.조건별 집계표 만들고 수식 확인하기

함수 이름을 몰라도 됩니다. 어느 칸에서, 무엇을, 어떤 조건으로 계산해 어디에 넣을지 말하면 됩니다. 먼저 결과를 넣을 요약 탭을 만듭니다.

맨 아래 왼쪽 +(시트 추가)를 누르고, 새 탭 이름을 요약으로 바꿉니다.

A1에 지점, B1에 매출 합계를 씁니다.

A2 · A3 · A4에 서울점 · 부산점 · 대구점을 씁니다.

아래 요청의 [ ]에 정리본의 마지막 행 번호를 넣어 보냅니다.

Google 시트 정리본은 A 주문번호, B 날짜, C 지점, D 품목, E 수량, F 단가, G 금액이야.
제목은 1행, 데이터는 2행부터 [실제 마지막 행]까지야.
요약 탭 B2에 A2 지점의 금액 합계를 구하고, B4까지 아래로 채우고 싶어.
금액이 '확인 필요'인 줄은 빼고, 원본 탭은 더하지 마.
결과 숫자만 넣지 말고 실제 함수로 넣어서, 정리본이 바뀌면 결과도 다시 계산되게 해줘. 네가 시트에 직접 넣을 수 없으면 붙여 넣을 함수를 알려줘.
아래로 채워도 범위가 밀리지 않게 하는 방법, 이 함수가 무슨 뜻인지, 맞는지 확인하는 방법도 알려줘.

AI가 말한 숫자와 시트의 수식은 다릅니다

답에 적힌 숫자는 그 순간의 계산 결과입니다. 시트에 들어간 수식은 자료가 바뀌면 결과도 다시 계산됩니다. 함수를 몰라도 어느 쪽인지 확인할 수 있습니다.

받은 함수를 요약 탭 B2에 붙여 넣고 B4까지 아래로 채웁니다. 패널이 직접 넣었다면 다음으로 넘어갑니다.

B2를 누르고 위쪽 수식 입력줄을 봅니다. =로 시작하면 수식, 숫자만 있으면 결과 값입니다.

숫자만 있으면 "결과 숫자 말고 실제 함수로 다시 넣어줘"라고 보냅니다.

정리본에서 서울점 줄의 금액 하나를 다른 숫자로 바꿉니다.

요약 탭 B2가 따라서 바뀌었는지 봅니다.

Ctrl + Z를 눌러 금액을 되돌립니다.

정리본 탭의 [날짜 · 지점 · 금액이 있는 열]로 2026년 1~3월 지점별 월매출 표를 요약 탭 [표를 시작할 칸]부터 만들고 싶어.
행에는 [무엇], 열에는 [무엇], 맨 아래와 맨 오른쪽에는 [무엇]을 넣어줘.

8.확인이 필요한 기록만 따로 찾기

확인할 기록을 사람이 한 줄씩 찾는 대신, 필요한 조건과 남길 열을 설명합니다. 정상·불일치·확인 필요를 나누는 기준도 직접 정합니다.

정리본의 [검사에 쓸 열]을 보고 [불일치 조건]이면 '불일치', [판단할 수 없는 조건]이면 '확인 필요', 나머지는 '정상'으로 표시해줘.
결과는 빈 열 [열 위치]에 실제 수식으로 넣고, 불일치 또는 확인 필요인 기록만 확인목록 탭에 모아줘.
목록에는 [남길 열]과 확인 이유를 적어줘. 원본과 정리본의 값을 임의로 고치지 마.
원본 기록 수, 상태별 건수, 추출한 기록 수를 함께 확인하는 방법도 알려줘.

정리본은 A 주문번호 B 날짜 C 지점 D 품목 E 수량 F 단가 G 금액이야.
H열에 금액 검사 결과를 실제 수식으로 넣어줘. E:G 중 숫자가 아닌 칸이 있으면 '확인 필요', G가 E×F와 다르면 '불일치', 나머지는 '정상'이야.
H가 불일치 또는 확인 필요인 기록만 확인목록 탭에 A:H와 확인 이유를 모아줘. 원본과 정리본의 값은 임의로 고치지 마.
전체 기록 수와 상태별 건수, 추출 건수가 맞는지 확인하는 방법도 알려줘.

Google 시트 수식 참고 — 외우지 않아도 됩니다

마지막 행이 3001행이고 H열에 상태가 있을 때의 예입니다. 실제 범위로 바꾸세요. Google 시트 FILTER의 뒤 인수에는 추가 조건이 들어갑니다.
=IF(COUNT(E2:G2)<3,"확인 필요",IF(G2=E2*F2,"정상","불일치"))
=IFNA(FILTER(정리본!A2:H3001,정리본!H2:H3001<>"정상"),"대상 없음")

정리가 잘 끝나 확인 목록이 비어 있어도 정상입니다. 연습하려고 정리본에 새 오류를 만들 필요는 없습니다.

9.다른 표에서 필요한 정보 연결하기

판매기록에 없는 원가는 제품목록에서 가져옵니다. 어떤 열을 기준으로 연결할지와 값이 없을 때 처리할 방법을 먼저 정합니다.

[판매표 이름]의 [품목 열]과 [기준표 이름]의 [기준 열]을 연결해 [가져올 값]을 빈 열 [위치]에 실제 함수로 넣어줘.
기준표에 같은 품목이 중복되면 임의로 첫 값을 고르지 말고 확인 대상으로 알려줘.
품목이나 원가가 비어 있으면 0원으로 만들지 말고 '확인 필요'로 남겨줘.
원본 단가와 금액은 유지하고, 품목 두세 개를 직접 확인할 방법도 알려줘.

정리본 D열 품목과 제품목록 A열 품목을 연결해 제품목록 D열 개당 원가를 정리본 I열에 실제 함수로 넣어줘.
제품목록의 품목 중복과 원가 빈칸을 먼저 확인해줘. 일치 품목이 없거나 원가가 비어 있으면 '확인 필요'로 남겨줘.
판매단가와 금액은 유지해줘. 제품 두세 개의 원가를 제품목록에서 직접 대조하는 방법을 알려줘.

매출총이익 분석은 이 연결 결과를 활용하는 추가 실습입니다. 원가 미확인 기록은 0원 원가로 계산하지 않습니다.

10.계획에 맞는 피벗 테이블 두 개 만들기

먼저 '확인 필요' 줄을 뺀 분석용 탭을 만듭니다.

정리본 탭을 마우스 오른쪽 버튼으로 누르고 복제를 고릅니다.

새 탭 이름을 분석용으로 바꿉니다.

분석용 탭을 연 채로 Gemini 패널에 "이 탭에서 '확인 필요'가 들어 있는 줄을 모두 지우고, 지운 줄 수를 알려줘."라고 보냅니다.

패널이 직접 지우지 못하면 Ctrl + F로 확인 필요를 찾고, 찾은 줄의 행 번호를 마우스 오른쪽 버튼으로 눌러 행 삭제를 합니다. 더 찾을 것이 없을 때까지 반복합니다.

지운 줄 수를 정리할 때 적은 '확인 필요' 줄 수와 비교합니다.

Gemini 패널에 아래 요청을 보냅니다. 패널이 적용 전 미리보기를 보여 주면, 범위가 분석용 탭인지 확인하고 넣습니다.

분석용 데이터로 피벗 두 개를 각각 새 탭에 만들어줘.

숫자가 텍스트라 개수로 집계되지 않았는지 확인하고 합계로 설정해줘.
원본·정리본·제품목록을 한꺼번에 범위로 잡지 마. 사용한 데이터 범위와 총합을 알려줘.

패널이 안 되면 분석용 탭에서 삽입 → 피벗 테이블 → 새 시트로 직접 만들고, 오른쪽 편집기에서 위와 같은 행 · 열 · 값을 고릅니다. 다 만든 뒤에는 지점월별 피벗의 숫자가 함수로 만든 지점별 월매출 표와 같은지, 두 피벗의 총합이 서로 같은지 확인합니다. 다르면 집계표 계산에 '확인 필요' 줄이 들어갔는지부터 봅니다.

12.프롬프트 역설계 — 자료와 판단까지 설계하기

원하는 결과의 일부와 원자료를 보고 요청을 거꾸로 설계합니다. 예시와 문장을 똑같이 만드는 것이 아니라, 근거·조건·판단 한계를 빠뜨리지 않는 것이 목표입니다. 결과를 그대로 받아쓰지 말고, 자료에서 쓸 것과 제외할 것·부족한 정보·확인 방법을 먼저 판단하세요. 필요한 요청을 직접 쓰고 실행한 뒤 한 번 이상 고칩니다.

역설계 1 · 중복과 정상 주문을 구분하기

받은 자료 · 수업용 가상 자료

열: 주문번호·날짜·지점·품목·수량·단가·금액. O01은 컵 2개 9,000원과 용지 1개 6,000원 두 줄. 컵 줄이 완전히 같은 값으로 한 번 더 있음. O02는 수량·금액 빈칸.

만들어야 할 결과의 일부 · 나머지는 직접 설계하기

정상 O01의 두 품목은 남고 완전 중복 컵 줄만 제거. O02는 확인 필요로 남기고 집계 제외. 확정 금액 합계는 15,000원.

막히면 생각할 지점 보기

주문번호만으로 중복을 지우면 어떤 일이 생기나요?

위 기록의 정리 문제를 먼저 진단하고 아직 수정하지 마.
주문번호가 같아도 품목이 다르면 정상 기록일 수 있어.
모든 열이 같은 완전 중복만 제거 대상으로 분류해줘.
수량·금액 빈칸은 추정하지 말고 확인 필요로 남겨줘.
내가 기준을 확인한 뒤 정리본과 수정 내역을 보여줘.
정상·삭제·집계 제외 기록 수와 확정 금액 합계를 각각 검산해줘.

■ 설계 포인트
중복 삭제 후 두 품목이 남는지, 미확정 금액을 0원 매출로 해석하지 않는지 확인하세요.

역설계 2 · 성장률만으로 지원 대상을 고르지 않기

받은 자료 · 수업용 가상 자료

1월→6월 매출(만 원): 서울 600→900, 부산 20→60, 대구 500→450. 지원 목적은 다음 분기 판매 기회와 운영 문제를 함께 검토하는 것. 원가·광고·재고 자료는 없음.

만들어야 할 결과의 일부 · 나머지는 직접 설계하기

부산 성장률이 가장 높아도 단독 지원 확정으로 결론내리지 않습니다. 증감액·규모·비교 한계와 추가 확인을 함께 봅니다.

막히면 생각할 지점 보기

성장률 200%와 증감액 40만 원을 어떻게 함께 보여줄까요?

위 지점 매출로 다음 분기 지원 후보를 검토해줘.
현재 규모·증감액·증감률을 같은 표로 계산하고 비교 기간과 단위를 표시해줘.
작은 기준 매출의 높은 성장률만으로 순위를 확정하지 마.
후보를 두 곳 제안하되 자료에 따른 이유와 추가 확인할 재고·원가·운영 정보를 나눠줘.
매출만으로 이익·수요·광고 효과를 단정하지 마.
계산식과 직접 검산할 숫자 두 개를 알려줘.

■ 설계 포인트
규모·변화율·절대 변화가 구분됐는지와 원인 단정이 없는지 확인하세요.

역설계 3 · 대시보드의 숫자 불일치 추적

받은 자료 · 수업용 가상 자료

피벗 총합 150만 원, 카드 총합 165만 원. 카드는 원본을, 피벗은 중복 제거 정리본을 사용. 지점 선택 후 차트만 바뀌고 카드는 그대로.

만들어야 할 결과의 일부 · 나머지는 직접 설계하기

원인 진단 → 범위 통일 → 필터 적용 범위 표시 → 같은 지점·기간의 숫자를 재검산하는 순서가 필요합니다.

막히면 생각할 지점 보기

오류라고 단정하기 전에 데이터와 필터 범위 중 무엇을 비교해야 하나요?

대시보드의 두 합계가 다르니 바로 숫자를 덮어쓰지 말고 원인을 진단해줘.
각 카드·피벗·차트의 원본 탭·범위·중복 처리·필터 조건을 대조할 표를 만들어줘.
원본과 정리본의 차이, 필터 적용 대상의 차이를 구분해줘.
분석용 데이터로 범위를 통일하는 수정 순서를 알려줘.
전체 값인 카드에는 전체라고 표시하거나 선택 지점을 참조하는 방식으로 바꿔줘.
같은 지점·기간으로 재검산하는 확인 절차까지 제안해줘.

■ 설계 포인트
보여 주는 범위를 먼저 맞추고 숫자를 고치는지 확인하세요.
