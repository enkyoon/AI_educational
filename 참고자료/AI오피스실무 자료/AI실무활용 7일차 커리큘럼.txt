5.조사계획 첨삭하고 실행

Deep Research는 바로 조사하지 않고 조사계획을 먼저 보여 줍니다. "계획 수정"을 누르고 빼고 더한 뒤 시작합니다.

지금 조사계획을 아래처럼 고쳐줘.
- 추가할 항목: [빠진 것]
- 뺄 항목: [관계없는 것 — 없으면 이 줄 지우기]
- 좁힐 범위: [기간·지역·대상 — 없으면 이 줄 지우기]
고친 부분만 따로 알려주지 말고, 반영한 전체 조사계획을 처음부터 끝까지 다시 보여줘.
바뀐 항목에는 (추가)·(수정) 표시를 붙여줘.

마지막 두 줄이 없으면 추가한 부분만 보여 주고 끝나서 전체를 점검할 수 없습니다. 계획이 마음에 들면 조사 시작.

8.Gemini Notebook이란?

Gemini Notebook

11.실습: 여러 자료를 엮어 묻기

한 자료만 보고는 알 수 없는 것을, 여러 자료를 엮어서 물어봅니다. 좋은 답은 메모에 저장해 모아 두세요.

시장 조사와 우리 판매 실적을 비교해 지원 후보를 검토하려고 해.
외부 자료의 대상·기간·단위가 우리 데이터와 비교 가능한지 먼저 확인해줘.
표: 주장 / 외부 근거와 시점 / 내부 근거와 단위 / 일치·차이 / 판단 한계 / 추가 자료.
시장 전체의 성장과 우리 회사의 성장을 같은 의미로 보지 마.
내부 매출이 늘었다는 이유만으로 시장점유율이 늘었다고 쓰지 마.
문장마다 자료 이름과 확인할 위치를 표시하고, 출처가 없으면 결론에서 제외해줘.

상품 소개서에서 시장 조사 결과와 맞지 않거나 보강해야 할 부분을 찾아줘.
항목마다 어느 자료의 어느 부분인지 알려줘.

지금 자료로 [판단할 것 — 예: 하반기에 어떤 품목을 밀지]를 결정하기에 부족한 정보가 무엇인지,
추가로 찾아볼 검색어와 함께 알려줘.

B. 8월 대구 담당자 메모: 가격 문의는 가끔, 기존 거래 계약 때문에 바로 바꾸기 어렵다는 의견이 많았음. 응답 수 기록 없음.
C. 9월 회사 내부 초안: 컵 로고 인쇄 최소 50개라고 적음. 작성자는 최신 여부 확인 전이라고 표시.
D. 승인 제품 카드: 일반 최소 주문 50개, 로고 인쇄 최소 100개. 인쇄비 별도 견적.

위 A~D를 비교해줘.
서로 모순인 것, 조사 대상·시점이 달라 직접 비교할 수 없는 것, 최종 결정 권한이 있는 부서의 최신 자료로 확인해야 하는 것을 구분해줘.
다수 의견이라는 표현을 쓸 수 있는지 표본 정보를 점검해줘.
로고 인쇄 최소 수량은 어느 문서를 기준으로 쓸지 이유와 함께 제안하되 승인 상태를 확인할 질문도 남겨줘.
표: 쟁점 / 관련 자료 / 지금 쓸 수 있는 표현 / 추가 확인.
자료 속 의견과 실제 확인 사실을 섞지 마.

답의 출처 번호를 눌러 원문을 확인합니다. 링크가 붙어 있다는 것과 주장을 실제로 뒷받침한다는 것은 다릅니다. 같은 원문을 인용한 여러 기사를 독립된 여러 근거로 세지 마세요.

14.자료의 목적에 맞는 결과물 만들기

여러 결과물을 모두 만드는 것보다 전달 목적에 맞는 것을 고르고, 설정을 바꿔 결과를 비교해 봅니다. 먼저 자료에서 중요한 사실과 확인할 내용을 정리한 뒤 생성합니다.

목적 | 고를 결과물 | 확인할 것 |

내용을 빠르게 설명 | AI 오디오·동영상 개요 | 원문과 다른 설명이 생기지 않았는가 |

흐름과 관계 파악 | 마인드맵 | 서로 다른 사실을 잘못 연결하지 않았는가 |

보고할 자료 준비 | 보고서·슬라이드 자료 | 대상·단위·미정 정보가 보존됐는가 |

한 화면에 정리 | 인포그래픽·데이터 표 | 숫자·출처·범위를 원문과 비교했는가 |

1.스튜디오에서 만들 결과물을 고릅니다.

2.맞춤설정 버튼이 있으면 엽니다.

3.언어와 사용할 소스를 선택합니다.

4.읽을 사람·목적·강조할 내용·넣지 않을 내용을 적습니다.

5.생성을 시작합니다.

6.완성한 결과물을 스튜디오 아래 목록에서 엽니다.

7.중요한 숫자와 주장 두 곳을 소스에서 확인합니다.

15.자료가 많아지면 라벨로 묶기

고객 의견·내부 실적·외부 조사처럼 성격이 다른 자료를 묶어 찾습니다. 라벨은 자료 정리를 돕는 기능이며, 질문에 실제로 선택된 소스는 별도로 확인합니다.

1.출처 목록 위의 라벨 아이콘을 누릅니다.

2.새 라벨 추가를 고릅니다.

3.자료 성격을 알 수 있는 이름을 적습니다.

4.라벨에 넣을 자료를 고릅니다.

5.재구성 메뉴에서 전체 소스와 라벨 없는 소스를 확인합니다.

 크게 보기

 크게 보기

주제별 자동 라벨 기능이 보이면 결과를 확인한 뒤 사용합니다. 자동으로 묶인 자료가 질문의 범위와 맞는지는 직접 판단합니다.

16.프롬프트 역설계 — 자료와 판단까지 설계하기

원하는 결과의 일부와 원자료를 보고 요청을 거꾸로 설계합니다. 예시와 문장을 똑같이 만드는 것이 아니라, 근거·조건·판단 한계를 빠뜨리지 않는 것이 목표입니다. 결과를 그대로 받아쓰지 말고, 자료에서 쓸 것과 제외할 것·부족한 정보·확인 방법을 먼저 판단하세요. 필요한 요청을 직접 쓰고 실행한 뒤 한 번 이상 고칩니다.

역설계 1 · 대상이 다른 시장 통계 구별

받은 자료 · 수업용 가상 자료

자료 A: 국내 생활용품 전체 온라인 매출 증가. 자료 B: 기업 구매 담당 15명 인터뷰. 자료 C: 해외 컵 시장 전망. 우리 과제: 국내 기업용 다회용 컵 판매 방향.

만들어야 할 결과의 일부 · 나머지는 직접 설계하기

A·C를 국내 기업용 컵 시장 성장률로 쓰지 않습니다. B는 구매자 의견의 단서지만 모집단 대표 통계로 일반화하지 않습니다.

막히면 생각할 지점 보기

자료가 관련 있다는 것과 직접 근거라는 것은 어떻게 다른가요?

위 자료를 국내 기업용 다회용 컵 판매 방향 검토에 쓸 수 있는지 평가해줘.
표: 자료 / 지역·대상·기간 / 직접 근거·보조 맥락·사용 보류 / 이유.
전체 생활용품 수치를 기업용 컵 성장률로 대신 쓰지 마.
소수 인터뷰를 전체 기업의 비율로 바꾸지 마.
지금 쓸 수 있는 신중한 문장과 추가 조사할 검색 질문을 제안해줘.
없는 시장 규모를 계산하지 말고 확인 불가로 남겨줘.

■ 설계 포인트
대상·지역·표본의 차이를 명시하고 관련 자료를 과도하게 일반화하지 않는지 확인하세요.

역설계 2 · 자료가 다를 때 하나를 임의로 고르지 않기

받은 자료 · 수업용 가상 자료

6월 설문 15곳: 가격 4, 세척 부담 4, 기타 7. 8월 대구 메모: 기존 계약 때문에 전환 어려움, 대상 수 미기록. 9월 영업 초안: “모든 고객은 가격 때문에 망설임”.

만들어야 할 결과의 일부 · 나머지는 직접 설계하기

가격을 유일한 원인으로 쓰지 않고 표본·시점·지점 차이를 설명합니다. 기존 계약은 대구 담당자의 관찰로 표시합니다.

막히면 생각할 지점 보기

무엇이 직접 모순이고 무엇이 조사 범위 차이인지 분리하세요.

등록한 세 자료의 구매 걸림돌 주장을 비교해줘.
원문 근거·표본·시점·지점 차이를 표로 정리해줘.
영업 초안의 모든 고객이라는 표현이 근거를 넘는지 판단해줘.
설문 개수를 정확히 유지하고 가격·세척을 동률로 보여줘.
대구 메모는 담당자 관찰로 표시하고 전체 고객 결론으로 확대하지 마.
결론은 지금 말할 수 있는 범위와 추가 확인 질문으로 끝내줘.

■ 설계 포인트
출처 표시뿐 아니라 출처가 주장 범위를 뒷받침하는지 확인하세요.

역설계 3 · 내부 실적과 외부 전망을 연결하기

받은 자료 · 수업용 가상 자료

우리 서울점 매출 증가. 외부 전망은 해외 개인 소비자 시장 성장. 원가·거래처 수·시장 전체 매출 없음. 팀장은 “우리 점유율과 수익성이 오른 거죠?”라고 질문.

만들어야 할 결과의 일부 · 나머지는 직접 설계하기

점유율·수익성은 판단 불가. 내부 매출 증가 사실은 유지하고 각 판단에 필요한 추가 자료를 구분합니다.

막히면 생각할 지점 보기

서로 다른 자료를 붙인다고 빠진 지표가 생기는 것은 아닙니다.

팀장의 질문에 답하는 검토 메모를 등록 자료만으로 써줘.
확인된 사실 / 자료로 판단 불가 / 판단에 필요한 자료로 나눠줘.
우리 매출과 해외 소비자 시장 전망을 직접 비교해 점유율을 계산하지 마.
점유율에는 동일 시장·기간의 전체 매출, 수익성에는 원가·비용이 필요함을 설명해줘.
현재 확인 가능한 변화만 근거 위치와 함께 적어줘.
자료가 더 생기면 무엇부터 다시 계산할지 순서를 제안해줘.

■ 설계 포인트
모르는 지표를 정직하게 남기면서 다음 확인 행동이 구체적인지 확인하세요.
