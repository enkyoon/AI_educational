실행할 기획안 만들기 · 나만의 선택 과제

실행 방법을 고르고, 서로 다른 세 상황 중 하나를 선택해 혼자 끝까지 해 보기

1.오늘의 수업

오늘 만들 것같이 만든 기획 1쪽과 내가 고른 과제의 분석·실행안·슬라이드

도구 — Gemini Canvas, Google 문서·시트·슬라이드

먼저 짧은 기획 연습을 함께 합니다. 이어서 내가 고른 상황을 스스로 해결합니다. 강사는 막히는 부분을 돕습니다.

필요한 자료는 이 페이지에서 제공합니다. 이전 수업의 결과물이 없어도 시작할 수 있습니다.

2.오늘의 작업 순서

1.자료에서 문제와 실행 방법 고르기

2.기획 1쪽 작성·수정

3.과제 선택

4.내 요청으로 분석·실행안 작성

5.중간 변경 반영·슬라이드 구성

6.저장하고 완료 확인

3.자료에서 실행할 기획안으로 바꾸기

앞에서 배운 분석·문서·조사를 바탕으로 다음에 할 일을 정합니다. 기획안은 왜 필요한지, 무엇을 할지, 어떻게 실행할지와 확인할 비용·성과를 정리한 문서입니다.

같이 해 볼 상황거래처가 재생 용지를 매번 주문하는 일이 번거롭다고 합니다. 팀장은 큰 투자 전에 작은 개선을 시험하려고 합니다. 판매 수량과 고객 의견은 참고할 수 있지만, 배송비와 추가 업무시간은 아직 모릅니다.

기획 연습 자료 · 수업용 가상 자료

거래처 의견: 매달 비슷한 양을 쓰는데 다시 주문하는 것이 번거롭다. 샘플을 먼저 확인하고 싶은 고객도 있다.
실행 조건: 기존 직원 2명, 3개월 시범, 추가 채용 제외.
비용: 안내 인쇄 30,000원 견적 확인. 배송비·추가 작업시간·신규 도구 비용은 미정.
현재 재주문율과 주문 처리시간 기준값은 미측정. 예산은 승인 전.

1.확인할 질문을 정하고 해결할 문제 하나를 고릅니다.

2.실행 방법 두 가지를 비교합니다.

3.내가 고른 방법과 선택 이유를 적습니다.

4.일정·담당·확정 비용·미정 비용·성과 확인 방법을 정리합니다.

5.Canvas에서 기획 1쪽으로 작성하고 필요한 부분만 고칩니다.

나는 [담당 역할]이야. 위 자료로 [해결할 문제]에 대한 작은 시범 운영을 제안하려고 해.
아직 본문을 쓰지 말고 확인할 질문을 정리하고, [비교할 방법 두 가지]를 [판단 기준]으로 비교해줘.
내가 하나를 고르면 준비·실행·확인 단계의 담당과 일정, 확정 비용과 미정 비용, 성과를 확인할 방법을 정리해줘.
목표와 현재 실적을 구분하고, 자료에 없는 비용·효과는 만들지 마.
마지막에 내가 고른 안을 [읽을 사람]이 검토할 기획 1쪽으로 작성해줘.

나는 총무·기획 담당자야. 위 자료로 거래처의 재생 용지 반복 주문을 간편하게 할 시범 운영을 제안하려고 해.
아직 본문을 쓰지 말고 확인할 질문을 정리하고, 정기 배송과 재주문 안내를 고객 편의·기존 2명의 운영 부담·비용 확인 가능성으로 비교해줘.
내가 하나를 고르면 준비·실행·확인 단계의 담당과 일정, 확정 비용과 미정 비용, 성과 확인 방법을 정리해줘.
현재 재주문율이 없으니 임의의 개선율을 과거 실적처럼 쓰지 마. 미정 비용은 0원으로 계산하지 마.
마지막에 팀장이 시범 준비 여부를 결정할 기획 1쪽을 작성해줘.

AI의 추천을 읽고 직접 선택합니다. 검토 의견도 모두 따를 필요는 없습니다. 실행 조건에 맞지 않거나 근거가 없는 부분을 골라 고칩니다.

4.내가 해 볼 과제 고르기

이번에는 배운 방법으로 혼자 시작하고 끝내 봅니다. 평가·채점·발표·제출은 없습니다. 막히면 도움말을 펼치거나 강사에게 도움을 요청하세요. 마음이 가는 상황 하나를 고르면 됩니다.

과제 1상품 판매 늘리기거래처 의견과 지점별 실적을 보고 작게 시험할 판매 방안을 정합니다.과제 2카페 운영 개선하기시간대별 주문과 고객 의견을 보고 인력을 늘리지 않고 운영을 개선합니다.과제 3사내 반복 문의 줄이기반복되는 직원 문의를 살펴보고 안내와 업무 절차를 개선합니다.

위에서 해 보고 싶은 상황을 하나 골라 주세요.

5.선택한 상황을 혼자 해결하기

과제를 고르면 그 상황의 요청과 자료가 이곳에 나타납니다. 아래 도움말은 필요할 때만 펼쳐 보세요.

자료에서 이미 답을 찾을 수 있는지 보고, 요청한 사람에게 물어볼 질문을 적습니다. 직접 할 일·AI에게 맡길 일·사람이 판단할 일을 짧게 나눠 보세요.

질문을 적은 뒤 펼치기 — 요청한 사람의 추가 설명

시범 기간은 3개월입니다. 대상 지점과 실행 방법은 제안해 주세요. 50만 원을 승인받은 상태는 아닙니다. 미정 비용은 확인 필요로 남겨도 됩니다. 경쟁사 소문은 확정 근거로 쓰지 않습니다.

분석 요약과 실행안 만들기

필요한 비교 기준을 골라 핵심 결론과 숫자 근거를 정리합니다. 실행 방법 두 가지를 비교해 하나를 고르고, 누가·언제·무엇을 할지와 확인할 비용·성과를 1쪽으로 정리하세요. 요청문은 직접 써서 입력하고 결과를 고칩니다.

막히면 생각할 질문

판매 수량과 매출을 구분했나요? 부산의 중간 흐름을 함께 봤나요? 의견을 원인으로 확정하지 않았나요?

그래도 막히면 요청 예시 보기

먼저 내 요청으로 한 번 실행해 보세요. 아래는 가능한 요청의 한 예입니다.

나는 해오름상사 영업기획 담당자야. 위 자료 A~C로 해결할 문제와 확인할 사실을 정리해줘.
숫자로 계산한 사실, 메모에 근거한 설명, 아직 모르는 것을 구분해줘.
내가 선택할 수 있는 실행 방법 두 개를 운영 부담·비용·현재 조건으로 비교해줘.
추천 이유를 읽고 내가 하나를 고른 다음, 담당 역할·순서·기간·확정 비용·미정 비용·성과 확인 방법을 넣어 실행안 1쪽을 작성해줘.
자료에 없는 숫자와 효과는 만들지 마. 중요한 숫자 두 개를 원자료와 확인할 방법도 알려줘.

초안을 만든 뒤 열기 — 중간 변경 요청

전 지점 동시 운영 대신 한 지점에서만 시범 운영해 주세요. 현금 지출은 50만 원 한도로 검토하되 승인 예산으로 쓰지 마세요. 기존 직원의 추가 업무도 따로 적어 주세요.

바뀐 조건과 유지할 내용을 나눠 수정 요청을 씁니다. 분석과 실행안에서 고칠 부분을 찾고, 이어 만들 슬라이드에도 같은 조건을 적용하세요.

내 선택을 설명하는 슬라이드 3장 만들기

① 결론과 문제 ② 핵심 근거 ③ 실행 방법과 확인할 일의 순서로 구성합니다. 이미 확인한 숫자·기간·조건을 사용하세요. Canvas에서 세 장을 확인할 수 있으면 기본 작업이 끝납니다. Google 슬라이드 내보내기와 실제 차트 연결은 더 해 볼 수 있습니다.

슬라이드에서 막히면 생각할 질문

읽는 사람이 첫 장만 보고 내가 하자는 일을 알 수 있나요? 분석과 기획의 숫자가 같은가요? 중간 변경 조건이 마지막 장에 반영됐나요?

이렇게 되면 완성입니다
내가 선택한 개선 방향과 이유가 있다.중요한 숫자 두 개를 원자료와 비교했다.미정 정보와 추측을 확정 사실처럼 쓰지 않았다.중간 변경이 분석·실행안·슬라이드에 반영됐다.결과물을 내 계정에 저장했다.
자료를 읽고, 방향을 고르고, 바뀐 조건까지 반영했습니다. 내가 선택한 일을 끝까지 마쳤습니다.

메일 내용: [예: 안녕하세요. Apps Script로 자동 발송한 첫 메일입니다.]
함수 이름은 [sendTestMail]로 해줘.

실습: 예제 ② 시트 명단으로 맞춤 메일 보내기

이번 코드는 메일을 바로 보내지 않고, 먼저 미리보기(누구에게 어떤 메일이 갈지 로그로만 보여 주기)를 실행한 뒤 실제로 보냅니다. 보낸 줄에는 "보냄"이 적혀서, 다시 실행해도 그 줄은 건너뜁니다.

오늘 만든 기획안을 관련 담당자들에게 이름을 넣어 안내하는 상황입니다.

STEP 01 같은 시트에 명단 만들기

A 이름 | B 이메일 | C 부서 | D 보낸 상태 |

김하늘 | 내주소+kim@gmail.com | 영업팀 | |

이바다 | 내주소+lee@gmail.com | 서울점 | |

박나무 | 내주소+park@gmail.com | 부산점 | |

Gmail은 주소 뒤에 +글자를 붙여도 모두 내 받은편지함으로 옵니다. 예) mymail@gmail.com → mymail+kim@gmail.com. 실제로는 나에게 3통이 오지만 3명에게 보낸 것처럼 연습할 수 있습니다. (회사 메일은 안 될 수 있으니 개인 Gmail로)

STEP 02 코드 요청

Google 시트의 '명단' 탭으로 기획안 안내 메일을 보내는 Apps Script를 만들어줘.
명단: 1행은 제목, A 이름 / B 이메일 / C 부서 / D 보낸 상태.
안전하게 연습하려고 해. 코드 맨 위에 내 Gmail 주소를 적는 칸을 두고, 내 주소(뒤에 +글자를 붙인 주소 포함)로만 보내줘.
이메일이 비었거나, 형식이 틀렸거나, 내 주소가 아니면 보내지 말고 로그에 이유를 남겨줘.
D열이 '보냄'인 줄은 건너뛰고, 보내는 데 성공한 줄에만 '보냄'을 적어줘. 실패하면 '오류'로 적고 다음 줄로 넘어가줘.
본문에는 이름·부서와 [기획안 문서 링크]를 넣어줘.
함수는 두 개로 만들어줘: 보내지 않고 로그로만 보여 주는 previewMails, 실제로 보내는 sendMails.
나는 코딩을 몰라. 코드가 하는 일을 쉽게 설명하고, 전체 코드와 실행 순서를 알려줘.

3Apps Script 화면으로 돌아와 예제 ① 코드 아래에 받은 코드를 이어 붙여 넣고 저장(Ctrl + S)합니다.

4코드 맨 위의 내 주소 칸을 실제 내 Gmail 주소로 바꾸고 다시 저장합니다.

5함수 선택 칸에서 "previewMails" → ▶ 실행. 아래 실행 로그에 세 사람의 받는 주소 · 제목 · 본문이 나오는지 봅니다. (권한 창이 또 나오면 같은 순서로 허용)

6로그가 맞으면 함수 선택 칸에서 "sendMails" → ▶ 실행을 한 번만 누릅니다.

7받은편지함에 메일 3통(이름·부서가 각각 다르게)이 왔는지, 시트 D열에 "보냄"이 적혔는지 확인합니다.

// 아래 TEST_EMAIL을 내 Gmail 주소로 바꾼 뒤 previewMails부터 실행하세요.
const TEST_EMAIL = '내주소@gmail.com';
function mailRows_() {
 const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('명단');
 if (!sheet) throw new Error('명단 탭이 없습니다.');
 const rows = sheet.getDataRange().getValues();
 if (rows[0].slice(0, 4).join('|') !== '이름|이메일|부서|보낸 상태') {
 throw new Error('1행의 열 순서를 확인하세요.');
 }
 if (!/^[^@\s]+@gmail\.com$/i.test(TEST_EMAIL) || TEST_EMAIL === '내주소@gmail.com') {
 throw new Error('TEST_EMAIL을 내 Gmail 주소로 바꾸세요.');
 }
 return {sheet, rows};
}
function baseGmail_(email) {
 const parts = String(email).trim().toLowerCase().split('@');
 return parts[0].split('+')[0].replace(/\./g, '') + '@' + parts[1];
}
function processMails_(send) {
 const {sheet, rows} = mailRows_();
 for (let i = 1; i < rows.length; i++) {
 const [name, rawEmail, dept, state] = rows[i];
 if (String(state).trim() === '보냄') continue;
 const email = String(rawEmail).trim();
 if (!/^[^@\s]+@gmail\.com$/i.test(email) || baseGmail_(email) !== baseGmail_(TEST_EMAIL)) {
 console.log('건너뜀: ' + (i + 1) + '행, 주소 확인 필요');
 continue;
 }
 const subject = '[해오름상사] 판매 기획안 검토 요청';
 const body = name + '님(' + dept + ') 안녕하세요.\n공유한 기획안을 검토해 주세요.\n문서 링크: 확인 필요';
 if (!send) { console.log(JSON.stringify({row:i+1, email, subject, body})); continue; }
 try {
 MailApp.sendEmail(email, subject, body);
 sheet.getRange(i+1, 4).setValue('보냄');
 } catch (e) {
 sheet.getRange(i+1, 4).setValue('오류');
 console.log((i+1) + '행 실패: ' + e.message);
 }
 }
}
function previewMails() { processMails_(false); }
function sendMails() { processMails_(true); }
