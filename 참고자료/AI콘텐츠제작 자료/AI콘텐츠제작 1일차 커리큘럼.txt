# 02. 생성형 AI와 콘텐츠 시장의 흐름 (15분)

생성형 AI란?
말로 요청하면 글·이미지·영상·음악 같은 새로운 결과물을 만들어 주는 AI

① AI는 어떻게 바뀌어 왔나
   검색 (내가 찾아 보기)
   → 대화 (물어보면 답해 줌)
   → 결과물 (글·이미지·영상·음악을 만들어 줌)
   → 대신 일하기 (여러 단계를 스스로 처리하는 "에이전트")

   콘텐츠 쪽에서는
   글 → 이미지 → 영상 → 음악 순서로 빠르게 넓어졌습니다.
   지금은 한 사람이 기획·이미지·영상·음악·편집을 모두 해 볼 수 있는 시대입니다.

② 이 과정에서 쓰는 도구
   Gemini      : 글, 이미지 만들기·고치기, 음악 만들기(Lyria)
   Google Flow : 글이나 이미지로 짧은 영상 만들기
   CapCut      : 영상 자르기·잇기·자막·음악 넣기 (편집 프로그램)
   Google 슬라이드 : 카드뉴스 글자, 만화 말풍선 배치

   그 밖에 많이 쓰는 도구 (이름만 알아 두기)
   이미지 : ChatGPT, Midjourney    영상 : Runway, Kling    음악 : Suno    디자인 : Canva
   ※ 도구는 계속 바뀝니다. "어떻게 설명하고, 결과를 보고 어떻게 고치는지"는 어느 도구에서나 통합니다.
   ※ 다른 유료 도구는 더 높은 품질을 원하는 사람만 개인적으로 선택합니다. (수업 중 안내)

③ 콘텐츠 일은 어떻게 바뀌나
   - 빨라진 것 : 시안 만들기, 여러 버전 비교, 배경·소품 촬영, 간단한 영상
   - 사람이 할 일 : 무엇을 만들지 정하기, 여러 결과 중 고르기, 어색한 곳 찾기, 최종 판단
   - "AI가 다 만들어 준다"가 아니라 "고르고 고치는 눈이 있는 사람이 잘 만든다"

※ 강사 준비 : 최근 AI 광고·뮤직비디오 사례, 관련 기사 2~3개를 수업 당일 기준으로 보여 주기
  (통계와 수치는 수업 당일 기사로 보충)


# 03. 안전 수칙 — 저작권·초상권·개인정보 (10분)

AI 콘텐츠는 쉽게 만들고 쉽게 퍼집니다. 그래서 만들기 전에 지킬 것이 있습니다.

하지 않기
- 실제 연예인·유명인·지인의 얼굴을 넣어 만들기 (초상권)
- 남이 찍은 사진·그린 그림을 허락 없이 참고 이미지로 올리기
- 실제 브랜드 로고·상표·캐릭터를 넣어 광고처럼 만들기
- 특정 작가·스튜디오·가수 이름으로 "○○풍으로" 요청하기
  → 대신 특징을 말로 설명하기 (예: "부드러운 수채화, 따뜻한 색, 손으로 그린 느낌")
- 실제 제품에 없는 효능·성능·수치를 광고 문구에 넣기

올리기 전에 확인
- 내 얼굴·아이 얼굴 사진을 올릴 때는 신중하게 (필요할 때만)
- SNS에 올릴 때 AI로 만든 콘텐츠라는 표시가 필요한지 확인 (플랫폼마다 규칙이 있음)
- 판매·광고 등 돈을 버는 데 쓸 때는 도구의 이용 약관 확인

AI 쓰기 전 3초 체크
① 남의 얼굴·작품·상표가 들어가지 않았나?
② 사실이 아닌 내용이 들어가지 않았나?
③ 마지막에 내가 확인했나?

# 05. AI를 대하는 마음가짐 3가지 (10분)

① AI는 "하버드를 나온 신입 사원"이다
   - 아는 것도 많고 손도 빠르다
   - 하지만 내가 머릿속에 그린 장면, 이 이미지를 어디에 쓸지는 전혀 모른다
   - "예쁘게 만들어 줘" 한마디만 하면? → AI가 생각하는 "예쁨"을 가져온다
   → 똑똑한 신입에게 일을 맡기듯, 무엇을·어디에·어떤 느낌으로 쓸지 설명해 주기

② AI랑 싸우지 마라
   - "아니 그게 아니라고!", "왜 말귀를 못 알아들어?"
   - 다그치는 말은 AI를 가르치는 게 아니라 대화의 맥락을 흐리는 행동
   - 대화가 꼬이면 AI는 앞의 틀린 결과와 화난 말까지 참고해서 더 헷갈린다
   → "무엇은 그대로 두고, 무엇만 바꿔 줘"라고 차분하게 한 가지씩 말하기
   → 너무 꼬였다면 새 채팅에서 제대로 된 요청으로 다시 시작

③ 원하는 결과가 안 나오면 AI 탓이 아니라 내 요청 탓
   - "AI 별로네"가 아니라 "내가 무엇을 덜 알려줬지?"를 먼저 생각하기
   - 대부분은 대상·장소·구도·분위기·용도 중 하나가 빠져 있다

한 줄 정리 : AI는 똑똑한 신입, 싸우지 말고 설명하고, 안 되면 내 요청부터 돌아보기


# 06. 프롬프트 사용 요령 — 콘텐츠 편 (5분)

① 구체적으로       "강아지 그려줘" → "잔디밭에서 공을 물고 뛰는 갈색 푸들"
② 용도를 알려주기   "인스타 프로필용", "쇼핑몰 대표 사진용", "포스터 배경용"
③ 모양을 정하기     비율(정사각형·세로·가로), 사진인지 그림인지
④ 한 번에 다 하려 하지 않기  처음 결과를 보고 이어서 고치기
⑤ 고칠 때는 "유지할 것 + 바꿀 것"   "강아지는 그대로, 배경만 바닷가로"
⑥ 결과는 내가 확인하기   손가락·글자·물건 모양이 이상하지 않은지

# 짧게 vs 자세히 비교하기 (10분)

두 요청을 각각 새 채팅에서 보내고 결과를 비교합니다.

A : 커피 사진 만들어줘.

    아침 햇살이 옆에서 들어오고, 잔 위로 김이 살짝 올라와.
    컵은 화면 가운데, 배경은 흐릿하게.
    카페 인스타그램에 올릴 편안한 분위기로, 정사각형으로 만들어줘.

→ A는 AI가 장소·빛·구도·분위기를 마음대로 정합니다.
→ B는 내가 정한 대로 나올 가능성이 높습니다.


# 07. 이미지 프롬프트 기본 구조 6칸 (5분)

무엇을    : 주인공이 무엇인가      (예: 노란 우비를 입은 아이)
어디서    : 어떤 장소·배경인가     (예: 비 오는 골목길)
어떻게    : 구도·거리               (예: 전신이 보이게, 눈높이에서)
빛·색     : 조명과 색감             (예: 흐린 날 부드러운 빛, 파스텔 톤)
느낌      : 분위기·스타일           (예: 동화책 삽화 같은, 따뜻한)
용도      : 어디에 쓸지·비율        (예: 인스타 피드용 세로 4:5)

※ 6칸을 매번 다 채우지 않아도 됩니다. 처음엔 3~4칸만 채우고, 결과를 보며 더합니다.
※ 구도·조명·화풍 키워드는 DAY 02에서 자세히 배웁니다.

작성 틀
[무엇을 — 예: 모닥불과 작은 텐트] 이미지를 만들어줘.
장소는 [어디서 — 예: 숲속 캠핑장]이고,
[어떻게 — 예: 텐트와 모닥불이 함께 보이게 조금 멀리서].
[빛·색 — 예: 밤, 모닥불의 주황빛과 별빛].
[느낌 — 예: 아늑하고 조용한 분위기의 사진].
[용도 — 예: 블로그 대표 이미지, 가로 16:9]로 만들어줘.

같은 채팅에서 하나씩 이어서 요청
① "[유지할 것]은 그대로 두고, 시간만 [바꿀 것 — 예: 새벽]으로 바꿔줘"
② "사진 말고 [그림 느낌 — 예: 따뜻한 수채화]로 바꿔줘"
③ "세로 비율(9:16)로 다시 만들어줘"

확인하기
□ 이어서 고칠 때 "유지할 것"이 정말 유지되었나?
□ 이상한 부분(물건 모양, 손가락, 글자)은 없나?
