# 1교시
# 같은 제품, 여러 구도


# 01. 구도가 바뀌면 이야기가 바뀐다 (5분)

같은 텀블러라도
- 정면에서 보면      → "이런 제품입니다" (쇼핑몰 대표 사진)
- 위에서 내려다보면  → "이런 일상에 어울려요" (인스타 피드)
- 아주 가까이 보면   → "이런 질감이에요" (상세 페이지)
- 멀리서 넓게 보면   → "이런 공간에 있어요" (배너·광고)

구도는 "무엇을 보여 줄지"를 정하는 일입니다.


# 02. 구도 키워드 상자 (5분)

실습 전에 먼저 읽어 보고, 쓰고 싶은 것에 표시해 둡니다.

거리
- 아주 가까이 (매크로)       : 표면 질감, 물방울, 글자 새김
- 가까이 (클로즈업)          : 제품이 화면을 꽉 채움
- 중간                        : 제품 + 주변 소품 조금
- 멀리 넓게 (와이드)          : 공간 전체, 제품은 작게

각도
- 정면 (눈높이)               : 가장 기본, 형태가 잘 보임
- 45도 비스듬히               : 입체감, 쇼핑몰에서 많이 씀
- 위에서 내려다보기 (탑뷰)    : 책상 위 물건들과 함께
- 바닥에 펼쳐 놓고 위에서 (플랫레이) : 소품을 가지런히 늘어놓은 구성
- 아래에서 올려다보기 (로우앵글) : 크고 당당해 보임

배치
- 가운데 두기 / 한쪽에 두고 여백 많이 (글자 넣을 자리)
- 배경 흐리게 (제품만 또렷하게)
- 손에 들고 있는 모습 (사용 장면)

# 03. 조명·색감 키워드 상자 (5분)

조명
- 부드러운 스튜디오 조명   : 그림자 적고 깔끔
- 창가 자연광              : 편안하고 일상적
- 역광 (뒤에서 비치는 빛)  : 테두리가 빛나고 감성적
- 노을빛 (골든아워)        : 따뜻하고 낭만적
- 어두운 배경에 한 줄기 빛 : 고급스럽고 극적
- 네온 조명                : 밤, 도시, 젊은 느낌

색감
- 파스텔 톤 / 선명한 원색 / 흑백·모노톤 / 따뜻한 톤 / 차가운 톤 / 빈티지 필름 느낌

# 04. 콘셉트 = 분위기 + 계절 + 화풍 (3분)

구도와 빛이 "어떻게 찍을까"라면
콘셉트는 "어떤 세계에 놓을까"입니다.

분위기  : 미니멀 / 빈티지 / 고급 / 자연 / 미래 / 귀여운
계절    : 봄 / 여름 / 가을 / 겨울 / 명절·기념일
화풍    : 사진 → 그림·3D·점토 등 표현 방식 자체를 바꾸기


# 실습 SET 04
# 분위기 바꾸기 (10분)

분위기 예시 (3개 골라 해 보기)
- 미니멀     : 흰 배경, 소품 없이, 넓은 여백
- 빈티지     : 낡은 나무 테이블, 오래된 책, 필름 사진 느낌
- 고급       : 대리석, 금색 포인트, 어두운 배경
- 자연       : 이끼 낀 바위, 나뭇잎, 흐르는 물
- 미래       : 반짝이는 금속 공간, 파란 빛
- 귀여운     : 알록달록 풍선, 사탕, 파스텔

작성 틀
기본 사진의 텀블러는 그대로 두고
[분위기] 콘셉트의 광고 사진으로 바꿔줘.
배경과 소품: [예: 대리석 테이블, 금색 스푼, 어두운 배경]
[누구에게 — 예: 30대 직장인]에게 어울리는 느낌으로 만들어줘.

확인하기 : 분위기가 바뀌어도 텀블러는 같은 제품인가?


# 실습 SET 05
# 계절 버전 만들기 (10분)

계절 이벤트용 사진 4장을 만듭니다.

작성 틀
기본 사진의 텀블러를 [계절 — 예: 봄] 이벤트용 사진으로 만들어줘.
[계절을 보여 줄 소품·배경 — 예: 벚꽃잎이 흩날리는 공원 벤치]
[비율 — 예: 인스타 피드용 세로 4:5]
제품이 가장 눈에 띄게 하고, 로고나 글자는 넣지 말아줘.

계절 예시
□ 봄   : 벚꽃, 연한 분홍, 피크닉 매트
□ 여름 : 바닷가 모래, 파란 하늘, 얼음
□ 가을 : 단풍잎, 따뜻한 니트, 창밖 비
□ 겨울 : 눈 쌓인 창가, 털장갑, 따뜻한 조명

이어서 요청
"4장 모두 [통일할 것 — 예: 텀블러 위치를 화면 가운데로] 맞춰서 다시 만들어줘."
→ 여러 장을 한 세트로 쓸 때는 "통일할 것"을 따로 말해 줍니다.


# 05. 화풍 키워드 상자 (3분)

- 따뜻한 수채화          - 연필 스케치

- 만화책 펜 선           - 스티커 느낌 (흰 테두리)

※ "○○ 작가 풍", "○○ 스튜디오 풍"처럼 실제 이름은 쓰지 않습니다.
  대신 "부드러운 파스텔 수채화, 손으로 그린 따뜻한 선"처럼 특징을 설명합니다.

# 07. 오늘의 핵심

이미지는 "한 장 잘 뽑기"가 아니라 "원하는 방향으로 바꿔 가기"입니다.
바꿀 때는 유지할 것(제품)과 바꿀 것(구도·빛·콘셉트·화풍)을 나눠서 말합니다.
여러 장을 한 세트로 쓸 때는 통일할 것을 따로 알려 줍니다.

다음 시간(DAY 03)에는
내가 가진 사진을 참고 이미지로 활용하고,
용도에 맞는 광고 이미지와 인스타 카드뉴스를 만듭니다.


# 강사용 메모

- 줄여서 진행할 때 : SET 02는 6가지 중 4가지(①②③⑥), SET 05는 계절 2개, SET 06은 화풍 2개
- 빨리 끝난 사람 : 자기 물건(가방, 신발, 화분 등)으로 구도 6가지 다시 해 보기
- 자주 막히는 곳 : 이어서 요청할수록 제품 색·모양이 조금씩 변함
  → "기본 사진과 똑같은 모양과 색으로"를 매번 붙이기, 너무 달라지면 기본 사진을 첨부해서 새 채팅에서 요청
