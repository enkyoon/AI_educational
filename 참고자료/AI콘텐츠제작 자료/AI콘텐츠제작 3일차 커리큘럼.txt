# 1교시
# 참고 이미지와 여러 결과물 만들기


# 01. 참고 이미지 = "이걸 보고 해 줘" (3분)

참고 이미지를 올릴 때는 "이 사진에서 무엇을 참고할지"를 꼭 말합니다.

- "이 사진의 컵 모양을 참고해서"       → 물건
- "이 사진의 색감을 참고해서"          → 분위기
- "이 사진의 구도를 참고해서"          → 배치
- "첫 번째 사진의 빵, 두 번째 사진의 배경" → 여러 장일 때는 번호로

올려도 되는 사진
○ 내가 찍은 사진, 내가 만든 이미지, AI로 만든 이미지
× 인터넷에서 가져온 남의 사진·그림, 실제 브랜드 광고, 다른 사람 얼굴


# 실습 SET 01
# 내 사진 올려서 분석받고 배경만 바꾸기 (10분)

STEP 01 사진 찍기 (2분)
책상 위 물건 하나를 휴대폰으로 찍습니다. (컵, 펜, 안경, 이어폰, 과자 봉지 등)
- 물건이 화면 가운데, 너무 어둡지 않게
- 휴대폰 Gemini 앱에서 바로 올려도 되고, PC로 옮겨서 올려도 됩니다.

STEP 02 바로 고치지 말고 먼저 분석받기
첨부한 이미지를 분석해줘.
[알고 싶은 것 — 예: 물건 형태 / 주요 색상 / 물건 위치 / 배경 / 조명 / 전체 분위기]를 알려줘.
아직 이미지는 수정하지 말아줘.

→ AI가 무엇을 보고 있는지 먼저 확인하면, 무엇을 유지하고 바꿀지 말하기 쉬워집니다.

STEP 03 배경 바꾸기
작성 틀
첨부한 사진의 [물건]은 [유지할 것 — 예: 모양·색·글자]를 그대로 유지해줘.
배경만 [새 배경 — 예: 햇살이 드는 카페 창가 나무 테이블]로 바꿔서
[용도 — 예: 인스타 광고] 사진처럼 만들어줘.

확인하기 : 물건의 모양·글자·색이 원래 사진과 같은가?

- "그림자만 조금 더 부드럽게 해줘"

# 02. 결과물 형태 키워드 (5분)

같은 소금빵이라도 "어떤 형태의 결과물"로 만드느냐에 따라 완전히 다른 이미지가 됩니다.
그래서 이미지를 만들기 전에 "무엇을 그릴까?"뿐 아니라 "어떤 결과물이 필요할까?"를 먼저 정합니다.

키워드 예시 상자 (우리말 이름 + 영어 키워드)
제품 사진 (/productshot)          제품 자체를 깔끔하게 — 쇼핑몰, 상세 페이지
생활 속 사진 (/lifestyle shot)     실제로 쓰는 장면 — SNS, 브랜드 콘텐츠
패키지 디자인 (/packaging)         상자, 봉투, 라벨
실물처럼 보여 주기 (/mockup)       디자인이 실제 물건·매장에 적용된 모습
잡지 표지 (/magazinecover)         위쪽에 제목 자리가 있는 표지
잡지 화보 (/editorial)             여백 넓은 분위기 사진
메뉴판 (/menu)                     카페·식당 메뉴 이미지
옥외 광고판 (/billboard)           건물 외벽 광고판에 걸린 모습
3D 옥외 광고 (/3d billboard)       광고판 밖으로 튀어나오는 입체 광고
여러 방향에서 (/360view)           정면·양옆·뒷면을 한 화면에
SNS 광고 (/meta ad)                세로, 광고 문구 자리
홈페이지 첫 화면 (/heroimage)      가로, 한쪽은 제목·버튼 자리

※ "/productshot" 같은 영어 키워드는 공식 명령어가 아니라 방향을 알려 주는 표현입니다.
  "잡지 표지처럼"처럼 우리말로 써도 됩니다. 키워드만 넣지 말고 대상·배경·빛·용도를 함께 씁니다.
※ 전체 30개 목록 : 참고자료 "이미지 결과물 키워드 모음.txt" (강사가 수업 페이지로 안내)

# 같은 제품을 여러 결과물로 바꾸기 (15분)

소금빵_광고 이미지를 첨부하고, 아래 중 3가지를 골라 만듭니다.

작성 틀
([영어 키워드 — 예: /packaging])
첨부한 이미지의 [유지할 것 — 예: 소금빵 모양과 따뜻한 색감]은 그대로 두고
[결과물 형태 — 예: 빵 봉투 패키지 디자인]으로 만들어줘.
[세부 조건 — 예: 크라프트 종이 봉투, 밀 이삭 그림, 가게 이름 '보리밭베이커리' 자리]
[분위기 — 예: 소박하고 따뜻한 동네 빵집 느낌]

고를 수 있는 결과물 (3가지 이상)
□ ① 패키지 → 실물처럼 : 빵 봉투를 디자인하고, 이어서 "이 봉투가 실제 매장 진열대에 놓인 사진처럼" (/packaging → /mockup)
□ ② 잡지 표지 → 화보 : 동네 빵집 특집 잡지 표지(위쪽 제목 자리), 이어서 "표지 말고 안쪽 화보 한 페이지로" (/magazinecover → /editorial)
□ ③ 옥외 광고판 → 3D 옥외 광고 : 도심 건물 외벽 광고판, 이어서 "거대한 소금빵이 광고판 밖으로 튀어나오게" (/billboard → /3d billboard)
□ ④ 메뉴판 : 소금빵·크루아상·식빵 3가지가 들어간 가게 메뉴판 (가격 칸은 비워 두기) (/menu)
□ ⑤ 여러 방향에서 : 소금빵을 위·옆·자른 단면으로 한 화면에 (/360view)

비교하기
같은 소금빵이 결과물 형태에 따라 어떻게 달라졌는지 한 줄씩 적기
(예: 패키지 — 가게 이름이 중심 / 3D 광고 — 눈길을 끄는 크기와 입체감)

※ 메뉴판·패키지의 글자가 틀리면 글자 없이 만들고, 2교시의 "슬라이드로 글자 넣기"로 넣습니다.
※ 가격·영양 정보 등 받지 않은 숫자는 만들지 않게 합니다.

# 03. 카드뉴스란? (5분)

여러 장의 이미지를 옆으로 넘기며 읽는 인스타그램 게시물
한 장에 한 가지 내용, 글은 짧게, 모든 장이 같은 디자인

기본 구성 (5장)
1장 표지     : 눈길을 끄는 제목 (넘겨 보고 싶게)
2~4장 본문   : 한 장에 한 가지 정보
5장 마무리   : 정리 한 줄 + 다음 행동 (예: "매장에서 만나요", "저장해 두세요")

잘 만든 카드뉴스의 특징
- 표지 제목만 봐도 무엇에 대한 글인지 안다
- 한 장에 글이 3줄을 넘지 않는다
- 색·글꼴·배치가 5장 모두 같다

이어서 요청

③ "장마다 어울리는 그림 설명도 한 줄씩 붙여줘"

→ 최종 문구를 메모장이나 Google 문서에 붙여 두기

방법 A — Gemini가 글자까지 넣기 (빠름)
이 이미지 [위치 — 예: 위쪽 빈자리]에 "[문구]"라는 글자를 넣어줘.
글꼴은 [예: 굵은 고딕], 색은 [예: 진한 갈색].
→ 한글이 틀리거나 뭉개지면 방법 B로

방법 B — Google 슬라이드로 글자 넣기 (정확, 추천)
STEP 01 새 Google 슬라이드 → 이름 "03_카드뉴스_이름"
STEP 02 파일 → 페이지 설정 → 맞춤 → 1080 × 1350 픽셀 (세로 4:5)
STEP 03 장마다 이미지 넣기 : 삽입 → 이미지 → 컴퓨터에서 업로드 → 화면 가득 늘리기
STEP 04 텍스트 상자로 제목·설명 넣기
        - 5장 모두 같은 글꼴·크기·색·위치
        - 첫 장 글자 상자를 복사해서 다음 장에 붙여넣으면 위치가 같아짐
STEP 05 장마다 이미지로 저장 : 파일 → 다운로드 → PNG 이미지 (지금 보고 있는 장이 저장됨)

※ 메뉴 이름은 업데이트에 따라 다를 수 있습니다.
  막히면 Gemini에게 "Google 슬라이드에서 페이지 크기를 1080×1350으로 바꾸는 순서를 알려줘"

최종 점검
□ 표지 제목이 한눈에 읽히는가?
□ 한 장에 글이 3줄 이내인가?
□ 5장 모두 글자 위치·색이 같은가?
□ 확인 안 된 내용이 들어가지 않았나?


# 04. 오늘의 결과물

① 내 사진 분석 결과와 배경을 바꾼 사진
② 일부분만 고친 사진
③ 두 장을 합친 소금빵 광고 이미지
④ 같은 소금빵으로 만든 여러 결과물 3가지 이상 (패키지·목업, 잡지 표지·화보, 옥외 광고, 메뉴판 등)
⑤ SNS 광고(4:5)와 홈페이지 첫 화면(16:9) 이미지
⑥ 인스타 카드뉴스 5장 (03_카드뉴스)


# 05. 오늘의 핵심

참고 이미지를 올릴 때는 먼저 분석받고, "무엇을 참고할지"를 말합니다.
이미지를 만들기 전에 "무엇을 그릴까?"뿐 아니라 "어떤 형태의 결과물이 필요할까?"를 먼저 정합니다.
키워드는 마법의 명령어가 아니라 AI에게 방향을 알려 주는 표현입니다.
같은 광고도 올리는 곳에 따라 비율과 글자 자리를 다시 정합니다.
카드뉴스는 "스타일 고정 문장"으로 5장을 한 세트처럼 맞춥니다.

다음 시간(DAY 04)에는
Google Flow로 이미지를 움직여 짧은 광고 영상을 만듭니다.


# 강사용 메모

- 줄여서 진행할 때 : SET 02 생략, SET 04는 2가지 결과물만, SET 05는 SNS 광고 1가지만, 카드뉴스는 3장(표지·본문1·마무리)
- 빨리 끝난 사람 : SET 04에서 고르지 않은 결과물 더 만들기 / 카드뉴스 표지를 다른 분위기로 2가지 더 / 가게 포스터(3:4)
- 결과물 형태 키워드 전체 30개는 "이미지 결과물 키워드 모음.txt" 참고 (원본 : 프롬프트엔지니어링1 3일차)
  · 수강생에게는 우리말 이름을 먼저 보여 주고 영어 키워드는 괄호로만. 외우게 하지 않기
- 자주 막히는 곳
  · 휴대폰 사진이 PC로 안 옮겨짐 → 휴대폰 Gemini 앱에서 바로 올리기, 또는 드라이브 앱으로 업로드
  · 슬라이드 페이지 크기 단위가 인치로 나옴 → 단위 목록에서 "픽셀" 선택
  · PNG 다운로드가 한 장씩만 됨 → 장마다 선택 후 다운로드 (정상)
