# 1교시
# 참고 이미지와 광고 이미지


# 01. 참고 이미지 = "이걸 보고 해 줘" (5분)

참고 이미지를 올릴 때는 "이 사진에서 무엇을 참고할지"를 꼭 말합니다.

- "이 사진의 컵 모양을 참고해서"       → 물건
- "이 사진의 색감을 참고해서"          → 분위기
- "이 사진의 구도를 참고해서"          → 배치
- "첫 번째 사진의 빵, 두 번째 사진의 배경" → 여러 장일 때는 번호로

올려도 되는 사진
○ 내가 찍은 사진, 내가 만든 이미지, AI로 만든 이미지
× 인터넷에서 가져온 남의 사진·그림, 실제 브랜드 광고, 다른 사람 얼굴


# 실습 SET 01
# 내 사진 올려서 배경만 바꾸기 (10분)

STEP 01 사진 찍기 (2분)
책상 위 물건 하나를 휴대폰으로 찍습니다. (컵, 펜, 안경, 이어폰, 과자 봉지 등)
- 물건이 화면 가운데, 너무 어둡지 않게
- 휴대폰 Gemini 앱에서 바로 올려도 되고, PC로 옮겨서 올려도 됩니다.

STEP 02 배경 바꾸기
작성 틀
첨부한 사진의 [물건]은 모양과 색을 그대로 유지해줘.
배경만 [새 배경 — 예: 햇살이 드는 카페 창가 나무 테이블]로 바꿔서
[용도 — 예: 인스타 광고] 사진처럼 만들어줘.

이어서 요청
"물건은 그대로, 배경만 [다른 배경 — 예: 여름 바닷가 모래 위]로 한 번 더"

확인하기 : 물건의 모양·글자·색이 원래 사진과 같은가?


# 실습 SET 02
# 일부분만 고치기 (5분)

전체를 다시 만들지 않고 한 부분만 고칠 수 있습니다.

이어서 요청 예시 (2개 이상 해 보기)
- "[물건] 옆에 [추가할 것 — 예: 작은 화분]을 하나 놓아줘"
- "[지울 것 — 예: 뒤쪽의 컵]만 지워줘"
- "[부분 — 예: 테이블] 색만 [예: 흰색]으로 바꿔줘"
- "그림자만 조금 더 부드럽게 해줘"


# 실습 SET 03
# 두 장 합치기 (10분)

STEP 01 재료 두 장 만들기 (Gemini)
A : 갓 구운 소금빵 3개가 나무 도마 위에 놓인 사진, 흰 배경
B : 아침 햇살이 드는 작은 동네 빵집 진열대, 사람 없이

STEP 02 합치기
작성 틀
첫 번째 이미지의 [가져올 것 — 예: 소금빵과 도마]를
두 번째 이미지의 [가져올 것 — 예: 빵집 진열대 배경] 위에 자연스럽게 놓아줘.
[빛·분위기 — 예: 아침 햇살, 따뜻한 톤]으로 맞추고,
[용도 — 예: 빵집 광고 사진]처럼 만들어줘.

확인하기
□ 두 사진의 빛 방향이 어색하지 않은가?
□ 빵 크기가 배경에 비해 너무 크거나 작지 않은가?


# 02. 용도별 비율 알기 (5분)

같은 광고라도 올리는 곳마다 모양이 다릅니다.

인스타 피드       세로 4:5 (또는 정사각 1:1)
인스타 스토리·릴스 세로 9:16 (휴대폰 화면 가득)
유튜브 썸네일·배너 가로 16:9
가게 포스터        세로 (A4 비율에 가깝게 3:4)

※ 비율만 바꾸면 끝이 아닙니다. 글자 넣을 자리(여백)와 제품 위치도 다시 정합니다.


# 실습 SET 04
# 한 광고를 3가지 용도로 바꾸기 (15분)

SET 03에서 만든 소금빵 광고(또는 마음에 드는 이미지 하나)를 사용합니다.

작성 틀
이 이미지의 [유지할 것 — 예: 소금빵, 빛, 색감]은 그대로 두고
[용도]용 [비율] 이미지로 다시 만들어줘.
[글자 자리 — 예: 위쪽 1/3은 비워서 글자를 넣을 수 있게]

만들 것
□ 인스타 피드 4:5 — 빵이 가운데, 아래쪽에 글자 자리
□ 스토리 9:16 — 위쪽에 글자 자리, 빵은 아래쪽
□ 가로 배너 16:9 — 빵은 오른쪽, 왼쪽에 글자 자리

문구 넣기 (셋 중 하나에만)
이미지에 [문구 — 예: 오늘 아침 갓 구운 소금빵]이라는 글자를 넣어줘.
글꼴은 [예: 둥글고 굵은 손글씨 느낌], 색은 [예: 흰색]으로, [위치]에 넣어줘.
→ 글자가 틀리게 나오면 2교시의 "슬라이드로 글자 넣기" 방법을 씁니다.

※ 광고 문구에는 확인되지 않은 효능·수치("살 안 찌는", "1위")를 넣지 않습니다.

# 인스타 카드뉴스 만들기


# 03. 카드뉴스란? (5분)

여러 장의 이미지를 옆으로 넘기며 읽는 인스타그램 게시물
한 장에 한 가지 내용, 글은 짧게, 모든 장이 같은 디자인

기본 구성 (5장)
1장 표지     : 눈길을 끄는 제목 (넘겨 보고 싶게)
2~4장 본문   : 한 장에 한 가지 정보
5장 마무리   : 정리 한 줄 + 다음 행동 (예: "매장에서 만나요", "저장해 두세요")

잘 만든 카드뉴스의 특징
- 표지 제목만 봐도 무엇에 대한 글인지 안다
- 한 장에 글이 3줄을 넘지 않는다
- 색·글꼴·배치가 5장 모두 같다


# 실습 SET 05
# 주제 고르고 5장 문구 짜기 (10분)

주제 예시 (하나 고르기)
- 보리밭베이커리 : 소금빵을 더 맛있게 먹는 방법 3가지
- 보리밭베이커리 : 빵을 오래 보관하는 요령
- 봄 나들이 도시락 챙길 것 5가지
- 비 오는 날 집에서 할 수 있는 일
- 초보 식집사를 위한 화분 물 주기 요령
- 우리 동네 산책로 소개 (가상의 동네)

작성 틀 (Gemini 새 채팅)
인스타그램 카드뉴스 5장의 문구를 만들어줘.
주제: [주제]
읽는 사람: [누구 — 예: 빵을 좋아하는 20~30대]
구성: 1장 표지 / 2~4장 본문 / 5장 마무리
장마다 [제목 한 줄 + 설명 2줄 이내]로 짧게 써줘.
사실이 확실하지 않은 내용은 [확인 필요]로 표시해줘.

이어서 요청
① "표지 제목을 더 궁금하게 5가지 버전으로"
② "본문 설명을 더 짧게, 한 줄씩"
③ "장마다 어울리는 그림 설명도 한 줄씩 붙여줘"

→ 최종 문구를 메모장이나 Google 문서에 붙여 두기


# 실습 SET 06
# 같은 스타일의 이미지 5장 만들기 (15분)

5장이 한 세트로 보이려면 "스타일 고정 문장"을 매번 붙입니다.

스타일 고정 문장 만들기 (한 번 정하고 복사해서 계속 쓰기)
[화풍 — 예: 부드러운 파스텔 평면 일러스트], [색 — 예: 크림색·갈색·연두색],
[배경 — 예: 크림색 단색 배경], 세로 4:5, 글자는 넣지 말 것,
[글자 자리 — 예: 위쪽 1/3은 비워 둘 것]

작성 틀 (장마다)
카드뉴스 [몇 장째] 이미지를 만들어줘.
내용: [SET 05에서 받은 그림 설명]
스타일: [스타일 고정 문장]

확인하기
□ 5장의 색·화풍·배경이 같은가?
□ 모든 장에 글자 넣을 빈자리가 있는가?
□ 튀는 한 장이 있으면 "1장과 같은 스타일로" 다시 만들기


# 실습 SET 07
# 글자 넣어 완성하기 (15분)

방법 A — Gemini가 글자까지 넣기 (빠름)
이 이미지 [위치 — 예: 위쪽 빈자리]에 "[문구]"라는 글자를 넣어줘.
글꼴은 [예: 굵은 고딕], 색은 [예: 진한 갈색].
→ 한글이 틀리거나 뭉개지면 방법 B로

방법 B — Google 슬라이드로 글자 넣기 (정확, 추천)
STEP 01 새 Google 슬라이드 → 이름 "03_카드뉴스_이름"
STEP 02 파일 → 페이지 설정 → 맞춤 → 1080 × 1350 픽셀 (세로 4:5)
STEP 03 장마다 이미지 넣기 : 삽입 → 이미지 → 컴퓨터에서 업로드 → 화면 가득 늘리기
STEP 04 텍스트 상자로 제목·설명 넣기
        - 5장 모두 같은 글꼴·크기·색·위치
        - 첫 장 글자 상자를 복사해서 다음 장에 붙여넣으면 위치가 같아짐
STEP 05 장마다 이미지로 저장 : 파일 → 다운로드 → PNG 이미지 (지금 보고 있는 장이 저장됨)

※ 메뉴 이름은 업데이트에 따라 다를 수 있습니다.
  막히면 Gemini에게 "Google 슬라이드에서 페이지 크기를 1080×1350으로 바꾸는 순서를 알려줘"

최종 점검
□ 표지 제목이 한눈에 읽히는가?
□ 한 장에 글이 3줄 이내인가?
□ 5장 모두 글자 위치·색이 같은가?
□ 확인 안 된 내용이 들어가지 않았나?

# 강사용 메모

- 줄여서 진행할 때 : SET 02 생략, SET 04는 2가지 용도만, 카드뉴스는 3장(표지·본문1·마무리)
- 빨리 끝난 사람 : 카드뉴스 표지를 다른 분위기로 2가지 더 만들어 비교 / 광고 이미지 한 장으로 가게 포스터(3:4) 만들기
- 자주 막히는 곳
  · 휴대폰 사진이 PC로 안 옮겨짐 → 휴대폰 Gemini 앱에서 바로 올리기, 또는 드라이브 앱으로 업로드
  · 슬라이드 페이지 크기 단위가 인치로 나옴 → 단위 목록에서 "픽셀" 선택
  · PNG 다운로드가 한 장씩만 됨 → 장마다 선택 후 다운로드 (정상)
