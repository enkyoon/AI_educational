※ '톡톡레몬'은 수업용 가상 브랜드입니다.

# 02. Flow 화면과 크레딧 아끼는 설정 (10분)

※ 메뉴 이름과 위치는 업데이트에 따라 다를 수 있습니다.
  막히면 Gemini에게 "Google Flow에서 [하고 싶은 것]을 하려면 어디를 눌러야 해?"라고 물어보세요.

STEP 01 labs.google/flow 접속 → Google 계정 로그인 → 새 프로젝트 → 이름 "04_톡톡레몬_이름"

STEP 02 화면 둘러보기
- 입력창 : 영상 설명(프롬프트)을 쓰는 곳
- 만드는 방식
  · 글로 만들기 (Text to Video)           : 글만으로 영상
  · 프레임으로 만들기 (Frames to Video)    : 시작 이미지를 움직여 영상
  · 재료로 만들기 (Ingredients to Video)   : 여러 참고 이미지(제품·배경 등)를 섞어 영상
- 설정 : 모델, 화면 비율(가로·세로), 한 번에 만들 개수
- 결과 : 재생, 다운로드, 이어 붙이기

STEP 03 크레딧 아끼는 설정 (꼭 확인)
□ 모델 : 기본(빠른) 모델 선택 — 고품질 모델은 크레딧이 훨씬 많이 듭니다
□ 한 번에 만들 개수 : 1개
□ 남은 크레딧이 어디에 보이는지 확인

오늘 우리 반 약속 : 한 번 만들고 바로 다시 누르지 않기.
결과를 보고 "무엇을 고칠지" 정한 뒤 다시 만듭니다.

# 04. 움직임·카메라 키워드 상자 (5분)

움직임 표현 (행동을 보이는 그대로 쓰기)
- 물방울이 천천히 흘러내린다     - 기포가 위로 올라온다
- 김이 피어오른다                - 머리카락이 바람에 살짝 흔들린다
- 꽃잎이 천천히 떨어진다         - 커튼이 바람에 흔들린다
- 빛이 창문으로 천천히 들어온다  - 파도가 모래 위로 밀려온다

카메라 움직임
- 고정                  : 카메라는 가만히, 대상의 움직임에 집중
- 천천히 다가가기       : 제품 강조
- 천천히 멀어지기       : 전체 공간, 마지막 장면
- 옆으로 이동하기       : 공간과 제품을 함께
- 대상 주위를 돌기      : 제품의 여러 면

한 장면에 넣을 양
주요 움직임 1개 + 보조 움직임 1개 + 카메라 움직임 1개
(움직임을 많이 넣을수록 원하는 대로 나오기 어렵습니다)

# 05. 끝 프레임은 무엇일까? (설명만, 5분)

Flow에는 "시작 이미지"와 함께 "끝 이미지"도 넣는 기능이 있습니다.
시작 화면에서 출발해 끝 화면으로 도착하는 영상을 만들어 줍니다.

예) 시작 : 병이 얼음 위에 조용히 서 있음
    끝   : 병 뒤로 물보라가 크게 퍼짐

그런데 이 기능은 다루기 어렵습니다.
- 두 이미지가 조금만 달라도 중간에 제품이 녹거나 바뀌는 등 어색해지기 쉽고
- 중간에 무엇이 일어날지 AI가 정하기 때문에 원하는 흐름이 잘 나오지 않습니다.

그래서 이 수업에서는 끝 프레임은 쓰지 않고,
시작 프레임 + 글로 설명하는 방식으로 장면을 만듭니다.


# 06. 유지할 것과 움직일 것 (5분)

유지할 것 예시                    움직일 것 예시
- 제품 모양은 그대로               - 물방울만 흘러내리게
- 제품 위치는 바꾸지 말고          - 배경의 나뭇잎만 흔들리게
- 배경 색은 그대로                 - 카메라만 다가가게
- 인물의 얼굴과 옷은 그대로

영상이 이상할 때는 프롬프트를 전부 바꾸지 않고
"[유지할 것]은 그대로, [고칠 것]만 바꿔 줘"로 한 가지씩 고칩니다.


# 실습 SET 04
# 같은 이미지, 카메라만 바꾸기 (10분)   ─ 영상 2개

"레몬_시작" 이미지를 다시 시작 프레임으로 넣고, 카메라만 바꿉니다.

A : 제품과 배경은 그대로 유지해줘. 카메라는 완전히 고정하고, 병 속 기포만 천천히 올라오게 해줘.
B : 제품과 배경은 그대로 유지해줘. 움직임은 최소로 하고, 카메라가 왼쪽에서 오른쪽으로 천천히 이동하게 해줘. 병이 화면 밖으로 나가지 않게 해줘.

비교하기
다가가기 → 제품 강조    고정 → 제품 주변 움직임에 집중    옆으로 → 공간과 제품을 함께


# 07. 광고를 장면으로 나누기 (5분)

"15초 광고 만들어 줘"라고 한 번에 요청하지 않습니다.
AI 영상은 한 번에 몇 초짜리 장면이 만들어지므로, 짧은 장면을 여러 개 만들어 이어 붙입니다.

예) 톡톡레몬 광고 3장면
SCENE 1  제품 등장     : 병이 조용히 서 있고, 카메라가 다가감
SCENE 2  상큼함 표현   : 레몬 조각이 탄산수 속으로 떨어지고 기포가 터짐
SCENE 3  마지막 컷     : 병 뒤로 물보라, 카메라 고정

장면마다 "왜 이 장면이 필요한지"가 달라야 합니다.

# 09. 오늘의 핵심

영상은 "무엇을 보여 줄지 → 무엇을 움직일지 → 무엇을 유지할지 → 카메라는 어떻게"를 나눠서 설명합니다.
긴 영상은 짧은 장면으로 나눠 만들고, 같은 이미지와 유지 문장으로 장면을 이어 줍니다.

다음 시간(DAY 05)에는
CapCut으로 영상 장면을 자르고 이어 붙이고, 자막과 음악을 넣어 광고 영상을 완성합니다.


# 강사용 메모

- 크레딧 : 1인 약 150크레딧 예상. 시작 전에 모델(기본)과 생성 개수(1개) 설정을 반드시 함께 확인
- 줄여서 진행할 때 : SET 04는 A만, SET 06은 장면 2개
- 빨리 끝난 사람 : 자기 주제(커피, 향수, 운동화, 화장품, 여행지 중 하나)로 영상용 이미지 → 시작 프레임 영상 1개
- 자주 막히는 곳
  · 영상 만드는 데 시간이 걸림 → 기다리는 동안 다음 장면 프롬프트를 미리 써 두게 하기
  · 제품 모양이 계속 바뀜 → 글로 만들기 대신 시작 프레임·재료 방식으로 바꾸기
  · 다운로드한 파일이 어디 있는지 모름 → 다운로드 폴더 확인 후 "AI콘텐츠제작" 폴더로 옮기기
