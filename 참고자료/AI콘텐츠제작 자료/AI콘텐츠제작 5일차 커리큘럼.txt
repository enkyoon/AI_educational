## 오늘의 수업

AI가 좋은 장면을 만들어 줘도, 그것만으로 광고가 되지는 않습니다.
필요한 부분만 남기고, 순서를 정하고, 자막과 음악을 넣어야
사람들이 끝까지 보는 "영상 콘텐츠"가 됩니다.

오늘은 무료 편집 프로그램 CapCut으로 15초 광고 영상을 완성하고,
Gemini의 음악 만들기(Lyria)로 배경음악을 직접 만들어 넣습니다.
남은 시간에는 영상의 얼굴인 유튜브 썸네일과,
이미지 여러 장으로 만드는 인스타 릴스까지 만들어 봅니다.

도구 : CapCut (PC), Google Flow, Gemini (음악 만들기·이미지)
오늘 사용할 크레딧 : 지난 영상이 없는 사람만 영상 3개, 약 45크레딧

새봄스튜디오 의뢰 :
가상의 음료 브랜드 '톡톡레몬'(레몬 탄산수)의 여름 광고 장면이 준비되어 있습니다.
"인스타 릴스에 올릴 15초 광고로 편집해 주세요. 음악과 자막도 넣어서요."
※ '톡톡레몬'은 수업용 가상 브랜드입니다.


오늘은 다음 순서로 진행합니다.

# 1교시
# CapCut으로 장면 잇고 자르고 자막 넣기


# 01. 영상 장면 준비 (10분)

A : 지난 시간에 만든 톡톡레몬 장면 3개가 있는 사람 → 그대로 사용
B : 없는 사람 → 파일 끝 "준비 자료"의 프롬프트 3개를 Flow에서 "글로 만들기"로 만들기
    (기본 모델, 한 번에 1개, 세로 9:16)
    → 다운로드 후 이름 : 01_등장 / 02_상큼 / 03_마무리

영상이 만들어지는 동안 CapCut을 설치·실행합니다.
- 학원 PC에 설치되어 있으면 실행만
- 없으면 capcut.com에서 PC 버전 설치 (강사 안내)


# 02. 편집이란? (3분)

생성 : 새 장면을 만드는 일 (지금까지 한 것)
편집 : 이미 있는 장면 중에서 고르고, 자르고, 순서를 정하고, 글과 소리를 입히는 일

편집에서 가장 먼저 생각할 것은 "무엇을 더할까"가 아니라 "무엇을 줄일까"입니다.


# 03. CapCut 화면 익히기 (5분)

※ 메뉴 이름과 위치는 업데이트에 따라 다를 수 있습니다.
  막히면 Gemini에게 "CapCut PC 버전에서 [하고 싶은 것]을 하는 순서를 알려줘"

- 미디어    : 영상·이미지·음악 불러오기
- 미리보기  : 지금 편집 중인 영상 보기
- 타임라인  : 아래쪽 긴 막대, 영상의 순서와 길이
- 텍스트    : 자막·제목
- 오디오    : 음악·효과음
- 전환      : 장면과 장면 사이 효과
- 내보내기  : 완성된 영상 저장 (오른쪽 위)

※ 왕관·"Pro" 표시가 붙은 기능은 유료입니다. 수업에서는 표시 없는 기능만 씁니다.
  (유료 기능을 넣으면 내보낼 때 결제 안내가 나옵니다)

STEP 02 미디어 → 가져오기 → 01·02·03 영상 불러오기

□ 이상하게 변하는 부분이 있나?


# 실습 SET 02
# 앞뒤 자르기와 나누기 (10분)

앞뒤 자르기 : 장면 끝을 잡고 안쪽으로 끌기
             → 처음에 멈춰 있는 1초, 끝에 모양이 이상해지는 부분 잘라내기
나누기(분할) : 자를 위치에 재생 막대를 두고 분할 버튼 (단축키 Ctrl+B)
             → 가운데 이상한 부분만 떼어 내 삭제

목표 길이 예
01_등장 4초  /  02_상큼 6초  /  03_마무리 5초  = 15초
(중요한 장면은 조금 길게, 이어 주는 장면은 짧게)

바꿔 보기 : 02와 03의 순서를 바꿔 재생해 보고, 어느 쪽이 자연스러운지 고르기
→ 장면 구성표는 "시작 기준"일 뿐, 실제로 보고 바꿔도 됩니다.


# 실습 SET 03
# 자막 넣기 (15분)

STEP 01 문구 받기 (Gemini)
작성 틀
[제품 — 예: 레몬 탄산수 '톡톡레몬']의 [길이 — 예: 15초] 세로 광고 영상에 넣을 짧은 문구를 만들어줘.
분위기: [예: 상큼하고 시원한 여름]
① 중간 장면용 짧은 문구 5개 ② 마지막 장면용 문구 5개
영상에서 1~2초 안에 읽을 수 있게 짧게 써줘.
확인되지 않은 효능이나 과장된 표현(예: "갈증 100% 해소")은 넣지 말아줘.

STEP 02 CapCut에 넣기
텍스트 → 기본 텍스트를 타임라인에 끌어다 놓기 → 문구 입력

□ 마지막 문구 + 제품 이름 (03 장면 위)

STEP 03 다듬기
□ 글자가 제품을 가리지 않는 위치
□ 휴대폰 화면 아래쪽(버튼이 겹치는 곳)은 피하기
□ 글꼴·색은 두 문구 모두 같게
□ (선택) 텍스트 애니메이션 "나타나기" 하나만

# 04. 음악 키워드 상자 (3분)

장르    : 밝은 팝 / 전자음악(일렉트로닉) / 어쿠스틱 기타 / 재즈 / 로파이(잔잔한 비트) / 오케스트라
빠르기  : 느리게 / 중간 / 빠르게
악기    : 피아노 / 기타 / 신시사이저 / 드럼 / 현악기 / 휘파람
분위기  : 상큼한 / 차분한 / 신나는 / 고급스러운 / 따뜻한 / 긴장감 있는
보컬    : 보컬 없음(배경음악) / 여자 목소리 / 남자 목소리 / 합창

※ "○○ 가수 노래처럼"이 아니라 장르·빠르기·악기로 설명합니다.


# 실습 SET 04
# Lyria로 배경음악 만들기 (10분)

Gemini → 도구 → 음악 만들기
(메뉴 이름은 다를 수 있음 — 안 보이면 Gemini에게 "음악을 만들고 싶어. 어디서 해?"라고 물어보기)

작성 틀
[어디에 쓸 음악 — 예: 15초짜리 레몬 탄산수 SNS 광고]의 배경음악을 만들어줘.
장르: [장르], 빠르기: [빠르기], 중심 악기: [악기]
분위기: [분위기]
[흐름 — 예: 가볍게 시작해서 마지막에 밝게 마무리]
보컬과 가사는 넣지 말아줘.

이어서 요청 (하나 골라서)
- "같은 분위기로 조금 더 느리게"

→ 마음에 드는 음악 다운로드 (이름 : 음악_톡톡레몬)


# 실습 SET 05
# 음악·효과음·전환 넣고 내보내기 (12분)

STEP 01 음악 넣기
미디어 → 음악 파일 가져오기 → 영상 아래 오디오 줄에 놓기
□ 영상 길이에 맞게 뒤쪽 자르기
□ 음악 끝부분에 페이드 아웃(서서히 작아지기) 0.5~1초
□ 음량 : 영상 소리가 있으면 음악을 조금 낮추기

STEP 02 효과음 1~2개 (선택)
오디오 → 효과음 → 검색 (예: "bubble", "splash", "whoosh")
→ 무언가 일어나는 순간(레몬이 떨어지는 순간)에 맞춰 놓기
※ 모든 장면에 넣지 않습니다. 강조할 곳에만.

STEP 03 전환 (선택)
먼저 전환 없이 재생 → 어색한 곳 한 군데에만 짧은 전환(예: 디졸브)

STEP 04 내보내기
오른쪽 위 내보내기 → 해상도 1080p → 이름 "05_톡톡레몬광고_이름"
→ 내보낸 파일을 한 번 더 재생해서 소리·자막이 잘 나오는지 확인


# 실습 SET 06
# 유튜브 썸네일 만들기 (10분)

썸네일 = 영상을 누르기 전에 보이는 대표 이미지
- 작은 화면에서도 무엇인지 알아볼 수 있게
- 주인공 하나 + 큰 글자 3~6자 정도
- 가로 16:9

작성 틀 (Gemini)
[영상 내용 — 예: 레몬 탄산수 여름 광고]의 유튜브 썸네일을 만들어줘.
주인공: [예: 얼음 위 레몬 탄산수 병, 화면 오른쪽에 크게]
배경: [예: 밝은 노란색, 물보라]
[글자 — 예: 왼쪽에 "여름엔 톡!"이라는 굵고 큰 글자, 흰 글씨에 검은 테두리]
가로 16:9, 작은 화면에서도 잘 보이게 단순하게 만들어줘.

→ 글자가 틀리면 글자 없이 만든 뒤, CapCut 또는 Google 슬라이드에서 글자 넣기

확인하기 : 휴대폰 화면에서 엄지손가락만 한 크기로 봐도 무엇인지 알겠나?


# 실습 SET 07
# 이미지로 릴스 만들기 (10분)

영상 없이 이미지 여러 장만으로도 릴스를 만들 수 있습니다.
(카드뉴스를 릴스로 올릴 때 많이 쓰는 방법)

재료 : 이미지 4~5장
A : 카드뉴스나 광고 이미지가 있는 사람 → 그대로 사용
B : 없는 사람 → Gemini로 세로 9:16 이미지 4장 만들기
    (예: "같은 스타일로, 여름 레몬 음료가 있는 장면 4장 — 해변, 피크닉, 카페, 수영장")

STEP 01 CapCut 새 프로젝트 9:16 → 이미지 4~5장 불러와 순서대로 놓기
STEP 02 장당 길이 2~3초로 맞추기
STEP 03 이미지에 움직임 주기 : 이미지 선택 → 애니메이션 → "확대"·"이동" 같은 움직임 하나
STEP 04 SET 04의 음악 넣기 → 내보내기 "05_이미지릴스_이름"

# 강사용 메모

- 크레딧 : 준비 자료로 영상을 만드는 사람만 약 45크레딧
- CapCut 설치가 오래 걸릴 수 있음 → 학원 PC에 미리 설치 권장, 로그인은 없이도 되는지 수업 전 확인

  · 자막이 영상 끝까지 늘어남 → 텍스트 막대의 끝을 잡고 줄이기



# 준비 자료 (수강생 복사용)

※ 수업용 가상 브랜드 '톡톡레몬'의 영상 프롬프트입니다.
※ Flow → 글로 만들기, 기본 모델, 한 번에 1개, 세로 9:16

[01_등장]
레몬 조각이 꽂힌 투명한 탄산수 병 하나가 얼음 위에 서 있다.
배경은 밝은 노란색 스튜디오.
병 표면의 물방울이 천천히 흘러내린다.
카메라는 병을 향해 아주 천천히 다가간다.
상큼하고 시원한 여름 음료 광고 영상.

[02_상큼]
투명한 탄산수가 담긴 유리잔 위로 얇게 썬 레몬 조각 하나가 천천히 떨어진다.
레몬이 물에 닿는 순간 작은 기포들이 위로 터져 오른다.
배경은 밝은 노란색 스튜디오.
카메라는 고정.
상큼하고 시원한 여름 음료 광고 영상.

[03_마무리]
레몬 조각이 꽂힌 투명한 탄산수 병이 화면 가운데에 크게 서 있다.
병 뒤로 시원한 물보라가 부드럽게 퍼진다.
배경은 밝은 노란색 스튜디오.
카메라는 고정.
상큼하고 시원한 여름 음료 광고의 마지막 장면.
