# DAY 06
# 캐릭터 만들기 · 이모티콘 세트 · 4컷 만화


## 오늘의 수업

가게·기관·브랜드는 캐릭터 하나로 훨씬 친근해집니다.
하지만 AI로 캐릭터를 만들 때 가장 어려운 것은
"다음 그림에서도 같은 캐릭터로 나오게 하는 것"입니다.

오늘은 캐릭터를 기획하고, 설정표를 만들고,
같은 모습을 유지하는 요령을 익혀 이모티콘 세트를 만듭니다.
2교시에는 그 캐릭터로 홍보용 4컷 만화를 완성합니다.

도구 : Gemini (글·이미지), Google 슬라이드 (만화 칸 나누기·말풍선), CapCut (선택)

새봄스튜디오 의뢰 :
가상의 '햇살구립도서관'이 홍보 캐릭터를 원합니다.
"아이부터 어른까지 좋아할 캐릭터를 만들어 주세요.
그 캐릭터로 도서관 이용 안내 4컷 만화도 부탁해요."
※ '햇살구립도서관'은 수업용 가상 기관입니다. 자기 주제로 바꿔도 됩니다.


오늘은 다음 순서로 진행합니다.

# 1교시
# 캐릭터와 이모티콘


# 01. 좋은 캐릭터의 조건 (5분)

- 한눈에 기억나는 특징 1~2개 (예: 책갈피 모양 귀, 큰 동그란 안경)
- 단순한 모양 (여러 번 그려도 같은 모습이 나오기 쉬움)
- 정해진 색 2~3가지
- 성격이 있음 (표정과 행동이 정해짐)

※ 이미 있는 유명 캐릭터와 비슷하게 만들지 않습니다.

# 캐릭터 아이디어 받기 (10분)

주제 예시 (의뢰처 또는 자기 주제 하나 고르기)
- 햇살구립도서관 홍보 캐릭터
- 동네 빵집 마스코트
- 우리 회사·가게 캐릭터
- 반려동물을 닮은 캐릭터
- 지역 축제 캐릭터 (가상의 축제)
- 나를 닮은 캐릭터

작성 틀 (Gemini 새 채팅)
[어디 — 예: 구립 도서관]의 홍보 캐릭터를 만들려고 해.
주로 보는 사람: [예: 아이와 부모님]
전하고 싶은 느낌: [예: 친근하고 똑똑한, 조용하지만 다정한]
캐릭터 아이디어 5개를 [이름 / 생김새 / 특징 1~2개 / 성격 / 대표 색]으로 표로 정리해줘.
이미 있는 유명 캐릭터와 비슷하지 않게 해줘.

이어서 요청
"[몇 번] 아이디어가 좋아. 생김새를 그림으로 그리기 쉽게 더 구체적으로 적어줘."

→ 여기서 나온 생김새 설명이 "캐릭터 고정 문장"이 됩니다. 복사해 두기
  예) 둥근 몸통의 작은 부엉이, 크림색 몸에 남색 날개, 큰 동그란 안경,
      머리 위에 빨간 책갈피 모양 깃털, 짧은 다리


# 실습 SET 02
# 캐릭터 설정표 만들기 (10분)

설정표 = 한 캐릭터를 앞·옆·뒤에서 본 그림을 한 장에 모은 것
다음 그림을 만들 때 참고 이미지로 계속 씁니다.

작성 틀
다음 캐릭터의 설정표를 만들어줘.
[캐릭터 고정 문장]
앞모습, 옆모습, 뒷모습을 한 장에 나란히, 같은 크기로.
스타일: [예: 두꺼운 선의 귀여운 2D 일러스트, 단순한 색칠]
배경은 흰색, 글자는 넣지 말아줘.

확인하기
□ 앞·옆·뒤가 같은 캐릭터인가? (색, 안경, 깃털 위치)
□ 너무 복잡해서 다시 그리기 어려운 부분은 없나? → 있으면 "더 단순하게"

→ 다운로드 (이름 : 캐릭터_설정표)


# 02. 같은 캐릭터를 유지하는 요령 (5분)

① 캐릭터 고정 문장을 매번 붙이기 (복사 → 붙여넣기)
② 설정표 이미지를 참고 이미지로 함께 올리기
   "첨부한 캐릭터와 똑같은 모습으로 [장면]을 그려줘"
③ 스타일 문장도 매번 같게 (예: 두꺼운 선의 귀여운 2D 일러스트)
④ 한 번에 하나만 바꾸기 (표정만, 또는 동작만)
⑤ 너무 달라지면 싸우지 말고 새 채팅에서 설정표를 올려 다시 시작

# 실습 SET 04
# 이모티콘 세트 만들기 (12분)

이모티콘은 표정 + 동작 + 짧은 글자가 합쳐진 것입니다.

이모티콘 문구 예시 (6개 고르기)
안녕! / 고마워 / 최고! / 미안해 / 잘 자 / 파이팅 / 축하해 / 알겠어 / 헉! / 배고파

작성 틀
첨부한 캐릭터로 메신저 이모티콘 6개를 한 장에 만들어줘.
[캐릭터 고정 문장]
① [문구] — [동작 — 예: 날개를 흔들며 인사]
② [문구] — [동작]
③ ...
각 이모티콘 아래에 문구를 굵고 둥근 글씨로 넣고,
스티커처럼 흰 테두리, 배경은 흰색, 같은 크기로 나란히.

이어서 요청
- "[몇 번]만 동작을 더 크게"
- "글자가 틀린 [몇 번]은 글자 없이 다시" → 글자는 슬라이드에서 넣어도 됨

※ 실제 메신저에 판매·등록하려면 각 플랫폼의 AI 이미지 규정을 따로 확인해야 합니다.

# 03. 4컷 만화의 구조 (5분)

1컷  시작   : 누가, 어디서 (상황 소개)
2컷  전개   : 무슨 일이 생김
3컷  반전   : 예상 밖의 일, 또는 해결 방법 등장
4컷  마무리 : 웃음 포인트나 전하고 싶은 한마디

홍보 만화 팁
- 전하고 싶은 정보는 딱 1개 (예: "책은 2주 동안 빌릴 수 있어요")
- 대사는 한 칸에 1~2개, 짧게
- 마지막 칸에 정보가 자연스럽게 나오게


# 실습 SET 05
# 4컷 이야기 짜기 (10분)

주제 예시 (하나 고르기)
- 도서관 : 책 반납 날짜를 잊어버린 부엉이
- 도서관 : 도서관에서 조용히 해야 하는 이유
- 도서관 : 읽고 싶은 책을 찾는 방법
- 빵집 : 갓 구운 빵이 나오는 시간
- 일상 : 월요일 아침 알람과의 전쟁
- 일상 : 다이어트 결심과 야식

작성 틀 (Gemini)
[캐릭터 이름과 성격]이 나오는 4컷 만화를 짜줘.
주제: [주제]
전하고 싶은 것: [예: 책은 2주 동안 빌릴 수 있고, 연장도 된다]
읽는 사람: [예: 초등학생과 부모님]
칸마다 [장면 설명 / 대사(20자 이내) / 캐릭터 표정]을 표로 정리해줘.
마지막 칸에서 가볍게 웃을 수 있게 해줘.

이어서 요청
① "3컷 반전을 더 재밌게 다른 버전 2개"
② "대사를 더 짧게"
③ "칸마다 그림 요청에 쓸 장면 설명을 한 줄로 따로 정리해줘"

# 칸별 그림 만들기 (15분)

한 칸씩 만듭니다. (4칸을 한 장에 요청하면 캐릭터가 달라지기 쉬움)

작성 틀 (칸마다)
첨부한 캐릭터와 똑같은 모습으로 만화의 [몇 컷] 그림을 그려줘.
[캐릭터 고정 문장]
장면: [SET 05의 장면 설명]
표정: [표정]
[스타일 문장 — 예: 두꺼운 선의 귀여운 2D 일러스트, 단순한 배경]
정사각형, 말풍선과 글자는 넣지 말아줘. 위쪽에 말풍선 넣을 여백을 남겨줘.

확인하기
□ 4칸 모두 같은 캐릭터인가?
□ 4칸의 그림 스타일·색이 같은가?
□ 말풍선 넣을 빈자리가 있나?
□ 튀는 칸은 "1컷과 같은 스타일로" 다시 만들기


# 실습 SET 07
# 슬라이드로 칸 나누고 말풍선 넣기 (15분)

STEP 01 새 Google 슬라이드 → 이름 "06_4컷만화_이름"
STEP 02 파일 → 페이지 설정 → 맞춤 → 1080 × 1350 픽셀 (인스타 세로)
STEP 03 4칸 배치 : 이미지 4장을 2 × 2로 놓기 (칸 사이 흰 여백 똑같이)
        (세로로 1칸씩 길게 놓는 방식도 가능 — 휴대폰으로 볼 때 좋음)
STEP 04 칸마다 검은 테두리 : 이미지 선택 → 테두리 색·두께
STEP 05 말풍선 : 삽입 → 도형 → 설명선(말풍선 모양) → 흰색 채우기, 검은 테두리
STEP 06 대사 넣기 : 말풍선 안에 텍스트, 4칸 모두 같은 글꼴·크기
STEP 07 제목 한 줄 (맨 위) + 도서관 이름 (맨 아래, 작게)
STEP 08 파일 → 다운로드 → PNG 이미지

※ 막히면 Gemini에게 "Google 슬라이드에서 말풍선 도형을 넣는 순서를 알려줘"

최종 점검
□ 대사를 읽는 순서가 헷갈리지 않나? (왼쪽 위 → 오른쪽 위 → 왼쪽 아래 → 오른쪽 아래)
□ 말풍선이 캐릭터 얼굴을 가리지 않나?
□ 전하고 싶은 정보가 들어 있나?


# 실습 SET 08 (선택)

# 05. 오늘의 핵심

캐릭터는 "고정 문장 + 설정표 + 같은 스타일 문장"으로 유지합니다.
만화는 한 칸씩 만들고, 글자와 말풍선은 슬라이드에서 넣으면 정확합니다.
전하고 싶은 정보는 딱 하나, 마지막 칸에.

다음 시간(DAY 07)에는
Lyria로 가사가 있는 노래를 만들고, 그 노래에 맞춘 뮤직비디오를 만듭니다.


# 강사용 메모

- 줄여서 진행할 때 : SET 03(표정) 생략하고 바로 이모티콘, 이모티콘은 3개, 만화는 2 × 2 한 가지 배치만
- 빨리 끝난 사람 : SET 08 움직이는 만화 / 캐릭터로 도서관 안내 포스터 한 장
- 자주 막히는 곳
  · 캐릭터가 칸마다 달라짐 → 설정표를 매번 첨부, 같은 채팅 유지, 너무 꼬이면 새 채팅에서 설정표부터
  · 슬라이드에서 이미지가 칸 크기와 안 맞음 → 이미지 선택 → 자르기로 정사각형 맞추기
  · 말풍선 꼬리 방향 → 도형의 노란 점을 끌어서 말하는 캐릭터 쪽으로
