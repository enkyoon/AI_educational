# DAY 07
# 뮤직비디오 — 가사 · Lyria 노래 · 앨범 커버 · 장면 만들기 · 박자 맞춰 편집


## 오늘의 수업

오늘은 노래 한 곡을 직접 만들고,
그 노래에 맞춘 짧은 뮤직비디오를 완성합니다.

노래 만들기 자체는 금방 끝납니다.
진짜 중요한 것은 "노래의 흐름에 맞춰 어떤 장면을 보여 줄지" 정하는 일입니다.

도구 : Gemini (가사·음악 만들기·이미지), Google Flow (영상), CapCut (편집)
오늘 사용할 크레딧 : 영상 6~8개, 약 120크레딧 (기본 모델, 한 번에 1개 생성 기준)

새봄스튜디오 의뢰 :
오늘은 의뢰처 없이 스튜디오 자체 작품을 만듭니다.
"스튜디오 SNS에 올릴 30초짜리 뮤직비디오를 한 편씩 만들어 봅시다. 주제는 자유!"


오늘은 다음 순서로 진행합니다.

뮤직비디오 = 노래 + 장면 + 가사 자막
↓
주제 고르고 가사 쓰기
↓
Lyria로 노래 만들기 → 두 버전 비교
↓
앨범 커버
↓
노래에 맞춘 장면 구성표
↓
주인공 이미지 만들기
↓
Flow로 장면 만들기
↓
CapCut에서 박자 맞춰 편집
↓
가사 자막 넣고 내보내기



# 1교시
# 노래 만들고 장면 짜기


# 01. 뮤직비디오는 어떻게 만들까? (5분)

순서가 중요합니다. 노래를 먼저 만들고, 노래에 맞춰 장면을 만듭니다.

노래 (길이와 분위기가 정해짐)
↓
장면 구성 (가사 한 줄 ≒ 장면 하나)
↓
장면 영상 만들기
↓
편집 (박자에 맞춰 자르기 + 가사 자막)

※ Gemini에서 만드는 노래는 30초 안팎의 짧은 곡일 수 있습니다.
  (길이는 업데이트에 따라 다를 수 있음) → 30초 = 장면 4개 정도


# 실습 SET 01
# 주제 고르고 가사 쓰기 (10분)

주제 예시 (하나 고르기)
- 월요일 아침 출근길 응원가
- 우리 집 반려동물 노래
- 여름 바다 여행 노래
- 비 오는 날 창가의 잔잔한 노래
- 지난 시간에 만든 캐릭터의 테마송
- 동네 빵집 홍보 노래 (가상의 가게)

작성 틀 (Gemini 새 채팅)
[주제]에 대한 짧은 노래 가사를 써줘.
분위기: [예: 밝고 신나는]
듣는 사람: [예: 월요일 아침 지친 직장인]
구성: 1절 4줄 + 후렴 4줄
후렴은 따라 부르기 쉽게 같은 말을 반복해줘.
한 줄은 짧게 (15자 이내).

이어서 요청
① "후렴을 더 쉽게 따라 부를 수 있게"
② "1절에 [넣고 싶은 장면 — 예: 붐비는 지하철]을 넣어줘"
③ "줄마다 어울리는 장면을 한 줄씩 붙여줘"

※ 실제 노래 가사를 베끼거나 비슷하게 만들지 않습니다.


# 02. 음악 키워드 상자 (3분)

장르    : 밝은 팝 / 댄스 / 발라드 / 어쿠스틱 / 록 / 힙합 / 로파이 / 동요 / 트로트
빠르기  : 느리게 / 중간 / 빠르게
악기    : 피아노 / 어쿠스틱 기타 / 일렉 기타 / 신시사이저 / 드럼 / 현악기
목소리  : 맑은 여자 목소리 / 부드러운 남자 목소리 / 아이 목소리 / 합창
분위기  : 신나는 / 잔잔한 / 따뜻한 / 신비로운 / 씩씩한 / 몽환적인

※ "○○ 가수처럼" 대신 장르·빠르기·악기·목소리로 설명합니다.

STEP 01 노래 들으며 시간 적기 (5분)
노래를 틀고 가사가 바뀌는 시간을 적습니다.
예) 0~7초 : 1절 1~2줄 / 7~15초 : 1절 3~4줄 / 15~22초 : 후렴 앞 / 22~30초 : 후렴 뒤

STEP 02 장면 구성 받기 (Gemini, 10분)
작성 틀
[길이 — 예: 30초] 노래의 뮤직비디오를 만들려고 해.

노래 분위기: [분위기]
그림 스타일: [예: 밝은 파스텔 일러스트, 앨범 커버와 같게]
주인공: [예: 노란 우비를 입은 작은 캐릭터]
가사와 시간:
[STEP 01에서 적은 시간별 가사]
시간 구간마다 장면 1개씩, [시간 / 가사 / 화면에 보이는 것 / 주요 움직임 1개 / 카메라]를 표로 정리해줘.

이어서 요청 : "장면마다 카메라 움직임이 겹치지 않게"

장면 [개수]칸을 순서대로 한 장에, 칸 아래에는 장면 번호만."

# 03. 뮤직비디오에서 주인공 유지하기 (5분)

장면마다 주인공이 달라지면 다른 사람의 이야기처럼 보입니다.

① 주인공 이미지를 먼저 한 장 만들고
② 장면마다 시작 프레임(또는 재료)으로 그 이미지를 쓰고
③ "주인공 고정 문장 + 스타일 문장"을 매번 붙입니다.

(지난 시간에 만든 캐릭터가 있다면 그 캐릭터를 주인공으로 써도 됩니다. 선택)

# 실습 SET 07
# CapCut에서 박자 맞춰 편집하기 (12분)

STEP 01 새 프로젝트 9:16 → 노래와 장면 영상 불러오기
STEP 02 노래를 먼저 오디오 줄에 놓기 (노래가 기준입니다)
STEP 03 노래를 들으며 박자가 강한 곳에 표시하기
        - 오디오 선택 → 박자 표시(비트) 기능이 있으면 사용
        - 없으면 재생하면서 가사가 바뀌는 지점에 표시(마커) 넣기
STEP 04 표시한 지점에 맞춰 장면 영상 놓고 자르기
        - 장면이 바뀌는 순간 = 가사가 바뀌거나 박자가 강한 순간
        - 영상이 짧으면 속도를 조금 늦추거나(0.8배) 같은 장면을 한 번 더 써도 됨
STEP 05 처음부터 끝까지 재생 → 가장 어색한 곳 한 군데만 고치기


# 실습 SET 08
# 가사 자막 넣고 내보내기 (8분)

STEP 01 가사 자막
텍스트 → 가사 한 줄씩, 노래에 맞춰 나오게
- 가사가 시작되는 순간에 맞춰 자막 시작, 다음 줄이 시작되면 끝
- 모든 줄 같은 글꼴·색·위치 (화면 아래 1/4 정도, 버튼 영역은 피하기)
※ 자동 자막(가사 인식) 기능이 무료로 되면 써도 되지만, 틀린 글자는 꼭 고치기

STEP 02 시작과 끝
- 첫 화면에 노래 제목 1~2초 (앨범 커버를 첫 장면으로 넣어도 좋음)
- 마지막에 음악 페이드 아웃

STEP 03 내보내기 "07_뮤직비디오_이름" → 파일로 한 번 더 재생해서 확인

# 05. 오늘의 핵심

뮤직비디오는 노래가 먼저, 장면은 노래에 맞춰 만듭니다.
주인공은 "고정 문장 + 같은 이미지"로 유지하고,
편집에서는 노래의 박자와 가사가 바뀌는 순간에 장면을 바꿉니다.

다음 시간(DAY 08)에는
지금까지 배운 것 중 원하는 것을 골라, 나만의 콘텐츠를 처음부터 끝까지 만듭니다.


# 강사용 메모

- 크레딧 : 1인 약 120크레딧 예상 (장면 4개 + 다시 만들기 몇 개)
- 노래 길이·가사 반영 방식은 업데이트에 따라 다를 수 있으니 수업 전에 한 곡 만들어 보기
- 줄여서 진행할 때 : 버전 B 생략, 장면 3개, 박자 표시 대신 가사 바뀌는 곳에서만 자르기
- 빨리 끝난 사람 : 같은 노래로 가로 16:9 유튜브 버전 / 뮤직비디오 썸네일 만들기
- 자주 막히는 곳
  · 영상 장면 길이와 노래 구간이 안 맞음 → 영상을 늘리지 말고 자르기, 부족하면 같은 장면 반복·속도 조절
  · 가사 자막 타이밍 → 재생 막대를 가사 시작점에 두고 자막 막대 앞을 맞추기
