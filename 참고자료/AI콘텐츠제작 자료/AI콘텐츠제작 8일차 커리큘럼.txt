# 02. 주제 고르기 (5분)

주제 예시

# 03. 종류별 진행 순서 (참고용)

필요한 종류만 보면 됩니다. 요청문은 스스로 쓰고, 막히면 괄호 속 힌트를 봅니다.

A. 광고 영상
① Gemini로 장면 구성 3~4개 (장면마다 역할·움직임 1개·카메라)
② 제품 이미지 1장 → 장면별 첫 화면 이미지 (같은 제품 유지 문장)
③ Flow 시작 프레임으로 장면 영상 (기본 모델, 1개씩)
④ 광고 문구 (확인 안 된 효능 넣지 않기) + Lyria 배경음악
⑤ CapCut : 자르기 → 순서 → 자막 → 음악 → 내보내기
⑥ (선택) 썸네일

B. 인스타 카드뉴스
① Gemini로 5장 문구 (표지·본문·마무리, 장마다 짧게)
② 스타일 고정 문장 정하기 → 이미지 5장 (글자 자리 비우기)
③ Google 슬라이드 1080 × 1350 → 글자 넣기 → PNG로 저장
④ (선택) CapCut으로 이미지 릴스 + 배경음악

C. 캐릭터 만화
① 캐릭터 아이디어 → 캐릭터 고정 문장 → 설정표
② 4컷 이야기 (전할 정보 1개, 마지막 칸에)
③ 칸별 그림 (설정표 첨부, 한 칸씩)
④ Google 슬라이드로 칸 배치 + 말풍선 → PNG
⑤ (선택) 이모티콘 세트 / 움직이는 만화

D. 뮤직비디오
① 가사 (1절 + 후렴, 짧게) → Lyria 노래
② 노래 들으며 시간 적기 → 장면 구성 4개
③ 주인공 이미지 → 장면별 첫 화면 → Flow 장면 영상
④ CapCut : 노래 먼저 → 박자 맞춰 장면 → 가사 자막 → 내보내기
⑤ (선택) 앨범 커버

# 빨리 끝낸 사람을 위한 선택 과제

① 같은 콘텐츠를 다른 형태로 : 카드뉴스 → 릴스, 광고 영상 → 포스터, 만화 → 움직이는 만화
② 같은 영상을 다른 비율로 : 세로 9:16 → 가로 16:9 (글자 위치 다시 잡기)
③ 썸네일·앨범 커버·프로필 이미지 등 대표 이미지 만들기
④ 다른 종류 하나 더 : 오늘 고르지 않은 종류를 작게 만들어 보기

# 강사용 메모

- 발표는 하지 않습니다. 결과물은 제출로 마무리합니다.
- 크레딧 : 영상을 만드는 사람(A·D)만 약 60~120크레딧. 남은 크레딧을 SET 01 전에 확인하게 하기
- 1교시 초반 10분은 교실을 돌며 기획표 크기를 확인 (너무 크면 SET 01에서 줄이도록)
- 1교시 끝, 2교시 중간에 진행 상황 확인 → 늦은 사람은 선택 과제·장면 수 줄이기
- 뒤처진 사람 축소안 : A는 장면 2개 + 자막 1개, B는 카드 3장, C는 4컷 대신 2컷, D는 장면 3개·가사 자막은 후렴만
- 자주 막히는 곳 : 무엇을 만들지 못 고름 → B(카드뉴스)나 C(만화)를 권하고 주제 예시에서 바로 고르게 하기
