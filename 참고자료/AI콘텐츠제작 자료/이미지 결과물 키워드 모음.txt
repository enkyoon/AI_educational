          AI실무활용 DAY 05(슬라이드용 이미지)


■ 먼저 알아둘 것

- "/productshot" 같은 영어 키워드는 Gemini나 ChatGPT의 공식 명령어가 아닙니다.
  원하는 결과물의 방향을 짧게 알려 주는 "표현"일 뿐입니다.
- 수업에서는 초보자를 위해 우리말 이름을 먼저 쓰고, 영어 키워드는 괄호로 함께 보여 줍니다.
  "제품 사진처럼", "잡지 표지처럼"처럼 우리말로 써도 AI가 충분히 알아듣습니다.
- 키워드만 넣지 말고 대상·배경·구도·빛·색·분위기·용도를 함께 씁니다.
- 30개를 외우는 것이 목표가 아닙니다. "어떤 형태의 결과물이 필요한가?"를 먼저 생각하고 고릅니다.
- 여러 개를 섞어 써도 됩니다. (예: 제품 사진 + 가까이 + 영화 같은)
  결과물 종류 + 구도 + 스타일 + 세부 조건


■ 1. 결과물 형태 — "무엇으로 만들까"

우리말 이름            영어 키워드              쓰는 곳
제품 사진              /productshot /packshot    쇼핑몰 대표, 상세 페이지
생활 속 사진           /lifestyle shot           SNS, 브랜드 콘텐츠 (실제 쓰는 장면)
스튜디오 사진          /studio shot              깔끔한 배경의 제품·인물
패키지 디자인          /packaging                상자, 파우치, 병 라벨
실물처럼 보여 주기     /mockup                   로고·패키지·포스터가 실제 물건·공간에 적용된 모습
잡지 표지              /magazinecover            표지, 콘텐츠 대표 이미지 (제목 자리 남기기)
잡지 화보              /editorial                패션·뷰티·브랜드 분위기 이미지
포스터                 /poster                   행사, 축제, 캠페인
SNS 광고               /social ad /meta ad       인스타그램·페이스북 광고 (글자 자리 남기기)
홈페이지 첫 화면       /heroimage                웹사이트 대표 이미지 (가로, 한쪽 여백)
랜딩페이지 대표        /landingpage              서비스·상품 소개 페이지
썸네일                 /thumbnail                유튜브, 블로그 대표 화면
카탈로그               /catalog                  여러 제품을 정돈해서 보여 주기
룩북                   /lookbook                 한 콘셉트의 패션·제품 모음
전시하듯 보여 주기     /showcase                 신제품 발표, 포트폴리오
메뉴판 이미지          /menu                     카페·식당 메뉴
인포그래픽             /infographic              정보를 그림으로 정리 (글자는 따로 넣는 편이 정확)
전후 비교              /beforeafter              인테리어, 정리 전후 (효과를 과장하지 않기)
스토리보드             /storyboard               영상·광고의 장면 순서
옥외 광고판            /billboard                건물 외벽 광고판에 걸린 모습
3D 옥외 광고           /3d billboard             광고판 밖으로 튀어나오는 입체 광고


■ 2. 구도·거리 — "어떻게 보여 줄까" (DAY 02 구도 키워드와 같음)

가까이                 /closeup                  제품 디테일, 음식, 소재
아주 가까이            /macroshot                물방울, 질감, 작은 디테일
펼쳐 놓고 위에서       /flatlay                  화장품, 음식, 문구, 소품
여러 방향에서          /360view                  정면·양옆·뒷면을 한 화면에 (실제로 돌아가는 360도 영상이 아님)
비스듬히 내려다본 입체 /isometric                작은 매장, 사무실, 서비스 구조도


■ 3. 표현 방식 — "어떤 느낌으로"

영화 같은              /cinematic                극적인 조명, 광고·여행·이야기
3D 그래픽              /3d render                제품, 캐릭터, 테크 광고
배경 없는 물건만       /transparent background   디자인 재료, 슬라이드에 얹기
  ※ Gemini는 투명 배경이 잘 안 될 수 있음 → "흰 단색 배경"으로 요청하고, 필요하면 배경 지우기 기능 사용


■ 4. 자주 쓰는 조합 예시

① 제품 사진 + 가까이 + 영화 같은
   (/productshot /closeup /cinematic)
   검은색 향수병 하나. 어두운 대리석 테이블 위, 부드러운 측면광.
   검정과 골드 색감. 고급 향수 브랜드의 광고 사진처럼.

② 생활 속 사진 + 잡지 화보
   (/lifestyle shot /editorial)
   아침 햇살이 드는 화장대 위의 향수. 작은 거울과 액세서리.
   잡지 화보처럼 여백을 넓게, 향수는 한쪽에.

③ 3D 그래픽 + 전시하듯 + 홈페이지 첫 화면
   (/3d render /showcase /heroimage)
   원형 받침대 위의 향수병, 부드러운 조명.
   가로로 긴 화면, 제품은 오른쪽, 왼쪽은 제목·버튼 자리로 비워 두기.


■ 5. 같은 제품, 다른 결과물 (운동화 예)

제품 사진       → 운동화 자체를 깔끔하게
생활 속 사진    → 실제로 신고 달리는 장면
펼쳐 놓고 위에서 → 운동화와 양말·물병·이어폰을 가지런히
잡지 표지       → 표지 모델처럼, 위쪽에 제목 자리
SNS 광고        → 세로, 한쪽에 광고 문구 자리
3D 옥외 광고    → 도심 광고판 밖으로 튀어나오는 거대한 운동화

→ 이미지를 만들기 전에 "무엇을 그릴까?"뿐 아니라 "어떤 형태의 결과물이 필요할까?"를 먼저 생각합니다.


■ 6. 고치는 요청 기본형

현재 이미지에서 [유지할 것]은 그대로 유지해줘.
대신 [바꿀 것]을 [원하는 방향]으로 수정해줘.
나머지는 가능한 한 바꾸지 말아줘.


■ 7. 첨부 이미지를 먼저 분석받기 (참고 이미지를 쓸 때)

첨부한 이미지를 분석해줘.
제품 형태 / 주요 색상 / 제품 위치 / 배경 / 조명 / 전체 분위기를 알려줘.
아직 이미지는 수정하지 말아줘.

→ AI가 무엇을 보고 있는지 먼저 확인하면, 무엇을 유지하고 바꿀지 말하기 쉬워집니다.
