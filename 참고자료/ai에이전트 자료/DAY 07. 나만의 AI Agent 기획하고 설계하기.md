# DAY 07

# 나만의 AI Agent 기획하고 설계하기

## 오늘의 학습 목표

DAY 01부터 DAY 06까지는 준비된 예제를 이용해 Workflow와 AI Agent를 만들었습니다.

오늘부터는 만드는 순서가 달라집니다.

지금까지는

```text
예제 확인
↓
Node 추가
↓
설정
↓
실행
```

순서였다면,

오늘부터는

```text
문제 발견
↓
목표 정의
↓
Flow 설계
↓
필요한 기능 결정
↓
도구 선택
↓
구현
```

순서로 진행합니다.

오늘 수업이 끝나면 다음 내용을 할 수 있습니다.

* 자동화하고 싶은 문제를 구체적으로 설명
* 아이디어와 기능을 구분
* Input과 Output 정의
* 작업을 작은 단계로 분리
* User Flow 작성
* AI가 필요한 부분과 필요하지 않은 부분 구분
* Workflow와 AI Agent 중 적절한 구조 선택
* 필요한 Trigger, Node, Tool, 외부 서비스 결정
* GPT에게 전체 제작을 맡기지 않고 설계를 검토받는 방법
* 자신의 기획을 다른 사람에게 말로 설명
* 작성한 Flow를 바탕으로 n8n 프로젝트 기본 구조 제작

\---

# 만들기 전에 먼저 설계하기

## 01\. 이제부터는 정답이 없다

지금까지는 수업에서 목표가 정해져 있었습니다.

예:

```text
Google Sheets에 저장하기
```

```text
Gemini로 문의 분류하기
```

```text
Gmail 보내기
```

```text
Agent가 고객 정보 조회하기
```

하지만 실제로 혼자 자동화를 만들 때는 먼저 다음 질문부터 시작합니다.

> 무엇을 만들어야 하지?

이 질문에 답하는 것이 오늘의 핵심입니다.

\---

# 02\. 가장 먼저 프로그램을 켜지 않는다

자동화를 만들고 싶다고 바로 n8n을 실행하면 다음과 같은 문제가 생길 수 있습니다.

```text
어떤 Node를 써야 하지?
```

```text
어디서 시작해야 하지?
```

```text
Gemini부터 넣어야 하나?
```

```text
Agent를 써야 하나?
```

```text
Google Sheets는 어디에 연결하지?
```

기능부터 생각했기 때문입니다.

오늘은 먼저 **메모장이나 종이**를 사용합니다.

\---

# 03\. 도구보다 문제를 먼저 생각하기

다음 두 문장을 비교합니다.

### 시작 A

> n8n으로 뭘 만들지?

### 시작 B

> 내가 반복해서 하고 있는 일 중 자동화하면 편한 것은 무엇일까?

두 번째 질문이 더 중요합니다.

도구는 문제를 해결하기 위한 수단입니다.

# 08\. User Flow란?

User Flow는 사용자가 기능을 이용하면서 어떤 과정을 거치는지 순서대로 표현한 것입니다.

복잡한 그림부터 만들 필요는 없습니다.

메모장에 화살표만 사용해도 됩니다.

예:

```text
사용자가 문의 작성
↓
문의 내용 저장
↓
AI가 문의 분석
↓
문의 유형 판단
↓
담당자에게 전달
↓
사용자에게 접수 완료 안내
```

이 정도만 있어도 구현 방향을 잡을 수 있습니다.

```text

↓

↓

```

\---

```text

↓

↙   ↘

```

\---

## AI Workflow가 적합한 경우

AI가 특정 작업을 합니다.

```text
문의
↓
Gemini 요약
↓
Sheets 저장
```

\---

## AI Agent가 적합한 경우

사용자의 요청에 따라 필요한 행동 자체가 달라집니다.

```text
"김민지 찾아줘."
```

```text
"새 고객 등록해줘."
```

```text
"이 고객에게 이메일 보내줘."
```

↓

```text
Agent가 필요한 Tool 선택
```

# 14\. 구조 선택 체크

다음 질문에 답합니다.

### 실행 순서가 항상 같은가?

YES  
→ 일반 Workflow 검토

### 명확한 조건으로 나뉘는가?

YES  
→ IF / Switch 검토

### 자연어의 의미를 이해해야 하는가?

YES  
→ Gemini 사용 검토

### 요청마다 필요한 기능이 달라지는가?

YES  
→ AI Agent 검토
