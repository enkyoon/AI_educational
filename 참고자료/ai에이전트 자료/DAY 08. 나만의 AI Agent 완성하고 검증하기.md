# DAY 08  
# 나만의 AI Agent 완성하고 검증하기

## 오늘의 학습 목표

DAY 07에서는 자신이 만들고 싶은 자동화 또는 AI Agent를 직접 기획했습니다.

오늘은 그 설계를 실제 결과물로 완성합니다.

오늘 수업의 핵심은 새로운 기능을 많이 배우는 것이 아닙니다.

이미 배운 내용을 조합하여

```text
기획
↓
구현
↓
실행
↓
테스트
↓
오류 확인
↓
수정
↓
재테스트
↓
완성
```

과정을 직접 경험하는 것이 목표입니다.

오늘 수업이 끝나면 다음 내용을 할 수 있습니다.

- DAY 07 기획서를 바탕으로 Workflow 제작
- Workflow를 작은 단위로 나누어 구현
- Node별 Input과 Output 확인
- AI Prompt 수정 및 결과 품질 개선
- IF / Switch 분기 정상 작동 확인
- AI Agent의 Tool 선택 결과 확인
- 오류가 발생한 위치 추적
- 화면 캡처를 이용해 GPT에 문제 설명
- GPT 답변을 검증한 뒤 직접 수정
- 다양한 Test Case를 이용한 검증
- 실제 사용 전 위험 요소 확인
- 자신의 Workflow 또는 Agent 구조를 말로 설명
- 향후 혼자 기능을 확장하는 방법 이해

↓

```text

```

```text

2. ______________________
```

## COULD

시간이 남으면 시도

```text
1. ______________________

2. ______________________
```

# 23. 디버깅 Debugging

Debugging은 프로그램이나 Workflow에서 문제가 발생한 원인을 찾고 수정하는 과정입니다.

자동화에서 다음 순서를 사용할 수 있습니다.

```text
문제 발견
↓
문제 위치 찾기
↓
Input 확인
↓
설정 확인
↓
Output 확인
↓
수정
↓
다시 실행
```

---

# 24. 가장 중요한 디버깅 질문

어느 Node에서 문제가 생겼는가?

↓

그 Node의 Input은 무엇인가?

↓

그 Input은 정상인가?

↓

Node 설정은 정상인가?

↓

Output 또는 Error는 무엇인가?

↓

바로 앞 Node는 정상인가?
