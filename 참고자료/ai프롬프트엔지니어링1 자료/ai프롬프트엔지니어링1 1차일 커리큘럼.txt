# 1교시
# 생성형 AI의 이해와 AI 윤리


# 01. 생성형 AI란?

생성형 AI는
사용자의 요청을 바탕으로

새로운 결과물을 만들어주는
인공지능입니다.


예를 들어


글 작성

요약

아이디어 제안

이미지 생성

자료 정리

표 만들기

코드 작성

번역

질문 답변


등의 작업을 할 수 있습니다.


기존의 프로그램이

정해진 기능을 실행하는 도구

였다면


생성형 AI는

사용자가 자연어로 요청하면
그 요청을 해석하고
결과를 만들어주는 도구

라고 생각하면 이해하기 쉽습니다.



# 02. 우리가 사용하는 생성형 AI

대표적인 생성형 AI에는
다양한 서비스가 있습니다.


예


ChatGPT

Gemini

Claude

Microsoft Copilot


각각 사용할 수 있는 기능과
특징은 조금씩 다르지만

기본적으로는


사용자가 요청
↓
AI가 요청을 해석
↓
결과 생성
↓
사용자가 결과 확인
↓
필요하면 다시 수정 요청


과정을 반복합니다.


이번 과정에서는

ChatGPT

를 중심으로 실습합니다.



# 03. 생성형 AI는 무엇을 만들 수 있을까?

생성형 AI는
다양한 형태의 결과물을 만들 수 있습니다.


텍스트


- 이메일
- 보고서
- 기획안
- 광고문구
- 블로그 글
- 요약문


아이디어


- 상품 아이디어
- 콘텐츠 아이디어
- 행사 기획
- 제목 제안
- 문제 해결방법


자료


- 표
- 목록
- 체크리스트
- 일정표
- 비교자료


이미지


- 제품 이미지
- 광고 이미지
- 일러스트
- 콘텐츠 이미지


코드


- 간단한 웹페이지
- 프로그램 코드
- 데이터 처리


중요한 것은

AI가 특정 프로그램 하나를 대신하는 것이 아니라

여러 업무에서

'생각하고 만드는 과정을 도와주는 도구'

라는 점입니다.



# 04. AI는 어떻게 답변을 만들까?

ChatGPT는
사람처럼 생각해서 정답을 찾는 방식이라기보다

사용자가 입력한 내용을 바탕으로

어떤 내용이 이어질 가능성이 높은지 예측하며
결과를 만들어냅니다.


쉽게 생각하면


사용자의 요청

"직장인 대상으로 AI 교육을 기획해줘."


↓

AI가 요청의 의미와 맥락 파악


↓

관련된 내용을 조합


↓

새로운 결과 생성


과정으로 볼 수 있습니다.


그래서

AI가 자연스럽게 말한다고 해서
모든 내용이 항상 사실인 것은 아닙니다.



# 05. AI에게 질문하면 항상 같은 결과가 나올까?

같은 질문을 입력해도

표현이나 구성,
추천하는 내용이 조금씩 달라질 수 있습니다.


또한 사용자가 어떤 정보를 제공하는지에 따라
결과도 달라집니다.


예를 들어


"여행 계획 만들어줘."


라고 요청하는 것과


"부산으로 2박 3일 여행을 갈 거야.
대중교통을 이용하고
카페와 맛집 중심으로 일정을 만들어줘."


라고 요청하는 것은
결과가 달라질 수 있습니다.


오늘은

AI에게 요청하면 결과가 달라질 수 있다는 점

정도만 먼저 이해합니다.


구체적인 프롬프트 작성방법은
다음 시간에 자세히 학습합니다.



# 06. 생성형 AI가 잘하는 일

AI가 특히 유용한 영역이 있습니다.


## 초안 만들기

출발점을 만들어줍니다.


## 내용 정리하기

긴 내용을
요약하거나 구조화할 수 있습니다.


## 아이디어 확장하기

하나의 아이디어에서
여러 방향을 제안받을 수 있습니다.


## 형태 바꾸기

긴 글을

표 /
목록 /
발표자료 /
이메일

등으로 바꿀 수 있습니다.


## 반복 수정하기

결과를 보고

더 짧게

더 쉽게

표로

전문적으로

등의 요청을 계속할 수 있습니다.



# 07. 생성형 AI가 어려워하는 일

AI를 사용할 때
주의해야 하는 부분도 있습니다.


AI는 때때로


사실이 아닌 내용을 자연스럽게 작성하거나

최신 정보가 필요한 질문에서
부정확한 내용을 제공하거나

사용자가 제공하지 않은 정보를
추측하거나

복잡한 상황을 지나치게 단순화할 수 있습니다.


따라서

AI의 답변

=

무조건적인 정답


이라고 생각하면 안 됩니다.


특히 중요한 정보는

사람이 다시 확인하는 과정

이 필요합니다.



# 08. AI를 사용하는 사람의 역할

AI가 많은 작업을 도와줄 수 있지만

최종적으로 판단하는 사람은
사용자입니다.


AI의 역할


아이디어 제안

초안 작성

내용 정리

다른 관점 제안

반복 작업 지원


사용자의 역할


목적 정하기

필요한 정보 제공하기

결과 확인하기

틀린 내용 찾기

필요한 결과 선택하기

최종 판단하기


즉,


AI가 만든다

+

사람이 판단한다


과정이 함께 필요합니다.



# 09. AI 윤리란?

AI를 잘 사용한다는 것은

좋은 결과를 만드는 것뿐만 아니라

안전하고 책임감 있게 사용하는 것

도 포함합니다.


오늘은 다음 네 가지를 기억합니다.


① 개인정보와 중요한 정보


② AI 결과의 사실 확인


③ 저작권과 다른 사람의 결과물


④ 편향된 결과와 사람의 판단



# 10. 개인정보와 중요한 정보 입력하기

AI에게 정보를 입력하기 전에

를 먼저 생각합니다.


주의해야 할 정보 예시


- 주민등록번호
- 계좌번호
- 비밀번호
- 연락처
- 고객 개인정보
- 환자 개인정보
- 학생 개인정보
- 회사 내부 기밀자료
- 공개되지 않은 계약내용


업무에서 AI를 사용한다면

회사나 기관의
AI 사용규정도 확인해야 합니다.

# 12. AI의 결과를 그대로 믿지 않기

AI가 다음과 같이 말한다고 생각해봅니다.

생성형 AI 교육을 원합니다."


숫자가 구체적이라고 해서
사실이라는 의미는 아닙니다.


중요한 정보라면


출처가 있는가?

언제 조사했는가?

누구를 조사했는가?

원문에서 확인할 수 있는가?


를 확인합니다.



# 13. 저작권과 AI 활용

AI를 사용한다고 해서

다른 사람이 만든 결과물을
마음대로 사용할 수 있는 것은 아닙니다.


예를 들어


다른 사람의 글 전체를 그대로 사용하기

유료 자료를 그대로 복제하기

타인의 콘텐츠를 본인이 만든 것처럼 사용하기

특정 창작물을 그대로 복제하여 상업적으로 활용하기


등은 주의가 필요합니다.


AI를 활용할 때도

출처와 사용 목적을 확인하고

필요하면
직접 수정하고 재구성하는 과정이 필요합니다.



# 14. AI의 편향 생각하기

AI가 제안한 결과에도
특정 관점이나 편향이 나타날 수 있습니다.


예를 들어


"좋은 직장인의 특징을 알려줘."


라고 질문했을 때

AI가 제시한 특징이
모든 직장이나 사람에게
동일하게 적용되는 것은 아닙니다.


따라서


AI가 왜 이런 결과를 제안했는지

다른 관점은 없는지

내 상황에도 적절한지


사람이 다시 생각해야 합니다.

# 37. 오늘의 핵심

오늘 가장 먼저 기억할 것은

생성형 AI는

'무조건 정답을 알려주는 도구'

가 아니라

'사용자의 요청을 바탕으로
새로운 결과를 만들어주는 도구'

라는 점입니다.


따라서


AI에게 요청하기

↓

AI가 결과 만들기

↓

사람이 확인하기

↓

필요하면 수정하기

↓

최종적으로 사람이 판단하기


과정이 필요합니다.


AI를 사용할 때는


개인정보와 중요한 정보 주의하기

AI의 결과를 그대로 믿지 않기

중요한 내용은 다시 확인하기

AI의 결과를 내가 판단하기


를 기억합니다.


그리고 ChatGPT에서는

한 번 질문하고 끝내는 것이 아니라


질문
↓
결과 확인
↓
추가 요청
↓
수정
↓
발전


과정을 반복할 수 있습니다.


오늘은

'ChatGPT를 사용할 준비'

를 했다면

다음 시간에는

'ChatGPT에게 어떻게 요청해야
내가 원하는 결과에 가까워지는가'

를 배우게 됩니다.
