# Claude 주요 기능 간단하게 살펴보기

### Claude란?

자연어로 질문하거나 원하는 작업을 요청하여 텍스트·코드·문서·아이디어 등의 결과를 생성할 수 있는 생성형 AI

웹코딩 활용 예시)

* 웹사이트 아이디어 정리하기
* 사이트 구성 기획하기
* 코딩 개념 질문하기
* 코드 설명받기
* 오류 원인 확인하기
* 디자인 방향 제안받기

### 기본 화면에서 확인할 것

**채팅 입력창**
→ Claude에게 질문과 작업 요청하기

**대화 목록**
→ 이전에 진행했던 대화 다시 확인하기

**파일 / 이미지 첨부**
→ 문서·코드·이미지 등을 함께 전달하기

**Projects**
→ 하나의 프로젝트에 필요한 자료와 작업지침 관리하기

**Artifacts**
→ Claude가 생성한 코드나 결과물을 별도의 결과 형태로 확인하기

# Claude 사용량 한도 이해하기

### Claude는 무제한으로 사용할 수 있는가?

Claude는 사용하고 있는 플랜에 따라 사용할 수 있는 양에 제한이 있음

단순히

**“하루에 질문 100번”**

처럼 메시지 개수만으로 정해지는 방식은 아님

사용량에 영향을 주는 요소

* 대화의 길이
* 입력한 내용의 양
* 첨부파일
* 사용하는 모델
* Effort 설정
* 사용하는 기능
* 대화에 누적된 내용
* Claude Code 작업량

Claude 웹과 Claude Code 등 같은 Claude 계정에서 사용하는 서비스의 사용량은 동일한 플랜 사용량 한도에 함께 포함될 수 있음

### 주요 사용량 한도

**세션 사용량 한도**

일정 시간 동안 사용할 수 있는 사용량

→ 일반적인 유료 플랜에서는 **5시간 단위의 세션 사용량 한도** 적용

**주간 사용량 한도**

한 주 동안 사용할 수 있는 전체 사용량

→ 플랜에 따라 사용 가능한 양 차이 발생

그 외 서비스 상황이나 플랜에 따라 추가적인 모델별·기능별 제한이 적용될 수 있음

### ※ 주의

Claude의 기본 사용량을

**일간 + 주간 + 월간의 세 가지 고정 한도**

라고 단순하게 이해하지 않기

**세션 사용량 한도 + 주간 한도 + 플랜별 추가 제한**

형태로 이해하기

# 사용 크레딧이란?

### 기본 사용량을 모두 사용했을 경우

지원되는 유료 Claude 플랜에서는 기본 사용량을 모두 사용한 이후 **사용 크레딧(Usage Credits)**을 이용하여 추가 비용을 지불하고 계속 사용할 수 있음

기본 플랜 사용량
↓
사용량 한도 도달
↓
사용 크레딧 사용
↓
추가 사용량에 대해 종량제 방식으로 계속 이용

사용 크레딧을 사용하지 않는 경우
↓
기본 사용량이 다시 초기화된 후 이용

### 사용 크레딧과 토큰은 같은 것인가?

**사용 크레딧 ≠ 토큰**

**토큰(Token)**
→ AI가 글자와 문장을 처리하기 위해 내용을 잘게 나눈 기술적인 데이터 단위

**사용 크레딧(Usage Credits)**
→ 기본 플랜 사용량을 초과하여 Claude를 추가 이용할 때 사용하는 결제·사용 방식

API에서는 실제 처리한 토큰 수가 비용 계산의 중요한 기준이 되지만

Claude 유료 플랜에서 추가 사용과 관련된 사용자용 공식 표현은 **사용 크레딧**

### 수업에서 기억할 것

**Claude는 무제한 서비스 X**

**현재 사용량을 확인하면서 작업하기**

특히 여러 파일을 읽고 수정하는 Claude Code 작업은 단순한 짧은 질문보다 사용량이 빠르게 증가할 수 있음

# 웹 Claude Code의 큰 장점

### 별도의 Local 개발환경 없이 작업 가능

내 컴퓨터에 프로젝트를 직접 Clone하거나 개발환경을 모두 구성하지 않아도 GitHub Repository를 연결하여 작업 가능

### 작업을 맡겨두고 다른 일을 할 수 있음

작업 요청
↓
Claude가 원격 환경에서 작업
↓
사용자는 다른 작업 진행
↓
완료 후 결과 검토

### 여러 작업을 동시에 진행하기 편리

서로 다른 작업을 각각 독립적인 환경에서 실행 가능

### 명확하게 정해진 작업에 강점

예시)

* 특정 오류 수정하기
* 반복적인 코드 정리하기
* 기존 프로젝트의 작은 기능 추가하기
* 특정 파일 리팩터링하기

**웹 Claude Code = 작업내용을 명확하게 전달하고 결과를 나중에 확인하는 방식에 강점**

Claude Code 웹은 GitHub Repository를 클라우드 환경으로 가져와 작업하며, 자주 개입할 필요가 없는 작업이나 병렬작업에 적합하게 설계되어 있음.

# Git을 설치하는 이유

### VS Code가 있는데 Git은 왜 따로 설치해야 할까?

VS Code에는 Source Control이라는 Git 관리 화면이 기본으로 존재

하지만

**VS Code 자체가 Git 프로그램을 대신하는 것은 아님**

VS Code는 컴퓨터에 설치되어 있는 Git을 이용하여

* 변경내용 확인
* Stage
* Commit
* Clone
* Push
* Pull

등의 작업 수행

따라서 Git 기반으로 프로젝트를 관리하려면 컴퓨터에 Git 설치 필요

VS Code 공식 문서에서도 Source Control 기능은 컴퓨터에 설치된 Git을 이용한다고 안내하고 있음.

### 쉽게 비유하기

**Git = 실제로 기록을 처리하는 엔진**

**VS Code Source Control = Git을 조작하는 운전대와 계기판**

VS Code에 화면은 존재하지만

실제 버전관리 기능은 Git이 수행

### 이번 수업에서 Git을 설치하는 이유

Claude Code 설치 때문 X

**프로젝트의 변경내용을 기록하고 GitHub와 연결하기 위해 설치 O**

# Git이란?

### Git의 역할

프로젝트 파일이 어떻게 변경되었는지 내 컴퓨터에서 기록하고 관리하는 **버전 관리 프로그램**

예시)

첫 웹페이지 제작
↓
Git으로 기록
↓
버튼 추가
↓
Git으로 기록
↓
디자인 수정
↓
Git으로 기록

### Git을 사용하지 않는 경우

`최종.html`
↓
`최종수정.html`
↓
`진짜최종.html`
↓
`진짜진짜최종.html`

### Git을 사용하는 경우

하나의 프로젝트 유지

*

수정한 시점마다 변경내용 기록

**여러 개의 복사본을 만들지 않고 하나의 프로젝트 안에서 작업이력 관리하기**

#

# Git과 GitHub의 차이

### Git

**내 컴퓨터에서 프로젝트의 변경내용을 기록하는 프로그램**

주요 역할

* 파일 변경 확인하기
* 작업이력 기록하기
* Commit 만들기
* 이전 변경내용 확인하기

인터넷이 없어도 기본적인 Local 버전관리 가능

쉽게 표현하면

**Git = 개인 작업일지**

---

### GitHub

**Git으로 관리하는 프로젝트를 인터넷에 저장하고 공유하는 온라인 서비스**

주요 역할

* 프로젝트 온라인 저장하기
* 다른 컴퓨터에서 가져오기
* 프로젝트 공유하기
* 협업하기
* 온라인에서 변경이력 확인하기

쉽게 표현하면

**GitHub = 작업일지를 저장하고 공유하는 온라인 공간**

### 가장 중요한 차이

Git 설치 = GitHub 설치 X

GitHub 계정 생성 = Git 설치 X

**Git과 GitHub는 서로 다른 도구**

| 구분    | Git         | GitHub     |
| ----- | ----------- | ---------- |
| 형태    | 프로그램        | 온라인 서비스    |
| 위치    | 내 컴퓨터       | 인터넷        |
| 핵심 역할 | 변경내용 기록     | 프로젝트 저장·공유 |
| 대표 기능 | Commit      | Repository |
| 인터넷   | 기본 기록에는 불필요 | 필요         |

**Local → GitHub**

### Pull

**GitHub → Local**

### 방향으로 기억하기

**Push = 내 작업을 GitHub로 보내기**

**Pull = GitHub의 작업을 내 컴퓨터로 가져오기**

# DAY 02 수업내용 정리

### 오늘의 핵심 키워드

**Claude**
일반적인 질문·기획·분석 등에 활용하는 생성형 AI

**사용량 한도**
플랜에 따라 일정 기간 사용할 수 있는 Claude의 사용량 범위

**사용 크레딧**
기본 사용량을 초과한 뒤 추가 비용으로 계속 이용할 때 사용하는 방식

**Token**
AI가 입력·출력 정보를 처리하는 기술적인 데이터 단위

**Claude Code**
실제 프로젝트의 파일을 읽고 생성·수정할 수 있는 AI 코딩도구

**웹 Claude Code**
GitHub Repository를 Cloud 환경에서 처리하며 코딩작업을 맡길 수 있는 방식

**VS Code**
실제 Local 프로젝트를 작성하고 관리하는 개발 작업공간

**Claude Code for VS Code**
VS Code 안에서 Claude Code를 사용할 수 있도록 하는 확장 프로그램

**Korean Language Pack**
VS Code의 인터페이스를 한국어로 변경하는 확장 프로그램

**Live Server**
웹페이지를 Local Server에서 실행하고 결과를 빠르게 확인하기 위한 확장 프로그램

**Git**
내 컴퓨터에서 프로젝트 변경내용과 작업이력을 기록하는 프로그램

**GitHub**
Git으로 관리한 프로젝트를 온라인에서 저장하고 공유하는 서비스

**Repository**
하나의 프로젝트를 관리하는 저장공간

**Local**
내 컴퓨터의 프로젝트

**Remote**
GitHub의 온라인 프로젝트

**Clone**
GitHub 프로젝트를 내 컴퓨터로 가져오기

**Stage**
Commit에 포함할 변경내용 준비하기

**Commit**
현재 작업상태 기록하기

**Push**
Local의 작업기록을 GitHub로 보내기

**Pull**
GitHub 변경내용을 Local로 가져오기

### 핵심 역할 구분

**Claude = 일반적인 AI 작업**

**웹 Claude Code = 원격환경에서 코딩작업 맡기기**

**VS Code = 내 컴퓨터의 실제 개발 작업공간**

**Claude Code = VS Code 안에서 함께 코딩하는 AI**

**Live Server = 웹페이지 결과 바로 확인하기**

**Git = 작업 변경이력 기록**

**GitHub = 프로젝트 온라인 저장**
