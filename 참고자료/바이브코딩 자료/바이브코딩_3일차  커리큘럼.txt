# 실습 STEP 01
# 사진 묶음 받기 · 파일 이름 정리 명령 (10분)

① 페이지의 [사진 묶음 내려받기] → 압축 풀기
② VS Code에서 새 폴더 mellow-bean 열기 → 그 안에 받은사진 폴더를 만들고 사진 7장 넣기
③ 사진 이름이 엉망인 것을 확인 (IMG_2041.jpg, 라떼사진 최종.jpg, tiramisu (1).jpg, 에이드.JPG …)

왜 이름부터 정리할까
- 웹에서는 한글 · 띄어쓰기 · 괄호가 들어간 파일 이름이 깨지거나 경로 오류의 원인이 된다
- 대문자 .JPG와 소문자 .jpg는 서버에서 다른 파일이다 (DAY 08에서 다시 만남)
- 규칙 : 영어 소문자 · 단어 사이는 - · 무엇인지 알 수 있는 이름

### 프롬프트 01 — Claude Code에 입력하기

받은사진 폴더에 카페 사진 7장이 있어.
사진을 하나씩 직접 열어 보고 무엇을 찍은 사진인지 확인해줘.
그 다음 images 폴더를 새로 만들어서, 웹사이트에서 쓰기 좋은 이름으로 알아서 바꿔 복사해줘. 봐도 무엇을 찍은 사진인지 알 수 있게 지어줘. 사진은 메뉴 이름에 맞춰줘. 메뉴는 Cream Latte, Classic Tiramisu, Mellow Ade(레몬 에이드), Strawberry Latte(딸기 음료)야. 사진은 첫 화면에, 매장 내부 사진은 소개에 쓸 거야.
KakaoTalk으로 시작하는 PNG 파일은 아직 옮기지 마. (뒤에서 따로 쓸 거야)
받은사진 폴더의 원본은 지우지 마.
끝나면 "원래 이름 → 새 이름 → 무엇을 찍은 사진인지" 표로 알려주고, 그렇게 지은 이유도 한 줄로 알려줘.

파일 이름은 학생이 정하지 않고 AI에게 맡긴다 (2026-11-25 사용자 확정) — 이름을 알아서 잘 짓고, 학생이 "파일 이름 관리까지 맡길 수 있다"는 것을 느끼게 하려고. 새 이름은 사람마다 조금 다를 수 있으니 이후 프롬프트는 파일 이름 대신 "핸드드립 사진", "매장 내부 사진"처럼 내용으로 가리킨다. 바꾸고 싶은 이름은 "○○ 사진 이름을 △△로 바꿔줘".

확인하기 : images 폴더 6장 / 원본은 그대로 / 이름만 보고 무슨 사진인지 알 수 있는가 / 표에서 짝이 맞는지 직접 사진을 열어 확인
핵심 — Claude Code는 코드만 쓰는 게 아니라 내 컴퓨터의 파일 · 폴더 일도 한다. 단, 지우는 일은 항상 "지우지 마" 또는 "지우기 전에 물어봐"를 붙인다.

# 02. 왜 AI가 만든 사이트는 다 비슷해 보일까 (5분)

"깔끔하고 따뜻한 카페 사이트 만들어줘" → AI는 가장 흔한 답을 낸다.
AI 티가 나는 모양 (점검표 — STEP 04에서 다시 씀)
- 무엇이든 둥근 카드 3개 + 약한 그림자 + 마우스를 올리면 살짝 뜨는 효과
- 보라 · 파랑 그라데이션, 반짝이는 배경, 이모지 아이콘
- 모든 글자가 가운데 정렬
- "Welcome to ○○", "Discover", "Experience the best" 같은 빈 문구
- 실제로 없는 기능의 버튼 (지도 보기, 예약하기, 더 알아보기)
- 크림색 배경 + 갈색 글자 + 둥근 버튼 (카페라고 하면 거의 항상)

해결 — AI에게 후보를 받고, 고르는 건 내가 한다 (2026-11-25 변경)
비전문가가 색 코드 · 배치를 처음부터 정하기는 어렵다. 그렇다고 "추천해줘" 한 번이면 AI는 또 가장 흔한 답 하나를 준다.
→ 서로 다른 후보를 여러 개(3가지) 받기 / 후보마다 어떤 느낌인지 설명 붙이게 하기 / 흔한 조합(크림 + 갈색)은 빼 달라고 하기 / 고르는 것은 학생
X "따뜻하고 깔끔한 느낌으로 만들어줘" / O "동네 골목의 조용한 로스터리에 어울리는 색 조합을 3가지 추천해줘. 배경 · 글자 · 포인트 색 코드와 어떤 느낌인지 한 줄씩. 크림색 + 갈색 조합은 빼줘." → 하나 고르기
X "예쁜 메뉴 카드로 보여줘" / O "카페 메뉴 4개를 보여 주는 방법을 3가지 추천해줘. 각각 어떻게 생겼는지, 어떤 가게에 어울리는지 설명해줘." → 오늘은 메뉴판 한 줄 방식
X "감성적인 소개 문구 써줘" / O "우리 가게 사실은 이거야: 테이블 여섯 개, 화요일과 금요일에 원두를 볶음, 골목 안쪽. 이걸로 첫 화면 문구를 3개 써줘. 없는 이야기는 지어내지 마." → 하나 고르고 내 말투로 고치기
가게의 사실은 학생만 안다 — 사실은 내가 주고, 문장 다듬기만 AI에게.

# Claude Code와 디자인 회의하고 디자인노트.md 남기기 (10분)

2026-11-25 변경 — 디자인노트 내용을 작성 틀로 주지 않고, Claude Code가 진행하는 "디자인 회의"로 정한다.
Claude Code가 하나씩 묻고 후보 3가지를 보여 주면 학생은 고르기만 한다. 회의가 끝나면 Claude Code가 디자인노트.md를 저장.

md 파일 : 제목(#)과 목록(-)만 쓰면 되는 메모 파일. 이 메모를 AI가 매번 자동으로 읽게 하면 DAY 06의 CLAUDE.md.

### 프롬프트 — 디자인 회의 시작하기
MELLOW BEAN이라는 작은 카페의 한 페이지 웹사이트를 만들기 전에, 디자인을 정하는 회의를 하고 싶어.
네가 진행자가 되어 나에게 질문을 하나씩 해줘. 한 번에 하나만 묻고, 내 대답을 들은 뒤 다음으로 넘어가.
■ 정할 것 (이 순서로)
1. 분위기 — 어떤 가게처럼 보이면 좋을지
2. 색 — 배경 · 글자 · 포인트 3가지
3. 글꼴 — 제목용 · 본문용 2가지 (Google Fonts에서 무료로 쓸 수 있는 한국어 글꼴)
4. 하지 않을 것 — 이 사이트에서 쓰지 않을 디자인
■ 회의 방식
- 질문할 때마다 서로 분위기가 다른 후보를 3가지씩 보여주고, 각각 어떤 느낌인지 한 줄로 설명해줘. 색은 색 코드도 같이.
- 크림색 + 갈색처럼 카페 사이트에 너무 흔한 조합은 후보에서 빼줘.
- 내가 고르기 어려워하면 후보를 비교해서 설명해줘. 결정은 내가 할게.
네 가지가 다 정해지면 디자인노트.md 파일로 정리해서 저장하고, 정한 내용을 짧게 보여줘.
아직 웹사이트 파일은 만들지 마.

진행 : 요청 보내기 → 질문 · 후보 3가지 → 번호("2번") · 섞기("1번 배경에 3번 포인트") · 내 말("조금 더 밝게")로 답하기 → 네 가지 반복 → 탐색기에서 디자인노트.md 열어 확인
다시 볼 때 : "포인트 색만 후보를 다시 보여줘" / 비교 : "1번과 2번 색 조합은 어떤 가게에 더 어울려?" / 나중에 바꿀 때 : "디자인노트.md에서 글꼴만 다시 정하자"
회의가 끝나면 생기는 파일 예시(접어 둠) = 완성 예시 사이트의 디자인노트 (분위기 · 색 3개 · 글꼴 2개 · 하지 않을 것)
고를 때 팁 — 배경은 아주 연한 색, 글자는 아주 진한 색, 포인트는 하나. 정한 내용이 사람마다 달라 완성 사이트가 서로 다른 것이 정상.
강사 메모 — 회의가 길어지는 학생은 접힌 예시를 디자인노트.md에 그대로 붙여 넣고 STEP 03으로. 결석생도 같은 방법.

# 실습 STEP 05
# 사진 명령 — 줄이기 · 추가 · 교체 · 삭제 · 자르기 (15분)

Claude Code는 사진을 "그리는" 도구가 아니다. 대신 이미 있는 사진의 크기 · 형식 · 이름 · 자르기 · 위치를 명령으로 바꿀 수 있다.
(배경 지우기, 사진 속 물건 바꾸기 같은 편집은 이미지 생성 AI의 일)
학원 PC는 Windows라 Claude Code가 PowerShell 등으로 처리한다. 프로그램 설치를 묻는 경우 내용을 읽고 허락.

① 용량 확인 — KakaoTalk_20261118_143052.png는 약 2.8MB, 다른 사진은 0.1~0.3MB
   (DAY 04 트래픽 예고 : 사진이 크면 사이트가 느려지고 비용이 든다)

### 프롬프트 04 — 줄여서 추가하기

받은사진 폴더의 KakaoTalk_20261118_143052.png는 카푸치노 사진이야.
가로 800px로 줄이고 JPG로 바꿔서 images 폴더에 저장해줘. 이름은 다른 사진들과 같은 방식으로 지어줘. 원본은 지우지 마.
바꾸기 전과 후의 용량을 알려줘.
그 다음 메뉴 두 번째 줄에 Cappuccino · 쿠키 한 조각을 곁들여 내는 진한 카푸치노 · 5,500 을 추가해줘.
다른 메뉴 줄과 똑같은 모양으로 만들고, 다른 Section은 바꾸지 마.

### 프롬프트 05 — 교체 · 자르기 · 삭제 (하나씩 해 보기)
- 교체 : "첫 화면 사진을 매장 내부 사진으로, 소개 Section 사진을 핸드드립 사진으로 바꿔줘. 크기와 배치는 그대로" → 마음에 안 들면 "방금 바꾼 것 되돌려줘"
- 자르기 : "매장 내부 사진을 가운데 기준으로 가로세로 4:3으로 잘라서 새 파일로 저장하고 소개 Section에 써줘. 새 파일 이름은 알아서 짓고, 원본은 그대로"
- 삭제 : "메뉴에서 Mellow Ade 줄의 사진만 빼고, 사진 자리에는 아무것도 두지 마" → 확인 후 "다시 원래대로"
- 정리 : "images 폴더에서 지금 사이트에서 쓰지 않는 사진을 찾아서 목록만 보여줘. 지우지는 마"

경로 한 줄 — 예를 들어 코드 안의 images/cappuccino.jpg는 "index.html이 있는 폴더 안의 images 폴더"라는 뜻(상대 경로). 사진이 안 보이면 거의 항상 이름이나 폴더가 다르다.

### 사진이 안 보일 때 프롬프트
카푸치노 사진이 화면에 보이지 않아. images 폴더의 실제 파일 이름과 HTML에 적힌 경로를 비교해서 다른 곳을 찾아줘. 사진과 관련 없는 코드는 고치지 마.
