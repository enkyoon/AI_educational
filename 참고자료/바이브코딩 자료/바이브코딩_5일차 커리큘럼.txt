# MVP란?

### MVP (Minimum Viable Product, 최소 기능 제품)

프로젝트가 목적을 달성하기 위해 반드시 필요한 기능만 갖춘 첫 번째 완성본

### 예시

카페 웹사이트

**Must Have**

- 카페 소개
- 메뉴 확인
- 위치 확인
- 문의 작성

**Nice to Have**

- 메뉴 검색
- 이미지 슬라이드
- 복잡한 애니메이션
- 좋아요 기능

### 핵심

처음부터 모든 기능을 만들지 않기

**필요한 기능을 먼저 완성하고 시간이 남으면 기능을 추가하기**

# DAY 05 수업내용 정리

### 오늘의 핵심 용어

**MVP (Minimum Viable Product, 최소 기능 제품)**

서비스 목적을 달성하기 위해 반드시 필요한 핵심기능만 갖춘 첫 번째 완성본

**Must Have (필수 기능)**

프로젝트 완성을 위해 반드시 구현해야 하는 기능

**Nice to Have (선택 기능)**

시간이 남으면 추가할 수 있는 기능

**User Flow (사용자 흐름)**

사용자가 목표를 달성하기까지 거치는 행동의 흐름

**Screen Flow (화면 흐름)**

사용자의 행동에 따라 화면이나 Section이 연결되는 흐름

**Wireframe (화면 설계도)**

최종 디자인 전에 콘텐츠와 기능의 위치를 결정하는 화면 구조
