# Header란?

### Header (헤더, 웹페이지의 상단 영역)

웹페이지 가장 위쪽에 위치하는 영역

주로

- Logo
- Navigation
- 로그인
- 문의 버튼
- 메뉴 버튼

등이 위치

### 예시

┌─────────────────────────────────┐
│ MELLOW     ABOUT  MENU  CONTACT │
└─────────────────────────────────┘

전체 영역

→ Header

ABOUT / MENU / CONTACT

→ Navigation

---

# Navigation이란?

### Navigation (내비게이션, 페이지 이동 메뉴)

사용자가 웹사이트의 주요 페이지나 Section으로 이동할 수 있도록 만든 메뉴

예시)

Home

About

Portfolio

Contact

### 줄여서

`Nav`

라고 표현하기도 함

### Claude Code 요청 예시

> Header의 Navigation 메뉴 사이 간격을 조금 넓혀줘.

또는

> 모바일에서는 Navigation 메뉴가 화면 밖으로 벗어나지 않도록 수정해줘.

---

# Hero Section이란?

### Hero Section (히어로 섹션, 첫 대표 영역)

웹사이트에 들어왔을 때 가장 먼저 크게 보이는 대표 영역

주로

- 메인 제목
- 설명
- 대표 이미지
- CTA Button

으로 구성

### 예시

┌─────────────────────────────────┐
│                                 │
│        BRAND NAME               │
│                                 │
│     Main Headline               │
│                                 │
│     Short Description           │
│                                 │
│        [ 자세히 보기 ]           │
│                                 │
└─────────────────────────────────┘

### Claude Code 요청 예시

> Hero Section의 높이를 조금 줄여줘.

또는

> Hero의 제목은 유지하고 설명과 버튼 사이 간격만 넓혀줘.

---

# CTA란?

### CTA (Call To Action, 행동 유도 요소)

사용자에게 다음 행동을 유도하는 버튼 또는 링크

예시)

[ 문의하기 ]

[ 프로젝트 보기 ]

[ 메뉴 보기 ]

[ 신청하기 ]

### 중요한 점

CTA는 단순한 장식이 아님

사용자의

**다음 행동을 연결하는 요소**

---

# Button이란?

### Button (버튼, 클릭하여 기능을 실행하는 요소)

클릭하면 특정 행동이 실행되는 UI 요소

예시)

등록하기

문의하기

더보기

삭제하기

저장하기

### CTA와 Button의 차이

Button

→ 클릭 가능한 UI 요소 자체

CTA

→ 사용자의 중요한 행동을 유도하는 역할

### 예시

`방명록 등록`

→ Button

`지금 신청하기`

→ Button이면서 주요 CTA가 될 수 있음

---

# Card란?

### Card (카드, 관련 정보를 하나로 묶어 보여주는 UI 요소)

하나의 정보를 독립적인 영역으로 묶어서 표현

예시)

┌─────────────────┐
│      IMAGE      │
│                 │
│ Project Name    │
│ Description     │
│                 │
│ [ 자세히 보기 ] │
└─────────────────┘

### 활용

- 상품
- 메뉴
- Portfolio
- 게시글
- 클래스
- 여행지
- 프로필

### Claude Code 요청 예시

> Portfolio Card 사이의 간격을 조금 넓혀줘.

---

# 오늘의 핵심 용어

### Header (헤더, 웹페이지의 상단 영역)

Logo와 Navigation 등이 주로 위치하는 상단 영역

### Navigation (내비게이션, 페이지 이동 메뉴)

사용자가 주요 Page나 Section으로 이동할 수 있도록 제공하는 메뉴

### Hero Section (히어로 섹션, 첫 대표 영역)

웹사이트의 목적과 핵심내용을 처음 전달하는 대표 영역

### Section (섹션, 콘텐츠 구역)

하나의 목적을 가진 웹페이지의 콘텐츠 영역

### CTA (Call To Action, 행동 유도 요소)

사용자에게 특정 행동을 유도하는 Button이나 Link

### Button (버튼, 클릭 가능한 조작 요소)

사용자의 클릭을 통해 특정 기능을 실행하는 UI 요소

### Card (카드, 정보를 묶어서 보여주는 UI 요소)

관련된 이미지와 텍스트 등의 정보를 하나의 영역으로 구성한 형태

### Form (폼, 사용자 입력 영역)

사용자로부터 정보를 입력받기 위한 UI 영역

### Input (인풋, 한 줄 입력창)

짧은 정보를 입력하는 UI 요소

### Textarea (텍스트에어리어, 여러 줄 입력창)

긴 내용을 입력하는 UI 요소

### Footer (푸터, 웹페이지의 하단 영역)

연락처, Copyright 등의 정보를 보여주는 페이지 하단 영역

### Task Decomposition (작업 분해)

큰 개발작업을 작고 확인 가능한 작업단위로 나누는 방식

### BUILD_SPEC (Build Specification, 제작 명세서)

실제 개발할 화면과 기능 등을 구체적으로 정리한 문서
