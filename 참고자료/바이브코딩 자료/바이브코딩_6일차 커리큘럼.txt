만들고 싶은 웹사이트: [예: 동네 필라테스 스튜디오 소개 · 체험 신청 사이트]

사용자가 사이트에서 했으면 하는 행동: [예: 수업 종류를 보고 체험 수업을 신청]
비슷한 사이트를 조사하며 알게 된 점: [PROJECT_PLAN.md의 레퍼런스 참고]

정리한 내용은 PROJECT_PLAN.md에 추가하고, 아직 코드는 만들지 마.

예시 (막히면 보기) — SOOM 필라테스 : 스튜디오 소개 / 수업 목록(classes Table) / 체험 신청 저장(applications Table) / 위치 · 운영 시간

확인하기 : 정말 필요한가? / 내 사이트와 맞는가? / 이틀 반 안에 가능한가? / 4개 이하인가?

# 실습 STEP 04
# 흐름(User Flow) 정하기 (7분)

- User Flow : 사용자가 원하는 일을 끝낼 때까지 거치는 화면 순서를 화살표로 적은 것
- 예 : 메인 → [수업 보기] → 수업 목록 → [신청하기] → 신청 입력창 → 신청 완료
- 한 페이지 사이트는 화면 대신 Section으로 적기
- 먼저 직접 적고 AI에게 검토받기

### 작성 틀 ③

내 최종 프로젝트의 사용자 흐름(User Flow)을 적어봤어.
내가 적은 흐름: [예: 메인 → [수업 보기] → 수업 목록 → [신청하기] → 신청 입력창 → 신청 완료]
PROJECT_PLAN.md의 목적과 꼭 필요한 기능을 기준으로 검토해줘.
1. 빠진 단계나 필요 없는 단계가 있는지
2. 한 페이지 사이트가 좋은지 여러 페이지 사이트가 좋은지
3. 화면(또는 구역)마다 다음으로 넘어가게 하는 버튼
고친 흐름을 화살표 한 줄로 정리해서 PROJECT_PLAN.md에 추가해줘. 아직 코드는 만들지 마.

# 실습 STEP 05
# 화면 설계도(Wireframe) 만들기 (12분)

- Wireframe : 꾸미기 전에 글 · 사진 · 버튼 위치를 회색 상자로 정하는 설계도. 비유 — 집의 평면도
- 예시 이미지 : img/vibecoding/day05-wireframe-1.jpg(병원), day05-wireframe-3.jpg(카페 여러 화면)
- 예전 STEP 07(글로 구조 제안)과 STEP 08(wireframe.html)을 한 프롬프트로

### 프롬프트

PROJECT_PLAN.md의 꼭 필요한 기능과 흐름(User Flow)을 바탕으로 화면 설계도(Wireframe)를 만들어줘.
1. 먼저 화면(또는 구역)마다 위에서 아래 순서로 Section을 나누고, Section마다 들어갈 요소(제목, 설명, 이미지, 버튼, 카드, 입력창)를 글로 정리해서 PROJECT_PLAN.md에 추가해줘.
2. 그 다음 프로젝트 폴더에 wireframe.html을 만들어서 눈으로 볼 수 있게 그려줘.
- 흰색 · 회색 · 검정색만 사용, 이미지 자리는 X 표시한 회색 상자
- Section마다 번호와 이름, 요소마다 작은 이름표
- 메인 화면은 휴대폰에서 보이는 모습도 옆에 함께
references 폴더의 캡처에서 배치 아이디어를 참고해줘.
색 · 사진 · 움직임은 넣지 말고, 다른 파일은 만들지 마.

확인하기 : 첫 화면에서 목적이 보이는가 / 중요한 버튼이 찾기 쉬운가 / Section이 너무 많지 않은가
고칠 곳 : "[찾은 문제]를 고쳐줘. Section 순서와 번호는 그대로 두고 그 부분만 고쳐줘."

### 프롬프트 — BUILD_SPEC

PROJECT_PLAN.md와 wireframe.html을 기준으로 실제 제작에 사용할 BUILD_SPEC.md를 만들어줘.

## 프로젝트
- [프로젝트 이름]: [한 줄 설명]
- 사용 기술: HTML, CSS, JavaScript[, Supabase]
- 작업 전에 항상 BUILD_SPEC.md를 먼저 확인하기
## 작업 규칙
- 설명은 코딩을 처음 배우는 사람이 이해할 수 있게 쉬운 우리말로
- 한 번에 하나의 Section이나 기능만 만들기
- 내가 요청하지 않은 Section · 디자인 · 기능은 바꾸지 않기
- BUILD_SPEC에 없는 기능을 새로 넣자고 하지 않기
- Supabase Secret Key는 절대 코드에 넣지 않기
- 작업이 끝나면 바뀐 파일 목록과 확인 방법 알려주기
- [내가 더하고 싶은 규칙]
