# 03. 화면 배치 — 개발자들은 / 우리는 이렇게 말해요 (5분)

| 개발자들은 | 무슨 뜻인가요? | 우리는 이렇게 말해요 |
| Container · Max Width | 내용이 좌우로 너무 퍼지지 않게 가운데 폭을 제한 | "PC에서 내용 폭을 최대 1120px로 가운데 모아줘" |
| Flexbox | 한 줄로 나란히 · 가운데 맞추기 | "제목과 사진을 좌우로 나란히, 세로 가운데 맞춰줘" |
| Grid | 바둑판처럼 칸 나누기 | "사진 6장을 PC 3칸, 휴대폰 1칸으로" |
| Gap | 반복되는 것들 사이 간격 | "목록 사이 간격을 똑같이 24px로" |
| Aspect Ratio | 사진 가로세로 비율 | "모든 사진을 4:3 비율로 맞춰줘. 찌그러지지 않게 잘라서" |
| Breakpoint | 화면이 바뀌는 폭 | "768px보다 좁으면 위아래로 쌓아줘" |
| Overflow | 내용이 화면 밖으로 넘침 | "휴대폰에서 가로로 밀리는 원인을 찾아줘" |
영어 용어는 외우지 않아도 된다. AI 답에 나오면 알아보면 충분.
