# Typography란?

### Typography (타이포그래피, 글자의 시각적 구성)

웹사이트에서 글자를

어떤 크기

어떤 굵기

어떤 간격

으로 보여줄지 정하는 것

### Typography를 구성하는 대표 요소

Font Family

Font Size

Font Weight

Line Height

Letter Spacing

---

# Font Family

### Font Family (폰트 패밀리, 사용하는 글꼴 종류)

예시)

Pretendard

Noto Sans KR

Arial

sans-serif

### 중요한 점

하나의 사이트에서

너무 많은 Font를 사용하지 않기

### 일반적으로

제목

+

본문

정도의 명확한 체계 유지

---

# Font Size

### Font Size (폰트 사이즈, 글자 크기)

정보의 중요도에 따라

크기 차이를 만들어야 함

### 예시

Hero Title

가장 큼

↓

Section Title

중간

↓

Card Title

작음

↓

Body Text

본문

### 핵심

모든 글자가 비슷한 크기라면

무엇이 중요한지 구분하기 어려움

---

# Font Weight

### Font Weight (폰트 웨이트, 글자 굵기)

예시)

400

일반 본문

500

약간 강조

600~700

제목 또는 중요한 내용

### 주의

모든 글자를 Bold로 만들면

강조효과가 사라짐

---

# Line Height

### Line Height (라인 하이트, 글줄 사이의 간격)

본문의 가독성에 중요한 요소

### 너무 좁으면

글이 답답해 보임

### 너무 넓으면

문장이 서로 떨어져 보임

---

# Letter Spacing

### Letter Spacing (레터 스페이싱, 글자 사이 간격)

특히

큰 제목

영문 브랜드명

Navigation

등에서 분위기 조절에 활용

### 주의

과하게 넓히거나 좁히지 않기

---

# Typography 수정 프롬프트 예시

> 현재 프로젝트의 Typography만 점검해줘.
>
> Hero Title, Section Title, Card Title, Body Text의 크기와 굵기 차이가 자연스럽게 구분되는지 확인해줘.
>
> 본문의 가독성을 위해 Line Height도 점검해줘.
>

>
> Layout과 기능은 변경하지 마.

# Shadow란?

### Shadow (섀도, 요소에 적용하는 그림자 효과)

Card나 Button 등이

배경과 구분되도록 도와주는 효과

### 주의

강한 Shadow를 모든 요소에 사용하면

오히려 화면이 복잡해질 수 있음

### 오늘의 원칙

**필요한 곳에 약하게 사용**

---

# Opacity란?

# Hover란?

### Hover (호버, 마우스를 요소 위에 올렸을 때 나타나는 상태)

# 오늘의 핵심 용어

### Typography (타이포그래피, 글자의 시각적 구성)

Font, Size, Weight, Line Height 등을 이용하여 글자의 정보구조와 분위기를 만드는 것

### Visual Hierarchy (시각적 위계, 정보의 중요도를 시각적으로 구분하는 방식)

크기, 굵기, 색상, 위치 등을 통해 사용자가 중요한 정보를 먼저 볼 수 있도록 만드는 방식

### Border (보더, 요소의 테두리)

Card, Button, Input 등의 경계를 구분하는 선

### Border Radius (보더 라디우스, 모서리 둥글기)

요소의 모서리를 둥글게 만드는 정도

### Shadow (섀도, 그림자 효과)

요소를 배경과 시각적으로 구분하기 위한 효과

### Opacity (오퍼시티, 투명도)

요소가 얼마나 투명하게 보일지 결정하는 값

### Hover (호버, 마우스를 올렸을 때 나타나는 상태)

클릭 가능한 요소에 마우스를 올렸을 때 나타나는 변화

### Transition (트랜지션, 상태 변화가 부드럽게 이어지는 효과)

Hover 등의 변화가 자연스럽게 나타나도록 만드는 효과

### Icon (아이콘, 기능이나 의미를 작은 그림으로 표현하는 요소)

검색, 메뉴, 이동 등의 기능을 직관적으로 표현하는 UI 요소

### Modal (모달, 현재 화면 위에 나타나는 별도 정보창)

현재 페이지를 유지하면서 추가정보나 기능을 보여주는 화면

### Consistency (일관성, 같은 역할의 요소를 비슷한 방식으로 표현하는 원칙)

Button, Card, Input 등 같은 종류의 UI가 비슷한 디자인 규칙을 유지하도록 하는 것

### Feature Freeze (기능 동결, 새로운 기능 추가를 멈추는 단계)

프로젝트 마무리 단계에서 새로운 기능 개발을 중단하고 현재 기능의 안정성과 완성도에 집중하는 것

### QA (Quality Assurance, 결과물의 품질을 최종 점검하는 과정)

기능, 디자인, 콘텐츠, Responsive 등을 포함하여 프로젝트 전체 품질을 확인하는 과정
