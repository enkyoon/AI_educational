# 03. GitHub Pages · 공개 전 안전 점검 (8분)

GitHub Pages : GitHub Repository의 HTML · CSS · JS를 무료로 인터넷에 공개해 주는 호스팅. 자물쇠(https) 자동.
할 수 있는 일 : 화면 파일(정적 사이트) 공개. 데이터 · 로그인은 Supabase가 맡으므로 우리 사이트는 그대로 동작
공개하면 사이트뿐 아니라 Repository의 모든 파일을 누구나 볼 수 있다.

### 프롬프트 05
이 프로젝트를 GitHub Pages로 공개하려고 해. 공개 전에 점검해줘.
1. Secret Key, 비밀번호, 개인정보가 든 파일
2. 첫 페이지가 맨 위 폴더의 index.html인지
3. 사진 · CSS · JS 경로 중 /로 시작하는 것 (/images/a.jpg → images/a.jpg 여야 함)
4. 코드에 적힌 파일 이름과 실제 파일 이름의 대소문자가 다른 곳
문제가 있으면 무엇을 고칠지 먼저 알려주고, 내가 허락하면 고쳐줘.
Repository가 Private이면 : 점검 후 Settings → General 맨 아래 Danger Zone → Change visibility → Public (무료 계정은 Public만 Pages 가능)

# 실습 STEP 06
# GitHub Pages로 공개 · 로그인 주소 등록 (8분)

Repository → Settings → Pages → Source: Deploy from a branch → Branch: main, / (root) → Save → 1~3분 뒤 새로고침 → Visit site
주소 : https://내GitHub아이디.github.io/저장소이름/
확인 : 자물쇠 / 사진 / Supabase 불러오기 · 저장 / 내 휴대폰으로 열기 (이제 진짜 휴대폰에서 확인 가능)

로그인이 있는 사람 — 공개 주소를 등록해야 공개 사이트에서 로그인이 된다
① Supabase → Authentication → URL Configuration → Site URL을 공개 주소로, Redirect URLs에 https://아이디.github.io/저장소이름/** 추가
② 구글 로그인을 쓴다면 : Google Cloud → Google Auth Platform → Clients → 내 클라이언트 → 승인된 JavaScript 원본에 https://아이디.github.io 추가 (경로 없이) → 저장 (반영까지 몇 분 걸릴 수 있음)
③ 테스트 중인 구글 앱은 테스트 사용자에 등록한 계정만 로그인된다. 강사 계정으로 확인받으려면 강사 Gmail을 테스트 사용자에 추가하거나, 제출 글에 이메일 테스트 계정을 적는다

# 04. 파일 경로와 사이트 주소 (4분)

지금 같은 index.html에 주소가 세 개 생겼다
| 어디서 보나 | 주소 모양 | 누가 볼 수 있나 |
| 내 컴퓨터 폴더 (파일 경로) | C:\Users\…\my-project\index.html | 이 컴퓨터만 |
| Live Server | http://127.0.0.1:5500/index.html | 이 컴퓨터만 (내 컴퓨터가 임시 서버) |
| GitHub Pages (사이트 주소) | https://아이디.github.io/저장소이름/ | 인터넷의 누구나 |
- 파일 경로 = 서랍 속 서류의 위치. 사이트 주소 = 가게 주소
- 사진 경로를 images/a.jpg(상대 경로)로 쓰는 이유 — "이 파일 옆의 images 폴더"라는 뜻이라 세 곳 어디서든 맞다
- C:\Users\… 나 /images/a.jpg(맨 앞 /)처럼 쓰면 공개 주소에서 깨진다 → 프롬프트 05의 3번이 이것
- 카톡으로 C:\… 경로를 보내면 상대는 열 수 없다. 공유는 항상 https:// 주소로

# 05. 나만의 사이트 주소 만들기 — 도메인 · DNS · SSL (8분)

- IP 주소 : 서버의 숫자 주소 (예: 185.199.108.153) — 가게 전화번호
- 도메인 : 사람이 기억하기 쉬운 이름 주소 (boribat.com) — 가게 상호
- DNS : 도메인으로 IP를 찾아 주는 시스템 — 전화번호부
- SSL 인증서 · HTTPS : 이 사이트가 그 도메인의 진짜 주인이라는 증명 + 주고받는 내용 암호화 — 봉인된 편지(자물쇠). http는 엽서
- 기본 주소(아이디.github.io)는 무료 / 내 도메인은 도메인 판매 업체(카페24 · 가비아 등)에서 1년 단위로 산다. .com은 1년에 대략 1~3만 원대 (업체 · 할인에 따라 다름)

내 도메인을 GitHub Pages에 연결하는 순서 (혼자 해 보기 — 수업에서는 순서만)
① 도메인 업체에서 도메인 구매 (예: 카페24 도메인)
② 업체의 DNS 관리 화면에서 기록 추가
   - www로 쓰려면 : CNAME · 이름 www · 값 아이디.github.io
   - www 없이 쓰려면 : A 기록 4개 — 185.199.108.153 / 185.199.109.153 / 185.199.110.153 / 185.199.111.153
③ GitHub Repository → Settings → Pages → Custom domain에 도메인 입력 → Save → DNS 확인이 끝나면 Enforce HTTPS 체크
④ 반영까지 몇 분 ~ 하루 (DNS가 퍼지는 시간)
⑤ 로그인이 있다면 Supabase Site URL · Redirect URLs, Google 원본도 새 주소로 추가
막히면 Claude Code에게 : "카페24에서 산 도메인 ○○.com을 GitHub Pages에 연결하려고 해. 카페24 DNS 화면에서 내가 할 일을 순서대로 알려줘"

다른 선택지 — 카페24 웹호스팅 · AI SPACE
- 카페24 : 도메인 · 웹호스팅 · 쇼핑몰을 함께 파는 업체. 웹호스팅은 PHP · 자체 Database 같은 서버 프로그램까지 올릴 수 있다
- AI SPACE : 카페24가 만든 "AI에게 말로 배포를 맡기는" 호스팅. Claude Code · ChatGPT 같은 AI 도구를 MCP로 연결하면 "배포해줘" 한마디로 서버 생성 · 주소 · SSL까지. 유료(체험 기간이 있음 — 조건은 공식 안내 확인)
- 고르는 기준 : 소개 · 포트폴리오처럼 화면만 있는 사이트 → GitHub Pages(무료, 오래 유지) / 서버 프로그램이 필요한 서비스 · 말로 관리하고 싶음 → 유료 호스팅

# 06. MCP — 앞으로 AI를 다른 도구와 연결하기 (5분, 이론)

오늘은 실습 · 시연을 하지 않는다. 연결할 서비스를 내가 결제 · 구독하고 있어야 하고, 내 계정 권한으로 AI가 움직이기 때문이다. 대신 내 분야에 적용하는 방법을 알고 간다.

- MCP(Model Context Protocol) : AI 도구가 다른 서비스(구글 드라이브 · Notion · GitHub · 카페24 · Figma …)와 연결할 때 쓰는 공통 규격
- 비유 — USB-C 단자. 규격이 하나라 어떤 기기든 같은 방식으로 꽂힌다. 서비스 회사는 MCP 서버(콘센트)를 만들고, AI 도구는 거기에 꽂기만 하면 된다
- 이미 본 적 있다 : ChatGPT 설정 → 앱에서 Google Drive · Gmail 등을 연결하는 화면. 그 연결 상당수가 MCP 방식이다 (직접 주소를 넣어 연결하는 것은 개발자 모드)
- Claude Code에서는 터미널에 claude mcp add … 한 줄로 연결하고, /mcp에서 로그인 · 승인
연결 전 / 후
- 전 : AI는 내 컴퓨터 파일만 본다. 다른 서비스 일은 내가 그 사이트에 들어가서 직접
- 후 : "Notion 회의록에서 할 일만 뽑아 표로 만들어줘" → AI가 Notion에서 직접 읽고 정리
분야별로 떠올려 보기
| 분야 | 연결할 서비스 | 맡길 수 있는 일 |
| 쇼핑몰 운영 | 카페24 · 스마트스토어 관리 도구 | 상품 등록 · 주문 목록 정리 |
| 디자인 | Figma · Canva | 디자인 파일을 읽어 웹페이지 코드로, 반복 수정 |
| 사무 | Google Drive · Gmail · 캘린더 · Notion | 자료 찾기 · 요약 · 일정 정리 |
| 웹 개발 | GitHub · Supabase | 저장소 관리 · 표 만들기 (지금은 내가 복사해서 실행하는 일) |
내가 쓰려면 확인할 것 3가지
① 쓰는 서비스가 공식 MCP 서버(또는 ChatGPT · Claude 앱 목록)를 제공하는가 — 서비스 이름 + MCP로 검색
② 내 요금제에서 쓸 수 있는가 (유료 플랜 전용인 경우가 많음)
③ AI가 할 수 있는 일(읽기만 / 쓰기 · 삭제까지)을 승인 창에서 읽고 허락 — 공식 서버만, 필요한 권한만

- Push했는데 안 바뀜 → Actions 탭에서 배포 진행 중인지, Ctrl + F5
- Settings에 Pages가 비활성 → Repository가 Private
