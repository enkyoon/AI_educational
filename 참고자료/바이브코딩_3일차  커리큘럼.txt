# STEP 04. Color 수정하기

### 오늘 사용할 Color 방향

→ 짙은 브라운

Point

→ 차분한 브라운

### 프롬프트 04

> 현재 웹페이지의 레이아웃과 Typography는 그대로 유지해줘.
>
> 이번에는 전체 색상만 변경해줘.

>
> 버튼에는 메인 텍스트보다 조금 따뜻한 브라운 계열을 사용해줘.
>
> 전체 웹사이트에서 사용하는 주요 색상은 3개를 넘지 않도록 해줘.
>
> 전체적으로 따뜻하고 차분한 분위기가 나도록 만들어줘.
>
> 기존 텍스트, 폰트 크기, 레이아웃은 변경하지 마.
