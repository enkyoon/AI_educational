# Claude Code에게 구조 기획 요청하기

처음부터 코드를 만들기 전에 다음과 같이 질문 가능

> 개인 포트폴리오 웹페이지를 만들려고 해.
>
> 한 페이지로 구성하고 싶고 상단 메뉴와 Hero, About, Portfolio, Contact, Footer 영역을 넣으려고 해.
>
> 코드를 작성하기 전에 초보자가 이해할 수 있도록 전체 페이지 구조를 먼저 정리해줘.
>
> 아직 파일은 수정하지 말고 어떤 Section으로 구성하면 좋을지만 알려줘.

### 중요한 방법

**바로 제작 요청하지 않고 먼저 구조를 확인하는 것도 가능**

Claude Code

→ 계획 제안

사용자

→ 확인

그 다음

→ 제작 요청

Claude Code 실행

### 첫 번째 제작 프롬프트

개인 프로필을 선택한 경우

> 개인 프로필용 미니 웹사이트를 만들어줘.
>
> 한 페이지로 구성해줘.
>
> 페이지에는 다음 Section이 필요해.
>
> 1. 상단 Navigation
> 2. Hero
> 3. About
> 4. Portfolio
> 5. Contact
> 6. Footer
>
> 상단 Navigation에는 About, Portfolio, Contact 메뉴를 넣어줘.
>
> 전체 디자인은 흰색 배경을 기본으로 하고 깔끔하고 미니멀한 스타일로 만들어줘.
>
> HTML, CSS, JavaScript는 각각 index.html, style.css, script.js 파일로 분리해줘.
>
> 초보자가 이후 수정하기 쉽도록 코드 구조를 너무 복잡하게 만들지 마.
>
> 필요한 파일을 생성하고 어떤 파일을 만들었는지 설명해줘.

# DAY 03 수업내용 정리

### 오늘의 핵심 키워드

**Section**  
웹페이지 안에서 특정 목적을 가진 콘텐츠 영역

**Hero Section**  
웹페이지에 들어왔을 때 가장 먼저 보이는 대표 영역

**Navigation**  
웹사이트의 주요 영역으로 이동하기 위한 메뉴

**CTA**  
사용자의 특정 행동을 유도하는 버튼이나 요소

**Live Server**  
작성한 웹페이지를 Local Server에서 실행하고 빠르게 확인하는 확장 프로그램

**Responsive Web**  
PC · Tablet · Mobile 등 화면 크기에 맞게 레이아웃이 변화하는 웹사이트

**Hover**  
마우스를 특정 요소 위에 올렸을 때 나타나는 변화

**Interaction**  
클릭·이동·Hover 등 사용자의 행동에 따라 웹페이지가 반응하는 기능
