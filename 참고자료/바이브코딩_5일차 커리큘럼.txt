# MVP란?

### MVP

Minimum Viable Product

**서비스가 작동하기 위해 반드시 필요한 최소한의 기능을 갖춘 첫 번째 완성본**

### 예시

온라인 청첩장

꼭 필요한 기능

- 예식 정보
- 사진
- 위치 안내
- 방명록 작성

있으면 좋은 기능

- 음악
- 사진 슬라이드
- 카운트다운
- 복잡한 애니메이션
- 공유 기능

### 처음부터 모든 기능을 만들지 않기

핵심기능

↓

먼저 완성

↓

시간이 남으면 추가기능

### 최종 프로젝트에서도

**Must Have**

반드시 필요한 기능

# STEP 08. Screen Flow 만들기

### 프롬프트 08

> 방금 만든 User Flow를 기준으로 Screen Flow를 설계해줘.
>
> 사용자가 어떤 화면에서 시작하고 어떤 버튼이나 행동을 통해 다음 화면으로 이동하는지 보여줘.
>
> 다음 내용을 포함해줘.
>
> 1. 화면 이름
> 2. 해당 화면에서 사용자가 할 행동
> 3. 다음 화면으로 이동시키는 버튼이나 요소
>
> 마지막에는 전체 흐름을 화살표 형식으로 한 번 더 정리해줘.
>
> 한 페이지 사이트라면 실제 페이지 이동 대신 어떤 Section으로 이동하는지도 표현해줘.

# DAY 05 수업내용 정리

### 오늘의 핵심 키워드

**Target User**

웹사이트를 사용할 주요 사용자

**MVP**

서비스가 작동하기 위해 반드시 필요한 최소한의 핵심 기능

**Must Have**

프로젝트 완성을 위해 반드시 구현해야 하는 기능

**Nice to Have**

시간이 남으면 추가할 수 있는 기능

**User Flow**

사용자가 목표를 달성하기까지의 행동 흐름

**Screen Flow**

사용자의 행동에 따라 화면이 연결되는 흐름

**Wireframe**

화면 안에서 콘텐츠와 기능의 위치를 정하는 설계도

**Build Specification**

실제 개발에 필요한 구조와 기능을 정리한 제작 명세
