# DAY 01. AI 활용 기초와 학원 자료 분석

> **과정명:** 수학의 힘 : AI 교육특강  
> **수업 주제:** Claude를 활용한 학원 자료 분석 기초  
> **학습 목표:** 교재·시험지 등 실제 학원 자료를 AI에 입력하고, 필요한 정보를 검색·분류·정리한 뒤 원문과 비교하여 결과를 검토할 수 있다.

---

## 01. Claude와 학원 자료 활용의 기본

생성형 AI는 질문에 답하는 도구를 넘어, **주어진 자료를 읽고 정리하는 도구**로 활용할 수 있다.

수학학원에서는 다음과 같은 업무에 활용할 수 있다.

- 교재나 시험지의 내용 확인
- 특정 단원이나 개념에 해당하는 문항 찾기
- 문항별 출제 단원과 주요 내용 정리
- 객관식·서술형 등 조건에 맞는 문제 추출
- 여러 문항의 공통점이나 차이점 정리
- 분석 결과를 표 형태로 구조화
- 기존 분석 결과와 원문 비교

### 핵심 원칙

AI에게 자료를 맡길 때는 단순히  
**“이 자료를 분석해줘”**라고 요청하기보다,

**무엇을 보고 → 어떤 기준으로 → 어떤 형태로 정리할지**

구체적으로 알려주는 것이 중요하다.

---

## 02. 자료를 입력하고 먼저 확인하기

Claude에 시험지나 교재를 등록한 뒤에는 바로 분석을 요청하기보다,  
먼저 AI가 자료를 제대로 읽고 있는지 확인한다.

### 자료 확인 요청 예시

```text
첨부한 자료의 전체 구성을 먼저 설명해주세요.

다음 항목만 확인해주세요.
1. 학년
2. 과목
3. 시험 범위
4. 전체 문항 수
5. 객관식과 서술형 문항 수

추가 분석은 아직 하지 말아주세요.
```

### 확인해야 할 내용

- 문항 번호가 빠지지 않았는가
- 페이지가 누락되지 않았는가
- 수식이나 기호가 잘못 인식되지 않았는가
- 객관식과 서술형이 제대로 구분되었는가
- 문제의 조건이 원문과 다르게 읽히지 않았는가

### 자료 확인 체크리스트

- [ ] 전체 페이지가 정상적으로 등록되었다.
- [ ] 전체 문항 수가 맞다.
- [ ] 문제 번호가 순서대로 확인된다.
- [ ] 수식과 기호가 크게 왜곡되지 않았다.
- [ ] 객관식과 서술형이 구분된다.

## 03. 원하는 결과를 얻는 요청 구조

AI에게 요청할 때는 다음 네 가지를 기준으로 작성하면 결과가 훨씬 안정적이다.

### 기본 요청 구조

**목적 → 자료 → 기준 → 결과 형식**

---

### 1) 목적

AI에게 무엇을 하기 원하는지 먼저 알려준다.

```text
이 시험지를 단원별로 정리하고 싶습니다.
```

### 2) 자료

어떤 자료를 기준으로 해야 하는지 알려준다.

```text
첨부한 중학교 2학년 수학 시험지를 기준으로 분석해주세요.
```

### 3) 기준

어떤 항목을 기준으로 나누거나 판단할지 알려준다.

```text
각 문항을 출제 단원과 주요 출제 내용으로 구분해주세요.
```

### 4) 결과 형식

어떤 모습으로 결과를 받고 싶은지 알려준다.

```text
문항번호 / 출제단원 / 주요 출제내용의 3개 열로 표를 만들어주세요.
```

---

## 04. 단순 요청과 구체적인 요청 비교

### 단순 요청

```text
이 시험지를 분석해줘.
```

이 경우 AI가 어떤 기준으로 분석해야 하는지 명확하지 않기 때문에  
결과가 길거나, 불필요한 내용이 포함되거나, 원하는 항목이 빠질 수 있다.

### 구체적인 요청

```text
첨부한 수학 시험지를 분석해주세요.

각 문항을 다음 기준으로 정리해주세요.

- 문항번호
- 출제단원
- 주요 출제내용

결과는 표로 작성해주세요.

문제에서 명확하게 판단할 수 없는 내용은 임의로 추측하지 말고
'확인 필요'라고 표시해주세요.
```

### 비교 포인트

| 구분 | 단순 요청 | 구체적인 요청 |
|---|---|---|
| 목적 | 불분명 | 명확함 |
| 분석 기준 | AI가 임의로 결정 | 사용자가 지정 |
| 결과 형식 | 일정하지 않음 | 원하는 형식으로 통일 |
| 수정 가능성 | 높음 | 낮아짐 |
| 재사용성 | 낮음 | 높음 |

## 05. 자료에서 필요한 내용 검색하기

AI는 단순히 특정 단어를 찾는 것뿐 아니라,  
**조건에 맞는 문항이나 내용을 골라내는 작업**에도 활용할 수 있다.

### 예시 1. 특정 단원 찾기

```text
첨부한 시험지에서 '삼각형의 성질' 단원에 해당하는 문항만 찾아주세요.

문항번호와 어떤 내용을 묻는 문제인지 함께 정리해주세요.
```

### 예시 2. 특정 개념 찾기

```text
첨부한 시험지에서 내심 또는 외심의 성질을 활용하는 문항을 모두 찾아주세요.

각 문항별로 어떤 개념이 사용되는지 한 문장으로 정리해주세요.
```

### 예시 3. 서술형 문항만 추출

```text
첨부한 자료에서 서술형 문항만 따로 정리해주세요.

문항번호 / 출제단원 / 요구되는 주요 내용 순서로 표를 작성해주세요.
```

### 예시 4. 합동 관련 문항 찾기

```text
첨부한 시험지에서 삼각형의 합동 조건을 활용하는 문항을 찾아주세요.

각 문항에서 어떤 합동 조건이 필요한지 함께 정리해주세요.
```

## 06. 문항별 단원과 출제 내용 분류하기

시험지를 분석할 때 처음부터 많은 항목을 한꺼번에 요구하기보다,  
가장 기본적인 정보부터 구조화한다.

### 기본 분석 항목

1. 문항번호
2. 출제단원
3. 주요 출제내용

### 요청 예시

```text
첨부한 수학 시험지의 모든 문항을 분석해주세요.

다음 기준으로 표를 작성해주세요.

| 문항번호 | 출제단원 | 주요 출제내용 |

출제단원은 가능한 한 교과서 단원 수준으로 구분하고,
주요 출제내용은 해당 문제에서 학생이 무엇을 알아야 풀 수 있는지를
한 문장으로 간단히 작성해주세요.
```

### 분석 결과 예시

| 문항번호 | 출제단원 | 주요 출제내용 |
|---|---|---|
| 1 | 삼각형의 성질 | 이등변삼각형의 밑각을 이용한 각의 크기 구하기 |
| 2 | 삼각형의 성질 | 직각삼각형의 합동 조건 활용 |
| 3 | 삼각형의 성질 | 내심의 성질을 이용한 각의 크기 구하기 |
| 4 | 사각형의 성질 | 평행사변형의 성질 활용 |

※ 위 표의 형식은 분석 연습용 예시이며, 실제 결과는 첨부한 시험지에 따라 달라진다.

## 07. 분석 기준을 한 가지씩 추가하기

기본 분석이 끝난 뒤에는 필요한 항목을 추가하여  
학원에서 사용하는 방식에 맞게 분석표를 확장할 수 있다.

### 추가할 수 있는 항목 예시

- 객관식 / 서술형
- 배점
- 문제 유형
- 주요 개념
- 계산 중심 / 개념 이해 중심
- 교재 페이지
- 확인 필요 여부

### 요청 예시

```text
기존 분석표에 다음 두 항목을 추가해주세요.

1. 문제 유형
2. 객관식 / 서술형 구분

기존 내용은 수정하지 말고,
새로운 열만 추가해주세요.
```

### 분석표 확장 예시

| 문항번호 | 출제단원 | 주요 출제내용 | 문제 유형 | 문항 형태 |
|---|---|---|---|---|
| 1 | 삼각형의 성질 | 이등변삼각형의 밑각 활용 | 계산형 | 객관식 |
| 2 | 삼각형의 성질 | 직각삼각형의 합동 활용 | 개념 적용형 | 객관식 |
| 3 | 사각형의 성질 | 평행사변형 성질 활용 | 추론형 | 서술형 |

## 08. 원하는 표 형식으로 결과 받기

같은 분석 내용이라도 목적에 따라 결과 형태를 달리할 수 있다.

### 문항별 분석표

```text
문항번호 / 단원 / 주요 개념 / 출제내용 순서로 표를 작성해주세요.
```

### 단원별 정리표

```text
문항별 결과를 다시 묶어서,
단원별 문항 수와 해당 문항번호를 정리해주세요.
```

### 핵심 개념 목록

```text
전체 시험지에서 반복해서 등장하는 주요 개념을 정리해주세요.

개념명 / 관련 문항번호 / 출제 횟수 순서로 표를 작성해주세요.
```

## 09. AI 분석 결과를 그대로 사용하지 않기

AI의 분석 결과는 빠르게 초안을 만드는 데 유용하지만,  
항상 원문과 비교하여 확인해야 한다.

### 반드시 확인해야 하는 항목

- 문제번호가 맞는가
- 출제단원이 맞는가
- 문제에서 요구하는 핵심 개념을 잘못 판단하지 않았는가
- 원문에 없는 내용을 추가하지 않았는가
- 애매한 문항을 지나치게 확정적으로 분류하지 않았는가

---

## 10. 잘못된 결과를 수정하는 방법

결과가 잘못되었다고 해서 처음부터 다시 요청할 필요는 없다.

문제가 있는 부분만 지정해 수정할 수 있다.

### 특정 문항 다시 확인하기

```text
4번 문항의 출제단원을 다시 확인해주세요.

문제 원문에 근거하여 판단하고,
왜 그렇게 분류했는지 이유도 함께 설명해주세요.
```

### 추측을 줄이기

```text
문제에서 명확하게 확인되지 않는 내용은 추측하지 말아주세요.

판단이 어려운 경우에는 '확인 필요'라고 표시해주세요.
```

### 누락된 문항 확인하기

```text
전체 문항 수와 현재 분석된 문항 수를 비교해주세요.

누락된 문항이 있다면 해당 문항만 추가로 분석해주세요.
```

### 기존 결과는 유지하고 일부만 수정하기

```text
기존 분석표의 형식은 그대로 유지해주세요.

5번과 8번 문항의 출제내용만 다시 확인하여 수정해주세요.
```

## 11. 원문 대조 실습

AI가 만든 분석표와 실제 시험지를 나란히 비교한다.

### 확인 순서

1. 전체 문항 수 확인
2. 문항번호 확인
3. 출제단원 확인
4. 주요 출제내용 확인
5. 누락 여부 확인
6. 잘못된 분류 수정
7. 최종 표 완성

### 원문 대조 체크리스트

- [ ] 전체 문항이 모두 분석되었다.
- [ ] 문항 번호가 일치한다.
- [ ] 단원 분류가 원문과 맞는다.
- [ ] 주요 출제내용이 문제의 실제 요구와 맞는다.
- [ ] AI가 임의로 추가한 내용이 없다.
- [ ] 불확실한 항목이 적절히 표시되었다.

## 12. 반복해서 사용할 수 있는 시험지 분석 요청문 만들기

매번 처음부터 요청문을 작성하기보다,  
자주 사용하는 형태를 기본 요청문으로 만들어 둘 수 있다.

### 기본형

```text
첨부한 수학 시험지를 분석해주세요.

1. 전체 문항 수를 먼저 확인해주세요.
2. 모든 문항을 빠짐없이 분석해주세요.
3. 다음 항목으로 표를 작성해주세요.

- 문항번호
- 출제단원
- 주요 출제내용

4. 판단이 불명확한 내용은 추측하지 말고 '확인 필요'라고 표시해주세요.
5. 마지막에 전체 문항 수와 분석된 문항 수가 일치하는지 확인해주세요.
```

### 확장형

```text
첨부한 수학 시험지를 분석해주세요.

다음 순서로 진행해주세요.

1. 시험지 전체 구성 확인
2. 전체 문항 수 확인
3. 문항별 분석
4. 분석 결과 검토

분석표는 다음 항목으로 작성해주세요.

| 문항번호 | 출제단원 | 주요 개념 | 주요 출제내용 | 문항 형태 |

조건:
- 원문에 근거해서만 판단해주세요.
- 판단이 불확실한 경우 '확인 필요'라고 표시해주세요.
- 임의로 새로운 내용을 만들어내지 말아주세요.
- 마지막에 누락된 문항이 없는지 다시 확인해주세요.
```

# 실습 02. 필요한 문제 찾기

다음 중 하나를 선택하여 요청문을 작성한다.
