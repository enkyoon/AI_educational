## 02. 생성형 AI는 어떻게 답을 만들까? (8분)

- 생성형 AI = 말로 요청하면 결과물을 만들어 주는 AI (글, 표, 요약, 코드, 이미지 설명 등)
- 원리 한 줄: **"다음에 올 가장 그럴듯한 말"을 예측해서 이어 쓴다**
  - 그래서 문장은 늘 자연스럽다 → 하지만 **자연스러움 ≠ 정확함**
  - 같은 질문도 할 때마다 답이 조금씩 다르다
  - 내가 준 정보가 많을수록 추측이 줄고 정확해진다
- **직접 확인 (2분)**: 새 채팅 두 곳에 같은 질문("중2가 도형을 어려워하는 이유 3가지")을 넣고 비교 → 답은 "정답"이 아니라 "그때그때의 초안"
- 비유: **하버드 대학을 나온 우리회사 신입사원** — 아는 것은 많은데 우리 학원 사정(학생, 교재, 방침)은 모른다.
  설명해 준 만큼 일한다.

## 03. 학원 업무에서 잘하는 일 · 어려워하는 일 (7분)

| 잘하는 일 | 어려워하는 일 (사람이 확인) |
|---|---|
| 초안 만들기 (안내문, 상담 문자, 공지) | 사실·숫자 확인 (그럴듯하게 틀림) |
| 긴 자료 정리·요약 (교재, 시험지) | 그림·도형·손글씨 정확히 읽기 |
| 형태 바꾸기 (글 → 표, 표 → 학부모용 문장) | 우리 학원·학생 사정 판단 |
| 조건으로 찾기 ("서술형만", "내심 문항만") | 최종 결정 (난이도, 지도 방향) |
| 계속 고치기 ("더 짧게", "표로") | 최신 입시 정보 (확인 필요) |

**끄덕임 체험 (3분)** — Claude 새 채팅에 입력해 봅니다.
```
수학학원 원장입니다. 내일 폭설 예보로 수업을 온라인으로 바꿉니다.
중학생 학부모님께 보낼 안내 문자를 써주세요.
포함할 것: 수업 시간은 그대로, 접속 링크는 오늘 저녁 따로 발송, 문의 전화
조건: 4줄 이내, 정중하고 간결하게
```
→ "이어서 더 짧게", "고등부용으로도" 한 번씩 더 요청해 보기

## 04. AI를 대하는 마음가짐 3가지 (7분)

1. **AI는 하버드 대학을 나온 우리회사 신입사원이다** — 우리 사정은 모르니 설명해 줘야 한다
2. **AI와 싸우지 않는다** — 다그치면 맥락만 흐려진다. 꼬이면 새 채팅에서 다시
3. **원하는 답이 안 나오면 내 요청을 먼저 본다** — AI 성능 탓보다 요청의 빈칸 탓인 경우가 많다

## 05. 기본 요청법 — 요청 4칸 (10분)

**목적 → 자료 → 기준 → 결과 형식**

| 칸 | 예 |
|---|---|
| 목적 | 이 시험지를 단원별로 정리하고 싶습니다 |
| 자료 | 첨부한 중2 수학 시험지를 기준으로 |
| 기준 | 문항마다 출제 단원과 주요 출제 내용으로 |
| 결과 형식 | 문항번호 / 출제단원 / 주요 출제내용 3칸 표로 |

**강사 시연 (끄덕임 포인트)** — 같은 시험지로 두 요청을 비교
- "이 시험지를 분석해줘" → 길고, 기준이 제멋대로, 원하는 항목이 빠짐
- 4칸을 채운 요청 → 원하는 표가 한 번에

추가로 기억할 한 문장: **"모르는 건 추측하지 말고 '확인 필요'라고 표시해줘"**

# 2교시 (50분) — 교재·시험지 등록하고 찾기

## 07. 시험지 등록하고 "제대로 읽었는지" 확인하기 (10분)

- 실습 자료(강사 제공 시험지) 또는 내 학원 시험지를 프로젝트에 올리기
- 바로 분석시키지 않고 먼저 확인

```
프로젝트에 올린 시험지의 전체 구성을 먼저 알려주세요.
학년 / 과목 / 시험 범위 / 전체 문항 수 / 선택형·서술형 문항 수
분석은 아직 하지 말아주세요.
```

확인: 문항 수가 맞나? 번호가 빠지지 않았나?

## 08. 도형을 제대로 읽었을까? (15분) ★ 이 수업의 핵심 장면

수학 시험지, 특히 도형 단원은 **AI가 가장 틀리기 쉬운 자료**입니다.
그림 속 각도·길이 표시, 보조선, 어느 점이 어디 있는지를 잘못 읽는 일이 아직 자주 있습니다.
학생이 남긴 손글씨(동그라미, 계산 숫자)를 문제 내용으로 착각하기도 합니다.

**실습 — AI에게 "그림을 글로 옮겨 적게" 하기**
```
3번, 5번, 7번 문항의 그림에 표시된 정보를 모두 글로 옮겨 적어주세요.
(표시된 각도, 길이, 같다는 표시, 점의 이름)
손글씨로 적힌 표시는 문제 내용이 아니니 무시해주세요.
확실하지 않은 부분은 '확인 필요'라고 표시해주세요.
```
→ 시험지 원본과 한 줄씩 대조. 틀린 곳이 있으면 표시.

**전하고 싶은 메시지**
- 아직은 틀린다. 그래서 **"그림을 먼저 글로 옮기게 하고 → 사람이 확인하고 → 그다음 분석"** 하는 순서를 쓴다.
- 이 순서와 요청문은 **도구가 좋아져도 그대로 쓸 수 있는 자산**이다.
  AI의 그림 읽기 실력은 빠르게 좋아지고 있다. 방법을 알고 있는 사람은 좋아진 날 바로 적용하고,
  모르는 사람은 그때 가서 처음부터 배운다.
- 오늘 AI가 틀린 문항을 메모해 두고, 몇 달 뒤 같은 요청을 다시 해 보는 것도 좋은 방법.

## 08-1. 시험지 사진을 고칠 수 있는 글로 옮기기 (10분) ★ 끄덕임 포인트

수업 자료를 만들려고 시험지를 다시 타이핑하던 일을 AI에게 맡긴다.
```
시험지의 1번부터 5번 문항을 원문 그대로 옮겨 적어주세요.
- 문제 문장과 보기는 한 글자도 바꾸지 말 것 / 수식은 읽기 쉬운 글자로
- 그림은 [그림: 한 줄 설명]으로 표시 / 손글씨 무시 / 불확실하면 [확인 필요]
```
- 원문 대조: 숫자·기호, 보기 다섯 개, 손글씨 섞임
- 이어서: "한글 파일에 붙여넣기 좋게", "Word 파일로 만들어주세요"
- 메시지: 그림은 아직 사람이, 글과 수식 타이핑은 AI 초안 + 내 확인

## 09. 조건으로 찾기 — 자료 검색 (5분 체험 + 3분 설명)

- 체험: "학생이 3번(내심)을 틀렸다 → 같은 개념 문항 찾기" (완성 문장으로 제공, 번호·개념만 바꿔 쓰기)
- **"솔직히 이런 생각 드시죠?"** — 21문항뿐이라 눈으로 찾는 게 빠르고, 번호 목록을 어디에 쓰나 싶다 → 맞다, 지금은 연습이라 자료가 작을 뿐
- **자료가 쌓이면**: 시험지 1장·21문항 vs 3년치 기출 + 교재 몇 권·수백 문항 (몇 시간 → 몇 분)
- 활용 상황 3가지: 오답 보충 숙제 / 다음 주 수업 자료 모으기 / 학부모 상담 질문에 바로 답하기
- 학원에 돌아가 내 기출·교재로 같은 요청을 해 보도록 권하기

## 10. 문항별 기본 분석표 + 원문 대조 (12분)

```
시험지의 모든 문항을 | 문항번호 | 출제단원 | 주요 출제내용 | 표로 정리해주세요.
주요 출제내용은 "무엇을 알아야 풀 수 있는지" 한 문장으로.
판단이 어려운 문항은 '확인 필요'. 마지막에 전체 문항 수와 분석 문항 수를 비교해주세요.
```
- 원문 대조: 문항 수 → 번호 → 단원 → 출제내용. 틀린 곳은 **그 부분만** 고치기
  - "4번 문항의 단원을 원문 근거로 다시 판단하고 이유를 설명해주세요"
- 이 표는 DAY 02에서 이어서 씁니다 (프로젝트 안에 두기)

**비교 메시지**: 이 표를 손으로 만들면 1시간 이상. AI 초안 2분 + 확인 15분.
AI는 "대신 해 주는 것"이 아니라 **"초안을 먼저 받아 놓고 나는 확인만 하는 것"**.

## 10-1. 분석표를 엑셀 파일로 받아 바로 쓰기 (8분)
