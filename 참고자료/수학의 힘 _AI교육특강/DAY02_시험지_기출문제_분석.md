# 1교시 (50분) — 한 시험지를 깊게

## 01. 지난 시간 이어서 (5분)

- 프로젝트 "수학의 힘 자료실" 열기 → 지난 시간 분석표가 있는 채팅 열기
- 오늘의 흐름: **유형·요구 개념 → 난이도 → 출제 비중 → 기출 비교 → 지도 방향 → 상담 자료**
- 결석했거나 프로젝트가 없다면: 새 프로젝트 → 시험지 올리기 → 기본 분석표 요청문(아래) 한 번 실행

```
시험지의 모든 문항을 | 문항번호 | 출제단원 | 주요 출제내용 | 표로 정리해주세요.
판단이 어려운 문항은 '확인 필요'. 마지막에 전체 문항 수와 분석 문항 수를 비교해주세요.
```

## 02. 유형과 요구 개념 더하기 (15분)

**분류 기준은 내가 먼저 준다** — 유형은 정답처럼 하나로 정해지지 않기 때문

유형 기준 예: 계산형 / 개념 확인형 / 개념 적용형 / 추론형 / 서술·증명형

```
기존 분석표에 '문제유형', '핵심 요구개념', '함께 필요한 개념' 열을 추가해주세요.
문제유형은 [계산형 / 개념 확인형 / 개념 적용형 / 추론형 / 서술·증명형] 중 하나로.
기존 내용은 바꾸지 말고 열만 추가해주세요. 애매한 문항은 이유를 함께 써주세요.
```

- 동의하지 않는 분류는 "○번은 ○○형으로 보는데, 원문 근거로 다시 판단해주세요" — 최종 분류는 선생님이
- "함께 필요한 개념"에 앞 학년 개념이 나오면 → 학생이 막히는 진짜 이유를 찾는 단서

## 03. 난이도 — AI는 근거를, 판단은 선생님이 (20분) ★

**왜 AI에게 상·중·하를 맡기지 않는가**
- 난이도는 학생 집단·수업 진도에 따라 달라지는 "판단"이다
- 특히 도형 문항은 그림을 잘못 읽으면 난이도 판단도 같이 틀어진다 (DAY 01에서 확인한 것)

**AI에게 맡길 것 = 판단 근거 모으기**
```
각 문항에 대해 다음을 표로 정리해주세요.
| 문항번호 | 필요한 개념 수 | 풀이 단계 수(대략) | 조건 해석이 필요한가 | 보조선·추론이 필요한가 |
그림이 있는 문항은 그림에서 읽은 정보를 한 줄로 함께 적어주세요.
```

**선생님이 할 것**
- 근거표를 보고 상·중·하를 직접 적거나, 기준을 주고 AI 초안을 받은 뒤 고치기
  - 하: 개념 1개 직접 적용 / 중: 개념 2개 이상 연결, 여러 단계 / 상: 복합 적용, 보조선·전략 선택
- AI 초안과 내 판단이 다른 문항 → 그 문항을 다시 보면 "AI가 그림을 잘못 읽었는지" 바로 드러난다

**메시지**: 지금은 AI가 도형 문항을 완벽히 풀어 내지 못해도, "근거를 먼저 모으고 판단은 사람이" 하는 방식은
AI가 좋아질수록 더 빨라진다. 좋아진 날에는 근거표의 정확도만 올라갈 뿐, 방법은 그대로다.

## 04. 출제 비중과 검산 (10분)

```
분석표를 기준으로 단원별 / 난이도별 출제 비중을 계산해주세요.
| 구분 | 문항 수 | 문항 비율 | 배점 합계 | 배점 비율 | 마지막 줄에 합계.
```
- 검산: 문항 수 합계 = 전체 문항 수? 배점 합계 = 100점? 비율 하나는 계산기로 직접
- 메시지: **문항 수가 많다고 비중이 큰 게 아니다** — 배점까지 같이 보기

# 2교시 (50분) — 넓게 보고 수업에 연결

## 05. 여러 기출 비교 — 방법 알기 (강사 시연, 7분)

- 실습 시험지가 한 장뿐이라 비교는 **강사 시연**으로 보여 주고, 요청문과 결과 읽는 법만 익힌다
- 학원에 돌아가 같은 학교·학년 기출 2~3개를 올려 같은 요청을 해 보도록 안내
```
프로젝트의 시험지들을 각각 확인한 뒤 비교표로 정리해주세요.
비교 항목: 단원별 출제 비중 / 반복 출제 개념 / 고배점 문항의 특징 / 서술형의 특징
실제 시험지에서 확인되는 내용만 쓰고, 다음 시험을 예측하지는 말아주세요.
```
- 좋은 분석: "3개 시험 모두 합동을 쓰는 문항이 2개 이상" / 주의: "다음 시험에도 반드시 나온다"
- 기출 분석은 **미래 예측이 아니라 과거의 반복을 확인하는 일**

## 06. 분석을 지도 방향으로 (10분)

```
지금까지의 분석으로 | 분석 결과 | 지도 시 확인할 내용 | 추천 학습 방향 | 표를 만들어주세요.
시험지에서 확인되지 않는 학생 개인의 수준이나 성향은 가정하지 말아주세요.
```
예: 서술형에서 근거 작성이 반복 요구됨 → 풀이 과정·근거 쓰기 연습 강화

## 07. 학생 한 명의 오답 → 학부모 상담 한 장 (15분) ★ 끄덕임 포인트

```
학생 A의 틀린 문항: 3, 7, 12, 15번
분석표와 연결해 다음을 정리해주세요.
1. 오답 문항의 공통 단원·개념·유형
2. 우선 복습할 내용 3가지
3. 학부모 상담용 한 장 요약 (전문 용어 없이, 5줄 이내)
학생의 능력이나 성격은 추측하지 말고 주어진 정보만 쓰세요.
```
- 이름 대신 "학생 A". 결과는 **상담 초안** — 실제 풀이를 본 선생님의 판단으로 마무리
- 반 전체라면? "학생 A~E의 오답을 모아 반 전체가 공통으로 약한 단원" (더 해 보기)

## 07-1. 학생·학부모용 시험 대비 안내문 (8분)

```
지금까지의 분석으로 학생·학부모에게 보낼 시험 대비 안내문을 써주세요.
- 지난 시험에서 비중이 컸던 단원과 꼭 복습할 개념 / 서술형 준비 방법
- 문자용 7줄 이내 / "반드시 나온다", 성적 보장 표현 금지
```
- 확인: 단원·비중이 분석표와 같은가, "지난 시험에서는 ~"처럼 사실로만 썼는가

## 07-2. 서술형 모범 답안과 채점 기준 초안 (10분) ★ 강사님들이 반길 부분

```
서술형 1번: 1) 그림 정보 먼저 글로 2) 모범 답안(단계별) 3) 부분 점수 채점 기준(배점에 맞게) 4) 자주 하는 실수
풀이에 확신이 없는 단계는 [확인 필요]
```
- **경고**: AI 수학 풀이는 틀릴 수 있다(특히 도형). 모범 답안은 반드시 선생님이 직접 풀어 확인
- AI가 맡는 것은 채점 기준표의 틀과 문장. 강사 회의 전 채점 기준 통일에 활용

## 08. 오늘의 분석을 한 번에 — 나의 기출 분석 요청문 (3분)

오늘 쓴 요청을 하나로 묶어 메모장에 저장 (다음 시험 때 그대로)
```
프로젝트의 [시험지]를 분석해주세요.
1. 전체 문항 수와 배점 확인
2. 문항별 표: 문항번호 / 단원 / 유형 / 요구 개념 / 판단 근거(개념 수·단계 수) / 배점
3. 그림이 있는 문항은 그림에서 읽은 정보를 따로 적기
4. 단원별·유형별 배점 비율
5. 반복 개념과 고배점 문항 특징
원문에 근거해서만 쓰고, 불확실하면 '확인 필요'. 마지막에 문항 수 대조.
```
