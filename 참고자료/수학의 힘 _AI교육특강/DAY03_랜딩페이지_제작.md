# 1교시 (50분) — 기획하고 만들기

## 01. 랜딩페이지란? (5분)

- 한 가지 목적(모집·설명회·특강)을 위한 **한 페이지짜리** 웹페이지
- 일반 홈페이지: 여러 메뉴, 학원 전체 소개 / 랜딩페이지: 한 페이지, **상담·신청 하나로 연결**
- 학원 활용 예: 겨울방학 특강 모집, 예비고1 설명회 신청, 신규 반 개설 안내

## 02. 목적 정하기 + 학원 정보 카드 (10분)

디자인보다 먼저 정할 것
- 누구에게 (예비고1 학부모 / 중등 내신반 학생)
- 무엇을 (학원 전체 / 특정 과정 / 설명회)
- 마지막에 무엇을 하게 할지 (전화 상담 / 설명회 신청 / 위치 확인)

**학원 정보 카드** — 한 번 적어 두면 오늘 페이지와 DAY 04 PPT·홍보 문구에 그대로 씁니다
```
학원명:
대상:
소개할 과정:
교육 방식:
특징 2~3개:
상담 방법 (전화·주소):
```
정보가 부족하면 → "랜딩페이지에 필요한 정보를 한 번에 하나씩 질문해주세요"

## 03. 페이지 구조 기획 (5분)

첫 화면(학원명·핵심 메시지·상담 버튼) → 학원 소개 → 교육 특징 → 프로그램 → 상담 안내

```
위 정보 카드로 1페이지 랜딩페이지를 기획해주세요.
영역: 첫 화면 / 학원 소개 / 교육 특징 / 프로그램 / 상담 안내
영역마다 제목 / 들어갈 문구 / 버튼을 표로. 과장된 광고 표현은 쓰지 마세요.
```
→ 문구를 먼저 확인하고 틀린 사실(과정명·연락처)부터 고치기

## 04. Claude로 만들기 (10분)

```
위 기획으로 수학학원 홍보용 1페이지 웹사이트를 만들어주세요.
- HTML 파일 하나로 실행
- 깔끔하고 신뢰감 있는 학원 홈페이지 느낌
- 휴대폰에서도 읽기 편하게
- 코드에 한국어 설명(주석)을 달아 쉽게 고칠 수 있게
```
- Claude 오른쪽에 미리보기가 뜬다 → 첫 모습 확인 (끄덕임 포인트 1)

## 05. 파일 두 가지만 알기 (5분)

- HTML = 내용과 뼈대 (`<h1>` 큰 제목, `<p>` 문장, `<button>` 버튼)
- CSS = 보이는 모습 (글자 크기, 색, 여백)
- **index.html** = 주소로 들어오면 가장 먼저 열리는 파일 이름
- 코드를 외울 필요 없음. "어디를 말하는지" 알 정도면 충분

## 06. index.html로 저장하고 열어 보기 (15분)

1. 바탕화면에 `my-page` 폴더
2. Claude에서 코드 복사 (또는 미리보기의 내려받기)
3. 메모장 → 붙여넣기 → 다른 이름으로 저장: `index.html`, 파일 형식 "모든 파일", 인코딩 "UTF-8"
4. 더블클릭 → 브라우저에서 확인
5. 브라우저 창을 좁혀 휴대폰 크기로도 보기

# 2교시 (50분) — 고치고 인터넷에 올리기

## 07. 말로 고치기 — 한 번에 한 곳씩 (15분) ★

- 나쁜 예: "전체적으로 더 좋게 해줘" → 어디가 바뀔지 모름
- 좋은 예: "첫 화면만. 제목은 짧게, 설명은 2줄 이내, 상담 버튼은 제목 아래로. 다른 영역은 그대로."

**고치는 요청의 틀**
```
[영역]만 수정해주세요.
이렇게: [구체적으로]
그대로 둘 것: [나머지]
수정된 전체 코드를 주세요.
```
2개 이상 고쳐 보기 (문구 / 영역 순서 / 버튼 / 여백·글자 크기)
→ 받은 코드를 index.html에 덮어써 저장 → 새로고침

## 08. 올리기 전 점검 (5분)

- 학원명·과정명·연락처가 정확한가 / 임시 문구("OOO")가 없는가
- "성적 보장" 같은 사실과 다른 표현이 없는가
- 파일 이름이 index.html인가

## 09. 닷홈에 올리기 (25분)

**웹 서버·FTP 한 줄 개념**: 내 컴퓨터의 파일은 나만 본다 → 인터넷에 늘 켜진 컴퓨터(웹 서버)에 올려야 누구나 본다 → 올리는 방법이 FTP

FTP 연결은 무료 프로그램 **파일질라(FileZilla Client)**를 사용합니다.

1. 닷홈 로그인 → **무료 호스팅 신청** → 관리 페이지에서 FTP 주소·아이디·업로드 폴더·내 웹 주소 확인
2. 파일질라 설치 — filezilla-project.org → **FileZilla Client** 내려받기 (Server 아님) → 설치
   - 설치 중 함께 설치를 권하는 다른 프로그램은 체크 해제
3. 파일질라 실행 → 위쪽 **빠른 연결** 줄에 호스트(FTP 주소)·사용자명(아이디)·비밀번호 입력, 포트는 비워 두기(기본 21) → 빠른 연결
   - 연결되면 아래 창이 둘로 나뉨: **왼쪽 = 내 컴퓨터, 오른쪽 = 서버**
4. 오른쪽에서 업로드 폴더로 이동 → 왼쪽 my-page 안의 index.html을 오른쪽으로 끌어다 놓기 (같은 이름이 있으면 덮어쓰기)
5. 내 웹 주소 접속 → **내 휴대폰으로도 열어 보기** (끄덕임 포인트 3)

주의: FTP 비밀번호는 공유하지 않고 AI 채팅에도 넣지 않는다
메뉴 이름·위치는 바뀔 수 있음 → 막히면 Claude에게 "닷홈 무료 호스팅에서 FTP 정보를 확인하는 순서" 묻기

## 10. 안 보일 때 (5분)

| 증상 | 확인 |
|---|---|
| 페이지가 안 보임 | 파일 이름 index.html? 올바른 업로드 폴더? |
| 이미지가 안 보임 | images 폴더도 올렸나? 파일 이름(대소문자)이 코드와 같나? |
| 고쳤는데 그대로 | 다시 저장 → 다시 업로드(덮어쓰기) → 새로고침 |
| 한글이 깨짐 | 메모장에서 UTF-8로 다시 저장 |
