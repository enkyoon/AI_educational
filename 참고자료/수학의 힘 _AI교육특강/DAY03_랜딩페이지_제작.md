## 01. 랜딩페이지란?

랜딩페이지는 방문자가 특정 목적을 위해 처음 도착하는 **한 페이지 중심의 웹페이지**이다.

학원에서는 다음과 같은 용도로 활용할 수 있다.

- 신규 학생 모집
- 학부모 상담 신청
- 설명회 안내
- 방학 특강 모집
- 예비중·예비고 과정 안내
- 특정 프로그램 소개

### 일반 홈페이지와 랜딩페이지의 차이

| 구분 | 일반 홈페이지 | 랜딩페이지 |
|---|---|---|
| 구성 | 여러 메뉴와 페이지 | 한 페이지 중심 |
| 목적 | 학원 전체 정보 제공 | 특정 과정·상담·모집 안내 |
| 정보량 | 비교적 많음 | 필요한 정보만 선별 |
| 방문자의 행동 | 여러 페이지 탐색 | 상담·신청 등 하나의 행동으로 연결 |

---

# 02. 페이지 제작 전에 목적 정하기

웹페이지를 만들기 전에 가장 먼저 정해야 하는 것은 디자인이 아니라 **페이지의 목적**이다.

## 먼저 확인할 내용

### 1. 누구에게 보여줄 것인가?

예:

- 예비중 학생과 학부모
- 중학생 학부모
- 예비고1 학생
- 고등 내신 대비 학생
- 방학 특강을 찾는 학생

### 2. 무엇을 소개할 것인가?

예:

- 학원 전체
- 특정 학년 과정
- 내신 대비 프로그램
- 겨울방학 특강
- 설명회
- 집중 관리 프로그램

### 3. 방문자가 무엇을 하길 원하는가?

예:

- 상담 신청
- 전화 문의
- 프로그램 확인
- 설명회 신청
- 학원 위치 확인

Claude에게 실제 웹페이지 코드를 생성하도록 요청한다.

이번 과정에서는 코드를 직접 처음부터 작성하는 것보다

## 기본 생성 요청

```text
아래 내용을 바탕으로

[페이지 내용 붙여넣기]

요구사항:
- HTML 파일 하나로 실행할 수 있게 작성

- 하단에 상담 문의 영역 추가
- 사용자가 내용을 쉽게 수정할 수 있도록 코드에 주석 추가

```

# 06. 웹페이지 파일 이해하기

생성된 웹페이지를 수정하기 위해 모든 코드를 이해할 필요는 없다.

이번 과정에서 필요한 핵심만 확인한다.

## HTML

웹페이지의 **내용과 구조**를 담당한다.

예:

```html
<h1>수학의 힘 학원</h1>
<p>학생의 현재 수준에서 시작하는 수학 학습</p>
```

- `<h1>` : 큰 제목
- `<p>` : 일반 문장
- `<button>` : 버튼
- `<section>` : 페이지의 하나의 영역

---

## CSS

웹페이지의 **디자인**을 담당한다.

예:

```css
h1 {
  font-size: 42px;
}
```

글자 크기, 여백, 배치, 배경 등  
화면에 보이는 모습을 조정한다.

---

## 가장 중요한 파일

기본적인 1페이지 웹사이트에서는 보통 다음 파일을 사용한다.

```text
index.html
```

웹사이트 주소로 접속했을 때  
가장 먼저 열리는 기본 페이지로 사용된다.

# 11. 웹 게시 전 최종 점검

웹에 올리기 전에 로컬에서 먼저 확인한다.

## 콘텐츠 확인

- [ ] 학원명이 정확하다.
- [ ] 과정명과 대상 학년이 정확하다.
- [ ] 날짜·시간·연락처에 오류가 없다.
- [ ] 임시 문구가 남아 있지 않다.
- [ ] 과도하거나 사실과 다른 홍보 표현이 없다.

## 화면 확인

- [ ] 제목과 본문의 구분이 명확하다.
- [ ] 한 영역에 내용이 너무 많지 않다.
- [ ] 버튼이 정상적으로 보인다.
- [ ] 이미지가 깨지지 않는다.
- [ ] 모바일에서도 내용을 읽을 수 있다.

## 파일 확인

- [ ] 기본 파일명이 `index.html`이다.
- [ ] 이미지 파일 경로가 정상적이다.
- [ ] 필요한 파일이 한 폴더에 정리되어 있다.

# 12. 웹사이트가 인터넷에 보이는 구조

내 컴퓨터에서 `index.html`을 열면  
현재 컴퓨터에서만 웹페이지를 확인할 수 있다.

다른 사람도 주소를 통해 접속하게 하려면  
웹사이트 파일을 **웹 서버**에 올려야 한다.

## 기본 흐름

**내 컴퓨터의 웹페이지 파일  
→ FTP를 이용해 서버에 업로드  
→ 웹주소로 접속**

---

# 13. FTP란?

FTP는 내 컴퓨터의 파일을  
웹 서버로 전송할 때 사용하는 방법 중 하나이다.

웹페이지 게시 과정에서는 다음 정보가 필요하다.

- 서버 주소
- 사용자 계정
- 비밀번호
- 연결 정보
- 업로드할 폴더

이 정보는 사용하는 호스팅 서비스의 관리페이지에서 확인한다.

---

# 14. 닷홈을 이용한 웹 게시

이번 실습에서는 닷홈의 웹 공간과 FTP를 활용하여  
제작한 웹페이지를 인터넷에 게시한다.

## 기본 과정

### STEP 1. 웹 공간 준비

닷홈에서 사용할 웹 공간을 준비하고  
관리페이지에서 접속 정보를 확인한다.

### STEP 2. FTP 접속 정보 확인

다음 정보를 확인한다.

```text
FTP 서버 주소 :
FTP 아이디 :
FTP 비밀번호 :
업로드 경로 :
```

### STEP 3. FTP 프로그램에서 서버 접속

FTP 프로그램을 실행하고  
확인한 정보를 입력하여 서버에 접속한다.

### STEP 4. 웹페이지 파일 업로드

제작한 다음 파일을 서버의 웹 공개 폴더에 업로드한다.

```text
index.html
images/
기타 사용한 파일
```

### STEP 5. 웹주소 접속

업로드가 완료되면  
발급받은 웹주소로 접속하여 페이지를 확인한다.

---

# 15. 업로드 후 확인하기

파일을 올렸다고 해서 작업이 끝난 것은 아니다.

실제 웹주소로 접속하여 다시 확인한다.

## 게시 후 체크리스트

- [ ] 웹주소가 정상적으로 열린다.
- [ ] `index.html`이 첫 화면으로 표시된다.
- [ ] 글자가 깨지지 않는다.
- [ ] 이미지가 정상적으로 표시된다.
- [ ] 버튼과 링크가 정상적으로 작동한다.
- [ ] PC와 모바일에서 모두 확인했다.

---

# 16. 자주 발생하는 문제 확인하기

## 페이지가 보이지 않는 경우

확인할 내용:

- `index.html` 파일명이 맞는가
- 올바른 서버 폴더에 업로드했는가
- 파일 업로드가 완료되었는가

---

## 이미지가 보이지 않는 경우

확인할 내용:

- 이미지 파일도 서버에 업로드했는가
- 이미지 파일명이 코드와 동일한가
- `images/파일명` 경로가 맞는가

예:

```html
<img src="images/academy.jpg">
```

---

## 수정했는데 웹에서 바뀌지 않는 경우

확인할 내용:

- 수정한 파일을 다시 저장했는가
- 서버에 새로운 파일을 다시 업로드했는가
- 기존 파일을 정상적으로 덮어썼는가
- 브라우저를 새로고침했는가

## 기억해야 할 5가지

### 1. 웹페이지 제작은 목적부터 시작한다

디자인보다 먼저  
누구에게 무엇을 보여줄 것인지 정한다.

### 2. Claude에게 페이지의 내용과 구조를 함께 전달한다

“홈페이지를 만들어줘”보다  
필요한 영역과 내용을 구체적으로 알려준다.

### 3. 모든 코드를 직접 작성할 필요는 없다

코드를 직접 외우는 것보다  
원하는 결과를 설명하고 수정하는 방법이 중요하다.

### 4. 수정할 부분을 정확하게 지정한다

전체를 반복해서 새로 만들기보다  
필요한 영역만 선택하여 수정한다.

### 5. 게시 후 실제 웹주소에서 다시 확인한다

내 컴퓨터에서 정상적으로 보이는 것과  
인터넷에 정상적으로 게시되는 것은 별도의 과정이다.
