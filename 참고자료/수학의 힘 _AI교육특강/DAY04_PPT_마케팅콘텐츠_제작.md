## 오늘의 핵심 관점 — "AI가 만든 PPT는 완성본이 아니라 레퍼런스"

- AI는 아직 PPT **디자인**을 사람 눈에 차게 잘하지는 못한다 (배치가 어색하거나, 글이 많거나, 학원 분위기와 다르다)
- 그런데 **백지에서 시작하는 것**과 **참고할 시안을 옆에 띄워 놓고 시작하는 것**은 완전히 다르다
  - 백지: 구성 고민 → 문구 작성 → 배치 고민 → 디자인 … 3시간
  - 레퍼런스: AI 시안에서 구성·문구·배치 아이디어를 골라 내 템플릿에 반영 … 1시간
- **3시간 걸릴 일이 1시간으로 줄었다면, 그것만으로 AI 활용은 성공이다**
- 그대로 쓰지 않아도 된다. 좋은 부분만 가져오면 된다 — 이 기준이 오늘 수업 전체를 관통합니다

## 이 수업의 "끄덕임 포인트" (강사용)

1. **설명회 PPT 5장 시안이 몇 분 만에 파일로 나온다** — "구성 고민이 사라지네"
2. **시안을 옆에 띄워 놓고 내 템플릿에 옮기는 속도** — "처음부터 만들 때랑 다르다"
3. **같은 정보 하나로 안내문·SNS 문구가 연달아** — "홍보물마다 새로 쓸 필요가 없구나"
4. **Flow 시연 — 우리 학원 교실 느낌 영상이 글로 만들어진다**

# 1교시 (50분) — 설명회 PPT: 시안 받기 → 레퍼런스로 쓰기

## 01. 하나의 정보, 여러 콘텐츠 (5분)

원본 정보 → 설명회 PPT → 모집 안내문 → SNS 문구 → 영상 프롬프트
**원본 정보가 정확해야 모든 결과물이 정확하다**

## 02. 원본 정보 정리 (8분)

DAY 03의 학원 정보 카드가 있으면 그대로 사용. 없으면 채우기 (예: 예비고1 겨울방학 공통수학 집중반)
```
과정명 / 대상 / 필요한 이유 / 핵심 수업 내용 / 운영 방식 / 일정 / 신청 방법
```
- 날짜·인원·수강료처럼 **정해지지 않은 것은 비워 둔다** (AI가 그럴듯한 숫자로 채우지 않게)

## 03. PPT 구성과 시안 받기 (15분)

**먼저 구성 (5장)**: 문제·상황 제시 → 교육 방향 → 프로그램 안내 → 관리 방식 → 상담·신청

```
다음 정보로 학부모 설명회 PPT 5장을 만들어주세요.
[원본 정보]
- 한 장에 핵심 메시지 하나, 본문 3줄 이하
- 제공한 정보에 없는 내용은 만들지 말 것
- 차분하고 신뢰감 있는 학원 설명회 분위기
PPT 파일로 만들어주세요.
```
- Claude가 PPT 파일을 만들어 준다 → 내려받아 열어 보기
- 파일이 안 만들어지면: 장별 구성(제목·본문)을 표로 받아도 된다

## 04. AI 시안 평가하기 — 무엇을 가져올까? (7분)

시안을 열고 장마다 표시해 봅니다.

| 가져올 것 (○) | 버릴 것 (✕) |
|---|---|
| 장 순서와 흐름 | 학원 분위기와 안 맞는 색·글꼴 |
| 제목 문구, 핵심 메시지 | 글이 너무 많은 장 |
| 숫자·키워드를 강조한 배치 아이디어 | 어색한 도형·아이콘 배치 |

→ 대부분 "구성과 문구는 쓸 만하고, 디자인은 절반쯤" 이라는 결론이 나온다. 그게 정상이다.

## 05. 레퍼런스를 옆에 두고 내 PPT 만들기 (15분) ★

1. 학원에서 쓰던 PPT 템플릿(없으면 PowerPoint·Google 슬라이드 기본 테마) 열기
2. **화면 한쪽에 AI 시안, 다른 쪽에 내 PPT** — 나란히 띄우기
3. 장마다: 제목·문구는 복사해 오고, 배치는 "이 아이디어만" 가져와 내 스타일로
4. 한 장이 넘치면 Claude에게: "3장 본문을 2줄로 줄여주세요"

**문장 줄이기 요령**
- 보고서 문장: "고등학교에 진학한 뒤 수학 학습에 어려움을 느끼는 학생들의 경우 …"
- PPT 문장: "고등 수학의 기초 = 공통수학 개념의 정확한 이해"

**정리 멘트**: 오늘 1장을 만드는 데 걸린 시간을 떠올려 보세요. 백지였다면 구성부터 고민했을 겁니다.
이 시간 차이가 AI 활용의 진짜 가치입니다.

# 2교시 (50분) — 홍보 문구와 영상

## 06. 모집 안내문 (8분)

```
앞의 설명회 내용으로 학부모 대상 모집 안내문을 써주세요.
대상 / 과정 / 주요 내용 / 신청 방법 포함, 300자 내외, 과장 없이.
```

## 07. SNS 문구 (7분)

```
같은 내용을 인스타그램 게시글로 바꿔주세요.
첫 문장에 대상이 바로 보이게, 5~7줄, 마지막에 상담 안내.
```
- 이어서 요청: "블로그용으로 조금 길게", "문자 발송용 3줄로"

## 08. 홍보 문구 점검 — 학원 광고에서 특히 조심할 것 (5분)

- "성적 향상 보장", "100% 합격", "1등급 만들어 드립니다" 같은 **결과를 약속하는 표현**은 빼기
- 대상 학년·과정명·일정이 원본 정보와 같은지 확인
```
다음 문구에서 과장되거나 결과를 보장하는 표현을 찾아
실제 운영 내용에 근거한 차분한 문장으로 바꿔주세요.
```

## 09. 영상은 "장면"으로 나눈다 (10분)

- PPT·문구가 "무엇을 말할지"라면, 영상은 "어떤 장면으로 보여 줄지"
- 한 장면에 다 넣으면 실패: "학생이 공부하고 선생님이 설명하고 공식이 나오고 로고가 나오고…" ✕
- 15초 = 4장면: 문제집 펼치기 → 칠판에 개념 정리 → 오답 확인 → 학원명·과정 안내

```
이 과정을 소개하는 15초 홍보영상을 4장면으로 나눠주세요.
장면마다 화면 / 주요 행동 / 분위기 / 필요한 문구를 표로. 차분하고 전문적인 학원 홍보 영상.
```

## 10. Flow 프롬프트 작성 + 강사 시연 (15분)

**영상 프롬프트 = 대상 + 공간 + 행동 + 카메라 + 분위기**

```
앞의 4장면을 Google Flow 영상 생성용 프롬프트로 바꿔주세요.
장면마다 대상 / 공간 / 행동 / 카메라 움직임 / 분위기를 한 문단으로.
한 장면에 요소를 너무 많이 넣지 말고, 실제 학원 수업 같은 자연스러운 장면으로.
```

예: 밝고 정돈된 수학학원 교실. 책상 위 문제집과 노트. 학생이 중요한 개념에 밑줄을 긋는다.
카메라는 책상 위를 천천히 이동한다. 차분하고 집중감 있는 학습 분위기.

- **강사 시연**: 수강생 프롬프트 1~2개를 받아 Flow에서 생성해 함께 보기
- 영상도 PPT와 같다 — 한 번에 완성본이 아니라 **장면 소스**. 마음에 드는 장면만 골라 편집에 쓴다
- 화면 속 글자는 틀리기 쉬우니, 학원명·문구는 편집할 때 넣는다
