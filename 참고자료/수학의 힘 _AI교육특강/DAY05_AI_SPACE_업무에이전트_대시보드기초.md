# DAY 05. AI SPACE 업무 에이전트와 대시보드 기초

> **과정명:** 수학의 힘 : AI 교육특강  
> **수업 주제:** 반복 업무를 AI 에이전트로 설계하고 결과를 관리하는 방법  
> **학습 목표:** 학원에서 반복되는 업무를 선택하고, 입력값·처리기준·출력값을 설계하여 평가 피드백 에이전트를 구성·테스트한 뒤 대시보드의 기본 활용 방식을 이해할 수 있다.

---

## 01. AI 에이전트란?

AI 에이전트는 매번 같은 설명을 반복해서 입력하는 대신,  
**정해진 업무를 일정한 기준과 형식으로 처리하도록 구성한 AI 작업 방식**이다.

예를 들어 학생 평가 피드백을 매번 새롭게 요청할 수도 있지만,  
반복적으로 사용하는 기준과 출력 형식을 미리 정해두면  
같은 유형의 업무를 더 일관되게 처리할 수 있다.

---

## 일반적인 AI 대화와 업무 에이전트의 차이

### 일반적인 AI 대화

```text
학생이 이번 시험에서 72점을 받았고
함수 단원에서 많이 틀렸습니다.

학습 피드백을 작성해주세요.
```

학생이 바뀔 때마다  
필요한 조건과 결과 형식을 다시 설명해야 한다.

---

### 업무 에이전트

미리 다음 내용을 정해둔다.

- 어떤 정보를 입력할 것인가
- 어떤 기준으로 처리할 것인가
- 어떤 결과를 만들 것인가
- 어떤 형식으로 출력할 것인가

그 다음 학생별 정보만 입력하여  
같은 구조의 결과를 반복해서 생성한다.

---

# 02. 에이전트로 만들 업무 선택하기

모든 업무를 에이전트로 만들 필요는 없다.

다음과 같은 특징이 있는 업무가 적합하다.

- 자주 반복된다.
- 입력되는 정보의 형식이 비슷하다.
- 처리 기준을 설명할 수 있다.
- 원하는 결과 형식이 어느 정도 정해져 있다.

---

## 학원 업무 예시

- 학생 시험 결과 정리
- 학습 피드백 초안 작성
- 오답 문항 요약
- 취약 단원 정리
- 상담 전 학생 정보 요약
- 수업 후 학습 상태 정리

이번 실습에서는  
**학생 평가 피드백 업무**를 중심으로 진행한다.


## 기본 구조

**입력값 → 처리기준 → 출력값**

---

## 예시: 학생 평가 피드백

### 입력값

- 학년
- 시험 점수
- 틀린 문항
- 취약 단원
- 교사 메모

### 처리기준

- 취약 단원 확인
- 반복되는 오답 특징 정리
- 우선 복습할 내용 결정
- 다음 학습 방향 정리

### 출력값

- 현재 학습 상태
- 주요 취약점
- 우선 복습 내용
- 다음 학습 방향
- 학부모 전달용 간단한 피드백

```text
↓
```

# 04. 입력값 설계하기

입력값은 에이전트가 업무를 처리하기 위해  
사용자가 제공해야 하는 정보이다.

입력값을 정할 때는  
**실제로 판단에 필요한 정보만 선택하는 것**이 중요하다.

---

## 학생 평가 피드백 입력값 예시

| 입력 항목 | 예시 |
|---|---|
| 학년 | 중학교 2학년 |
| 시험 점수 | 72점 |
| 오답 문항 | 4, 7, 12, 15번 |
| 취약 단원 | 삼각형의 성질 |
| 교사 메모 | 개념은 이해하나 응용문제에서 시간이 오래 걸림 |

---

## 필요하지 않은 정보는 줄이기

예를 들어 학생의 이름이  
피드백 내용 자체에 꼭 필요한 정보가 아니라면  
실습에서는 이름 대신 다음과 같이 사용할 수 있다.

```text
학생 A
학생 B
학생 C
```

실제 학생 자료를 사용할 경우에는  
수업에 꼭 필요하지 않은 개인 식별정보를 제외하고 활용한다.

# 05. 출력값 설계하기

출력값은 에이전트가 업무를 처리한 뒤  
최종적으로 보여줄 결과이다.

출력값이 명확하지 않으면  
매번 다른 형태의 결과가 만들어질 수 있다.

---

## 학생 평가 피드백 출력 예시

### 1. 현재 학습 상태

시험 결과에서 확인되는 특징을 간단하게 정리

### 2. 주요 취약점

반복해서 확인되는 단원·개념·문제유형 정리

### 3. 우선 복습 내용

먼저 확인해야 하는 개념이나 유형 정리

### 4. 다음 학습 방향

다음 수업이나 복습에서 집중할 내용 정리

### 5. 학부모 전달용 피드백

전문적인 분석 내용을 짧고 이해하기 쉬운 문장으로 변환

---

## 출력 형식 예시

```text
[현재 학습 상태]

[주요 취약점]

[우선 복습 내용]

[다음 학습 방향]

[학부모 전달용 피드백]
```

입력값과 출력값이 정해졌다면

## 기본 구성

**역할 → 해야 할 일 → 판단 기준 → 출력 형식 → 주의사항**

---

## 평가 피드백 에이전트 예시

```text
당신은 수학학원의 학생 평가 피드백을 정리하는 업무를 담당합니다.

사용자가 입력한 학생의 시험 결과와 교사 메모를 바탕으로
학습 상태와 다음 지도 방향을 정리해주세요.

다음 순서로 결과를 작성해주세요.

1. 현재 학습 상태
2. 주요 취약점
3. 우선 복습 내용
4. 다음 학습 방향
5. 학부모 전달용 피드백

조건:
- 입력된 정보만 사용해주세요.
- 학생의 성격이나 능력을 임의로 추측하지 마세요.
- 부족한 정보가 있으면 임의로 채우지 말고 '확인 필요'라고 표시해주세요.
- 학부모 전달용 피드백은 너무 전문적인 용어를 사용하지 말고 간결하게 작성해주세요.
```

# 07. 지시문을 너무 복잡하게 만들지 않기

처음부터 모든 조건을 넣으면  
오히려 결과를 확인하기 어려울 수 있다.

먼저 핵심 업무부터 만들고  
테스트하면서 필요한 조건을 추가한다.

### 처음부터 너무 많은 조건을 넣은 경우

```text
학생의 수준을 5단계로 나누고,
성향도 분석하고,
다음 시험 예상점수도 제시하고,
학부모 상담문과 문자 메시지와 수업계획까지 만들어주세요.
```

### 필요한 업무부터 시작한 경우

```text
시험 결과와 교사 메모를 바탕으로
현재 학습 상태와 다음 지도 방향을 정리해주세요.
```

에이전트는  
**업무 하나를 정확하게 처리하도록 만드는 것부터 시작한다.**

# 08. AI SPACE에서 업무 에이전트 구성하기

AI SPACE에서 에이전트를 구성할 때는  
앞에서 정리한 업무 설계를 기준으로 설정한다.

## 구성 순서

### STEP 1. 업무 선택

어떤 반복 업무를 처리할 것인지 정한다.

### STEP 2. 입력값 설정

사용자가 어떤 정보를 제공할지 정한다.

### STEP 3. 업무 지시 작성

입력된 정보를 어떻게 처리할지 설명한다.

### STEP 4. 출력 형식 설정

결과가 어떤 순서와 형태로 나오도록 할지 정한다.

### STEP 5. 테스트

샘플 데이터를 입력하고 실제 결과를 확인한다.

### STEP 6. 수정

불필요하거나 부족한 부분을 찾아 지시문을 수정한다.

---

# 09. 샘플 데이터로 테스트하기

에이전트를 만든 뒤에는  
한 명의 데이터만 테스트해서 끝내지 않는다.

서로 다른 조건의 샘플을 넣어  
결과가 일정하게 나오는지 확인한다.

---

```text

시험 점수: 78점
오답 문항: 6, 8, 13, 15번
취약 단원: 사각형의 성질
교사 메모: 기본 문제는 해결하지만 복합 조건 문제에서 시간이 오래 걸림
```


---

## 샘플 C

```text
학년: 중학교 2학년
시험 점수: 63점

교사 메모: 개념 정리가 충분하지 않아 기본 유형에서도 오답이 반복됨
```

# 10. 테스트 결과 확인하기

에이전트가 결과를 생성하면  
다음 항목을 확인한다.

## 결과 확인 체크리스트

- [ ] 입력한 정보가 정확하게 반영되었다.
- [ ] 입력하지 않은 내용을 임의로 만들지 않았다.
- [ ] 출력 항목의 순서가 일정하다.
- [ ] 결과가 지나치게 길지 않다.
- [ ] 같은 표현이 반복되지 않는다.
- [ ] 학생마다 다른 결과가 만들어진다.
- [ ] 지도 방향이 실제 입력정보와 연결된다.
- [ ] 학부모용 문장이 이해하기 쉽다.

# 13. 입력과 출력의 범위 정하기

에이전트가 할 수 있는 일을  
필요 이상으로 넓히지 않는다.

### 평가 피드백 에이전트가 할 일

- 시험 결과 정리
- 취약 단원 확인
- 복습 우선순위 정리
- 지도 방향 초안 작성
- 학부모 전달용 문장 정리

### 별도로 확인해야 할 일

- 학생의 실제 풀이 과정
- 수업 중 이해도
- 장기적인 학습 변화
- 학생과의 상담 내용
- 최종 지도 판단

AI 에이전트는  
**교사의 판단을 대신하는 것이 아니라 반복적인 정리 업무를 지원하는 도구**로 활용한다.

# 14. 대시보드란?

대시보드는 여러 업무 결과나 정보를  
**한 화면에서 확인하기 쉽게 정리한 화면**이다.

에이전트가 한 번의 업무를 처리하는 도구라면,  
대시보드는 여러 처리 결과의 상태를 확인하고 정리하는 데 활용할 수 있다.

---

## 학원 업무에서 확인할 수 있는 예시

- 학생별 피드백 처리 결과
- 최근 평가 결과
- 확인이 필요한 학생
- 처리 완료 여부
- 반복되는 취약 단원
- 학생별 기록 상태

---

# 15. 에이전트와 대시보드의 관계

## 업무 흐름 예시

```text
학생 정보 입력
↓
평가 피드백 에이전트 실행
↓
피드백 결과 생성
↓
결과 저장 또는 정리
↓
대시보드에서 여러 결과 확인
```

### 에이전트

**하나의 업무를 처리**

### 대시보드

**여러 업무 결과를 모아서 확인**

# 16. 대시보드에서 중요한 정보 정하기

대시보드에 모든 정보를 넣을 필요는 없다.

한 화면에서 자주 확인해야 하는 정보만 선택한다.

## 예시

| 학생 | 학년 | 시험점수 | 주요 취약단원 | 피드백 상태 |
|---|---|---:|---|---|
| 학생 A | 중2 | 78 | 사각형의 성질 | 완료 |
| 학생 B | 중2 | 91 | 삼각형의 성질 | 완료 |
| 학생 C | 중2 | 63 | 삼각형의 성질 | 확인 필요 |

# 17. 대시보드 구성 원칙

### 1. 한눈에 확인할 수 있어야 한다

너무 많은 설명보다  
상태와 핵심 정보를 빠르게 확인할 수 있도록 구성한다.

### 2. 자주 보는 정보를 먼저 배치한다

매일 또는 매주 확인하는 정보를 우선한다.

### 3. 상세 내용과 요약 정보를 구분한다

대시보드에는 요약 정보를 표시하고  
필요할 때 상세 결과를 확인할 수 있도록 구성한다.

### 4. 상태를 구분한다

예:

- 완료
- 확인 필요
- 재검토
- 미처리

### 5. 대시보드 자체가 목적은 아니다

업무 결과를 더 쉽게 확인하고 관리하기 위한 도구로 사용한다.

## 오늘 배운 흐름

**반복 업무 선택 → 입력값 설계 → 처리기준 설정 → 출력값 설계 → 에이전트 구성 → 테스트 → 수정 → 대시보드로 결과 확인**

---

## 기억해야 할 5가지

### 1. 에이전트는 반복 업무에 적합하다

매번 비슷한 방식으로 처리하는 업무를  
일정한 흐름으로 만들 때 효과적이다.

### 2. 도구보다 업무 설계가 먼저다

AI SPACE에서 기능을 설정하기 전에  
입력·처리·출력 구조를 먼저 정한다.

### 3. 처음부터 완벽하게 만들지 않는다

간단한 업무부터 만든 뒤  
샘플 데이터를 넣어 테스트하면서 개선한다.

### 4. AI가 입력하지 않은 내용을 추측하지 않도록 한다

특히 학생 평가에서는  
제공된 정보와 AI의 추측을 구분하는 것이 중요하다.

### 5. 대시보드는 결과를 확인하기 위한 도구다

에이전트가 처리한 여러 결과를  
한 화면에서 관리하기 쉽게 만드는 것이 목적이다.

# 과정 최종 활용 방향

이번 과정에서 익힌 AI 활용 방법은  
특정 결과물을 한 번 만드는 데서 끝나는 것이 아니라  
학원에서 반복되는 업무에 계속 적용할 수 있다.

교재·시험지 검색 및 정리

### 분석 업무

기출문제 분석과 지도 방향 정리

### 홍보 업무

랜딩페이지·PPT·홍보문구 제작

학생 평가 피드백 에이전트 활용

핵심은 새로운 AI 기능을 많이 사용하는 것이 아니라  
**학원 업무의 목적과 기준을 명확하게 정한 뒤 AI가 그 업무를 지원하도록 만드는 것**이다.
