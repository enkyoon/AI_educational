# DAY 05. Claude로 만들고 AI SPACE로 배포하기

> **과정명:** 수학의 힘 : AI 교육특강 (5회차, 회당 2시간)
> **도구:** Claude (유료 계정) + 카페24 AI SPACE (14일 무료 체험)
> **공식 커리큘럼:** 업무 선정·입출력 설계 / 평가 피드백 에이전트 제작·테스트 / 처리 결과를 확인하는 대시보드 구성 시연
> **결과물:** 평가 피드백 도우미(웹 도구) 1개 + 인터넷 주소(`○○.mycafe24.ai`) + 나만의 업무 도구 설계서
> **한 줄 요약:** **Claude는 만들고, AI SPACE는 올린다.**

---

## 먼저 바로잡을 것 — AI SPACE는 무엇인가 (강사용)

카페24 AI SPACE는 **"AI 에이전트를 만드는 도구"가 아니라, AI로 만든 웹사이트·웹앱을 서버 지식 없이 인터넷에 올려 주는 배포 공간(호스팅)** 이다.

- Claude에 커넥터(MCP)로 연결해 두면 **"배포해줘" 한 마디**로 코드가 올라가고 `https://{호스팅ID}-{프로젝트명}.mycafe24.ai` 주소가 생긴다 (SSL 자동)
- 수정도 대화로: "문구 바꿔서 다시 배포해줘", "상태 보여줘", "로그 보여줘", "백업해줘"
- MySQL·PostgreSQL 같은 DB도 대화로 붙일 수 있다 → 데이터를 저장하는 앱도 가능
- AI 기능 자체는 없다. "만드는 일"은 Claude가 하고, AI SPACE는 그 결과를 **올려 두는 자리**

### 공식 표현 → 실제 수업 대조표

| 공식 커리큘럼 표현 | 실제로 하는 것 |
|---|---|
| 업무 선정·입출력 설계 | 반복 업무 하나를 골라 입력(넣는 정보)·처리(정리 기준)·출력(받을 결과)을 정한다 — 그대로 유지 |
| 평가 피드백 **에이전트** 제작·테스트 | AI SPACE 안에서 에이전트를 만드는 것이 아님. **Claude로 "평가 피드백 도우미" 웹 도구를 코딩**하고 샘플 A·B·C로 테스트·수정한다 |
| 플랫폼: 카페24 AI SPACE | 만든 도구를 **AI SPACE에 배포**해 내 인터넷 주소로 연다 |
| 처리 결과를 확인하는 대시보드 구성 시연 | 강사가 **DB를 붙인 "반 전체 피드백 현황판"** 을 만들어 배포하는 과정을 시연 |
| 결과물: 단일 업무 에이전트 기초 실습 | 결과물: 한 가지 업무만 하는 웹 도구 1개 + 배포 주소 + 설계서 |

> 수강생 화면에서는 "에이전트"라는 말을 앞세우지 않는다. "한 가지 업무를 정해진 기준대로 처리하는 **업무 도우미**"로 부르고, "이런 걸 업무 에이전트라고도 부릅니다" 정도로만 언급.

---

## 이 수업의 "끄덕임 포인트" (강사용)

1. **3회차와 비교** — "닷홈 가입 → 호스팅 신청 → 파일질라 → FTP 접속 → 업로드" 하던 일이 **"배포해줘" 한 마디**. 가장 크게 끄덕이는 장면
2. **내 휴대폰으로 내 도구가 열린다** — 주소를 받아 바로 휴대폰으로 열어 보기
3. **AI는 만들 때만 쓴다** — 완성된 도우미는 AI 없이 돌아간다. 같은 점수를 넣으면 늘 같은 결과, 학생 정보가 AI로 가지 않음, 사용료 없음
4. **현황판 시연** — 학생 결과가 저장되고 반 평균·취약 단원이 자동으로 모이는 화면. "이걸 말로 만들 수 있다고?"

# 1교시 (50분) — 연결하고, 설계하고, 만들기

## 01. 3회차를 떠올리며 — AI SPACE란? (7분)

| | 3회차 (닷홈) | 오늘 (AI SPACE) |
|---|---|---|
| 준비 | 회원가입 → 무료 호스팅 신청 → FTP 정보 확인 | 카페24 로그인 → 서비스 신청 → Claude에 연결(처음 1번) |
| 올리기 | 파일질라로 FTP 접속 → html 폴더에 파일 끌어다 놓기 | Claude에게 **"배포해줘"** |
| 주소 | `아이디.dothome.co.kr` | `호스팅ID-프로젝트명.mycafe24.ai` |
| 고치기 | 파일 고쳐서 다시 업로드 | "○○ 바꿔서 다시 배포해줘" |
| 올릴 수 있는 것 | 화면만 있는 페이지(HTML) 위주 | 화면 + 저장 기능(DB)이 있는 웹앱까지 |

비유: **Claude = 가게를 꾸며 주는 인테리어 업자, AI SPACE = 가게 자리(점포)**. 3회차엔 점포를 빌리고 짐을 직접 날랐다면, 오늘은 업자가 꾸미고 입주까지 해 준다.

## 02. 실습 01 — AI SPACE 신청 (8분)

1. hosting.cafe24.com → AI SPACE 상품 페이지 → **카페24 로그인** (지난 시간 숙제로 가입한 계정)
2. 이용약관 동의 → **서비스 신청** (14일 무료 체험)
3. "AI 연결" 단계는 다음 실습에서 하므로 건너뛰어도 됨

**무료 체험 꼭 알아 둘 것**
- 카드 등록 없음, 끝나도 **자동 결제 없음** (종료 5·3·1일 전 알림)
- 사양: 메모리 256MB, 저장공간 500MB, 동시 접속 25명, 공간 1개
- **배포(빌드)는 하루 5번, 체험 기간 전체 30번** → "배포해줘"는 미리보기로 충분히 고친 뒤에
- 체험이 끝나면 서비스 중단 → 7일 보관 → 삭제. 유료로 바꿔도 체험 데이터는 옮겨지지 않음
- 계속 쓰려면 1단계 월 4,900원부터 (2단계 8,900 / 3단계 14,900 / 4단계 29,900)

## 03. 실습 02 — Claude에 AI SPACE 연결 (10분)

Claude 웹(claude.ai) 기준, 처음 한 번만:
1. 왼쪽 아래 **계정 아이콘 → 설정 → 커넥터**
2. **커스텀 커넥터 추가** → 주소 입력: `https://aih-proxy.cafe24.com/mcp`
3. **연결** → 카페24 계정으로 로그인 (비밀번호는 Claude에 전달되지 않음, API 키 필요 없음)
4. 새 채팅 **"+" → 커넥터 → Cafe24 AI SPACE 켜기**
5. 연결 확인:
```
AI SPACE 연결 확인하고 내 프로젝트 보여줘
```

- Claude 데스크톱 앱: 입력창 "+" → Connectors → Manage Connectors → Add custom connector (같은 주소)
- 공용 PC라면 수업 후 카페24·Claude 로그아웃

## 04. 오늘 만들 것 — 업무 고르기와 입력·처리·출력 (8분)

업무 도우미로 만들기 좋은 일: 자주 반복된다 / 들어오는 정보 모양이 비슷하다 / 처리 기준을 말로 설명할 수 있다 / 결과 모양이 정해져 있다

오늘 함께 만들 것: **평가 피드백 도우미** — DAY 01 문자 실습(시험 결과 피드백)을 "매번 AI에게 부탁하는 일"에서 **"내 학원 전용 도구"** 로 바꾸기

| 입력 (넣는 정보) | 처리 (정리 기준) | 출력 (받을 결과) |
|---|---|---|
| 학생 표시(학생 A) · 학년 · 이번 점수 · 지난 점수 · 틀린 문항 · 취약 단원 · 선생님 메모 | 점수 변화 계산 / 점수 구간별 상태 문장 / 취약 단원으로 복습 안내 / 메모 반영 | 한 줄 상태 요약 · 다음 2주 복습 계획 · 학부모 문자 초안(5줄 이내) · 복사 버튼 |

## 05. 실습 03 — Claude로 도우미 만들기 (15분) ★

```
수학학원에서 쓸 "평가 피드백 도우미" 웹페이지를 HTML 파일 하나로 만들어주세요.

[입력 칸] 학생 표시(예: 학생 A) / 학년 / 이번 점수 / 지난 점수 / 틀린 문항 / 취약 단원 / 선생님 메모
[처리 기준]
- 점수 변화(이번 - 지난)를 계산해 올랐는지, 내렸는지, 같은지 표시
- 점수 구간별 상태 문장: 90점 이상 / 70~89점 / 69점 이하 세 가지로 미리 써 두기
- 취약 단원을 넣으면 "다음 2주 복습 계획" 3줄을 정해진 문장 틀로 만들기
[출력] 한 줄 상태 요약 / 다음 2주 복습 계획 / 학부모 문자 초안(5줄 이내, 전문 용어 없이) / 문자 복사 버튼
[조건]
- AI 없이 페이지 안에서만 계산해 주세요 (같은 입력이면 늘 같은 결과)
- 휴대폰에서도 보기 좋게, 청록색 계열의 깔끔한 디자인
- 아직 배포하지 말고 미리보기로 먼저 보여주세요
```

- 채팅 오른쪽 미리보기에서 바로 써 본다
- 핵심 메시지: **AI는 만들 때만 쓴다.** 완성된 도우미는 혼자 돈다 → 학생 정보가 AI로 넘어가지 않고, 사용료도 없다

# 2교시 (50분) — 테스트하고, 올리고, 모아 보기

## 06. 실습 04 — 샘플 A·B·C로 테스트하고 고치기 (12분)

| | 학년 | 이번/지난 | 틀린 문항 | 취약 단원 | 메모 |
|---|---|---|---|---|---|
| 학생 A | 중2 | 78 / 65 | 6, 8, 13, 15번 | 사각형의 성질 | 복합 조건 문제에서 시간이 오래 걸림 |
| 학생 B | 중2 | 91 / 94 | 9, 17번 | 삼각형의 성질 | 고난도 문제에서 계산 실수 |
| 학생 C | 중2 | 63 / 63 | 2, 3, 7, 9, 10, 16번 | 삼각형의 성질 | 기본 유형에서도 오답 반복 |

확인: 입력이 그대로 반영되는가 / 점수가 내린 B에게도 부드러운 문장인가 / 변화 없는 C를 어떻게 표현하는가 / 휴대폰 크기에서 보기 좋은가

고치기 요청 예:
- "점수가 내린 학생의 문자는 '격려 → 원인 → 계획' 순서로 바꿔줘"
- "변화가 0점이면 '유지'라고 써 줘"
- "입력 칸이 비어 있으면 결과를 만들지 말고 어떤 칸이 비었는지 알려줘"
- "문자 끝에 학원 이름과 상담 전화 자리를 넣어줘"

원칙: 결과 문장을 손으로 고치지 말고 **도구(규칙)를 고친다** → 다음 학생부터 좋아진다

## 07. 실습 05 — "AI SPACE에 배포해줘" (12분) ★

```
방금 만든 평가 피드백 도우미를 AI SPACE에 배포해줘.
프로젝트 이름은 feedback-helper로 해주고, 배포가 끝나면 접속 주소를 알려줘.
```

- 배포 진행: 코드 분석 → 환경 구성 → 앱 시작 (1~2분)
- 받은 주소를 **휴대폰으로** 열어 보기 → 샘플 A로 한 번 더 써 보기
- 고친 뒤 다시 올리기: "문자 마지막 줄을 '궁금하신 점은 편하게 연락 주세요'로 바꿔서 다시 배포해줘"
- 상태 확인: "내 앱 상태 어때?"
- 빌드는 하루 5번 — 여러 번 고칠 땐 미리보기로 다 고친 뒤 한 번에 배포

## 08. 강사 시연 — 대시보드: 반 전체 피드백 현황판 (12분)

대시보드 = 여러 결과를 **한 화면에 모아 보는 요약판**. 도우미가 한 명씩 처리한다면, 현황판은 반 전체를 본다.

시연 요청문:
```
반 전체 피드백 현황판을 만들어서 AI SPACE에 배포해줘.
- 학생 표시 / 학년 / 점수 / 지난 점수 / 취약 단원 / 피드백 상태(완료·확인 필요·미처리)를 입력하고 저장
- 저장은 MySQL을 연결해서 해줘
- 목록 표, 반 평균, 가장 많이 나온 취약 단원 TOP 3, 상태별 학생 수를 위쪽 카드로
- 학생 이름 대신 '학생 A'처럼 쓰도록 입력 칸 안내 문구를 넣어줘
- 프로젝트 이름은 class-dashboard
```

- 샘플 A·B·C를 넣고 → 평균·TOP 3가 바뀌는 장면
- 보여 줄 대화: "MySQL 연결해줘" / "백업해줘" / "에러 났어. 로그 보고 고쳐서 다시 배포해줘"
- 수강생은 따라 하지 않아도 됨 (체험 공간 1개 + 빌드 횟수 제한). 집에서 체험 기간 안에 해 볼 수 있다고 안내

## 09. 꼭 지킬 것 — 학생 정보와 공개 범위 (5분)

- 배포된 주소는 **주소를 아는 누구나 열 수 있다**
- 연습·체험 단계에서는 **실명·연락처·학교 입력 금지**, 학생 A·B·C만
- 실제 학원에서 쓰려면: 접근 제한("○○를 내부 사용자용으로 만들어줘. 특정 IP만 접근 가능하게"), 로그인 기능, 유료 전환 + 백업
- 무료 체험 종료 → 7일 뒤 데이터 삭제. 계속 쓸 데이터는 백업

## 10. 실습 06 — 나만의 업무 도구 설계서 (7분)

```
1. 도구 이름: [예: 상담 전 학생 요약 도우미]
2. 처리할 업무: [예: 학부모 상담 전에 학생의 최근 기록을 한 장으로 요약]
3. 입력: [예: 학년 / 최근 시험 2회 점수 / 오답 단원 / 출결 메모 / 선생님 메모]
4. 처리 기준: [예: 점수 변화 계산 / 반복 오답 단원 정리 / 상담 때 짚을 점 3개]
5. 출력: [예: 최근 변화 / 반복되는 약점 / 상담 때 짚을 점 / 학부모께 드릴 한 줄]
6. 저장이 필요한가: [예: 필요 없음 / 필요함 → DB 연결]
7. 주의: [예: 학생 이름 대신 학생 A / 실제 정보는 접근 제한 후에]
```

아이디어: 상담 전 요약 / 레벨 테스트 결과지 / 숙제 체크 / 보강 일정 안내 / 수업 일지

이 설계서를 그대로 Claude에 붙이고 "이 설계대로 만들어서 미리보기로 보여줘" → 마음에 들면 "배포해줘"
